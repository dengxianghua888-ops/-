# 文风 DNA

## 一句话风格定性

现代网暴反转爽文：第一人称冷静叙述，证据链驱动，短句和直播弹幕制造围观压力，以公开场合的逻辑反杀兑现爽点。

## 加载 genre 默认值

- genre: `modern_reversal`
- 默认基线: 平均句长 15-20 字，短句 70%+，对话占 35-45%，第一人称主导，偏好现代证据物件与公开场域。
- 本文差异: 直播审判段对话占比更高；结尾加入语言、外婆、大学校园等温情余味，降低纯复仇戾气。

## 定量特征

### 句式

- 平均句长: 约 18-24 字，直播对话段约 12-18 字，抒情收束段约 25-35 字。
- 长短句比例: 短句 68% : 中长句 32%
- 偏好句式模板:
  1. “我看着 X，笑了。”
  2. “你不是说 X 吗，Y？”
  3. “不是 A，是 B。”
  4. “他说 X。可事实是 Y。”
  5. “我没有 X，只是 Y。”
- 忌用句式: 大段抒情议论、复杂倒装、玄学宿命式总结、连续排比说教。

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 反讽 | 高 | “寒门学子这四个字，现在看起像是个笑话。” | 直接击穿人设，制造爽感 |
| 对比 | 高 | “我英语确实很差……但我考的是俄语。” | 让弱点变成无关项 |
| 具象定格 | 中 | “得意还没来得及收回去，就僵在了那里。” | 反派崩塌可视化 |
| 弹幕合唱 | 高 | “等等？她报的是俄语？？？” | 放大围观场域，替读者反馈 |
| 温情意象 | 中 | “窗外月亮很亮，像莫斯科冬天的雪。” | 结尾提供情感补偿 |

### 对话

- 对话占比: 约 42%，直播段可达 55%-65%。
- 对话风格: 犀利、短促、审问式。
- 对话功能: 推动证据链、制造公开审判、完成道德反转。
- 高效对话特征: 很少寒暄，每句都推动“谁在撒谎”“谁有证据”“谁该负责”。

### 叙述

- 人称视角: 第一人称
- 叙述温度: 前中段冷峻，后段温暖
- 距离感: 贴近主角心理，但不滥用内心独白
- 时态: 过去式为主，直播/弹幕带即时感
- 叙述策略: 主角知道关键真相，但延迟向读者和场内人物完全展示。

### 用词

- 色温倾向: 前半冷，中后段转暖
- 书面/口语比: 4:6
- 现代社会物件: 热搜、直播、U盘、监控、录屏、官网、通告、处分通知、公章。
- AI 高频词检测: 原文出现“深吸一口气”“嘴角微微上翘”“眼中闪过”等少量 AI 味表达；改编应替换为更具体的身体反应。

### 标点

| 标点 | 使用频率 | 功能 |
|------|---------|------|
| 逗号 | 高 | 快速推进动作与信息 |
| 冒号 | 中 | 引出证据、通知、弹幕 |
| 引号 | 高 | 直播对话和弹幕构成主叙事 |
| 破折号 | 低中 | 标出关键物件或解释 |
| 问号 | 中高 | 逼问反派，强化审判感 |
| 感叹号 | 低 | 保持冷静，不靠吼叫制造情绪 |

| 金句类型 | 频次(次/千字) | 代表原文 | 结构模板 |

| 对仗反讽式 | 1.1 | “一个连信息都不确认的人……却口口声声为了所有考生的公平。” | “【正义名义】；【反向事实】。” |

## 代表性原句（Top 5）

1. “因为我高考报的外语，根本就不是英语，而是俄语。” — 核心反转一句话完成。
2. “我的时间很宝贵，不想听你废话。” — 主角冷静强势，不自证讨好。
3. “一个连信息都不确认的人，一个拿出的证据全是断章取义的人，却口口声声为了所有考生的公平。” — M3 道德回旋。
4. “你到底是急，还是早有预谋？” — 从误会推入阴谋。
5. “我为什么要为了别人的期待，去学一门我不需要的东西？” — 主题升维。

## 反面教材（绝对不能出现的表达）

- 宿命感大词: “命运的齿轮”“人心幽暗如深渊”
- 抒情式自怜: “我委屈得快要碎掉”
- 反派脸谱化吼叫: “你这个贱人我要杀了你”
- 无证据爽点: “网友突然都相信了我”
- AI 味违禁词: “然而”、“总而言之”、“宛如命运的齿轮”、“眼中闪过一丝复杂/暗芒”、“深吸一口气”、“不禁”、“心中涌起”
