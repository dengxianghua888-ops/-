# 爆款神髓合约模板 (V4)

## 1. 读者承诺

- **一句话承诺**: 读者将看到一个被丈夫、小三和制度身份剥夺到绝境的母亲，带着女儿假死脱身，让负心人和白莲小三失去一切。
- **读者愿意追读的理由**: 前半压迫足够具体且不公：假结婚证、女儿黑户、替小三顶罪、母女分离，每一刀都必须等到后文清算。
- **最终必须兑现的体验**: 母女不回头，渣男迟来悔恨无效，小三被制度惩罚，孩子确认自己仍被很多人爱。

|---------|-----------|---------|-------------|

## 3. 爽点因果链

```text
施害者种因: 宋知安借孟然资源上位，却出轨白薇薇、伪造婚姻秩序、牺牲妻女保小三。
主角表面承受: 孟然忍受出轨羞辱，护住女儿，被逼顶罪，被拖走，制造“死亡”假象。
规则反身应用: 宋知安相信白薇薇的柔弱，最终被她的罪证、假孕和利用反噬；他曾把孟然当可牺牲品，最后自己被单位和家庭抛弃。
崩塌/清算: 外祖家揭开身份资源，厂长追责，白薇薇进军事法庭，宋知安降职、残疾、失去家属房。
余味/补偿: 孟然拿回属于自己的东西，年年确认自己有很多人爱，不需要父亲。
```

## 4. 道德坐标

- **读者站队对象**: 孟然和年年，尤其是被父亲牺牲的母女。
- **反派必须被惩罚的理由**: 宋知安违反婚姻忠诚、亲子保护和基本公平；白薇薇违反救命恩、女性互助、儿童安全和国家机密规则。
- **主角可被允许的狠度边界**: 孟然可以假死、设局、借外祖权力清算；不能主动伤害无辜，不能为了复仇牺牲年年。

## 5. 主角姿态

- **核心姿态**: 前期隐忍护女，触底后清醒退场。
- **语言姿态**: 克制短句，少控诉，关键处一句封死关系。
- **行动姿态**: 先忍后走，借假死切断旧关系，再让证据和权力自然清算。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 孩子第一视角 | 天真误读是全文刺痛源 | 每个核心伤害 Beat 必须有年年看见/听见/误解 |
| 父亲要求母亲替小三顶罪并转走孩子 | 这是情绪债峰值 | Beat 中必须同时出现“顶罪”和“夺女” |
| 母亲假死退场 | 这是中后段最大反转 | 必须先让读者相信死讯，再揭示主动设局 |
| 外祖家身份反差 | 清算力量来源 | 必须有“原以为无依无靠，实则有资源”的揭露 |
| 父亲悔恨无效 | 价值观落点是不回头 | 结尾不得复合，不得让孩子重新接纳父亲 |
| 年年结尾被爱补偿 | 爽点最终落在孩子安全感 | 结尾必须有“缺父爱但不缺爱”的表达 |

## 8. 失败预警

- **最容易丢的神髓**: 把故事写成普通小三上位复仇，忽略女儿黑户与转养这类制度性剥夺。
- **一旦丢失会导致**: 爽点变浅，父亲惩罚显得过重，母亲假死不再有正当性。
- **写作时补救方式**: 在中段追加一笔“孩子未来被毁”的具体后果，并让父亲亲口合理化牺牲母女。
