# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 读者会看到一个前世被豪门和妻子联手毁掉的人，今生清醒避坑、保护母亲、积累资源，最终用更高阶联姻和自身价值摆脱所有操控。
- **读者愿意追读的理由**: 前半的陆家冷待、苏瑶接近、母亲受苦都明确欠债；读者知道主角带着前世记忆，期待他一步步把“命运剧本”改写。
- **最终必须兑现的体验**: 主角必须离开陆家牢笼，母亲必须安稳，苏瑶和陆家必须失去控制主角的资格，沈若曦线必须给出尊重与新生感。

## 2. 情绪债

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|
| 苏瑶前世亲手推季然坠崖 | Beat 1 | 恨、震惊 | 今生拒绝她，让她嫁错对象并失去高价值目标 |
| 陆家把季然当摆设和棋子 | Beat 1-4 | 憋屈、愤怒 | 主角借沈家联姻脱离陆家，反让陆家攀附无门 |
| 母亲前世被抛下受苦 | Beat 2-3 | 心疼 | 今生第一时间安顿母亲，后续接进山庄 |
| 陆家轻视主角“不务正业” | Beat 4-7 | 压抑、期待 | 主角用药材、射箭、山庄和沈家资源证明价值 |
| 亲生父母仍把他当多余的人 | Beat 8 | 刺痛、愤怒 | 主角彻底断掉血缘幻想，不再为陆家服务 |
| 苏家和陆家把婚姻当利益交易 | Beat 9-10 | 厌恶、期待反转 | 沈家以更高权力提亲，改写婚姻交易方向 |

## 3. 爽点因果链

```text
施害者种因: 陆家把季然当工具，苏瑶把他当跳板，前世甚至害死他。
主角表面承受: 他今生仍进入陆家，保持木讷顺从，避免过早暴露。
规则反身应用: 陆家用联姻和身份控制他，他反过来借沈家联姻脱离陆家。
崩塌/清算: 陆家由轻视转为讨好，苏家悔青肠子，陆航接盘苏瑶。
余味/补偿: 母亲被安顿，事业成立，沈若曦从交易对象变成尊重他的伴侣。
```

## 4. 道德坐标

- **读者站队对象**: 季然与季母，尤其是被血缘豪门伤害却仍想过普通安稳生活的主角。
- **反派必须被惩罚的理由**: 他们不是单纯“不喜欢季然”，而是把亲情、婚姻和身份都工具化，甚至前世造成死亡。
- **主角可被允许的狠度边界**: 可以设局、拒绝、断亲、借势反击；不能主动滥杀、不能伤害无辜、不能为了复仇牺牲母亲。

## 5. 主角姿态

- **核心姿态**: 清醒、克制、先忍后脱身。
- **语言姿态**: 短句砸脸，少解释，多拒绝。
- **行动姿态**: 优先保护母亲，暗中积累资本，等待机会切断陆家控制。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 开篇“死过一次”的死亡级 Hook | 这是全文追读发动机 | 首 100 字内必须出现前世死亡或同级极端冲突 |
| 前世妻子/亲密对象致死 | 恨点必须足够强，才能支撑今生避坑 | Beat 1 必须有亲密背叛导致死亡 |
| 母亲必须是第一保护对象 | 她是主角人性和行动动机 | 前 25% 必须完成一次对母亲的实质安顿 |
| 死亡地反转为资源地 | 这是“命运反写”的核心爽点 | 前世伤害地点必须在今生变成资本来源 |
| 沈若曦必须理性强势 | 她不是恋爱脑，而是高权力盟友 | 出手前必须有利益逻辑或能力展示 |
| 陆家态度大反转 | 打脸爽点依赖轻视到讨好的转向 | 后 70% 必须出现陆家谄媚或攀附失败 |
| 结尾必须新生而非单纯复仇 | 主题是摆脱错误关系 | 结尾必须落到自由、事业、母亲或尊重关系 |

## 8. 失败预警

- **最容易丢的神髓**: 把主角写成靠金手指一路炫耀，而不是靠死亡记忆和冷静选择一步步脱身。
- **一旦丢失会导致**: 情绪债没有根，读者只看到开挂，不会心疼，也不会觉得清算成立。
- **写作时补救方式**: 每个爽点前先补一笔压迫或误判；每次主角胜利都要对应前文一项债务。
