# 解构报告

## 全文概述（200 字以内）

女主连续三次高考 0 分，死后重生回第一次高考前。她起初以为是奶奶托梦害人，试图不睡、验证试卷、求助闺蜜，却发现真正异常不是答案错，而是“高考全科 0 分本身不可能”。闺蜜识破梦中试卷其实是省三诊旧卷，进而牵出致幻药、催眠、草稿纸误认答题卡、三婶与二叔二婶为“献祭成绩”合谋害她三年的真相。结尾恶人进警局，女主带着父母和闺蜜的支持重新走入考场。

## 核心发现 Top 5

1. 核心钩子不是“托梦”，而是“全科 0 分不符合常识”，用理性漏洞撕开玄学骗局。
2. 反转递进清晰：奶奶托梦是假因，答题卡异常是真因，催眠致幻是手段，亲族献祭是伦理黑洞。
3. 家庭伦理爽点建立在“最信任的三婶背刺”上，读者的恨点来自亲情伪装而非单纯坏人。
4. 阿昭承担关键侦探功能，她不是陪衬，而是把读者从玄学带回逻辑推理的人。
5. 结尾没有过度惩罚，由警局和法院接管，保留现实爽文的正当性。

## 仿写难点预警 Top 3

1. 必须设计一个“看似玄学、实则现实作恶”的核心诡计，否则故事会塌成普通重生文。
2. 0 分谜题要有可验证逻辑链：为什么不是答案错、不是缺考，而是答题卡被误认。
3. 亲族背叛要有温度落差：三婶前期必须像真的疼女主，后期清算才痛又爽。
