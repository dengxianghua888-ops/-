# 读者心理引擎模板 (V4)

> Phase 1 必填。逐 Beat 记录读者心理状态,供 blueprint 和 writer 控制追读欲。

## 总览

- **核心读者期待**: 想知道女主为什么无论怎么考都是 0 分，以及她能否夺回高考。
- **主要恨点**: 亲族用伪善和迷信毁掉她三年人生。
- **主要爽点**: 常识破局、验血实锤、当面对质、恶人进警局、重新入考场。
- **追读驱动力**: 想看真相 + 想看打脸 + 想看亲族报应。
