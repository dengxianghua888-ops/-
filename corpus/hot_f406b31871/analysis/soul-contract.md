# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 让一个被亲族用伪玄学毁掉三年人生的女孩，亲手揭穿骗局、夺回高考和未来。
- **读者愿意追读的理由**: “连续三次高考 0 分”极端违和，读者必须知道这件不可能的事如何发生。
- **最终必须兑现的体验**: 真相必须现实闭环，恶人必须被法律清算，女主必须重新走进考场。

## 2. 情绪债

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|
| 女主三次高考 0 分，被毁三年 | Beat 1 | 憋屈、心疼 | 查清 0 分机制，让她重新考试 |
| 奶奶形象被利用成托梦幻象 | Beat 1-3 | 恐惧、愤怒 | 证明奶奶无辜，恶人亵渎亲情 |
| 三婶长期下药催眠 | Beat 3, 8-9 | 恨、恶心 | 当面对质，送警局 |
| 二叔二婶为儿子献祭女主成绩 | Beat 10-11 | 震怒 | 被传唤清算 |
| 爸妈两世为女儿痛苦 | Beat 1, 6, 12 | 心疼 | 让他们见证女儿重新掌控人生 |

## 3. 爽点因果链

```text
施害者种因: 二叔二婶迷信大师，为儿子上大学策划献祭瑶瑶三年高考成绩，三婶因欠债收钱配合。
主角表面承受: 瑶瑶连续三次高考 0 分，以为是奶奶托梦和自己命运异常。
规则反身应用: 阿昭指出“想考 0 分和考省状元一样难”，女主从 0 分结果反推施害证据。
崩塌/清算: 医院验出致幻药和催眠，三婶供出全套骗局，二叔二婶被传唤。
余味/补偿: 女主清醒走入考场，不靠托梦，不靠捷径，只靠自己。
```

## 4. 道德坐标

- **读者站队对象**: 瑶瑶、真心爱她的父母、清醒帮她的阿昭。
- **反派必须被惩罚的理由**: 他们不是普通嫉妒，而是以迷信和金钱交易毁掉未成年/年轻学生的人生机会，并长期投药催眠。
- **主角可被允许的狠度边界**: 可以报警、验血、公开对质、拒绝原谅；不能私刑伤害无辜者，不能把不知情三叔一并打成恶人。

## 5. 主角姿态

- **核心姿态**: 从惊恐求生转为冷静追凶。
- **语言姿态**: 前期急促自问，后期短句质问、冷笑打脸。
- **行动姿态**: 先验证，再求助，再验血取证，最后交给法律。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| “连续多次 0 分”这一极端数字谜题 | 全文追读发动机 | 开篇 300 字内必须出现极端数字异常 |
| 0 分必须有现实作案闭环 | 伪玄学转现实反杀的爽点 | 结尾能解释为什么客观上必然 0 分 |
| 近亲伪善投喂/安排 | 家庭伦理恨点来源 | 施害者必须能自然接近主角生活 |
| 清醒朋友指出常识漏洞 | 读者心理从恐惧转推理的关键 | 中段必须有外部理性角色点破 |
| 女主最终重新考试 | 情绪补偿终点 | 结尾必须回到被夺走的人生机会 |

## 7. 可替换项

| 可替换维度 | 原文 | 改编允许范围 |
|-----------|------|-------------|
| 考试类型 | 高考 | 考研、艺考、竞赛、执业资格、保送面试 |
| 投药载体 | 安神茶 | 牛奶、营养剂、药膳、助眠香薰 |
| 伪玄学载体 | 奶奶托梦 | 遗物显灵、神婆预言、录音幻听、祖传符 |
| 近身施害者 | 三婶 | 舅妈、继母、姑姑、监护人、班主任亲戚 |
| 幕后动机 | 献祭成绩给堂弟 | 交换名额、保送资格、遗产继承、竞赛排名 |

## 8. 失败预警

- **最容易丢的神髓**: 把故事写成真玄学，或只写亲戚坏而不给出 0 分逻辑闭环。
- **一旦丢失会导致**: 读者觉得前文悬念被糊弄，爽点无根。
- **写作时补救方式**: 用一个可验证的现实载体解释异常结果，并让中段角色提前指出“这件事按常识不可能”。
