# 爆款神髓合约模板 (V4)

## 1. 读者承诺

- **一句话承诺**: 让一个被丈夫、亲哥、绿茶联手逼疯的母亲，带着女儿和孩子们的血债夺回叙事权，让所有施害者付出法律、情感与人生代价。
- **读者愿意追读的理由**: 前半压迫极重但证据不断出现，读者知道她不是疯，而是被权势和亲密关系共同围剿，因此期待她逃离并证明真相。
- **最终必须兑现的体验**: 真相公开、凶手入罪、旧爱悔疯、哥哥失去荣耀、女主不原谅并拥有新生活。

## 2. 情绪债

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|
| 孩子被取走、月月被实验 | Beat 1,4,5 | 心疼、愤怒 | DNA/照片/实验室证据公开，凶手入罪 |
| 容观洲用“你疯了”控制她 | Beat 1,4,6 | 憋屈、窒息 | 法庭直播证明她清醒，反派口供坐实真相 |
| 孟庭作为哥哥背叛她 | Beat 3,6,7 | 双重心寒 | 失去律师资格，被女主拒见 |
| 林婉清撕画、虐打、撞车 | Beat 3,6,7 | 恨 | 被关、互咬、入罪，失去靠山 |
| 月月尸骨无存 | Beat 5 | 极痛 | 墓园抓捕、来世祝福、女主幸福补偿 |
| 女主被精神病院虐待 | Beat 1,7 | 恐惧、压抑 | 火烧精神病院，彻底离开旧牢笼 |

## 3. 爽点因果链

```text
施害者种因: 容观洲和孟庭为了林婉清及晨晨牺牲月月和女主的孩子，并用精神病标签封口。
主角表面承受: 女主被关、被电击、被污名、被公开否定，仍保留照片与离开计划。
规则反身应用: 他们用权势压她，女主借法律、直播、证据、林婉清求生欲反向锁死他们。
崩塌/清算: 容观洲被抓入狱并失去女主；林婉清供出同谋；孟庭职业坍塌。
余味/补偿: 女主拒绝原谅，和西蒙进入尊重型关系，梦见月月祝福她幸福。
```

## 4. 道德坐标

- **读者站队对象**: 孟昭妍、月月、所有被实验的孩子。
- **反派必须被惩罚的理由**: 他们侵犯母亲对子女的保护权、剥夺正常人的叙事权、以亲密关系为名实施系统性虐待。
- **主角可被允许的狠度边界**: 可以设局、诱导供述、报警、烧毁无人精神病院；不能滥杀无辜，不能用同样方式虐杀孩子或无关者。

## 5. 主角姿态

- **核心姿态**: 前期破碎隐忍，后期冷静设局，终局不原谅。
- **语言姿态**: 从哀求质问转为短句拒绝，如“我不想要你了”“不见”。
- **行动姿态**: 先承受并保留证据，再假死脱身，最后主动回笼反杀。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 孩子/月月必须是情绪债核心 | 没有子女血债，女主不原谅的强度不足 | 至少 3 个 Beat 围绕孩子具体受害 |
| “她疯了”的污名化机制 | 这是剥夺叙事权的主压迫 | 必须出现精神病证明/机构/公开作证 |
| 容观洲和孟庭曾经真宠她 | M5 温度反转需要正峰 | 前 30% 必须有旧日温柔闪回 |
| 女主最终不原谅 | 爽点承诺是脱钩，不是破镜重圆 | 结尾不得复合，不得替容观洲洗白 |
| 法律清算 | 主题是夺回叙事权和秩序 | 必须有证据、警方/法庭、公开真相 |
| 新男主尊重边界 | 补偿关系不能复制控制关系 | 西蒙不能强迫、绑架、替她决定 |

## 7. 可替换项

| 可替换维度 | 原文 | 改编允许范围 |
|-----------|------|-------------|
| 实验室 | 医疗实验室救晨晨 | 可换基因治疗、器官移植、药物试验、非法疗法 |
| 精神病院 | 电击、鞭打、封口 | 可换戒治中心、疗养院、私立医院 |
| 证据载体 | 照片、DNA、口供 | 可换监控、病历、录音、样本报告 |
| 海外新生 | 澳洲、西蒙 | 可换新城市、新国家、新职业圈，但必须有外部秩序 |
| 旧爱身份 | 掌权人、律师哥哥 | 可换豪门继承人、法官、医生、媒体人，但权势压迫要成立 |

## 8. 失败预警

- **最容易丢的神髓**: 把西蒙写成单纯甜宠，把复仇主线稀释。
- **一旦丢失会导致**: 读者觉得前半虐点没有被等价偿还。
- **写作时补救方式**: 每个甜宠段都要回扣“尊重/相信/协助清算”，而不是只发糖。
