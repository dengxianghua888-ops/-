# 爆款神髓合约模板 (V4)

## 1. 读者承诺

- **一句话承诺**: 看一个清醒女主拒绝攻略男人，转而以神女身份降维改造乱世，让饥民、女子、寒门、工匠、医者都站起来。
- **读者愿意追读的理由**: 前期饥荒、愚昧、贪官、山匪、礼教、瘟疫等压迫越深，后续神迹与制度打脸越爽。
- **最终必须兑现的体验**: 读者必须看到旧秩序被否定，新秩序由神女与凡人共同建立，且女主不被爱情线拖累。

|---------|-----------|---------|-------------|

## 3. 爽点因果链

```text
施害者种因: 乱世权力者、贪官、妖道、国师、礼教、皇权把百姓当草芥。
主角表面承受: 云姝维持神女人设，不能直接暴露现代身份，也不能无脑乱杀。
规则反身应用: 她利用“神权大于皇权”的古代认知，反向瓦解皇权、礼教与阶级压迫。
崩塌/清算: 贪官被审判，妖道被揭穿，国师被公开处刑，雍朝龙脉被斩。
余味/补偿: 饥者有粮，寒者有衣，女子有工，医者有典，百姓开始相信自己也能改变世界。
```

## 4. 道德坐标

- **读者站队对象**: 云姝、底层百姓、被压迫女性、寒门读书人、医者工匠。
- **反派必须被惩罚的理由**: 他们不是单纯“坏”，而是用权力、礼教、神棍话术夺走弱者活路与尊严。
- **主角可被允许的狠度边界**: 可以杀山匪、贪官、作恶者；不能滥杀无辜，不能为了宏大目标牺牲普通人而不自省。

## 5. 主角姿态

- **核心姿态**: 冷静设局、神性表演、底层悲悯。
- **语言姿态**: 人前清冷短句，价值宣言有神谕感；人后与系统吐槽有现代网感。
- **行动姿态**: 先造神格，再授生产力，再启蒙思想，最后推翻旧秩序。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 拒绝攻略男主，选择救世 | 这是整篇的最大反套路承诺 | 前 3 章必须明确“男主不是目标” |
| 白粥作为第一个神迹 | 用最基础生存需求打开信仰入口 | 必须有“饥饿+食物神迹” |
| 假神女人设 | 读者爽点来自“我知道她在演，但她演成真神” | 必须有人前神性、人后吐槽双声部 |
| 技术/生产力神迹 | 爽点不是单纯法术，而是文明升级 | 至少有粮食、医疗、工业三类 |
| 女子觉醒线 | 原文重要增量爽点 | 必须有女性承接技术/反抗婚约/被认可 |
| 罗道清镜像反派 | 反衬云姝道德坐标 | 必须保留“现代知识作恶”的反派 |
| 神女不直接称帝 | 主题是教化众生，不是爽当女皇 | 必须让凡人参与治理与战争 |

## 8. 失败预警

- **最容易丢的神髓**: 把神迹写成单纯装逼，忘了每次神迹都要推动社会结构变化。
- **一旦丢失会导致**: 故事变成普通系统爽文，缺少“文明开荒+思想启蒙”的高级爽。
- **写作时补救方式**: 每次神迹后必须回答三个问题：救了谁？改变了什么生产/秩序？让哪类人站起来？
