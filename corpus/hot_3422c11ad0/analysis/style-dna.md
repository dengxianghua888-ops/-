# 文风 DNA

## 加载 genre 默认值

- genre: family_ethics
- 默认基线: 第一人称女主视角，家庭物件密集，平均句长 14-18 字，对话占比 40%+，情绪高压，反和解。
- 本文偏离点: 主角是死亡女童灵魂，虐心浓度高于普通家庭伦理，后半兼具 M4 灵魂旁观与法庭清算。

## 一句话风格定性

冷静童声叙述包裹极端虐待，短句高频推进，用家庭物件和儿童口吻制造强心疼，再用直播、监控、警察、庭审完成外部清算。

## 定量特征

### 句式

- 平均句长: 约 16-20 字
- 长短句比例: 7:3
- 偏好句式模板:
  1. “哥哥/妈妈 + 动作，我 + 受罚结果。”
  2. “我知道，……”
  3. “妈妈说，……”
  4. “直到……才……”
  5. “看啊，……”
- 忌用句式: 大段议论文总结、抽象抒情、复杂长复句、宏大命运式旁白。

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 反复 | 高 | “杀鸡儆猴”“那只鸡” | 固化虐待逻辑，形成主题锚 |
| 反问 | 中 | “那我呢，妈妈，你生我就是为了让我当那只鸡吗？” | 逼读者站队 |
| 反讽 | 高 | “妈妈居然说，她爱我？” | 拆穿迟来忏悔 |
| 物理化痛感 | 高 | “膝盖血肉模糊”“身体控制不住地发抖” | 让虐点可见 |
| 儿童口吻对照 | 高 | “妈妈，我会听话的。” | 加倍心疼与愤怒 |

### 对话

- 对话占比: 约 43%
- 对话风格: 直白、短促、带压迫感
- 对话功能: 推动情节、暴露母亲掌控欲、制造哥哥愧疚、完成庭审清算

### 叙述

- 人称视角: 第一人称
- 叙述温度: 表层冷静，底层高痛
- 距离感: 前半贴近受害身体，后半灵魂旁观
- 时态: 过去式与死亡后的现在旁观混用

### 用词

- 色温倾向: 冷
- 书面/口语比: 3:7
- AI 高频词检测: 原文有“深吸一口气”“缓缓”等少量常见词，但主体不是 AI 腔；禁用“然而”“总而言之”“宛如命运的齿轮”。

### 标点

| 标点 | 使用频率 | 功能 |
|------|---------|------|
| 句号 | 高 | 短句砸落，增强冷感 |
| 问号 | 中 | 形成伦理审判 |
| 感叹号 | 中 | 用于哥哥崩溃、母亲尖叫 |
| 引号 | 高 | 家庭冲突主要靠对话推进 |
| 省略号 | 低-中 | 用于死亡、迟疑和回忆断裂 |

## 代表性原句（Top 5）

1. “哥哥不听话，妹妹受罚，很合理啊。” — 体现核心荒诞规则。
2. “妈妈，我这只鸡当得还算合格吧？” — 童声自毁式心疼。
3. “妈，我已经死了，你连我的尸体都不放过吗？” — 灵魂视角反讽。
4. “谁都有资格恨我，就他们不行！！” — 母亲逻辑反噬。
5. “看啊，口口声声说爱我的人，连我的生日都不知道。” — 结尾否定和解。
