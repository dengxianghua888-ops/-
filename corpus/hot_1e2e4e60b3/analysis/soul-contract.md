# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 让一个被父亲抛弃、眼睁睁失去母亲的女儿，把迟来的深情和恶毒夺位者一起钉在真相上。
- **读者愿意追读的理由**: 前半的压迫有明确待偿债务：母亲被假债逼卖肾、救命钱变空卡、女儿耳朵被打坏、父亲还装深情。
- **最终必须兑现的体验**: 施害者必须知道真相、承认罪责、失去最重视的东西；女主必须不原谅，并获得继续活下去的出口。

## 2. 情绪债

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|
| 父亲装穷，把债留给妻子 | Beat 3 | 憋屈、恨 | 真相公开，公众深情人设破产 |
| 母亲卖肾卖血，仍等他回家吹蜡烛 | Beat 3 | 心疼 | 父亲亲眼面对遗像与死亡事实 |
| 父亲婚礼上骂母女疯子并赶出 | Beat 3 | 羞辱、愤怒 | 后期被许若薇反咬“你也有份” |
| 父亲打坏女儿耳朵 | Beat 4 | 心疼、恨 | 病房里被女主当面指出，补偿失效 |
| 五十万救命卡为空 | Beat 5/8 | 极恨 | 许若薇承认转走钱，父亲彻底崩塌 |
| 母亲因没钱手术死亡 | Beat 5/6 | 悲痛 | 遗产设立医疗救助基金，反向补偿同类母亲孩子 |
| 许若薇诬陷女主害她孩子 | Beat 5/10 | 恨、恐惧 | 许若薇失去儿子、持刀杀人后死刑 |
| 父亲迟来道歉 | Beat 7/11 | 厌恶、复杂 | 挡刀死亡，但女主不原谅 |

## 3. 爽点因果链

```text
施害者种因: 林景川假破产、偏袒许若薇、冻结/纵容转走救命钱，许若薇假绝症夺位并羞辱母女。
主角表面承受: 女主当服务员、戴助听器、独自祭奠母亲，被父亲继续误解和施舍。
规则反身应用: 父亲自称深情却被死亡事实击穿；许若薇用孩子压人，最终亲儿目睹丑恶并死亡；五十万救命钱最终被遗产基金反向修复。
崩塌/清算: 父亲查病历、听空卡真相、清算许家、挡刀死亡；许若薇破产、失子、杀人未遂变杀人，判死刑。
余味/补偿: 女主不原谅，但把钱变成医疗救助基金，完成对母亲遗愿的温柔继承。
```

## 4. 道德坐标

- **读者站队对象**: 女主、母亲、所有被亲人和钱困住的弱者。
- **反派必须被惩罚的理由**: 他们违反的不是普通婚姻忠诚，而是把救命钱、孩子、病人尊严当成争宠工具。
- **主角可被允许的狠度边界**: 女主可以拒绝、控诉、揭穿、接受遗产并清算；不能主动伤害无辜孩子，不能为了复仇变成滥杀者。

## 5. 主角姿态

- **核心姿态**: 克制复仇，伤到底后仍清醒。
- **语言姿态**: 短句砸脸、连续反问、事实判决。
- **行动姿态**: 先承受与陈述事实，再让施害者自己面对证据和因果。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 父亲不知道母亲已死 | 首章最大信息差和追读钩子 | Beat 1 末必须有“他不知道她已死”同级钩子 |
| 空卡/救命钱导致母亲死亡 | 全文情绪债核心物件 | 中后段必须有“本该救命的钱不存在”真相爆炸 |
| 女主不原谅父亲 | 防止伦理复仇变亲情和解 | 结尾不得出现理解、原谅、团圆 |
| 父亲迟来挡刀但无效 | M5 温度反转的负值谷底 | 挡刀后女主必须明确“太迟了” |
| 遗产转化为救助基金 | M3 回旋修复，升华主题 | 结尾必须把钱用于救别人，而非单纯暴富 |
| 许若薇自曝与法律清算 | 让恶意被亲口坐实 | 必须有反派亲口承认或证据闭环 |

## 8. 失败预警

- **最容易丢的神髓**: 把父亲写成“被许若薇骗了的无辜人”。
- **一旦丢失会导致**: 读者恨点转移不足，女主不原谅显得过狠。
- **写作时补救方式**: 增加父亲“明知有疑点但选择不查”的证据，如未接电话、拒看病历、默认情人欺辱母女。
