# 文风 DNA

## 一句话风格定性

第一人称冷叙述，短句密集，靠对话推进伦理冲突；情绪高点不靠大段哭诉，而靠“冷静拒绝 + 具体断亲/赶人/签字”等动作落地。

## 加载 genre 默认值

- genre: family_ethics
- 默认基线: 第一人称女主、家庭物件与亲缘称谓密集、对话占比 40%+、平均句长 14-18 字、强恨点与强清算。
- 本文差异: 商业家族/首富圈层元素更重，家庭伦理与豪门继承权结合。

## 定量特征

### 句式

- 平均句长: 约 16-22 字
- 长短句比例: 短句 72% / 中长句 28%
- 偏好句式模板:
  1. “我 + 动作/态度”: “我笑了。”“我不说话。”
  2. “对方台词 + 我冷回应”: “不近人情？”“如果一定要这么说，那，我承认。”
  3. “二十年前/二十年后”镜像句。
  4. “不是 A，是 B”: “不是你的孩子。”“准确的说，是我抛弃了他。”
  5. “如果……那就……”断亲规则句。
- 忌用句式: 长篇心理剖析、华丽比喻、连续排比说教。

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 镜像回环 | 高 | “二十年前，我和母亲签过一次。二十年后，我又和儿子签了一次。” | 形成代际宿命与反讽 |
| 冷反问 | 中高 | “我不选你，还要给你提交报告吗？” | 强化掌权姿态 |
| 对照 | 高 | “对不起妹妹的人，从来不是我。” | 将伦理责任重新归位 |
| 留白短句 | 高 | “我笑了。” “不行。” | 让读者补足情绪 |
| 物理化动作 | 中 | “眼眶一下子就红了。” “手颤抖起来。” | 高点具象化 |

### 对话

- 对话占比: 约 48%
- 对话风格: 短促、逼问式、冷淡回击
- 对话功能: 推动冲突、暴露偏心逻辑、完成打脸与清算

### 叙述

- 人称视角: 第一人称
- 叙述温度: 冷峻中带隐痛
- 距离感: 贴近女主感受，但不沉溺
- 时态: 过去式与当下叙述混用

### 用词

- 色温倾向: 冷
- 书面/口语比: 3:7
- AI 高频词检测: 原文出现“然而”“微微”等少量词，但整体以口语短句为主，AI 味不重。
- preferred_imagery_in_source: 婚纱、话筒、饭、床、宴会、茶、断亲协议、雨、病床、继承人、门。

### 标点

| 标点 | 使用频率 | 功能 |
|------|---------|------|
| 句号 | 高 | 制造短句顿挫 |
| 冒号 | 高 | 引出台词，增加现场感 |
| 问号 | 中高 | 逼问、反问、制造冲突 |
| 省略号 | 低中 | 表示哽咽或停顿 |
| 感叹号 | 中 | 用于反派失控，女主少用 |

## 代表性原句（Top 5）

1. “你妹妹比你更适合做首富夫人。” — 全文原罪，母亲偏心逻辑一句定型。
2. “我是祝氏唯一的掌门人，我的儿媳，我不选你，还要给你提交报告吗？” — 掌权后冷爽姿态。
3. “不想她难过，就可以让我难过吗？” — 亲情债核心拷问。
4. “毕竟，你的不幸，终究只是你自己的事情。” — 儿子背刺的最大痛点。
5. “我不仅不会放过她。我还会把当初她给我的，原封不动、甚至加倍的还给她。” — M3 回旋清算。

## 反面教材（绝对不能出现的表达）

- 大段哭诉式控诉：“我这些年多么不容易你们知道吗。”
- 过度文学化比喻：“命运的齿轮碾过我的灵魂。”
- 霸总油腻腔：“女人，你成功引起了我的注意。”
- 和解式鸡汤：“血浓于水，一切都会过去。”
- AI 味违禁词: “然而”、“总而言之”、“宛如命运的齿轮”、“眼中闪过一丝复杂/暗芒”、“深吸一口气”、“不禁”、“心中涌起”。
