# Beat Sheet 节拍器

## 全文概况

- 总字数: 约 12600 字
- 节拍数: 14 幕
- 核心母题（Logline）: 重生女主为了逃离渣男与黑月光的伤害，顺势打掉孩子并离婚，却在母亲被害死后彻底断情，让悔疯的男主永远失去补偿机会。
- 情绪模式: 违和钩子 → 背叛曝光 → 极致打压 → 尊严碾碎 → 至亲死亡触底 → 反派内斗清算 → 迟来悔恨 → 不可逆冷拒
