# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 读者将看到一个被爱人骗到尊严尽失的女人，如何冷静离开、让迟来的真相反噬所有伤害者，并把人生重新弹回自己的琴键上。
- **读者愿意追读的理由**: 前半持续压迫足够具体，夜场、嫁妆、镯子、失业、网暴都让读者替女主憋屈；读者相信后半必须让齐衍深痛、让陆晚月还。
- **最终必须兑现的体验**: 女主不回头，男主追悔但不可得，小三被同样方式反噬，女主拿回职业、家庭和自我。

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|

| 五十万协议打发六十万嫁妆与尊严 | Beat 4/6 | 憋屈 | 女主拒绝回头，并收下房产等欠债但不收感情 |
| 威胁女主工作、导致失业 | Beat 4/7 | 恨、替她急 | 女主后期进入音乐学院附中，职业尊严恢复 |

## 3. 爽点因果链

```text
施害者种因: 齐衍深因自卑和试探，装病骗女主钱财与牺牲；陆晚月利用假恩情、假孕和柔弱表演夺位。
主角表面承受: 女主卖嫁妆、夜场唱歌、失去工作、被偷拍视频羞辱，却一直克制不爆发。
规则反身应用: 陆晚月用网络羞辱女主，后期被同样挂网；齐衍深用“离婚/接受小三”逼女主，女主真正同意离开后他失控。
崩塌/清算: 假恩情、假孕、资金流水、日记、跪求预支依次揭开，齐衍深追悔，陆晚月被清算。
余味/补偿: 女主通过面试、回家、走出琴房，证明自己的人生不再以男主回应为中心。
```

## 4. 道德坐标

- **读者站队对象**: 沈念歌，尤其是她的职业尊严、家族传承和被试探的真心。
- **反派必须被惩罚的理由**: 齐衍深违反亲密关系的诚实与保护义务；陆晚月违反事实、公平和底线，利用假孕假恩情侵占他人劳动与尊严。
- **主角可被允许的狠度边界**: 可以断联、拒绝、收回应得财产、让真相曝光；不能主动诬陷、滥伤无辜或为了报复毁掉自己的职业人格。

## 5. 主角姿态

- **核心姿态**: 隐忍到触底后的冷静切割。
- **语言姿态**: 短句判词，不哭喊，不长篇控诉。
- **行动姿态**: 先承受并搜集心理证据，后主动离开；最终靠自我重建完成最高级反击。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 男主装病骗钱 | 这是情绪债源头，决定女主牺牲被玷污 | 前 10% 必须出现“假病/假危机”与女主为其筹钱 |
| 女主原本有体面专业 | 反差来自“钢琴教师沦落夜场”，职业尊严是主线 | 必须有专业能力、被迫降格、最终回归 |
| 祖传物件被送给小三 | 将爱情背叛升级为家族传承被羞辱 | 必须有不可替代物件被反派占有并损坏/玷污 |
| 男主递刀又递糖 | M5 温度曲线核心，没有它男主会扁平 | 至少 3 次“伤害后给温度”的场景 |
| 女主同意离婚后消失 | 爽点转折，男主失控的触发器 | 中段必须有短句切割和断联 |
| “不是小三毁了我们，是你自己选择” | 道德坐标，防止男主甩锅 | 后半必须有女主当面判责 |
| 结尾不复合 | 全文承诺是自我重建，不是破镜重圆 | 结尾必须落在女主自身，而非男主怀抱 |

## 8. 失败预警

- **最容易丢的神髓**: 把故事写成“男主被小三骗所以可怜”的追妻文。
- **一旦丢失会导致**: 读者对女主前半受苦的情绪债无法被偿还，结尾复合会变成背叛读者。
- **写作时补救方式**: 每次揭小三真相后，都必须追加男主自主选择的责任句；每次男主补偿后，都要让女主保留边界。
