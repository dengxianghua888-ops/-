# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 读者将看到一个被最爱之人误解至死的女孩，在死后等来迟到真相、极致火葬场和彻底抽离。
- **读者愿意追读的理由**: 前半所有虐待都在积累情绪债，读者相信后半会用真相、悔恨、报应和拒绝复合逐笔偿还。
- **最终必须兑现的体验**: 女主不原谅、不回头、不复合；男主付出不可逆代价，女主回到没有他的干净人生。

## 3. 爽点因果链

```text
施害者种因: 裴宴时误判沈黎“不知羞耻”，杨昭昭出于嫉妒设局夺位，并把沈黎推向战区凌虐。
主角表面承受: 沈黎断指、失声、流产、患癌，回国后继续被羞辱、抽血、逼酒、陷害。
规则反身应用: 杨昭昭用在沈黎身上的男人、舆论、清白污名，后期被裴宴时反向施加；裴宴时用消毒水、灵牌、冰棺自虐偿还。
崩塌/清算: 死亡、尸检、病历、调查报告逐层引爆，裴宴时精神崩塌，杨昭昭名誉和身体双重报应。
余味/补偿: 沈黎拒绝复合，裴宴时耗尽气运换她重生，她回到父母身边，世界里再无裴宴时。
```

## 4. 道德坐标

- **读者站队对象**: 沈黎、小白、未出生的孩子、被网暴和误判的弱者。
- **反派必须被惩罚的理由**: 杨昭昭违反友情、清白、生命底线；裴宴时违反养育责任、信任责任和基本救助义务。
- **主角可被允许的狠度边界**: 沈黎可以拒绝、冷眼旁观、不给原谅；不能主动虐杀无辜，也不能被写成享受复仇暴力的人。

## 5. 主角姿态

- **核心姿态**: 前期创伤性顺从，死亡后冷静抽离，终局彻底拒绝。
- **语言姿态**: 生前短句、否认、求饶；死后平静旁观；重逢时冷静审判。
- **行动姿态**: 不主动复仇，而是用死亡和真相迫使施害者面对因果。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 女主必须死亡或等价彻底离场 | M4/M5 的火葬场必须建立在不可逆失去上 | 是否有不可逆死亡/灵魂/离场节点 |
| 男主必须是共罪者 | 若洗白成纯受骗，读者恨点和拒绝复合都会变弱 | 是否明确他主动抛弃/误判/加害 |
| 女主不能原谅复合 | 核心爽点是抽离，不是团圆 | 结尾是否无复合、无拥抱和解 |
| 反派必须夺走女主原本拥有的宠爱信物 | 才能形成“被替代”痛点 | 是否有玉镯/资源/身份转移物 |
| 火葬场必须迟于死亡 | 迟来悔恨才成立 | 男主真相认知是否发生在女主死亡后 |
| 结尾必须给女主无男主的新生 | 偿还最大情绪债 | 是否女主进入干净人生，男主退出 |

## 8. 失败预警

- **最容易丢的神髓**: 把男主写得太可怜，削弱女主拒绝的正当性。
- **一旦丢失会导致**: 读者从“替女主解脱”转为“劝她原谅”，火葬场爽点崩塌。
- **写作时补救方式**: 每次男主忏悔后，都补一句女主冷静旁观的无用判定，如“可那又怎样，她已经死了。”
