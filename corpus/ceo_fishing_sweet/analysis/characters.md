# 角色标签图谱

## 角色清单

### 林向晚 — 清醒大女主/钓系美人
- 叙事功能: 第一女主角，故事核心驱动力
- 核心标签: 明艳冷淡、外冷内热、独立坚韧
- 弧光: 骄纵千金 → 受伤逃离 → 回国独立复仇 → 与爱人携手
- 台词风格: 冷淡中带刺，偶尔撒娇，情绪爆发时直白犀利
- 关键行为: 逃婚出国→回国夺权→对抗林家→与江时璟重新相爱
- 读者情绪关系: 心疼+代入+爽（看她一步步变强）

### 江时璟 — 疯批深情/钓系总裁
- 叙事功能: 第一男主角，情感核心与保护者
- 核心标签: 桃花眼妖孽、外风流内专一、偏执到骨
- 弧光: 温柔黏人少年 → 装作花心三年 → 不择手段追回 → 为爱赴死 → 失忆重来
- 台词风格: 痞气玩味、撩拨勾人、委屈撒娇（对女主）
- 关键行为: 三年守护机密→多次舍命相救→装失忆骗关心→最终团圆
- 读者情绪关系: 心动+心疼+上头

### 温浅 — 仗义闺蜜/母老虎
- 叙事功能: 女主最坚实的后盾，配角CP女主
- 核心标签: 爱喝酒、仗义、嘴硬心软
- 弧光: 富家大小姐 → 为闺蜜两肋插刀 → 与周宴相爱相杀
- 台词风格: 直来直去、骂人不带脏字、真诚热烈
- 关键行为: 始终站在林向晚身边，与周宴从冤家到恋人
- 读者情绪关系: 喜欢（提供轻松调剂）

### 周宴 — 傲娇表哥/话痨
- 叙事功能: 男主的后盾，配角CP男主
- 核心标签: 傲娇、话多、护弟心切
- 弧光: 反对林向晚 → 逐渐认可 → 成为帮手 → 与温浅在一起
- 台词风格: 吐槽多、大惊小怪、偶尔正经
- 关键行为: 从阻碍到助力的转变，配合江时璟各种计划
- 读者情绪关系: 搞笑担当+偶尔心疼

### 林西钧 — 阴险私生子/核心反派
- 叙事功能: 家族对手，制造核心商战冲突
- 核心标签: 阴狠、嫉妒、不甘心
- 弧光: 得意继承人 → 被赶出公司 → 疯狂报复 → 彻底失败
- 台词风格: 阴阳怪气、暗讽、急眼时粗鲁
- 关键行为: 夺取机密技术、车祸谋杀、与秦鸥勾结
- 读者情绪关系: 恨（越恨越爽）

### 秦鸥 — 偏执追求者/终极威胁
- 叙事功能: 后期核心反派，制造生死危机
- 核心标签: 表面正派、内心偏执、不择手段
- 弧光: 保镖伪装 → 追求被拒 → 疯狂报复 → 变植物人
- 台词风格: 前期稳重温柔，后期阴沉威胁
- 关键行为: 伪装保镖→暴露身份→逼江时璟跳海→被彻底解决
- 读者情绪关系: 恶心+恐惧

## 关系网络

```
林向晚 ←→ 江时璟（主CP：深情纠缠）
林向晚 ←→ 温浅（铁闺蜜）
江时璟 ←→ 周宴（表兄弟）
温浅 ←→ 周宴（配角CP：欢喜冤家）
林向晚 ←→ 林西钧（异母兄妹：死对头）
江时璟 ←→ 江柯（叔侄：爱中有控）
秦鸥 → 林向晚（单方面偏执追求）
```
