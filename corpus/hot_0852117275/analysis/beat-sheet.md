# Beat Sheet 节拍器

## 全文概况

- 总字数: 约 10300 字
- 节拍数: 12 幕
- 核心母题（Logline）: 女主为了带闺蜜回现代，面对伪装成闺蜜的恶灵欺骗与夺路，逐步识破真相并完成清算，最终救回真正的闺蜜。
- 情绪模式: 违和惊疑 → 自我安抚 → 二次疑云 → 友情回暖 → 致命顿悟 → 逻辑拆穿 → 反派反扑 → 极限阻拦 → 清算补偿
