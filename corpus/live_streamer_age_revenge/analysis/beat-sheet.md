# Beat Sheet 节拍器

## 全文概况

- 总字数: 约 14500 字
- 节拍数: 12 幕
- 核心母题（Logline）: 女老板夏棉被自己捧红的男主播和继妹羞辱后，撤走资源转捧更值得的人，最终让白眼狼主播、假千金继妹和其母亲全部失去靠山。
- 情绪模式: 极致羞辱 → 冷撤资源 → 舆论围攻 → 合同打脸 → 家庭产权揭底 → 事业清算 → 甜爽补偿
