# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 让一个被“为你好”打压到自疑的姑娘，被真正懂她的人珍爱，并亲眼看见错误的人失去资格、疯执落空。
- **读者愿意追读的理由**: 前半陆景的羞辱密集且具体，读者会等待杜若被高位偏爱、被公开承认，并等待陆景发现“她真的不等了”。
- **最终必须兑现的体验**: 杜若获得自由、爱情、孩子和被尊重的一生；沈煜活下来；陆景被困在自己的执念和妾室化处境里。

## 2. 情绪债

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|
| 陆景嫌杜若脸招摇、轻浮、心机 | Beat 1-2 | 憋屈、心疼 | 沈煜和长公主公开喜欢她这副模样 |
| 陆景当众说她不配做正妻 | Beat 2 | 羞辱、愤怒 | 她成为郡王妃，并亲口反问“郡王妃不当去当妾？” |
| 陆景禁止她大笑、骑马 | Beat 4-5 | 心疼 | 沈煜陪她骑马，让她重新笑出来 |
| 陆景以孤女身份羞辱她 | Beat 7 | 愤怒 | 姨母给足嫁妆，公主府给足身份接纳 |
| 陆景梦中强占她为妾并折磨她 | Beat 11-12 | 恐惧、恶心 | 当世杜若拒绝他，姨母长期拘禁他 |
| 陆景等沈煜死讯、等她流产守寡 | Beat 16 | 极恨 | 沈煜平安，杜若生女，陆景当场崩塌 |

## 3. 爽点因果链

```text
施害者种因: 陆景把“喜欢”伪装成规训，用容貌、身份、正妻资格持续贬低杜若。
主角表面承受: 杜若曾自疑、压抑笑声、放弃骑马，但没有彻底认同他的规则。
规则反身应用: 陆景说她不配正妻，她偏成郡王妃；陆景想让她做妾，自己最后被丫鬟和子嗣困在后宅泥潭。
崩塌/清算: 陆景发现杜若真的不等他，沈煜也没有死，前世优势全部失效，被姨母关押。
余味/补偿: 杜若与沈煜白头到老，女儿能骑马拉弓，自由被传给下一代。
```

## 4. 道德坐标

- **读者站队对象**: 杜若，其次是沈煜、姨母和下一代女儿。
- **反派必须被惩罚的理由**: 陆景不是单纯“不爱”，而是用亲情和婚约预期长期规训、贬低、侵占女性自主权。
- **主角可被允许的狠度边界**: 可以冷言拒绝、公开反击、永不原谅；不主动滥杀、不用无关者陪葬，保持甜宠文的温柔正义。

## 5. 主角姿态

- **核心姿态**: 清醒自救，被爱后更坚定。
- **语言姿态**: 前期温和克制，关键处短句反问砸脸。
- **行动姿态**: 先离开错误婚约，再接受正确关系，最后用具体准备（金丝软甲）主动改命。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 陆景对女主“被羞辱特质”的持续规训 | 这是所有甜宠补偿和后悔清算的情绪债源头 | 前 30% 至少 3 次具体打压 |
| 沈煜对同一特质的正向珍视 | 形成“错的人打压，对的人欣赏”的爽点闭环 | 至少 3 次具体宠爱动作，不只口头夸 |
| 女主关于真正喜欢的价值宣言 | 锁定主题，防止变成雌竞换夫 | 必须保留一段“喜欢让人自在”的表达 |
| 前世梦中做妾投河 | 抬高逃离陆景的必要性和命运重量 | 中后段必须揭示错误选择的死亡后果 |
| 金丝软甲救命 | 证明女主不是被动享福，而是也救了沈煜 | 危机前必须埋实物，危机中必须兑现 |
| 陆景等死讯反被喜讯打脸 | 全文最高爽点之一 | 清算段必须让他先期待成功，再被现实击碎 |

## 7. 可替换项

| 可替换维度 | 原文 | 改编允许范围 |
|-----------|------|-------------|
| 世界观 | 古代侯府/公主府/郡王 | 古代宅斗、将门、侯府、王府、仙门低玄均可 |
| 职业/身份 | 常胜将军小郡王 | 少将军、世子、国公府继承人、仙门少主 |
| 道具 | 金丝软甲、护心镜 | 护身符、药囊、甲衣、剑穗、玉佩，但必须能救命 |
| 被压抑行为 | 大笑、骑马 | 作画、舞剑、经商、弹琴、出门游历 |
| 前世死亡 | 投河、遇刺 | 落崖、毒杀、战死、火灾，但需与当世改命呼应 |
| 反派关系 | 表哥 | 竹马、未婚夫、师兄、养兄，必须有亲近权力 |

## 8. 失败预警

- **最容易丢的神髓**: 把沈煜写成单纯见色起意，而不是让杜若恢复自我。
- **一旦丢失会导致**: 甜宠补偿变轻，读者会觉得女主只是换了个男人依附。
- **写作时补救方式**: 每个甜段都对应一个前文伤口：被嫌招摇→被夸好看；被禁骑马→一起赛马；被贬孤女→给足家与身份。
