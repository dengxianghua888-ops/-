# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 让被丈夫和闺蜜联手毁掉人生的女主，重生后保住父母、夺回前途，并让背叛者承受迟到但不可逃的报应。
- **读者愿意追读的理由**: 前半压迫都和“上一世真实失去”绑定，读者知道女主一旦失败会再次失去父母和人生，所以能忍受栽赃、舆论、病危等高压情节。
- **最终必须兑现的体验**: 女主不复合、不原谅、不沉溺复仇；她拿回录取通知、保住父母，走向属于自己的轻盈人生。

## 3. 爽点因果链

```text
施害者种因: 钟然与宋攸宁偷情、改志愿、买通陈越、利用舆论逼女主认罪。
主角表面承受: 女主被背叛、被道德绑架、被诬告作弊、父母再次病危。
规则反身应用: 对方用公开舆论审判她，她就在公开场合揭穿记者与钟家的关系；对方想用证词毁她，调查反向查出收买证据。
崩塌/清算: 钟然和陈越被判刑，宋攸宁失去 A 大执念后崩溃，钟然后半生被悔恨吞没。
余味/补偿: 女主拿回录取通知，保住父母，补上旅行，拒绝把人生继续交给爱情。
```

## 4. 道德坐标

- **读者站队对象**: 孟开颜，以及她上一世失去、第二世必须保住的父母。
- **反派必须被惩罚的理由**: 他们不是普通出轨，而是篡改女主教育机会、毁掉家庭、用清白和舆论诬告，把私欲包装成无辜。
- **主角可被允许的狠度边界**: 可以揭穿、报警、反击、拒绝求情；不能主动制造无辜者伤害，不能为了复仇牺牲父母或自己前途。

## 5. 主角姿态

- **核心姿态**: 清醒护亲，先切断关系，再守住命运关键点。
- **语言姿态**: 短句砸脸，冷嘲反问，拒绝解释过度。
- **行动姿态**: 先保志愿和父母，再公开反杀，最后低温划清边界。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 背叛必须同时来自恋人与闺蜜 | 双重亲密背叛是开篇痛感来源 | Beat 1 必须有恋爱/婚姻与友情两条背叛线 |
| 被毁的必须是人生关键选择 | “高考志愿”承载命运被偷走的愤怒 | 必须有具体、可验证、决定前途的载体 |
| 父母必须是女主最大软肋 | 亲情补偿是区别于普通复仇文的核心 | Beat 4-8 必须出现上一世丧亲与第二世抢救 |
| 女主不能原谅钟然 | 读者要的是边界，不是追妻复合 | 结尾必须有明确拒绝或不复合动作 |
| 宋攸宁必须具备寄生/模仿特质 | 她不是普通小三，而是想替代女主的人 | 后半必须有模仿、占位、抢人生行为 |
| 公开围剿必须被公开反杀 | M3 爽点依赖规则回旋 | 舆论场必须出现反向揭穿或证据反噬 |

## 8. 失败预警

- **最容易丢的神髓**: 把故事写成普通小三复仇，忽略“人生被偷”和“父母被命运夺走”的深层债。
- **一旦丢失会导致**: 读者只觉得女主在争男人，站队强度和结尾轻盈感都会下降。
- **写作时补救方式**: 每个大爽点都要回扣“她要拿回自己的路、保住父母”，不要让钟然成为情绪中心。
