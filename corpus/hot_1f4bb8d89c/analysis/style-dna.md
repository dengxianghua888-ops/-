# 文风 DNA

## 一句话风格定性

都市退婚爽文外壳下的重生情感文：短句推进、强对话冲突、物件触发回忆，以“清醒女主口吻”压住狗血情节。

## 加载 genre 默认值

- genre: `urban_sweet_ceo`
- 默认基线: 第一人称女主、对话占比 45%+、都市豪门场景、情感拉扯与身份反差并重。
- 本文差异化: 甜宠不是主线前置，而是退婚清算后补偿出现；女性同盟比男女拉扯更突出。

## 定量特征

### 句式

- 平均句长: 约 18-24 字
- 长短句比例: 约 3:7
- 偏好句式模板:
  1. “我没有 X，只是 Y。”
  2. “你以为 X？其实 Y。”
  3. “不是因为 X，而是因为 Y。”
  4. “上辈子，……这辈子，……”
  5. “对我来说，已经不重要了。”
- 忌用句式: 大段哲理议论、复杂长复句、古风铺陈、过密环境描写。

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 物件象征 | 高 | “棺材”“收购合同”“婚戒”“星星罐” | 用实物承载羞辱、权力、创伤和旧爱 |
| 对照 | 高 | “上辈子 / 这辈子” | 强化重生改写的爽感 |
| 反问 | 中 | “你凭什么觉得我做这一切都是欲擒故纵？” | 击碎男主自恋逻辑 |
| 反讽 | 高 | “因为你不行。” | 短句砸脸，制造社交羞辱 |
| 重复递进 | 中 | “不是去找林知意，就是来找我求和。” | 表现傅沉舟失控降格 |

### 对话

- 对话占比: 约 55%
- 对话风格: 犀利、直给、网文短句化
- 对话功能: 推动情节 45%，展示性格 35%，信息传递 20%
- 典型对话张力: 傅沉舟不断误判“欲擒故纵”，女主反复冷静否认并升级反击。

### 叙述

- 人称视角: 第一人称
- 叙述温度: 表层冷静，回忆段带痛感
- 距离感: 贴近
- 时态: 现在推进 + 前世回忆混用
- 叙事习惯: 每次现实冲突后插入一段前世因果，解释女主为何绝不回头。

### 用词

- 色温倾向: 中性偏冷，结尾转暖
- 书面/口语比: 3:7
- AI 高频词检测: 原文使用“微微”“缓缓”等软性词少量出现；未形成明显 AI 腔。
- 偏好词: 退婚、联姻、收购、股份、婚戒、白月光、重生、欲擒故纵、清醒、放下。

## 代表性原句（Top 5）

1. “婚礼当天，傅沉舟让人送来一顶棺材。” — 极端 Hook，第一句完成冲突投放。
2. “现如今，我是傅氏集团的第二大股东。” — 资源反转核心句。
3. “傅沉舟他爱的不是我们任何人，他爱的永远只是他自己。” — 价值观反转核心句。
4. “这辈子，不做别人的白月光，只做自己的光。” — 女性同盟金句。
5. “对我来说，已经不重要了。” — 旧爱归零的温度反转收束。

- 大段“命运安排我们重逢”式抒情。
- 女主哭诉“为什么你不爱我”的低姿态。
- 傅沉舟突然深情忏悔并被原谅。
- 林知意继续恶毒雌竞到底。
- AI 味违禁词: “然而”、“总而言之”、“宛如命运的齿轮”、“眼中闪过一丝复杂/暗芒”、“深吸一口气”、“不禁”、“心中涌起”。
