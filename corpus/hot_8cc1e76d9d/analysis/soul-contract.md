# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 读者将看到一个被竹马长期否认和贬低的女孩，彻底离开旧爱与旧评价体系，让迟来的深情永远失效。
- **读者愿意追读的理由**: 前半所有憋屈都有明确债主：男主、情敌、同学舆论；读者期待女主什么时候不再忍，以及男主什么时候意识到失去。
- **最终必须兑现的体验**: 男主公开承认、长期追悔、仍被女主平静拒绝；女主证明“我很优秀，我配得上任何人”。

## 3. 爽点因果链

```text
施害者种因: 周屿享受程小满的爱，却为了面子和优越感在公开场合否认她、贬低她、控制她的前途。
主角表面承受: 程小满一次次沉默、等待官宣、相信“开学就复合”，甚至长期接受“配不上”的评价。
规则反身应用: 周屿最看重公开体面，最终必须在公开场合承认喜欢；他抢走伞，最后只能在雨中撑伞却无效。
崩塌/清算: 女主拉黑出国，周屿找不到她；他补官宣、追到国外、等四年，都换不回她回头。
余味/补偿: 女主在新环境里获得认可，确认自己优秀，结尾走出雨季。
```

## 4. 道德坐标

- **读者站队对象**: 程小满，被长期否认、羞辱、剥夺选择权的女孩。
- **反派必须被惩罚的理由**: 周屿不是单纯变心，而是把女主的尊严、前途和公开身份都放在自己的面子之后。
- **主角可被允许的狠度边界**: 可以拉黑、离开、拒绝复合、公开清算；不能恶意毁掉林曦或无差别报复同学，否则偏离“自救成长”。

## 5. 主角姿态

- **核心姿态**: 从隐忍等待到清醒抽离，再到温和坚定。
- **语言姿态**: 前期沉默短句，爆发时直白控诉，结尾克制告别。
- **行动姿态**: 不抢不闹，先收回自己的人生选择，再让男主所有补偿失效。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 秘密恋爱多年却被公开否认 | 全文最大情绪债来源 | 前 20% 必须出现“只有我知道我们在一起”的信息差 |
| 男主为了面子不承认女主 | 火葬场成立的根 | 至少 3 次公开否认/划清界限 |
| 伞/雨的前后回旋 | M3 的物象骨架 | 前期伤害一次，后期补偿一次但失效 |
| 女主离开不是赌气，而是人生选择 | 防止降级成小情侣误会 | 必须有留学/升学/工作等不可逆成长路径 |
| 男主补官宣太迟 | 读者要的不是复合，是迟来无效 | 后期公开承认必须发生在女主离开之后 |
| 女主最终不复合 | 最终读者承诺 | 结尾必须明确拒绝等待 |

## 8. 失败预警

- **最容易丢的神髓**: 把故事写成“误会解除后复合”的普通追妻。
- **一旦丢失会导致**: 前半所有羞辱债无法兑现，读者会觉得女主不争气。
- **写作时补救方式**: 增加女主在新环境中的正向确认，并让男主的补偿全部晚一步。
