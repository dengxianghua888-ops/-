# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 让一个被父亲、养女、学校和舆论夺走人生的真女儿，在母亲无条件归来后，被公开承认、彻底带走，并亲眼看见夺位者和悔恨者付出代价。
- **读者愿意追读的理由**: 前半压迫极具体且极不公平，读者会等“妈妈回来认出她、站在她这边”的补偿。
- **最终必须兑现的体验**: 女主不原谅、不回头、不再乞求父爱，拿着未来走向真正爱她的人。

## 2. 情绪债

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|
| 父亲因母亲失踪迁怒亲女 | Beat 1-3 | 心疼、愤怒 | 母亲归来后公开指出他“有病”，并离婚 |
| 顾诗予夺走生日、身份、房间 | Beat 1-2 | 憋屈、恨 | 直播揭穿收养身份，赶出顾家 |
| 父亲直播说女主是佣人亲属 | Beat 4 | 极致屈辱 | 母亲直播宣布“亲生女儿顾初宜” |
| 项链被偷并摔碎 | Beat 4-5 | 崩溃、心疼 | 母亲确认项链属于女主，父亲公开认错 |
| 学校和同学霸凌女主 | Beat 1,3,7 | 憋屈 | 母亲到校撑腰，男生和家长道歉 |
| 顾诗予刺激女主跳湖 | Beat 5 | 恨、后怕 | 顾诗予失宠、被孤立、落魄 |
| 父亲迟来补偿求原谅 | Beat 9-12 | 复杂、拒绝 | 母亲和女主均不原谅，父亲自毁谢罪 |

## 3. 爽点因果链

```text
施害者种因: 父亲迁怒亲女，养女夺走身份与母爱遗物，学校和舆论集体误判女主。
主角表面承受: 女主住佣人房、被孤立、被网暴、被锁房、被迫怀疑自己不配被爱。
规则反身应用: “佣人亲属”“顾家独女”“妈妈遗物”等施害者话术被母亲和女主反向使用。
崩塌/清算: 母亲归来认女，学校打脸，直播澄清，解除收养，离婚，父亲自杀，顾诗予落魄。
余味/补偿: 女主获得母亲、新家、朋友、成绩、遗产和光明未来，但不再需要父亲的爱。
```

## 4. 道德坐标

- **读者站队对象**: 顾初宜和周梦，尤其是被长期精神虐待的亲女儿。
- **反派必须被惩罚的理由**: 他们违反了亲情中的保护义务、公平中的身份事实、公共舆论中的真相底线。
- **主角可被允许的狠度边界**: 可以不原谅、可以冷嘲、可以看反派落魄开心；不能主动伪造罪名或伤害无辜者。

## 5. 主角姿态

- **核心姿态**: 前半隐忍麻木，触底后被母亲托住，后半冷静脱离。
- **语言姿态**: 短句、克制、关键时刻直接刺穿幻想。
- **行动姿态**: 被动承受十年 → 生死触底 → 借母亲归来完成身份修复 → 主动拒绝回头。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 母亲必须在女主触底时归来 | 这是最大补偿点，偿还十年无人兜底 | Beat 5-6 必须形成“濒死/绝望 → 母亲出现” |
| 父亲必须曾经爱过女主 | M5 温度反转成立依赖正峰 | 前 30% 必须有父亲昔日疼爱回忆 |
| 养女必须夺走具体物件和身份 | 抽象偏心不够爽，必须有可见侵占 | 至少有生日、房间/身份、母亲遗物三类载体 |
| 公开误判必须公开澄清 | 舆论债要同场域偿还 | 必须有学校/直播/公共场景反转 |
| 女主不能原谅父亲 | 本文核心不是家庭团圆，而是脱离伤害 | 结尾必须保留“不回头”姿态 |
| 母亲必须选择女儿而非丈夫 | 读者期待的护崽承诺 | 母亲必须离开父亲或做等价决裂 |

## 8. 失败预警

- **最容易丢的神髓**: 把母亲写成只安慰不行动，或让父亲轻易被原谅。
- **一旦丢失会导致**: 前半压迫无法兑现，读者认为爽点烂尾。
- **写作时补救方式**: 增加母亲公开站队、反问父亲、带女儿离开的硬动作；保留女主“不需要了”的终局姿态。
