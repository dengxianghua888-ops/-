# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 让读者看到一个被竹马轻贱十年的女孩，被真正爱她的人公开珍视，并亲手拒绝迟来的深情。
- **读者愿意追读的理由**: 前半的羞辱足够具体，且女主始终保留“孩子父亲是谁/生日夜真相”的信息差，读者相信后面会有公开打脸。
- **最终必须兑现的体验**: 江衍帆彻底失去顾茜，顾茜不回头，沈盛的爱落到婚姻与余生。

## 3. 爽点因果链

```text
施害者种因: 江衍帆长期享受顾茜的爱，却否认她、羞辱她、误判她，把她的解释当纠缠。
主角表面承受: 顾茜不争辩、不哭闹，只反复澄清孩子不是他，并保留关键证据。
规则反身应用: 江衍帆曾不认她、不听她、不珍惜她；结尾顾茜不认他的爱、不听他的求和、不珍惜他的悔恨。
崩塌/清算: 同学会监控真相公开，方懿汝退婚，婚礼抢亲失败，墙角求复合被彻底拒绝。
余味/补偿: 顾茜嫁给沈盛，孩子在期待中出生，真正拥有被珍视的爱情。
```

## 4. 道德坐标

- **读者站队对象**: 顾茜、未出生的孩子、所有被长期轻视后清醒离开的人。
- **反派必须被惩罚的理由**: 江衍帆不是单纯“不爱”，而是享受女主付出、贬低她人格、干涉她身体与孩子归属。
- **主角可被允许的狠度边界**: 可以公开证据、拒绝复合、让对方社交性崩塌；不能主动造谣陷害或伤害无辜孩子。

## 5. 主角姿态

- **核心姿态**: 清醒、克制、彻底抽离。
- **语言姿态**: 短句澄清，冷静否认，关键处一刀封喉。
- **行动姿态**: 不解释过度，保留证据，公开关系，终局拒绝。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 女主爱了前任十年 | 火葬场悔恨重量来源 | 前 40% 至少 3 处具体付出回忆 |
| 孩子不是前任的 | 全文最大误判与反转核心 | Beat 1-9 反复澄清，Beat 9 证据引爆 |
| 真男主曾被低估后逆袭 | 补偿爽点来源 | 必须有旧身份被嘲与新身份公开 |
| 前任迟来深情不可挽回 | 终局爽感核心 | 结尾女主必须明确拒绝，不能暧昧 |
| 证据公开场合 | 打脸必须社交化 | 至少一次多人场合公开真相 |
| 婚礼抢亲失败 | 火葬场峰值 | 必须有公开求和和当众拒绝 |

## 8. 失败预警

- **最容易丢的神髓**: 女主“真的不爱了”的确定性。
- **一旦丢失会导致**: 读者以为女主在赌气，火葬场变成狗血拉扯，爽点变弱。
- **写作时补救方式**: 每次江衍帆示弱，都让女主用具体新生活回应，而不是心理摇摆。
