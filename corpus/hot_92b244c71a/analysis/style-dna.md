# 文风 DNA

## 一句话风格定性

半文半白的古言虐爽文体，以第一人称痛感叙述承压，以短对话和身体损伤制造强情绪，再用帝王身份反转完成补偿。

## 加载 genre 默认值

- genre 基线: ancient_BE
- 基线特征: 器官隐喻、血色意象、宿命错付、半文半白、破句高频、虐点前置、悔恨后置。
- 本文差异: 结尾并非纯 BE，而是“虐恋底色 + 重生复仇 + 帝王甜宠补偿”。

## 定量特征

### 句式

- 平均句长: 18-24 字
- 长短句比例: 4:6
- 偏好句式模板:
  1. “我……，却……”制造错付反差。
  2. “他……，却……”制造负心对照。
  3. “第一下……第二下……第三下……”递进虐感。
  4. “不是的！我……”用于崩溃自证。
  5. “你若……就……”用于威胁压迫。
- 忌用句式: 现代网感吐槽、过度解释型长复句、议论文式总结。

### 对话

- 对话占比: 约 43%
- 对话风格: 直接、短促、带强压迫性
- 对话功能: 推动冲突、暴露谎言、完成身份揭露

### 叙述

- 人称视角: 第一人称为主，后半有第三人称切入萧承均悔恨
- 叙述温度: 前半冷痛，后半温柔补偿
- 距离感: 贴近身体痛感与母女关系
- 时态: 过去式为主，重生后线性推进

### 用词

- 色温倾向: 冷色与血色并行
- 书面/口语比: 6:4
- AI 高频词检测: 原文有“无论如何”1 次，“不由地”1 次；整体 AI 味较低。
- preferred_imagery_in_source: 血、雨、玉佩、桃树、祠堂、悬崖、红墙黄瓦、葡萄、玉簪。

> 改编 writer 须达到原文同量级的金句密度(容差 ±15%)，尤其要保留“身体痛感 + 母爱保护 + 负心对照”。

## 代表性原句（Top 5）

1. “你身子不好，是因为我给你下了毒。” — 开篇极端背叛。
2. “是女儿，原来我生的是个女儿……” — 全文母题落点。
3. “别动我女儿，我来。” — 主角姿态核心。
4. “霜儿，朕来迟了……” — 救赎型身份反转。
5. “那封信我没给任何人看过，你怎么会知道他要我准备万两黄金！” — 证据回旋清算。
