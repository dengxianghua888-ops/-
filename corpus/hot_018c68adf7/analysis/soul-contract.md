# 爆款神髓合约模板 (V4)

## 1. 读者承诺

- **一句话承诺**: 读者会看到一个高举“科学和平等”的傲慢穿越女，因为施暴和伪善，被真正的神迹与疯批护短皇帝双重打脸。
- **读者愿意追读的理由**: 前半压迫足够密集，且每次温月委屈都会出现异象，读者知道反派正在把自己推向更大的清算。
- **最终必须兑现的体验**: 沈知意必须承认失控或被迫低头；温月必须被确认“不是因有用才被爱”；结尾必须有轻爽金句回收。

## 3. 爽点因果链

```text
施害者种因: 沈知意以科学、平等、文明为名，先入为主把温月定为骗局和特权象征，并动手羞辱。
主角表面承受: 温月怕吵、怕疼、不善辩解，只会委屈落泪。
规则反身应用: 沈知意说众生平等，却随意殴打拖拽温月；她说科学解释一切，却无法解释温月泪落即天灾。
崩塌/清算: 皇帝掌嘴、下狱、逼跪；天地异象不断升级，击穿沈知意的绝对自信。
余味/补偿: 温月被确认“因自己被爱”，最后以“天意说，别惹我”轻爽收尾。
```

## 4. 道德坐标

- **读者站队对象**: 温月，尤其是作为被围观、被误解、被暴力对待的弱者。
- **反派必须被惩罚的理由**: 她不是单纯质疑神权，而是借“正确理念”合理化殴打、羞辱、拖拽和公开审判。
- **主角可被允许的狠度边界**: 温月可以触发天灾、拒绝原谅、让对方跪；但不主动虐杀无辜，清算动作主要由规则和皇帝执行。

## 5. 主角姿态

- **核心姿态**: 软、困、怕吵、委屈；不主动争辩但不可冒犯。
- **语言姿态**: 短句直给，童真式反问，最后轻爽金句。
- **行动姿态**: 被动承受，情绪触发神迹；关键处用简单问题戳穿反派伪善。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 反派必须打着“进步/平等/科学”旗号施暴 | 爽点来自伪善反噬 | 反派至少 3 次使用正义话术压人 |
| 主角必须柔弱、不雄辩 | 反差爽来自世界替她反击 | 主角反击台词短，不做长篇演说 |
| 神迹必须真实且逐层升级 | M7 降维打击核心 | 至少 4 次自然异象递进 |
| 皇帝必须确认爱的是“温月本人” | 情感债偿还核心 | 必须有“不是因身份被爱”的明确句 |
| 结尾必须轻爽回收 | 平台读者需要补偿 | 最后 500 字有轻松金句和秩序恢复 |

## 8. 失败预警

- **最容易丢的神髓**: 把沈知意写成纯恶女，而不是“正确话术下的暴力者”。
- **一旦丢失会导致**: M3 反讽失效，结尾打脸变成普通雌竞。
- **写作时补救方式**: 给反派保留“平等/真理/文明”高频台词，再让她行动上违反这些词。
