# 爆款神髓合约模板 (V4)

## 1. 读者承诺

- **一句话承诺**: 让被错爱、误解、羞辱到失去一切的女主，亲手改写命运，并让施害男主永远困在无法补偿的悔恨里。
- **读者愿意追读的理由**: 前半压迫足够极致，且有“五年前的自己还能逃”的希望钩子，读者会忍受虐点等待命运改写与男主反噬。
- **最终必须兑现的体验**: 女主不回头、不复合，亲情事业爱情全部补偿；男主知道真相但永远无法挽回。

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|

## 3. 爽点因果链

```text
施害者种因: 傅烬言误信嫁祸，把夏星眠当成害死妹妹的罪人，用婚姻、医疗资源、事业封锁持续折磨她。
主角表面承受: 夏星眠为了父亲活命忍受羞辱，直到通过跨时空直播提醒五年前的自己逃离。
规则反身应用: 傅烬言曾用记忆、旧情、父亲性命困住她；改写后，他自己被两套记忆困住，旧情变成无法补偿的刑具。
崩塌/清算: 世界抹除婚姻，妹妹活着，父亲健康，真相指向陆晚晴，傅烬言失去所有解释和挽回资格。
余味/补偿: 女主拥有事业、父亲、新爱和自由，旧疤还在，但已经长好。
```

## 4. 道德坐标

- **读者站队对象**: 夏星眠、夏远山、被误判与被亲密关系压迫的弱者。
- **反派必须被惩罚的理由**: 傅烬言不是单纯变心，而是未经查证就以爱之名实施长期精神虐待、资源控制和人格羞辱。
- **主角可被允许的狠度边界**: 可以彻底离开、拒绝解释、拒绝补偿、拒绝复合；不能主动伤害无辜者，不能为了爽而抹杀新时空里健康生活的温度。

## 5. 主角姿态

- **核心姿态**: 冷静、麻木后清醒、彻底断爱。
- **语言姿态**: 短句砸脸，少控诉，多事实判断。
- **行动姿态**: 先忍到牵绊断裂，再通过过去的自己改写命运；后半以“不回应”作为最高反击。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 跨时空自救结构 | 这是本文区别普通重生/追妻火葬场的核心 | 必须有“未来我”警告“过去我”的桥段 |
| 父亲作为女主走不了的锁链 | 解释前半忍耐合理性 | 前半必须有亲人医疗/生存资源被男主控制 |
| 女主不复合 | 爽点在拒绝火葬场 | 结尾不得出现原谅、复婚、暧昧动摇 |
| 男主保留旧记忆 | 悔恨惩罚必须持续 | 后半男主必须记得旧时空罪行 |
| 事业被毁与重建对照 | 补偿不只靠新男人 | 必须有女主职业价值回归 |
| 真凶闭环 | 男主悔恨要有事实落点 | 必须查明当年误会另有真凶 |

## 8. 失败预警

- **最容易丢的神髓**: 把故事写成“男主后悔求复合”的普通火葬场。
- **一旦丢失会导致**: 读者前半承受的虐债无法被等价偿还，女主清醒感坍塌。
- **写作时补救方式**: 增加女主明确拒绝、删除复合暗示，把男主戏份集中在真相反噬与精神惩罚。
