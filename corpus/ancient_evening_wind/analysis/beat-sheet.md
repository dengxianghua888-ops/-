# Beat Sheet 节拍器

## 全文概况

- 总字数: 约 12500 字
- 节拍数: 12 幕
- 核心母题（Logline）: 白手起家的女主收留落难闺蜜，却被男友和闺蜜双重背叛；她撤回庇护、公开证据、让背叛者自食其果，最终重建自我。
- 情绪模式: 极致信任 → 双重背叛 → 被迫退场 → 回忆加刀 → 冷静设局 → 公开清算 → 对方反噬 → 女主放下
