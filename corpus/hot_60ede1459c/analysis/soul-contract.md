# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 读者将看到一个被爱困住的温柔父亲被逼到彻底离开，而亲手逼死他的母亲用余生偿还“他不要她了”的惩罚。
- **读者愿意追读的理由**: 前半压迫极重，但系统倒计时、陈律师伏笔和父亲留下的文件持续暗示“死亡后会清算”，读者忍受虐点是为了看迟来真相与拒绝原谅。
- **最终必须兑现的体验**: 父亲获得离开，孩子获得自由，母亲永远得不到回应，外部反派被法律清算。

## 2. 情绪债

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|
| 母亲停爷爷救命药，逼奶奶暴雨道歉 | Beat 1 | 恨、震惊 | 真相证明沈家无辜，母亲终身悔恨 |
| 母亲夺走沈家最后股份给许景洲 | Beat 2 | 憋屈 | 股份与非法所得追回给顾辰 |
| 许景洲入住主卧，拔掉父亲兰花 | Beat 3 | 被侵占感 | 后期母亲砸尽许景洲痕迹，却找不回父亲痕迹 |
| 母亲强制抽父亲血救白月光 | Beat 4 | 心疼、怒 | 法律追责“严重伤害”，母亲失去监护资格 |
| 许景洲栽赃顾辰，母亲要送管教学校 | Beat 5 | 恐惧、恨 | 监控曝光，孩子拒绝母亲监护 |
| 母亲用骨灰逼父亲下跪并毁骨灰 | Beat 6 | 极致痛恨 | 父亲死亡脱离，母亲永远无法再道歉 |
| 母亲死后才查真相 | Beat 7-8 | 反讽 | 陈律师指出“肯查一次就不必如此” |
| 许景洲伪装受害者 | Beat 8/10 | 厌恶 | 证据当庭播放，入狱并财产追缴 |
| 母亲求孩子回头 | Beat 11-12 | 冷爽 | 顾辰明确拒绝，且临终不探望 |

## 3. 爽点因果链

```text
施害者种因: 顾清霜偏信许景洲，主动伤害沈家、丈夫和儿子。
主角表面承受: 沈知珩签协议、被抽血、被打、被迫下跪，顾辰被夺走安全感。
规则反身应用: 她不查真相，所以真相在他死后才一页页砸向她；她不看他的痛，所以死后她再也见不到他。
崩塌/清算: 许景洲入狱，顾清霜辞职、失监护权、余生墓前无回应。
余味/补偿: 顾辰继承父亲留下的底气，建立基金和图书馆，把“离开的权利”传下去。
```

## 4. 道德坐标

- **读者站队对象**: 沈知珩和顾辰。
- **反派必须被惩罚的理由**: 许景洲恩将仇报、构陷无辜；顾清霜作为母亲和妻子，拒绝查证、滥用权力、主动伤害弱者。
- **主角可被允许的狠度边界**: 顾辰可以拒绝原谅、拒绝探望、接受赔偿、追责清算；不能主动虐杀或伪造证据，必须站在法律与边界一侧。

## 5. 主角姿态

- **核心姿态**: 受伤但清醒，继承父亲的“离开权利”。
- **语言姿态**: 前期哭求质问，后期平静短句砸脸。
- **行动姿态**: 被动见证 → 接受保护 → 拒绝监护 → 主动离开 → 用遗产帮助同类受害者。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 父亲曾为母亲主动留下 | 这是“她亲手让他后悔”的最大刀点 | 后文必须揭示“本可离开，为她留下” |
| 母亲主动不查真相 | 决定她不是无辜被骗，而是主债务人 | 至少 3 次有人提醒她查证，她拒绝 |
| 孩子最终不原谅 | 爽点落在边界，不是和解 | 结尾不能有母子和解或代父原谅 |
| 死亡/离开不可逆 | 付费卡点成立依赖不可逆 | 父亲不能复活，不能转世重逢安慰母亲 |
| 主题金句“被困住” | 串联父亲、孩子、结尾公共价值 | 前中后至少出现 3 次变奏 |
| 外部反派与母亲双清算 | 许景洲倒下不等于顾清霜无罪 | 法庭或叙述必须明确“她是递刀者” |

## 8. 失败预警

- **最容易丢的神髓**: 把母亲写成“被骗后也很可怜”，导致主债务转移到白月光身上。
- **一旦丢失会导致**: 读者无法享受她被拒绝原谅的爽点，只会觉得惩罚过重。
- **写作时补救方式**: 增加母亲拒绝查证、主动命令、主动伤害孩子和父亲的具体场景。
