# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 读者将看到一个被误认为娇气废物的末世吉祥物，在被毁掉封印后觉醒为丧尸女王，用施害者的弱肉强食规则完成降维清算。
- **读者愿意追读的理由**: 前半所有羞辱都有明确物证和规则后果，读者知道“她的娇气不是矫情”，因此会忍受压迫等待真相反杀。
- **最终必须兑现的体验**: 雷铁男必须亲眼确认自己亲手放出怪物，并在自己宣扬的残酷现实里崩塌；女主必须获得权力、补偿和危险的新身份。

## 3. 爽点因果链

```text
施害者种因: 雷铁男以“人人平等”“不养闲人”“弱肉强食”为名，毁掉奶茶、裙子、洁净和女主的人类自我。
主角表面承受: 女主反复解释、哀求、忍耐，甚至被挂上旗杆，仍未主动释放体内灾厄。
规则反身应用: 女主觉醒后撤去圣域，让所有人进入雷铁男要求的“真实末世”和“人人平等”。
崩塌/清算: 丧尸臣服女主，雷铁男从教官变成猎物，亲眼看见团队被吞噬，最后被精神风暴摧毁。
余味/补偿: 善良者被保下，女主换上红色女王袍，建立由丧尸守卫的新基地；她仍爱奶茶，但不再温顺。
```

## 4. 道德坐标

- **读者站队对象**: 女主、老王头、少数曾流泪或阻拦的弱者。
- **反派必须被惩罚的理由**: 她不是单纯“坏”，而是用公共正义口号实施羞辱、剥夺、献祭，并毁掉保护所有人的封印。
- **主角可被允许的狠度边界**: 可以杀起哄者、动手者、主犯；应保留善意者或无力阻止者，以免清算变成无差别屠杀。

## 5. 主角姿态

- **核心姿态**: 前半娇软隐忍，触底后冷漠觉醒，终局高位审判。
- **语言姿态**: 前半“姐姐，我不行……”式哀求；后半“脏”“好吵”“饿了”式极短命令。
- **行动姿态**: 被动承受污染与献祭，觉醒后撤销庇护、命令尸潮、选择性保人。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 女主“娇气/被宠”必须是封印规则 | 这是全文最大价值反转，决定读者前半忍耐是否有回报 | 后半必须明确解释宠爱、奶茶、裙子、快乐与世界安全的因果 |
| 雷铁男必须输出错误规则 | M3 回旋需要原话作为清算依据 | 至少 3 句反派规则原话在后半被女主/陆野回敬 |
| 污染媒介必须具体 | 末世异能规则需要物理触发，不能抽象觉醒 | 奶茶、裙子、血衣、泥水至少保留等价物 |
| 旗杆献祭必须保留 | 这是触底濒死卡点和公开羞辱峰值 | 必须有高处示众/献祭/众人沉默帮凶场面 |
| 女主身份必须是新坐标系顶点 | M7 降维打击核心，不能变成普通强者 | 后半必须出现旧规则失效、敌方武器无效、群体臣服 |
| 结尾必须有危险余味 | M8 让故事从纯爽升级为“女王秩序” | 最后 500 字必须暗示她不再完全温顺 |

## 8. 失败预警

- **最容易丢的神髓**: 把“娇气”写成普通大小姐脾气，而不是维持世界安全的封印机制。
- **一旦丢失会导致**: 前半压迫显得合理，读者不再心疼女主，后半清算变成任性滥杀。
- **写作时补救方式**: 在每次女主被羞辱时都埋一个规则后果：尸潮靠近、警报异常、某个怪物苏醒、知情人脸色骤变。
