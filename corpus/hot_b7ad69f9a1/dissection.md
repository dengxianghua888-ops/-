# 解构报告

## 全文概述（200 字以内）

故事以“丈夫擅自把瘫痪婆婆搬进主卧、要求妻子睡客厅”为起点，女主许静用封闭培训抽身，迫使丈夫独自承担他口中的孝道。丈夫从道德绑架、亲属骚扰、苦肉计到伪证陷害层层升级，女主则通过提前报备、离婚协议、录音取证和反向威胁完成清算。核心爽点是：谁把“孝道”当武器，谁就被自己的规则反噬；谁想困住女主，谁就失去婚姻、财产和前途。

## 核心发现 Top 5

1. “孝道”不是价值观背景，而是反派施压工具；女主的反击必须始终围绕“你自己尽你的孝”展开。
2. 女主不靠吵赢，而靠提前抽身、保留证据、引诱对方升级，形成家庭伦理文里的逻辑反杀。
3. 丈夫的每次压迫都以“家人/良心/责任”为名，但实际都在转嫁成本，读者恨点稳定。
4. 反转不是一次性爆发，而是四层递进：搬主卧 → 封闭培训 → 苦肉计 → 伪证陷害 → 录音清算。
5. 结尾爽感来自“双清算”：离婚财产清算 + 职业名誉清算，同时给女主新生活补偿。

## 仿写难点预警 Top 3

1. 女主必须冷静、强硬、会算账；不能写成只会崩溃或哭诉。
2. 家庭伦理压迫要具体到空间、床位、护工费、签字、财产，不能空喊“婆媳矛盾”。
3. 反杀证据链必须闭合：对方设局 → 棋子动摇 → 录音落手 → 二选一威胁。
