# 爆款神髓合约模板 (V4)

## 1. 读者承诺

- **一句话承诺**: 看一个被恶意涨租逼迁的女老板，不哭不求，带全家核心客流撤场，把旧平台抽成空壳，并反杀幕后父权。
- **读者愿意追读的理由**: 前半压迫具体且过分，断电、封货梯、羞辱、扣押金都打在经营者命门上；读者相信女主手里有更大的牌。
- **最终必须兑现的体验**: 旧商场破产、反派失势、女主事业升级、婚姻边界被重新确立。

## 3. 爽点因果链

```text
施害者种因: 物业和幕后父权把苏念当成可拿捏的弱租户/儿媳。
主角表面承受: 苏念答应搬走，不争吵，只快速转移人、货、客流和舆论。
规则反身应用: 既然你说“嫌贵就走”，她就带走真正值钱的客流；既然你讲商业规则，她就用账单、合同、股权压回去。
崩塌/清算: 王强被开除报警，星茶跑路，周总破产，陆振国被股东身份打脸。
余味/补偿: 女主新店爆火，员工拿奖金，丈夫完成选择，旧城改造象征新秩序。
```

## 4. 道德坐标

- **读者站队对象**: 苏念及其员工、家人、被平台压榨的优质经营者。
- **反派必须被惩罚的理由**: 他们违反公平交易、契约精神、经营伦理和女性主体尊严。
- **主角可被允许的狠度边界**: 可以撤场、曝光、起诉、商业反击、拒绝和解；不能主动造假陷害无辜商户。

## 5. 主角姿态

- **核心姿态**: 冷静、能忍、先撤再杀。
- **语言姿态**: 短句砸脸，反问少而准，关键处不解释。
- **行动姿态**: 用商业资源与证据反制，不靠哭闹和暴力。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| “四家核心店一起搬” | 这是抽干客流的根爽点 | Beat 1 必须出现集体撤场宣言 |
| 物业先断电/封货梯 | 压迫必须具体打到经营命门 | 至少 2 个经营损害事件 |
| 会员群/客流迁移 | 反击必须证明“人心在女主这边” | 必须有顾客站队与老商场客流暴跌 |
| 证据反杀王强 | 爽点不能只靠吵赢 | 必须有账单/录像/流水等固化证据 |
| 股东身份反杀陆父 | 后段价值升维的核心 | 必须有硬权力文件落地 |
| 女主不求回旧平台 | 保持主体性 | 周总求回必须被拒绝 |

## 7. 可替换项

| 可替换维度 | 原文 | 改编允许范围 |
|-----------|------|-------------|
| 行业 | 烘焙、金店、健身、电竞 | 可换餐饮、医美、教育、宠物、书店，但要形成客流闭环 |
| 场景 | 老商场 vs 万象城 | 可换商业街、园区、平台、景区、写字楼 |
| 道具 | LED 屏、会员群、股份认购书 | 可换热搜、业主群、董事会席位、产权证 |
| 反派 | 物业经理、网红、老板、公公 | 可换平台运营、招商主管、资本方、家族长辈 |
| 证据 | 账单照片、录像 | 可换后台数据、录音、转账流水、监控 |

## 8. 失败预警

- **最容易丢的神髓**: 把反击写成单店搬迁，而不是生态客流迁移。
- **一旦丢失会导致**: 旧商场崩盘缺乏因果，爽点像开挂。
- **写作时补救方式**: 给主角阵营增加 3 个互相导流的资源点，并用数字证明旧平台失血。
