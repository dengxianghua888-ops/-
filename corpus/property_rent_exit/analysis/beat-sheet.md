# Beat Sheet 节拍器

## 全文概况

- 总字数: 约 12500 字
- 节拍数: 12 幕
- 核心母题（Logline）: 女老板苏念被物业恶意涨租断电逼迁后，带全家核心店铺撤场迁往对面新商场，抽干老商场客流，并在幕后公公施压时以股东身份完成终极反杀。
- 情绪模式: 极致打压 → 表面顺从 → 集体撤场 → 商业碾压 → 幕后升级 → 身份反杀 → 温和补偿
