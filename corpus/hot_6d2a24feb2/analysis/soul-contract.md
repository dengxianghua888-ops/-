# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 让读者看见一个被“他其实爱你”洗脑多年的女孩，亲手撕掉滤镜，选择自己，并让拧巴男为迟来的爱付出不可逆代价。
- **读者愿意追读的理由**: 前半每一次羞辱都有弹幕洗白，读者会憋着一口气等女主何时醒悟、何时反驳这套荒唐叙事。
- **最终必须兑现的体验**: 女主不回头、不负责男主崩塌，用新的事业、友情和健康爱意证明她值得被正面爱。

## 3. 爽点因果链

```text
施害者种因: 厉屿白长期用贬低、冷淡、反话和偏袒师妹消耗安苒，却仗着救命恩和弹幕解释享受她的照顾。
主角表面承受: 安苒七年里相信弹幕，从男主刻薄里寻找爱意，牺牲事业、生活和尊严。
规则反身应用: 安苒不再替他翻译爱意，也不再履行照顾义务；既然他说不出口，她就按现实行为判定他不爱。
崩塌/清算: 厉屿白失去照顾者、灵感缪斯和情感支点，事业、人际、尊严逐层崩塌，最后求复合失败。
余味/补偿: 安苒获得事业认可、友情守护和直球爱意，男主自毁带来阴影，但她的生活继续。
```

## 4. 道德坐标

- **读者站队对象**: 安苒，以及所有在关系中被迫解读伤害为爱的人。
- **反派必须被惩罚的理由**: 厉屿白不是“不会表达”这么简单，而是长期享受女主付出，却不给尊重、安全感和对等回应。
- **主角可被允许的狠度边界**: 可以断联、拒绝照顾、拒绝复合、冷处理男主崩塌；不能主动诱导男主自杀或以恶意报复无关者。

## 5. 主角姿态

- **核心姿态**: 克制清醒、先忍后醒、温柔但不再自我牺牲。
- **语言姿态**: 短句反问、冷静拆解、价值观砸脸。
- **行动姿态**: 不争辩、不自证，直接离开旧场域，转向事业和健康关系。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 弹幕强行洗白男主 | 这是反洗脑爽点核心 | 前 70% 至少 5 次弹幕误读现实伤害 |
| 男主“有爱但伤人”的复杂性 | 支撑女主七年沉没成本和 M5 温度曲线 | 必须有救命/画女主/心疼伤口等证据 |
| 女主主动离开 | 爽点来自她不再等待男主解释 | 必须有明确收拾行李并出门的动作 |
| 健康爱意对照组 | 证明“爱要表达”不是空口说教 | 新男主/朋友至少 3 次实际保护或直球表达 |
| 垃圾桶/低位狼狈对峙 | 男主尊严坍塌的视觉高潮 | 必须有他狼狈出现却仍不开口的场景 |
| 迟来告白被拒绝 | 温度反转不可逆 | 终局必须直接拒绝复合 |
| 男主结局的道德阴影 | 让故事从单纯爽文升到余味 | 结尾不得大团圆，也不得让女主承担责任 |

## 8. 失败预警

- **最容易丢的神髓**: 把“不表达的爱不是爱”写成“女主移情别恋所以男主可怜”。
- **一旦丢失会导致**: 读者站队动摇，女主拒绝复合显得过狠，男主结局显得过重。
- **写作时补救方式**: 每个男主可怜场景前，补一笔他曾经给女主造成的具体伤害；每个新男主发糖场景，都落到“尊重与表达”而非单纯宠。
