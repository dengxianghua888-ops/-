# 文风 DNA

## 一句话风格定性

现代虐恋复仇文风：高密度虐点、短句砸心、对话推进、以身体伤害和儿童意象制造伦理痛感，再用庭审与新爱完成补偿。

## 定量特征

### 句式

- 平均句长: 约 18-24 字
- 长短句比例: 短句 68%：长句 32%
- 偏好句式模板:
  - “他/她只是……”
  - “明明……明明……最后却……”
  - “不是 A，也不是 B，而是 C。”
  - “你要 X，那我呢？那 Y 呢？”
  - “这个世界没有如果。”
- 忌用句式: 大段议论、总分总说教、玄学宿命式抒情、过长心理独白。

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 排比递进 | 高 | “坠楼，落水，车祸……” | 压迫累积迅速 |
| 反复追问 | 高 | “那我呢？那程程呢？” | 强化被遗弃感 |
| 温柔反讽 | 中高 | “砚舟乖，不要闹。” | 让施害者温柔显得更可怖 |
| 物理化痛感 | 高 | “每一步都像走在刀尖上。” | 把情绪转成身体感 |
| 今昔对照 | 高 | 儿童画曾被珍藏，如今被撕碎 | 激活 M5 温度反转 |

### 对话

- 对话占比: 约 42%
- 对话风格: 短促、压迫式、带强伦理指控
- 对话功能: 推动冲突、制造误判、揭示真相、完成打脸

### 叙述

- 人称视角: 第三人称限知，贴近孟砚舟
- 叙述温度: 前半冷虐，后半温柔补偿
- 距离感: 贴近主角身体痛感与心理崩塌
- 时态: 过去式为主，关键场景即时化

### 用词

- 色温倾向: 前半冷色（白炽灯、地下室、冷库、雨夜），后半暖色（咖啡馆、雪、阳光）
- 书面/口语比: 4:6
- AI 高频词检测: 原文存在少量“深吸一口气”“眼中闪过一丝”等套路表达，改编应替换为具体动作。

### 标点

| 标点 | 使用频率 | 功能 |
|------|---------|------|
| 逗号 | 高 | 控制短句节奏 |
| 省略号 | 中 | 表示未尽痛感、崩溃停顿 |
| 感叹号 | 中 | 虐点爆发、争吵 |
| 问号 | 高 | 伦理追问和反问 |
| 破折号 | 低 | 转折补充 |

> 改编 writer 须达到原文同量级的金句密度(容差 ±15%),由 editor 的 I4 维度验证。

## 代表性原句（Top 5）

1. “容寄月，我真恨你啊。” — 极简情绪核爆。
2. “我不想要你了。也不想要孟昕了。” — 关系断裂的短句砸脸。
3. “知道错了就要付出代价，不是吗？” — 主题与清算逻辑合一。
4. “这个世界没有如果。” — 火葬场拒绝原谅的核心句。
5. “我会幸福的。” — 补偿闭环，替代复仇后的空洞。

## 反面教材（绝对不能出现的表达）

- 长篇“命运安排”“宿命纠缠”式抒情。
- 让主角轻易原谅施害者。
- 把孩子之死写成误会或意外，削弱伦理罪。
- AI 味违禁词: “然而”、“总而言之”、“宛如命运的齿轮”、“眼中闪过一丝复杂/暗芒”、“深吸一口气”、“不禁”、“心中涌起”。
