# 文风 DNA

## 加载 genre 默认值

- genre: `urban_sweet_ceo`
- 基线: 第一人称男主视角，都市甜宠，短句高频，对话占比高，情绪通过生活物件和动作落地。
- 本文差异: 不是传统霸总男主，而是“中彩票普通男人 + 千亿女总裁女主”的性别权力反置。

## 一句话风格定性

朴素短句、低姿态男主旁白、密集生活物件承载深情，以“沉默照顾”和“女总裁回追”制造甜爽。

## 定量特征

### 句式

- 平均句长: 约 12-18 字
- 长短句比例: 短句 78% / 中句 18% / 长句 4%
- 偏好句式模板:
  1. “我没有 X。没有 Y，没有 Z。”
  2. “她 X。没有 Y。”
  3. “不是 X，是 Y。”
  4. “第 X 次/第 X 天，动作重复，成为习惯。”
  5. “从 A 到 B，从 C 到 D。”
- 忌用句式: 大段心理剖白、长复句解释、总分总议论文式总结。

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 排比短句 | 高频 | “没有辞职，没有买车，没有买房。” | 强化男主克制，制造反差 |
| 物件复现 | 高频 | “牛奶”“酸辣汤”“鸡汤”“卤味”“蛋炒饭” | 把爱落到可触摸的生活物 |
| 身份对比 | 高频 | “千亿女总裁，卖蛋炒饭？” | 形成甜宠爽点 |
| 回旋句 | 中高 | “合同结束。”/“给少了。” | 情感闭环 |
| 具象动作 | 高频 | “锅铲掉在地上。哐当一声。” | 用动作替代解释 |

### 对话

- 对话占比: 约 42%
- 对话风格: 简短、直给、带轻微网感和生活喜剧感
- 对话功能: 推动关系变化、制造反差、释放甜点、揭开暗恋信息。

### 叙述

- 人称视角: 第一人称为主；第11章切女主第一人称番外
- 叙述温度: 温暖克制
- 距离感: 贴近男主自卑与温柔，女主前期保持中距神秘
- 时态: 过去式叙事，关键场景用当下感短句加速

### 用词

- 色温倾向: 暖中带冷；沈墨染出场冷，家庭日常暖
- 书面/口语比: 2:8
- AI 高频词检测: 原文出现“然后”“像”“不由解释型句”较多；但核心段落基本靠短句和动作推进。后续仿写应避免“然而”“总而言之”“不禁”“心中涌起”。

### 标点

| 标点 | 使用频率 | 功能 |
|------|---------|------|
| 句号 | 极高 | 切短节奏，形成男主木讷感 |
| 引号 | 高 | 对话推动剧情 |
| 问号 | 中 | 萌娃与男女主关系推进 |
| 逗号 | 中低 | 很少使用长复句 |
| 省略号 | 低 | 只在尴尬、语塞处使用 |

## 代表性原句（Top 5）

1. “我买彩票中了两个亿。” — 极短高概念 Hook。
2. “然后关掉APP，继续吃泡面。” — 巨额财富与低欲望反差。
3. “合同结束。你自由了。” — 克制放手，后文回旋核心。
4. “陆时年，你当年给少了。” — 女主回追的爽点开关。
5. “从夜市走到家，从黑夜走到天亮。从五年走到一生。” — 甜宠终章的抒情收束。

## 反面教材（绝对不能出现的表达）

- 油腻霸总腔：“女人，你成功引起了我的注意。”
- 大段解释男主多么深情，而不提供具体动作。
- 把女主写成只会被救的弱者，削弱她东山再起能力。
- AI 味违禁词: “然而”、“总而言之”、“宛如命运的齿轮”、“眼中闪过一丝复杂/暗芒”、“深吸一口气”、“不禁”、“心中涌起”。
