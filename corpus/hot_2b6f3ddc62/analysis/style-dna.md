# 文风 DNA

## 一句话风格定性

高网感、快节奏、弹幕吐槽驱动的都市豪门爽文；第一人称女主冷静算账，短句打脸，情绪不往爱情里落，往钱、证据、继承权上落。

## 定量特征

### 句式

- 平均句长: 18-24 字
- 长短句比例: 约 3:7
- 偏好句式模板:
  1. “我 + 动作 + 结果”: “我接过支票，折好，放进钱包。”
  2. “对方误判 + 我冷静反问”: “所以呢？”
  3. “证据名词 + 直接陈列”: “这是陈斌医生过去一年的银行流水。”
  4. “弹幕吐槽 + 剧情偏航”: “剧情崩了！彻底崩了！”
  5. “一句利落结算”: “这波血赚。”
- 忌用句式: 长篇心理剖白、诗化抒情、命运式总结、古风比喻。

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 金钱物化 | 高频 | “这可是我的两个小财神爷啊！” | 把孕球从狗血伦理转为爽文资产 |
| 弹幕插科打诨 | 高频 | “剧情乱成一锅粥了，大家趁热喝了吧” | 降低狗血压力，增加追读笑点 |
| 反讽 | 高频 | “不愧是母子。” | 女主不哭诉，直接冷评 |
| 身体崩塌描写 | 中频 | “脸色惨白，浑身发抖” | 让打脸有可视反馈 |
| 利益对照 | 高频 | “五千万替身费，换来万亿家产和龙凤胎” | 强化血赚爽点 |

### 对话

- 对话占比: 约 42%
- 对话风格: 短促、针锋相对、带网感冷幽默
- 对话功能: 推动情节、制造打脸、直接展示权力关系变化

### 叙述

- 人称视角: 第一人称
- 叙述温度: 冷静、现实、带吐槽感
- 距离感: 贴近女主即时判断
- 时态: 过去式叙事为主，弹幕为即时现在感

### 用词

- 色温倾向: 中性偏冷，爽点处转热
- 书面/口语比: 3:7
- AI 高频词检测: 原文出现“深深吸了一口气”等少量套路表达，但主体仍是网文短句和具体动作。

| 对仗反讽式 | 0.9 | “三年替身换五千万本来以为已经赚翻了，没想到天降双份彩票。” | “【旧收益】；【新收益升级】。” |

> 改编 writer 须达到原文同量级的金句密度(容差 ±15%),由 editor 的 I4 维度验证。

## 代表性原句（Top 5）

1. “打什么胎？这可是我的两个小财神爷啊！” — 核心爽点转译，孩子=资产。
2. “有些东西没了，可就真没了。” — 信息差打脸，短句留钩。
3. “凭他们是陆尘沅这辈子，唯一的孩子。” — 权力博弈中的价值锚点。
4. “陆总，现在，你信了吗？” — 检查报告后的低声打脸。
5. “五千万替身费，换来万亿家产和龙凤胎！血赚！” — 结尾读者代餐式总结。

## 反面教材（绝对不能出现的表达）

- 大段“我其实还爱他”的恋爱脑剖白。
- 古言式宿命词: “红尘”“宿命”“命运齿轮”。
- 抽象控诉: “他们伤害了我脆弱的心灵”。
- 过度圣母: “我愿意成全他们的爱情”。
- AI 味违禁词: “然而”、“总而言之”、“宛如命运的齿轮”、“眼中闪过一丝复杂/暗芒”、“深吸一口气”、“不禁”、“心中涌起”。
