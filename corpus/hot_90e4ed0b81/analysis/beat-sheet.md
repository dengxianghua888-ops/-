# Beat Sheet 节拍器

## 全文概况

- 总字数: 约 11800 字
- 节拍数: 12 幕
- 核心母题（Logline）: 蒙冤牺牲的缉毒女警沈云澜死后五年，被迫旁观前夫将她当叛徒，直到毒枭公审爆出真相，前夫追查内应、洗清她污名，最终以死亡赎罪，而她选择不再回头。
- 情绪模式: 死亡蒙冤 → 二次伤害 → 真相裂缝 → 触底确认 → 反查凶手 → 公开昭雪 → 悔恨清算 → 冷静离开
