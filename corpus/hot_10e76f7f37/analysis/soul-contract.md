# 爆款神髓合约模板 (V4)

## 1. 读者承诺

- **一句话承诺**: 让读者看到被嫌弃的迟钝“野鸡精”带着五个萌崽被误解后，最终以凤凰真身救夫救族，完成追妻、打脸、团圆三重补偿。
- **读者愿意追读的理由**: 前半的和离、女配挑衅、男主离开都被逆鳞和弹幕暗示“另有隐情”，读者会为了真相与男主悔爱继续读。
- **最终必须兑现的体验**: 凤晴不是被怜悯收留，而是凭自身凤凰身份成为敖赢和龙族的救命者；一家五崽必须团圆。

## 2. 情绪债

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|
| 敖赢以“不能生”为由和离 | Beat 1 | 憋屈、误会 | 五崽破壳喊爹，证明她早已生下龙嗣 |
| 白瑶骂凤晴傻子、野鸡精 | Beat 3-4 | 恨、想看打脸 | 逆鳞弹飞白瑶，凤凰身份彻底压过兔族公主 |
| 敖赢称凤晴为外人 | Beat 3 | 心疼 | 真相证明他是为护她赴死，并承认只爱她 |
| 敖赢再次离开妻儿 | Beat 8 | 心碎、愤怒 | 弹幕揭示大天劫死局，离开变成保护 |
| 龙族长老骂凤晴废物扫把星 | Beat 11 | 愤怒 | 凤晴挡天劫救全族，长老不再催纳妾 |
| 凤晴童年被娘亲抛弃 | Beat 2,8 | 心疼 | 她没有抛弃崽崽，并与敖赢一起寻找亲娘 |

## 3. 爽点因果链

```text
施害者种因: 敖赢和离、白瑶挑衅、长老轻视，全部把凤晴定义为无用野鸡精。
主角表面承受: 凤晴因迟钝不争辩，带着五颗龙蛋独自离开，误以为自己和孩子被抛弃。
规则反身应用: 龙族重视血脉和强者，凤晴先用五崽证明血脉，再用凤凰真身证明强者身份。
崩塌/清算: 白瑶失去上位资格，长老被凤凰救族打脸，敖赢为误伤妻儿痛悔。
余味/补偿: 敖赢交位、陪凤晴游历寻母，一家团圆，凤晴从被弃者变成被珍重者。
```

## 4. 道德坐标

- **读者站队对象**: 凤晴和五个刚出生的龙崽。
- **反派必须被惩罚的理由**: 白瑶违反伴侣边界、羞辱弱者、诬陷孩子血脉；长老以族群利益压迫个体；敖赢的问题是隐瞒造成伤害，必须用悔恨和行动补偿。
- **主角可被允许的狠度边界**: 凤晴可以逃、可以拒绝、可以带崽自保；不能主动伤害无辜，不能用孩子报复敖赢。

## 5. 主角姿态

- **核心姿态**: 迟钝天然 + 母性坚定 + 关键时刻破釜沉舟。
- **语言姿态**: 短句直给，字面理解羞辱，少控诉。
- **行动姿态**: 前期被动误解，中期主动带崽逃，后期主动归还逆鳞并挡劫。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 女主“迟钝但护崽” | 这是喜剧与泪点共存的根 | 女主至少 3 次字面误解，至少 2 次为崽主动行动 |
| 五个孩子/蛋的具体数量 | 数字带标题点击欲和萌点密度 | 标题/正文必须有明确多胎数字 |
| 逆鳞级唯一保命物 | 男主爱意必须有硬证据 | 前 30% 给出，后 80% 归还并救命 |
| 弹幕前误导后揭真相 | 追读依赖信息差翻转 | Beat 1-6 误导，Beat 9 反转揭示 |
| 终局凤凰身份 | 最大爽点是身份升维 | 前文有黑毛/鸟/翅膀伏笔，终局涅槃 |
| 男主不是移情而是赴死 | 甜宠结尾成立的道德基础 | 必须解释和离、联姻、拒接妻儿的保护逻辑 |

## 8. 失败预警

- **最容易丢的神髓**: 把凤晴写聪明后，白瑶挑衅和误会喜剧都会失效。
- **一旦丢失会导致**: 前半变成普通雌竞虐文，后半凤凰重生像外挂。
- **写作时补救方式**: 每个虐点后安排一个迟钝反差动作；每个甜点前埋一个男主保护证据。
