# Beat Sheet 节拍器

## 全文概况

- 总字数: 约 10500 字
- 节拍数: 14 幕
- 核心母题（Logline）: 清醒豪门妻子江雾发现丈夫边界感转移给女特助后，为保住尊严与人生主动离婚出逃，面对父母利益捆绑、丈夫维护第三者和失子痛苦，最终让丈夫悔恨失控，自己在异国重获幸福。
- 情绪模式: 甜蜜旧账 → 越界羞辱 → 孤立压迫 → 装乖设局 → 流产出逃 → 追妻火葬场 → 新生补偿
