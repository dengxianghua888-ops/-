# 文风 DNA

## 一句话风格定性

高情绪密度的第一人称家庭伦理爽文：短句推进、强对话压迫、身体痛感密集，以“被污名化的母亲”视角制造憋屈，再用公开证据完成阶梯式打脸。

## 定量特征

### 句式

- 平均句长: 16-22 字
- 长短句比例: 约 3:7
- 偏好句式模板:
  - “可/却 + 反向事实”
  - “我 + 身体反应 + 动作”
  - “他说/她说 + 指责句”
  - “直到/下一秒 + 反转动作”
  - “不是……是……”纠偏句式
- 忌用句式: 长篇议论、总分总说教、复杂心理独白、抽象抒情大词

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 对比反讽 | 高频 | “他语气温柔，却一把拔掉了我的氧气管。” | 温柔语气与杀人动作对撞 |
| 身体物理化 | 高频 | “浑身的血液凉透。” | 把恐惧具体化 |
| 重复强调 | 中频 | “快了……快了。” | 增强压迫与临场感 |
| 公共目光 | 中频 | “所有人看我的眼神就像在看疯子。” | 放大社死屈辱 |
| 物象锚点 | 高频 | 红痣、氧气管、监控、大屏幕、警徽 | 让真相可视化 |

### 对话

- 对话占比: 约 45%
- 对话风格: 短促、压迫、指责密集，反派台词多用道德审判
- 对话功能: 推动情节、制造污名、公开打脸、完成情绪反转

### 叙述

- 人称视角: 第一人称
- 叙述温度: 前冷后烈，压迫段痛感强，反杀段冷静
- 距离感: 贴近女主身体感受
- 时态: 过去式为主，重生后线性推进

### 用词

- 色温倾向: 冷色偏多，血、雨、冰、警徽、大屏幕形成冷硬质感
- 书面/口语比: 3:7
- AI 高频词检测: 原文出现“眼底闪过一丝”等套路表达，改编应清洗；“然而”“总而言之”等明显 AI 连接词未形成风格核心

### 标点

| 标点 | 使用频率 | 功能 |
|------|---------|------|
| 句号 | 高频 | 短句落点，形成快节奏 |
| 引号 | 高频 | 对话压迫和打脸 |
| 省略号 | 中频 | 临终、求救、崩溃时留白 |
| 问号 | 中频 | 质问和道德审判 |
| 感叹号 | 低中频 | 高潮喊话，不滥用 |

| 物理化感受式 | 2.4 | “听到他们要把我的女儿送走，我浑身的血液凉透。” | “【消息】+【身体部位/血液】+【冷/痛动作】。” |

> 改编 writer 须达到原文同量级的金句密度(容差 ±15%),由 editor 的 I4 维度验证。

## 代表性原句（Top 5）

1. “他语气温柔，却一把拔掉了我的氧气管。” — 体现温柔与谋杀的反讽撞击。
2. “我看得清清楚楚，我的女儿眉间没有红痣！” — 体现物证锚点和母亲确认。
3. “我会好好‘关照’你的宝宝。” — 体现绿茶威胁的钩子。
4. “正好这宴会厅有大屏幕，就让你们一次性看个够。” — 体现公开审判爽点。
5. “陆砚修，我们没有以后了，离婚吧。” — 体现女主清醒决绝。

## 反面教材（绝对不能出现的表达）

- 大段解释“我为什么痛苦”，应改为动作、血痕、雨夜、婴儿哭声。
- 反派突然良心发现，破坏清算逻辑。
- 女主圣母原谅丈夫或父母。
- AI 味违禁词: “然而”、“总而言之”、“宛如命运的齿轮”、“眼中闪过一丝复杂/暗芒”、“深吸一口气”、“不禁”、“心中涌起”
