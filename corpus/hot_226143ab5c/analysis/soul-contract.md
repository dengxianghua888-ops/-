# 爆款神髓合约模板 (V4)

> Phase 1 必填。它是后续改编、写作、审校、定稿的最高优先级约束；若与普通 Beat 指令冲突，以本合约为准。

## 1. 读者承诺

- **一句话承诺**: 让一个被丈夫和亲生儿子逼死的母亲彻底断情，复活女儿，站到新世界高处，看施害者悔疯却永远得不到原谅。
- **读者愿意追读的理由**: 前半每一笔羞辱都明确对应后半报应，读者知道阮清秋不是软弱，而是在为女儿忍到任务结束。
- **最终必须兑现的体验**: 阮清秋不复合、不认子、不心软；佳佳复活；父子被她拒绝并彻底抹杀。

## 3. 爽点因果链

```text
施害者种因: 顾振海以爱与权力为名包庇白雅琴，儿子抛弃母亲，白雅琴不断诬陷投毒。
主角表面承受: 阮清秋为复活佳佳忍满一年，承受遗物被毁、骨灰被夺、掏粪羞辱、抽血与亲人惨死。
规则反身应用: 他们曾让她去死、不要她；现代线她让他们去死，永远不许靠近佳佳。
崩塌/清算: 举报材料引爆，白雅琴被杀，顾振海入狱自杀，小军病死，父子求原谅失败。
余味/补偿: 阮清秋带着复活的佳佳，在现代拥有集团、阳光和安宁。
```

## 4. 道德坐标

- **读者站队对象**: 阮清秋和佳佳。
- **反派必须被惩罚的理由**: 他们践踏母亲底线、滥用公权、毁灭无辜亲人、亵渎亡者，并在事后要求受害者体谅。
- **主角可被允许的狠度边界**: 可以拒绝、报复、送走、清算、让施害者生不如死；不能主动伤害无辜者，不能为了复仇牺牲佳佳。

## 5. 主角姿态

- **核心姿态**: 冷静断情、忍辱蓄证、母性底线不可碰。
- **语言姿态**: 短句砸脸，少解释，多切断关系。
- **行动姿态**: 前期承受换时间，中段收证，死亡脱离，后期降维拒绝。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 儿子亲口盼母死 | 开篇最大伦理钩子，也是 M3 回旋根 | 前 300 字必须出现亲子背刺 |
| 女儿遗物被亵渎 | 触发母亲底线，支撑后续狠度 | 必须有亡女遗物被踩/毁/污 |
| 女主为复活女儿忍满任务 | 解释她为何不立刻离开 | 必须有倒计时或不可违抗目标 |
| 顾振海迟到悔悟无效 | 火葬场爽点的核心 | 男主悔悟发生在女主死亡/离开后 |
| 现代线阮清秋不原谅 | 最终读者承诺 | 结尾不得复合、不得认子、不得开放式原谅 |
| 佳佳复活并被保护 | 补偿闭环 | 结尾佳佳必须安全幸福 |

## 8. 失败预警

- **最容易丢的神髓**: 把顾振海写成“深情但误会”而不是“亲手施害”。
- **一旦丢失会导致**: 读者无法接受女主狠心，也无法获得火葬场爽感。
- **写作时补救方式**: 增加顾振海主动选择白雅琴、主动牺牲阮清秋和佳佳的具体场景，让每次悔恨都对应一笔旧债。
