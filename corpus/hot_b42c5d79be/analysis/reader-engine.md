# 读者心理引擎模板 (V4)

> Phase 1 必填。逐 Beat 记录读者心理状态,供 blueprint 和 writer 控制追读欲。

## 总览

- **核心读者期待**: 想知道女主死亡真相、钟越到底是不是渣夫、季棠棠如何被清算。
- **主要恨点**: 季棠棠装弱夺爱并买凶杀人；钟越前半冷血包庇；刀哥残忍厌女。
- **主要爽点**: 录音公开、季棠棠供出真凶、真实尸检报告曝光、刀哥被诱捕。
- **追读驱动力**: 想看真相 + 想看打脸 + 想看悔恨 + 想看迟来深情是否成立。

## 空 Beat 排查

无完全空 Beat。Beat 3 和 Beat 11 情节推进较慢，但承担温度反转和情绪偿还功能，不能删除；改编时可压缩细节，但必须保留“照片裂缝”和“逐项解释”两个功能点。
