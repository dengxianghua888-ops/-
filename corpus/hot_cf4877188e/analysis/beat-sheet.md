# Beat Sheet 节拍器

## 全文概况

- 总字数: 约 23000 字
- 节拍数: 14 幕
- 核心母题（Logline）: 一个被母亲临终送回傅家的三岁小女孩，为了吃饭和证明妈妈清白，面对二房污名、伪证和舆论围剿，最终用母亲留下的证据链让冷血傅家承认错误并接她回家。
- 情绪模式: 极致心疼 → 冷家破冰 → 恶意围剿 → 证据反杀 → 迟来道歉 → 回家补偿

- **核心事件**: 三岁半小奶团雨夜抱兔子上门，称傅临川欠三年奶粉钱，兔子裂开露出录音笔。

- **情绪强度**: 8.7/10
- **情绪方向**: ⚡突变
- **冲突类型**: 大转折
- **悬念钩子**: 录音笔里到底藏着什么，孩子和傅临川是什么关系。
- **叙事速度**: 快
- **对话占比**: 35%
- **reversal_mechanism**: [M2, M6]
- **hook_strength**: 8.6/10（极端度 2.5/3，信息密度 2.8/3，悬念 1.8/2，利落度 1.5/2）
- **关键句**: “妈妈说，爸爸欠我三年奶粉钱。”
- **原文摘录**: 傅家人人冷漠，亲情淡得像会议室里的白开水。直到雨夜，一个三岁半的小奶团抱着兔子站在傅家门口。她踮脚按门铃，奶声奶气地说：“我找傅临川。”小姑娘从兔子背包里摸出一张皱巴巴的医院缴费单，又认真补了一句：“妈妈说，爸爸欠我三年奶粉钱。”下一秒，她怀里的兔子玩偶掉在地上。玩偶肚子裂开，露出半截旧录音笔。
