# 爆款神髓合约模板 (V4)

## 1. 读者承诺

- **一句话承诺**: 让一个自以为能拿捏前妻的前夫，亲眼看见她已被更强、更正当、更爱她的人接住，并为旧债新债一起付出代价。
- **读者愿意追读的理由**: 前半压迫足够具体：合同羞辱、旧日流产、抢走满月孩子、伪造亲子鉴定，每一笔都要求强偿还。
- **最终必须兑现的体验**: 前夫和绿茶秘书双双入狱、身败名裂，女主不原谅不回头，带着孩子和现任走向新生活。

## 3. 爽点因果链

```text
施害者种因: 黎初长期把安宁的痛苦解释成闹脾气，纵容林梓微，流产后仍怪女主，离婚后又抢走小宝。
主角表面承受: 安宁为了合作、孩子和安全多次忍耐，反复解释小宝不是黎初的孩子。
规则反身应用: 黎初用“规矩/鉴定/身份”压人，最终被谢行舟的真实身份、法律证据和司法程序反压。
崩塌/清算: 谢行舟军车截停，林梓微伪造鉴定败露，旧流产案重查，黎初和林梓微入狱，黎氏破产。
余味/补偿: 安宁探监补刀后轻松离开，与谢行舟看电影，未来转暖。
```

## 4. 道德坐标

- **读者站队对象**: 安宁、小宝、被长期情感控制的受害者。
- **反派必须被惩罚的理由**: 黎初违反婚姻忠诚、母子安全、法律边界和基本尊重；林梓微直接伤害孕妇并伪造鉴定。
- **主角可被允许的狠度边界**: 可以起诉、补刀、看反派身败名裂；不能主动伤害无辜或为了复仇牺牲小宝。

## 5. 主角姿态

- **核心姿态**: 清醒离开，护子到底，拒绝圣母。
- **语言姿态**: 短句反问、冷静定性、情绪峰值直接骂。
- **行动姿态**: 前期避让，危机中保留求援线索，后期借法律完整清算。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 前夫把离婚当“闹” | 这是全文误判爽点的根 | 开篇和中段至少两次出现“闹/服软/回来”逻辑 |
| 旧流产债 | 提供反派不可原谅的道德底座 | 必须有孕期受害、前夫错判、女主旧痛 |
| 抢走孩子 | 触发最高情绪峰值 | 必须有孩子被夺和母亲无力阻止段 |
| 现任身份保密且强于前夫 | M2/M6 的核心 | 前半查不到，后半公开证件/权力实体 |
| 伪造亲子鉴定 | M3 反身清算工具 | 鉴定必须从压迫证据变成反派罪证 |
| 女主不原谅 | 结尾爽感来源 | 不能复合，不能替前夫开脱 |

## 8. 失败预警

- **最容易丢的神髓**: 把前夫写成单纯后悔深情，弱化其违法和自负。
- **一旦丢失会导致**: 读者会质疑女主狠心，反而不站女主。
- **写作时补救方式**: 增加前夫“我都是为你好/你只是在闹”的误判台词，并让每次误判造成实际伤害。
