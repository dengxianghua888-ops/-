# 文风 DNA

## 一句话风格定性

高密度家庭伦理爽文：第一人称冷叙述，短句切割，物件细节压迫，靠对话羞辱和数字筹码推动反转。

## 定量特征

### 句式

- 平均句长: 16-22 字
- 长短句比例: 短句 72% / 中句 24% / 长句 4%
- 偏好句式模板:
  - “我 + 动作 + 具体物件。”
  - “他/她 + 直接羞辱台词。”
  - “数字 + 物件 + 道德反差。”
  - “不是 A。是 B。”
  - “你不是说 X 吗？现在 Y。”
- 忌用句式:
  - 长篇心理解释
  - 抽象抒情总结
  - “命运/宿命”式宏大旁白

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 数字反差 | 高 | “三十万”“八十万”“三百万” | 把伦理恶转换为可计算筹码 |
| 物件反讽 | 高 | 塑料骨灰盒 / 金丝楠木狗骨灰盒 | 强化“人不如狗” |
| 镜像回旋 | 高 | 救命钱给狗 → 遗产给狗 | 爽点闭环 |
| 身体物理化 | 中高 | “生生呕出一口鲜血”“后槽牙” | 把憋屈落到身体 |
| 冷幽默补刀 | 中 | “切整齐点，别连着皮” | 形成黑色爽感 |

### 对话

- 对话占比: 约 45%
- 对话风格: 粗粝、直接、口语化、攻击性强
- 对话功能: 制造恨点、推动借贷/逼钱/揭露、完成回旋金句

### 叙述

- 人称视角: 第一人称
- 叙述温度: 冷峻
- 距离感: 贴近主角身体感受，但不沉溺内心
- 时态: 过去式为主，高潮段接近现场纪实

### 用词

- 色温倾向: 冷中带血色
- 书面/口语比: 2:8
- AI 高频词检测: 原文偶有“深吸一口气”，但整体以网文短句为主；改编需规避“然而”“总而言之”“心中涌起”等。

### 标点

| 标点 | 使用频率 | 功能 |
|------|---------|------|
| 句号 | 极高 | 短句砸脸，制造冷感 |
| 感叹号 | 中高 | 反派咆哮、崩溃 |
| 问号 | 中 | 逼问与反问 |
| 引号 | 极高 | 对话推进剧情 |
| 省略号 | 低 | 少用拖沓情绪 |

### 金句密度(V3 新增第 7 维)

| 金句类型 | 频次(次/千字) | 代表原文 | 结构模板 |
|---------|-------------|---------|---------|
| 反问-自答式 | 0.8 | “现在你也是个累赘了，谁来换你？” | “【对方旧规则】?【反向落回对方】。” |
| 对仗反讽式 | 1.1 | “老伴的钱，就算全喂给街边的野狗，也比给那个养不熟的白眼狼强。” | “【宁愿给低位对象】,也不给【背叛者】。” |
| 物理化感受式 | 1.4 | “我浑身发抖”“生生呕出一口鲜血” | “【情绪】+【身体】+【具象反应】。” |

> 改编 writer 须达到原文同量级的金句密度(容差 ±15%),由 editor 的 I4 维度验证。

## 代表性原句（Top 5）

1. “用一个半死不活的老东西换八十万，这笔买卖多划算！” — 极端伦理倒置。
2. “这可是你自己把脖子伸进绞肉机的。” — 反击启动句。
3. “收呗。反正你连亲爹的命都能不管，一套房子算什么？” — M3 回旋。
4. “现在你也是个累赘了，谁来换你？” — 父亲被物化后反向砸回儿子。
5. “全部捐给流浪狗救助站。” — 终局精神补刀。

## 反面教材（绝对不能出现的表达）

- “我心中涌起一阵复杂情绪。”
- “命运终于给了他惩罚。”
- “他眼中闪过一丝懊悔。”
- “毕竟血浓于水，我还是心软了。”
- AI 味违禁词: “然而”、“总而言之”、“宛如命运的齿轮”、“眼中闪过一丝复杂/暗芒”、“深吸一口气”、“不禁”、“心中涌起”
