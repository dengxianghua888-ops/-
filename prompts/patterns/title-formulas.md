# 标题公式库（Title Formulas）— V3

> 番茄/知乎短篇爆款的**标题即广告**,要在 20-35 字内完成"信息量+悬念+情绪"三件事。本文件归纳 5 种高复用标题公式,基于 37 篇语料的频次统计。dissector 识别原文的公式类型,adapter 生成新标题时优先套用同公式或同题材推荐公式。
>
> **番茄平台硬约束**:标题 ≤30 字;避免出现"然而""然后"等 AI 味词;可以用标点(?!？,),不可用全角逗号过多(≤2 个)。

---

## 公式枚举与频次(样本:37 篇)

| ID | 公式名 | 频次 | 占比 |
|----|--------|-----|------|
| T1 | 因果反转式 | ≥12 篇 | 32% |
| T2 | 身份反转式 | ≥8 篇 | 22% |
| T3 | 生死悖论式 | ≥6 篇 | 16% |
| T4 | 数字对比式 | ≥5 篇 | 14% |
| T5 | 极致标签式 | ≥4 篇 | 11% |
| 古言对仗式 | 古言专用 | ≥6 篇 | 16% |

> 标题可混合公式(如 T1+T4 = "我每月给女儿四千,她却只能啃馒头")。

## T1 · 因果反转式

### 结构

```
[被动遭遇/事件] + 后/却 + [我的主动反击] + 对方 疯了/悔疯了/慌了/灭门
```

### 识别关键词

- 连接词:"后""却""反而"
- 主语交替:【对方主动】→【我主动】
- 结尾情绪词:"疯了/悔疯了/慌了/杀疯了/笑疯了"

### 代表案例

- 《末世让我滚出基地后,所有人都死了》
- 《老公给我妈下药后,我杀疯了》
- 《瞒着老公空降公司,他竟带小三上台官宣,我当场笑疯》
- 《货主坑我超载罚三千,我拉走一吨沉香他疯了》
- 《物业涨租逼我走,全家撤场让他慌》
- 《因为落水老公没救我我提了离婚》
- 《一手捧红的男主播嫌我老,我砸钱转捧更年轻的弟弟》
- 《保他 30 万货还嫌我碍事?我撤单后他悔疯了》
- 《背尸六年为姐姐治病,我离开后她们疯了》
- 《夫君被断腿后,我摇魔丸爹娘杀疯了》

### 生成规则

1. 先写被动:谁干了什么坏事(≤15 字)
2. 再写主动:我用一个**具体动作**(不是"我反击"而是"我 XX")反击(≤12 字)
3. 结尾情绪词优先级:杀疯 > 笑疯 > 悔疯 > 慌了 > 全家撤场

### 适配题材

现代反转/家庭伦理/都市空降/末世大女主

## T2 · 身份反转式

### 结构

```
[主角的表层弱/边缘身份] + 却/然而 + [隐藏的反差事实]
```

### 识别关键词

- 弱势词:"假""对照组""空降""无名""一事无成"
- 反差词:"却""原来""其实"
- 强势词:"朋友多""国公之女""副总"

### 代表案例

- 《我是姐姐的对照组》
- 《相府假千金一事无成,可她朋友多啊》
- 《姐姐新生之时,是我的死亡之日》
- 《为高考后能继承千万遗产特寻失踪弟弟》
- 《她代号深渊》

### 生成规则

1. 选一个极致"表层弱"标签(假千金/对照组/空降员工/普通考生)
2. 暗示一个反差资源/身份(朋友多/国公血脉/副总职位)
3. 反差越**不对称**越爆(表层越弱,反差越强)

### 适配题材

古言宅斗/都市反转/大女主/甜宠

---

## T3 · 生死悖论式

### 结构

```
[死亡/消失事件] + 出乎意料的后续/未被发现的真相
```

### 识别关键词

- 死亡词:"死后""脱离世界""离开""消失""灭门"
- 后续词:"却""未发现""悔疯了""都死了"

### 代表案例

- 《我死后,老公亲手解剖了我的尸体,却没发现我怀孕了》
- 《背尸六年为姐姐治病,我离开后她们疯了》
- 《娘亲脱离世界后,父皇悔疯了》
- 《成为高考状元却接到断亲书后,我举报全家被灭门》
- 《末世让我滚出基地后,所有人都死了》

### 生成规则

1. 前半:极致死亡/消失事件(≤15 字)
2. 后半:最令施害者崩溃的"未被发现的真相"或"反向结果"
3. **标题必须暗示信息差**——有什么是活人不知道的?

### 适配题材

虐心/BE/灵魂复仇/家庭伦理

---

## T4 · 数字对比式

### 结构

```
[数字 1 的事实] + 却/可 + [数字 2 的反差事实]
```

### 识别关键词

- 金额词:"三千""四千""30 万""百人""一吨"
- 反差连接:"却""可""才"

### 代表案例

- 《我穷得吃不起饭,妈妈却说每月给我三千》
- 《保他 30 万货还嫌我碍事?我撤单后他悔疯了》
- 《我每月给女儿四千,她却只能啃馒头》
- 《五一订房嫌贵?可我有百人旅游团》
- 《货主坑我超载罚三千,我拉走一吨沉香他疯了》

### 生成规则

1. 选一个**具体、日常**的数字(不是"很多钱"而是"四千")
2. 反差不是简单的大小对比,而是**量级+情境的错位**(四千看似不少,但在"啃馒头"情境下显得荒唐)
3. 数字本身自带画面感(四千 → 月度生活费;一吨 → 物流重量;百人 → 团建规模)

### 适配题材

现代反转/家庭伦理/商战

---

## T5 · 极致标签式

### 结构

```
[极端形容词/身份标签] + 行为/冲突 + 强烈后果
```

### 识别关键词

- 标签词:"状元""老伴""小三""副总""魔丸""神明"
- 强后果:"灭门""杀疯""悔疯""官宣"

### 代表案例

- 《成为高考状元却接到断亲书后,我举报全家被灭门》
- 《老伴在 ICU 等救命,他拿手术费给宠物狗买墓地》
- 《瞒着老公空降公司,他竟带小三上台官宣,我当场笑疯》

### 生成规则

- 标签必须自带道德/伦理判断(状元=值得尊敬;老伴=应该照顾;小三=该被唾弃)
- 标签冲突越强,标题越爆("状元"+"断亲"、"老伴"+"宠物墓地")

### 适配题材

家庭伦理/都市反转

## 古言对仗式(古言专用)

### 结构

```
[4-8 字古意象 A] + [4-8 字古意象 B,与 A 对仗或反差]
```

### 识别特征

- 使用古诗词词汇:云/月/花/残/寒/梦/星/夜/春/别/忆
- 结构多为四字或六字排偶
- 不直接说情节,用**意象隐喻**剧情走向

### 代表案例

- 《不再是你的笼中雀》(意象:笼中雀 = 被困)
- 《东瓶西镜放,恨不能遗忘》(对仗 + 情绪)
- 《云满春山关残月》(云 vs 残月)
- 《残梦不暖九冬寒》(残梦 + 九冬寒,双重衰落)
- 《盼我流年,花满蹊径》(时间 + 花意象)
- 《纵有星光坠落时》(星光 + 坠落,转折)
- 《晚风别忆旧时人》(晚风 + 旧人)
- 《棠花落尽不相逢》(花落 + 不相逢)
- 《春和不负景明》(春和 + 景明,双正)
- 《花落月都星已沉》(花 + 月 + 星,三段式)

### 生成规则

1. 选两个**对位古意象**(一正一反 / 一盛一衰)
2. 字数可以 4-4 / 4-6 / 6-6
3. 不要用现代词(手机/网红/地铁)
4. 允许留白——古言标题不解释剧情

### 适配题材

古言 BE/古言甜宠/仙侠/宫斗

## 标题生成流程(adapter 使用)

```
Step 1: 读取 dissection.md 中识别的 genre + 机制清单
Step 2: 根据 genre 从上面对照表选 1-2 个优先公式
Step 3: 根据机制在标题中暗示(如 M1 死环 → 暗示"反杀";M4 灵魂线 → 暗示"死后")
Step 4: 生成 3 个候选标题,每个 ≤30 字,打分:
        · 信息密度(是否塞进冲突+主角+反差)
        · 悬念尖锐度(是否让人必须点开)
        · 情绪词强度(杀疯/悔疯/灭门...)
        · 平台适配(番茄:口语化;知乎盐言:略带文学)
Step 5: 选最高分输出为改编新标题
```

## 反面教材(标题 AI 味)

以下模式禁止出现在改编标题中:

- "我"字过度前置:"我我我..." → 前 2 字就有"我"是 OK,但整标题 ≥3 个"我"是 AI 味
- 抒情式开头:"当...的时候"/"那一天"/"如果..."
- 评论式结构:"论...的重要性"/"浅谈..."
- 过长的复合句:"我被 A 然后 B 所以 C 最后 D"(番茄标题超 30 字直接截断)
- 无具体名词的形容词堆砌:"那场突如其来的绝望"
- 使用"命运""宿命""红尘"等大词作为主要构成(古言对仗式除外)
