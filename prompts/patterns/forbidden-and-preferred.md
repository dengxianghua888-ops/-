# 违禁词与偏好词库（Forbidden & Preferred）— V3

> 本文件整合当前产线分散在 writer.md / editor.md / finalizer.md / workspace.yaml 中的违禁词,并**按 genre 分层**扩充,补充偏好词汇库与情绪物理化素材库。产线各阶段按 genre 动态加载对应子集。
>
> **硬规则**:所有 genre 共享"全局硬性违禁词";额外的 genre-specific 违禁词/偏好词叠加使用。

---

## 一、全局硬性违禁词(所有 genre 共用)

出现即扣分、必须替换。源自当前 writer.md / finalizer.md:

| 违禁词 | 出错原因 | 建议替换 |
|-------|---------|---------|
| 然而 | AI 过渡词 Top 1 | 用"但""可""只是"或直接去掉连接词 |
| 总而言之 | AI 总结式 | 删除 |
| 不禁 | AI 惯性 | 删除或改为具体动作("手抖了一下") |
| 心中涌起 | AI 抒情 | 改为身体反应 |
| 深吸一口气 | AI 最高频 | 改为具体动作/删除 |
| 宛如命运的齿轮 | AI 滥用比喻 | 删除 |
| 眼中闪过一丝 XX | AI 惯性表情 | 改为具体眼神描写 |
| 嘴角微微上扬 | AI 表情套路 | 改为具体笑容描写("他笑了一下,嘴角往下拉"这类破常) |
| 不由得 | AI 语气词 | 删除或改为动作 |
| 颤抖着说道 | AI 对话标签 | 改为具体动作("他声音发抖,说——") |
| 眼神变得凌厉/复杂 | AI 表情 | 改为具体眼神细节 |
| 空气仿佛凝固 | AI 滥用 | 改为具体人物反应 |
| 无论如何 | AI 连接 | 删除 |

## 二、全局软性违禁词(高频使用即违禁)

允许偶尔出现,但每篇 ≤2 次,连续段落不可重复使用:

- 悄然
- 缓缓
- 默默
- 微微
- 淡淡
- 轻轻

## 二.五、叙述拐杖词(soft-ban,全篇≤5处)

与全局软性违禁词同级别管理。这些"告知型"句式削弱叙事张力,优先用动作/对话替代:

| 模式 | 替代策略 |
|------|----------|
| 她知道/他知道 | 用动作暗示认知 |
| 她明白/他明白 | 用沉默或微表情 |
| 她意识到/他意识到 | 用行为突变 |
| 她心想/他心想 | 直接写内心碎句(不加引导词) |
| 她终于明白 | 用一个精准动作替代 |
| 他这才知道 | 用对话中的停顿/转折 |

检测规则: 正则 `(她|他)(知道|明白|意识到|清楚|心想|暗忖|终于明白|这才知道)`
- 全篇命中 >5 次 → soft-fail(warning,critic 必须标注,不阻断产线)
- 全篇命中 >8 次 → hard-fail(必须返工)

## 三、全局 AI 句式禁区

- 连续段落用同一句式开头(如连续 3 段都是"我..."或都是"他...")
- "不仅...更..."超过 2 次
- 总分总说教结构("首先...其次...最后...")
- 段落之间过度使用连接词("于是""因此""所以")

## 四、Genre-Specific 违禁词 / 偏好词

### G1 · modern_reversal(现代反转/反贪爽文)

**额外违禁**(在通用违禁基础上加):
- 命运、宿命、红尘(现代语境违和)
- 浓妆艳抹、秋水般的眼眸(言情古风)
- 所谓的 XX、所谓(AI 评论式)

**偏好词库**:
- 动作动词:砸、撂、掀、拍、怼、堵、杀疯、笑疯、崩
- 物件名词(现代社会感):完税单、合同、POS 机、监控、录音、朋友圈
- 情绪物理化:见下方"情绪物理化素材库"

**句式偏好**:
- 平均句长 15-20 字
- 短句 70%+
- 对话占 35-45%
- 第一人称(我)主导

### G2 · ancient_BE(古言 BE/虐恋)

**额外违禁**:
- 现代词全套:手机、电话、公司、地铁、网红、KPI、社保、微信、朋友圈
- 网感动词:杀疯、笑疯、怼、扎心、扎马步
- 外来词:KO、battle、low、high
- 现代度量衡:公斤、公里、元(用两、里、贯/文替代)

**偏好词库**:
- 意象词:残月、冷雪、孤灯、寒梅、枯荷、长街、青砖、药香、血丝
- 器官隐喻(BE 核心):心尖、骨缝、指甲、瞳仁、血脉
- 动作古意:望、凝、叹、顿、怔、颤、踉跄、指尖颤
- 时间感:一瞬、刹那、经年、半生、三日、一晃
- 颜色:朱红、鸦青、霜白、血色

**句式偏好**:
- 平均句长 25-35 字(比现代反转长)
- 破句高频(一句一刀):"我被生生阉割。/ 孩子被打掉了。/ 第九次。"
- 允许半文半白:"她的指尖,已凉了三日"
- 留白高频(省略号/破折号)

### G3 · ancient_sweet(古言甜宠/双强)

**额外违禁**:同 G2 的现代词禁用
- 但允许部分**轻量现代语感词**(如"磕到了"这类网感词,在"钓系总裁"这类标题已有先例)—— 是**都市甜宠**而非古言甜宠

**偏好词库**:
- 甜宠意象:红绸、玉镯、梨花、酒酿、酥饼、帕子、金钗、罗裙
- 温度词:暖、软、甜、糯、酥、蜜
- 动作:揉、抱、捏、逗、护、挡、蹭

**句式偏好**:
- 平均句长 20-28 字
- 对话占比高(50%+)
- 发糖密度:每 800-1200 字一次显性发糖(拥抱/深情对视/保护行为)

### G4 · apocalypse_heroine(末世大女主)

**额外违禁**:
- 过度抒情:"她的眼泪像珍珠般"、"她心中五味杂陈"——末世文必须冷硬
- 白莲花句式:"我不怪你,你有你的难处"(大女主不原谅)

**偏好词库**:
- 世界观词:辐射、异兽、基地、庇护所、能量核心、S 级、SSS 级、觉醒值、末日第 X 天
- 冷硬动作:碾、斩、撕裂、踏、踹、镇压
- 身份符号:神明、王、祭品、吞噬者、污染源、净化体

**句式偏好**:
- 平均句长 15-22 字(比现代反转略长,因为有 worldbuilding)
- 设定密度高:前 500 字必须建立至少 3 个世界观概念
- 工具理性叙述(冷漠)

### G5 · family_ethics(家庭伦理复仇)

**额外违禁**:
- 和稀泥词:"毕竟是一家人"、"血浓于水"(和仿写主旨冲突)
- 原谅/和解套路("我终于理解了他的苦")

**偏好词库**:
- 家庭符号:母亲十二年的积蓄、保温杯、保险柜、存折、房本、遗嘱、户口本
- 伦理标签:啃馒头、病床、手术费、养老金、补习费
- 情绪动作:跪、抓、嘶吼、扑、抱着

**句式偏好**:
- 平均句长 14-18 字(更短促,情绪密度高)
- 对话占 40%+(家庭戏靠对话推)
- 第一人称女主视角(95%+ 案例)

### G6 · urban_sweet_ceo(都市甜宠/霸总)

**额外违禁**:
- 硬核 AI 词:"瞳孔地震""血脉偾张"(小说圈梗,原文用则 OK,仿写勿滥用)

**偏好词库**:
- 场景:会议室、玻璃幕墙、加长车、品牌 Logo、珠宝盒
- 人设:钓系、清冷、禁欲、小奶狗、狐狸精、御姐
- 动作:圈、锁、拉近、掐住下巴、手背抵唇

**句式偏好**:
- 平均句长 18-25 字
- 对话占 45%+
- 第一人称女主
- 语气可以"网感"("磕到了""撩疯了""笑不活了")

## 五、情绪物理化素材库(按强度)

> writer 在情绪强度 ≥7 的 Beat 必须使用物理化表达。本库分 7 大核心情绪,每类提供 5-8 个可选表达,允许 writer 组合或微调。

### 愤怒
- 后槽牙咬得咯吱响
- 太阳穴的青筋跳了三下
- 指甲掐进掌心
- 手背上的青筋鼓起来
- 喉咙里像卡了块铁
- 指节一根一根攥白
- 耳根子烫得发紧

### 绝望
- 耳鸣阵阵
- 指尖止不住地发麻
- 眼前发黑
- 腿像踩在棉花上
- 身体不受控制地发抖
- 血从身体里一寸寸抽走
- 喉咙里有个破洞,空气灌进去

### 紧张
- 手心全是汗
- 后背发凉
- 心跳堵到嗓子眼
- 舌头发硬
- 签字笔差点滑出去
- 膝盖在桌面下撞了一下
- 吞咽动作响得自己都听见

### 心痛
- 胸腔里像被泼了一整壶滚水
- 鼻腔发酸
- 喉咙像被人掐住
- 眼眶发烫但没有泪
- 心脏像被一只手攥着,一下一下
- 指尖冰到失去知觉
- 胃里翻江倒海

### 惊讶
- 筷子悬在半空
- 夹着的花生米掉回碗里
- 瞳孔剧缩
- 嘴巴张了张没合上
- 手里的杯子差点滑下去
- 呼吸卡在喉咙里
- 血液倒流般的冷意

### 恐惧
- 汗毛炸起来
- 头皮发麻
- 冷汗顺着脊椎流下去
- 心脏像被人攥住
- 脚底发软
- 耳朵里只剩心跳声
- 指头抠进桌沿的缝里

### 爽/痛快
- 一口浊气吐出来
- 整个人像卸了力
- 血液重新流动起来
- 肩膀塌下来
- 笑意从胸腔一直漫到眼底
- 指尖终于暖了
- 像多年压在肩上的石头被卸下

## 六、金句模板库(writer 与 finalizer 使用)

用于"金句密度"第 7 维度对齐。三类金句,每类给出结构模板:

### 反问-自答式
```
"【反问句】?【自答句,冷静陈述】。"

例:"你凭什么?就凭你是个什么狗屁'净化体'。"
例:"他听得到吗?他现在什么都听不到了。"
```

### 对仗反讽式
```
"【正向陈述,对方视角】;【反向事实,主角视角】。"

例:"我以为的浪漫奔赴,不过是亲眼见证丈夫出轨的刑场。"
例:"他说这是爱。但这种爱,把我送进了地狱。"
```

### 物理化感受式
```
"【情绪】+【具体器官/身体部位】+【具象动作】。"

例:"我的心,一点一点地沉入冰冷的深海。"
例:"胸腔里像被人泼了一整壶滚水,滚一下,就烫掉一块肉。"
```

## 七、使用接入

### dissector
- Step 3 Style DNA 第 7 维"金句密度":统计全文反问-自答/对仗反讽/物理化句式的出现频次(每千字 X 次)
- Step 5 文风 DNA 输出 `preferred_imagery_in_source: [...]`(从原文抽取的高频意象词)

### adapter
- blueprint.md 全局指令段加载:`genre-specific forbidden + preferred from workspace.yaml::genre_profiles.{genre}`
- 每个 Beat 的照镜子参考下方,新增一列"**本 Beat 可用偏好词/意象(从 style-dna.md 与本词库同 genre 子集)**"

### writer
- 写作前先加载:全局硬性违禁 + 当前 genre 的额外违禁 + 当前 genre 偏好词 + 物理化素材
- 写作中实时扫描违禁词
- 情绪强度 ≥7 的 Beat 必须使用至少 1 个物理化素材(来自本库)

### editor
- C4 AI 味检测:扫描全局硬性违禁(0 容忍)+ 当前 genre 额外违禁(0 容忍)
- C4 额外:软性违禁词单篇 ≤2 次
- I4 金句密度对齐:比对原文与定稿的金句三类频次,容差 ±15%

### finalizer
- Step 2a 违禁词终扫:按 genre 加载并逐行清洗
- Step 2e(新增)金句锐度打磨:如密度不足,按模板补 1-2 句
