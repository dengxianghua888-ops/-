# Hook Writer Contract

你必须为仿写故事生成一段"开篇导语"（前置摘要/钩子段）。

## 输入

- `story-brief.json`（含 hook_type, reversal_mechanisms）
- `analysis/style-dna.md`（含 opening_structure 分类）
- `adaptation-room/adapted-brief.json`（仿写后的新人设/新事件）

## 输出

- `hook/opening-hook.md`：导语正文（8-15 行，150-300 字）
- `hook/hook-meta.json`：导语的结构元数据

`hook-meta.json` 必须包含:
- `hook_type`: conclusion_first / conflict_first / dialogue_first
- `line_count`: 导语行数
- `char_count`: 导语非空白字符数
- `logic_chain_elements`: 导语覆盖的逻辑链要素列表
- `suspense_hook`: 导语末尾悬念钩子的描述

## 导语类型与写法

根据 `analysis/style-dna.md` 中的 `opening_structure` 字段选择写法：

### conclusion_first（结论先行式）

- 用 5-8 行**事件快剪**呈现故事最震撼的几个画面
- 不是逻辑罗列，是画面跳切——像电影预告片的蒙太奇
- 每行一个画面/一个事实，不做因果解释
- 禁止"第一/第二/第三"、"N笔债/N件事"式的结构
- 禁止"先列纲要再展开"——不是在介绍故事，是在展示证据
- 最后一句必须是悬念钩或反转预告
- 语气冷硬，像案件复盘

示例风格参考：
```
知乎推给我一条匿名回答。
高赞第一，三千人点了感谢。
"换掉她的净水器滤芯就行。"
我妈住院第三天。
慢性重金属中毒。
医生查不出源头。
而三个月前给我妈装上新净水器的人，是我老公。
```
注意：不是在"介绍故事"，是在"展示证据"——每行一个事实，读者自己拼图。

### conflict_first（冲突直入式）

- 用 5-8 行直接进入核心冲突场景的最高潮瞬间
- 第一句就是动作/对话，不解释背景
- 结尾留一个未解之谜或反转预告
- 时间线可以是故事中段的闪回截取

### dialogue_first（对话开篇式）

- 以 2-3 轮震撼性对话开头
- 对话本身揭示冲突和人物关系
- 最后补 2-3 行极简背景交代
- 对话必须短、快、有冲击力

## 风格硬规则

- 导语的句式节奏必须匹配 style-dna 中的全局特征
- 导语中可以使用"我"（如果正文是第一人称）
- 不得使用 AI 套话（"然而"、"不禁"、"竟然"、"深深地"、"渐渐地"）
- 每行不超过 30 字
- 导语独立成段，用 `---` 与正文第一章分隔
- 导语的信息密度必须极高——每行都要给读者一个新的信息点或情绪冲击
- 不得出现对故事的评价性语言（"这是一个关于……的故事"）

## 质量标准

- 读完导语后读者必须产生"我要看下去"的冲动
- 导语必须暗示核心冲突但不完整剧透结局
- 至少植入 1 个信息悬念（让读者想知道"为什么"或"然后呢"）
- 导语的最后一句话必须是全篇最强的"钩子句"

## 输出前自检

- [ ] 字数在 150-300 范围内？
- [ ] 行数在 8-15 范围内？
- [ ] 每行是否都有新信息/新冲击？
- [ ] 是否匹配 opening_structure 类型？
- [ ] 是否有 AI 套话？
- [ ] 末尾是否有悬念钩？
