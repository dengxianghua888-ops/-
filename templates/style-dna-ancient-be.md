# 文风 DNA · ancient_BE（古言 BE/虐恋）

> 本文件是 **genre 级默认值 + 取值范围**,dissector 拆解具体原文时以此为起点。
> 配套词库:`prompts/patterns/forbidden-and-preferred.md#G2`。

## 一句话定性
半文半白、意象密集、破句高频;叙述宿命论基调,情绪剧毒靠器官隐喻与留白;极少直抒胸臆。

## 定量基线

| 维度 | 典型范围 | 说明 |
|------|---------|------|
| 平均句长 | 25-35 字 | 比现代反转长,意象需铺陈 |
| 长短句比例 | 5:5 | 长短交替,长句铺景,短句砸心 |
| 对话占比 | 25-35% | 相比现代反转低,独白与景物描写更多 |
| 段落长度 | 3-6 行/段 | 允许较长 |
| 情绪峰值物理化覆盖 | ≥80%,且偏好**器官隐喻**(心尖/血脉/指甲/瞳仁/骨缝) | |
| 人称视角 | 第一人称女主 / 全知略带宿命感旁观 | |
| 叙述温度 | 冷峻 / 悲凉 / 宿命 | 不悲不怒,但字字剜心 |
| 时态 | 过去式主导,闪回密集 | |
| 金句密度 | 对仗/排偶 3-5 次/千字;物理化器官隐喻 4-6 次/千字 | |

## 偏好句式模板

1. **破句一刀式**:"我被生生阉割。/ 孩子被打掉了。/ 第九次。"
2. **对仗排偶**:"云满春山,月冷寒江。"
3. **指尖凉意式**(BE 典型):"她的指尖,已经凉了三日。"
4. **留白省略**:"他看着她。没说话。一刻钟。"
5. **宿命论陈述**:"这辈子该了的,终究是要了的。"

## 禁用句式

- 现代语感词:杀疯、笑疯、KO、磕到了、撩炸了、上头
- 现代词:手机、公司、地铁、社保、微信、外卖、朋友圈、kpi、年薪
- 现代度量衡:公斤、公里、元 → 应为两、里、贯、文
- 现代心理学词:pua、NPD、边界感、原生家庭
- 网文烂梗:"瞳孔地震""血脉偾张"过度使用

## 意象词库(偏好)

**自然**:残月、冷雪、孤灯、寒梅、枯荷、长街、青砖、药香、朱砂、鸦青、霜白、血丝
**器物**:玉佩、梳篦、长剑、香炉、帘幕、纸钱、灯芯、药碗
**时间**:一瞬、刹那、经年、半生、三日、一晃、片刻、须臾
**身体**:心尖、骨缝、指甲、瞳仁、血脉、眉梢、鬓角、心口

## 标题公式倾向

古言对仗式 > T3 生死悖论式 > T2 身份反转式

## 适配机制

优先 M4(灵魂线)+ M5(温度反转)+ M8(道德模糊结尾);次选 M6(多层反转)

## 首 300 字 Hook 优先级

H2 死亡反讽 > H3 预言违和 > H1 倒叙

## 代表作

《残梦不暖九冬寒》《娘亲脱离世界后,父皇悔疯了》《花落月都星已沉》《晚风别忆旧时人》《棠花落尽不相逢》《我死后,老公亲手解剖了我的尸体》

## 特别提示

- 情绪"剧毒"不靠控诉,靠**冷静地说出不该平静的事** + **器官隐喻**(取心/阉割/挖眼这种肉感词)
- 留白是核心武器——很多段不解释,让读者脑补
- AI 特别容易写垮的点:误把古言写成白话叙事 + 现代词混入(比如"她的手机响了"在古言里是死罪)
