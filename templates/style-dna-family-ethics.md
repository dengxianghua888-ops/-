# 文风 DNA · family_ethics（家庭伦理复仇）

> 配套词库:`prompts/patterns/forbidden-and-preferred.md#G5`。

## 一句话定性
第一人称女主独白为主,家庭场景细节密集,情绪密度极高;对话推进为主,短句为王;不原谅不和解。

## 定量基线

| 维度 | 典型范围 | 说明 |
|------|---------|------|
| 平均句长 | 14-18 字 | 家庭戏最短促 |
| 对话占比 | 40-50% | 家庭对话密度最高 |
| 段落长度 | 1-3 行/段 | 最碎 |
| 人称视角 | 第一人称女主(95%+) | |
| 叙述温度 | 压抑 + 爆发交替 | |
| 情绪峰值物理化覆盖 | ≥85% | 家庭戏情绪峰值多,必须物理化 |
| 金句密度 | 反问-自答 4-6 次/千字(家庭戏最高) | |

## 偏好句式模板

1. **家庭反问式**:"妈,你真的爱我吗?"
2. **回忆穿插式**:"我记得五岁那年,她是这么说的。"
3. **物件触发式**:"我打开她的保温杯。里面是我的。"
4. **数字砸脸**(T4 标题机制在正文的复用):"每月四千。她说给我四千。"
5. **冷静陈述式**:"我没有哭。我在想,她这十年到底给我花了多少。"

## 禁用句式

- 和稀泥:"毕竟是一家人"、"血浓于水"、"她也有她的难处"(和仿写主旨冲突)
- 廉价和解:"我原谅你"、"我理解你了"
- 抒情式回忆("那段被爱的时光"类)

## 意象词库(偏好)

**家庭符号**:保温杯、保险柜、存折、房本、遗嘱、户口本、病床、手术费、养老金、补习费、学费单
**情绪动作**:跪、抓、嘶吼、扑、抱着、推开
**细节物件**:馒头、咸菜、过期药、补丁衣服、廉价鞋

## 标题公式倾向

T1 因果反转式 > T4 数字对比式 > T5 极致标签式

## 适配机制

优先 M3(因果回旋)+ M1(死环反杀)+ M5(温度反转)

## 首 300 字 Hook 优先级

H1 倒叙冲突 > H2 死亡反讽

## 代表作

《老公给我妈下药后,我杀疯了》《我每月给女儿四千,她却只能啃馒头》《我穷得吃不起饭,妈妈却说每月给我三千》《老伴在 ICU 等救命,他拿手术费给宠物狗买墓地》《背尸六年为姐姐治病,我离开后她们疯了》《姐姐新生之时,是我的死亡之日》

## 特别提示

- 家庭伦理的"金句"往往是**日常对白**里扎人的那句(如"你怎么不去死")——要精确采集进 Style DNA
- 不要写成"儿女如何原谅父母"——那是另一种文,不是爆款
- 情绪跌宕靠**家庭物件**作锚(保温杯/存折/病历),不要写空气和天气
