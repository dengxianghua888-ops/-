# 文风 DNA · ancient_sweet（古言甜宠/双强）

> 本文件是 **genre 级默认值 + 取值范围**。
> 配套词库:`prompts/patterns/forbidden-and-preferred.md#G3`(古言用全套)。

## 一句话定性
半文半白 + 甜宠节奏;对话密度高;叙述温度明显偏暖;发糖与权力/身份反差交替推进。

## 定量基线

| 维度 | 典型范围 | 说明 |
|------|---------|------|
| 平均句长 | 20-28 字 | 比 BE 短,比现代长 |
| 对话占比 | 45-55% | 对话驱动主要情节 |
| 段落长度 | 2-4 行/段 | 碎段利于快速推进 |
| 发糖密度 | 每 800-1200 字一次显性发糖 | 亲密动作/深情对视/保护行为 |
| 叙述温度 | 温暖 / 带狡黠/带俏皮 | 不能悲凉 |
| 金句密度 | 俏皮对白 3-5 次/千字 | |

## 偏好句式模板

1. **俏皮对白**:"'你要我怎么谢你?''嫁给我。'"
2. **权力 + 宠溺并行**:"他掌天下权,独独宠她一人。"
3. **身份反差发糖**:"相府嫡女嫁了个痴儿。可那痴儿,是北疆王。"
4. **欲擒故纵**:"我不嫁你。可你要是真娶,我也不拦。"

## 禁用句式

- 现代词全套(同 BE)
- 过度悲情陈述(甜宠不虐主线)
- 长段内心独白(冲淡甜感节奏)

## 意象词库(偏好)

红绸、金钗、罗裙、梨花、玉镯、酒酿、月光、蜜饯、帕子、马车、佳酿、灯笼、屋檐雪

## 标题公式倾向

古言对仗式 > T2 身份反转式

## 适配机制

优先 M2(身份反差爆发)+ M3(因果回旋);次选 M6(多层反转)

## 首 300 字 Hook 优先级

H4 空降揭露 > H3 预言违和

## 代表作

《盼我流年,花满蹊径》《相府假千金一事无成,可她朋友多啊》《皇后要遁走》《春和不负景明》《夫君被断腿后,我摇魔丸爹娘杀疯了》(权谋甜宠混合)
