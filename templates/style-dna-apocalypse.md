# 文风 DNA · apocalypse_heroine（末世大女主/异能/系统文）

> 配套词库:`prompts/patterns/forbidden-and-preferred.md#G4`。

## 一句话定性
冷硬、工具理性、设定密度极高;叙述保持距离,感情降到最低;每 500 字必有 1 个世界观概念或能力概念被展示。

## 定量基线

| 维度 | 典型范围 | 说明 |
|------|---------|------|
| 平均句长 | 15-22 字 | 略长于现代反转,因为有 worldbuilding |
| 对话占比 | 25-35% | 低于甜宠,动作与设定描写多 |
| 设定密度 | 前 500 字 ≥3 个世界观概念 | 硬性 |
| 能力可量化 | SSS 级 / 第 9 境 / 辐射值 100% 类 | |
| 叙述温度 | 冷硬 / 近乎冷漠 | |
| 时态 | 过去式 | |
| 金句密度 | 冷硬判断句 3-5 次/千字 | |

## 偏好句式模板

1. **冷硬判断式**:"她不再净化辐射。她就是辐射本身。"
2. **设定陈述式**:"末日第 472 天。能级:SSS。污染指数:爆表。"
3. **权力反转式**:"他还以为自己在审判我。他不知道,他是我眼下的祭品。"
4. **道德模糊尾句**:"我拥有了整个世界。却也永远地失去了它。"

## 禁用句式

- 抒情词:"她的眼泪像珍珠般" / "心中五味杂陈"
- 白莲花句式:"我不怪你"、"我相信你是好的"(大女主不原谅)
- 现代都市词混用(末世文可有科技词,但不要出现 KPI、微信)

## 意象词库(偏好)

辐射、异兽、基地、庇护所、能量核心、觉醒值、末日第 X 天、S/SS/SSS 级、净化体、污染源、废墟、白骨、血脉、生存点、积分、坐标系

## 标题公式倾向

T1 因果反转式 > T3 生死悖论式

## 适配机制

优先 M7(降维打击)+ M6(多层反转)+ M8(道德模糊结尾)

## 首 300 字 Hook 优先级

H1 倒叙冲突 > H3 预言违和

## 代表作

《末世让我滚出基地后,所有人都死了》《她代号深渊》

## 特别提示

- 末世文**必须建立坐标系**——没有坐标系就无法谈升维/降维
- 工具理性叙述不等于干巴巴:可以通过极简短句建立冷酷气质(见代表作)
- 主角的情感线存在但克制——大女主不是没有情感,是情感不干扰判断
