# 文风 DNA · urban_sweet_ceo（都市甜宠/霸总/钓系）

> 配套词库:`prompts/patterns/forbidden-and-preferred.md#G6`。

## 一句话定性
高对话占比,网感语言密集,情绪明快;叙述自带"嗑 CP"的俏皮视角;允许"撩疯了""磕到了"这类小说圈梗。

## 定量基线

| 维度 | 典型范围 | 说明 |
|------|---------|------|
| 平均句长 | 18-25 字 | |
| 对话占比 | 45-55% | 对话几乎驱动全文 |
| 发糖密度 | 每 600-1000 字一次显性发糖 | 比古言甜宠密集 |
| 人称视角 | 第一人称女主 | |
| 叙述温度 | 明快 / 俏皮 / 轻度调笑 | |
| 金句密度 | 俏皮对白 5-7 次/千字(最高) | |

## 偏好句式模板

1. **内心吐槽式**:"这算什么?当街撩妹?"
2. **反向嗑 CP**:"我是要拒绝的。但他眼睫毛抖了一下。"
3. **动作特写 + 独白**:"他掐住我下巴。我忽然想起奶奶说的,好的男人,手要稳。"
4. **身份反差发糖**:"他是裴家独子。他替我挡了一刀。"

## 禁用句式

- 过度玛丽苏词:"他眼底是我看不懂的深情"
- 抒情长段(超过 3 行的心理描写)
- 陈旧言情词:"他宠溺地看着我"(AI 味重)

## 意象词库(偏好)

**场景**:会议室、玻璃幕墙、加长车、品牌 Logo、珠宝盒、西装、领带、顶楼餐厅
**人设**:钓系、清冷、禁欲、小奶狗、狐狸精、御姐、高岭之花、病娇
**动作**:圈、锁、拉近、掐住下巴、手背抵唇、抱起、壁咚、拽到怀里

## 标题公式倾向

T1 因果反转式 > T5 极致标签式;可用网感词"撩疯了""磕到了""笑不活了"

## 适配机制

优先 M2(身份反差)+ M3(因果回旋);次选 M5(温度反转)

## 首 300 字 Hook 优先级

H4 空降揭露 > H1 倒叙冲突

## 代表作

《磕到了!钓系总裁他撩疯了!》《瞒着老公空降公司,他竟带小三上台官宣,我当场笑疯》《天生微醺的我带球跑后,嫁入了百年世家》《愚人节是他的放纵日》

## 特别提示

- 网感语言是都市甜宠的核心竞争力,**不能"净化"成古言雅语**
- 发糖不是堆形容词,是**具体动作+独白**:"他掐我下巴 → 我内心翻白眼 → 结果膝盖还是软了"
- 霸总不能只霸不宠,不能只宠不霸——黏性来自两者交错
