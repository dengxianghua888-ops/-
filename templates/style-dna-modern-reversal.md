# 文风 DNA · modern_reversal（现代反转/反贪爽文）

> 本文件是 **genre 级默认值 + 取值范围**,dissector 拆解具体原文时以此为起点,填入该原文的实际数值。
> 配套词库:`prompts/patterns/forbidden-and-preferred.md#G1`。

## 一句话定性
口语化、短促、极强现代代入感;叙述冷静带克制讽刺;对话驱动情节。

## 定量基线(对一篇合格的现代反转爆款)

| 维度 | 典型范围 | 说明 |
|------|---------|------|
| 平均句长 | 15-20 字 | 短句为王 |
| 长短句比例 | 3:7 或 2:8 | 短句主导,长句偶用于冷静陈述死环逻辑 |
| 对话占比 | 35-45% | 对话推情节 |
| 段落长度 | 2-5 行/段 | 碎段制造节奏 |
| 情绪峰值物理化覆盖 | ≥80%(高强度 Beat) | 硬性 |
| 人称视角 | 第一人称"我"主导(95%+) | |
| 叙述温度 | 冷峻带讽刺 | |
| 时态 | 过去式为主 + 少量现在式转折 | |
| 金句密度 | 反问-自答 2-4 次/千字;对仗反讽 1-2 次/千字;物理化 5-8 次/千字 | |

## 偏好句式模板(原文常见)

1. **短促动作句**:"他掀开箱子,看了一眼,笑了。"
2. **反问+判断**:"凭什么?就凭你穿了身制服。"
3. **数字砸脸**:"一千万。整整一千万。"
4. **冷峻独白**:"我没哭。我在想怎么弄死他。"
5. **死环陈述**(涉 M1 机制时):"他如果说 A,就是 X;说 B,就是 Y。"

## 禁用句式

- 长复句抒情("那是一段早已被岁月模糊的记忆...")
- AI 式过渡词开头("然而""总之""无论如何")
- 感叹号排比(中文现代反转用太多感叹号显得油)
- 成语扎堆(每段 >1 个成语即显 AI)

## 意象词库(偏好)

现代社会物件:POS 机、完税单、监控、录音、朋友圈、转账记录、合同、身份证、户口本、银行流水、群聊截图

## 标题公式倾向

T1 因果反转式 > T4 数字对比式 > T3 生死悖论式 > T5 极致标签式

## 适配机制

优先 M1(死环反杀)+ M3(因果回旋);次选 M2(身份反差)

## 首 300 字 Hook 优先级

H1 倒叙冲突 > H4 空降揭露
