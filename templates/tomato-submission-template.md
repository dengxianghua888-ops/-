# 番茄投稿包模板 (V3)

> 短篇仿写产线的**番茄平台投稿产出**模板。在 Phase 5 定稿完成后,若目标平台含番茄,由 finalizer 填写一份,置于 `stories/{slug}/tomato-submission.md`。平台硬约束已内化到字段规则里。

---

## 1. 基本信息(番茄硬字段)

```yaml
title: ""              # 标题, ≤30 字, 避免 AI 过渡词
subtitle: ""           # 副标题(可选), ≤20 字
author_pen_name: ""    # 笔名
genre_tag_primary: ""  # 主标签(番茄分类): 言情/悬疑/都市/穿越/古言/末世/甜宠/虐恋/家庭/大女主
genre_tag_secondary: []  # 次标签最多 2 个
target_word_count: ""  # 目标篇幅(短篇 8000-15000 字)
protag_gender: ""      # 女主/男主/双主
narrative_pov: ""      # 第一人称/第三人称
platform_targets: ["tomato"]  # 投稿平台列表, 可附加 "zhihu_yanyan" / "toutiao" 等
```

## 2. 简介(Synopsis)

番茄简介有硬性规范:

- **字数**:90-120 字
- **结构**:身份前提(1 句) + 极端冲突(1 句) + 反转钩子(1 句)
- **禁忌**:不透结局,不剧透死环,不承诺爽点(只吊胃口)

模板:

```
我是 [身份标签]。
[被动遭遇的极端事件,含具体数字/对象]。
[我的反击动作暗示,留悬念]。
```

示例(以 hermes_customs_package 为例):
```
我是义乌皮具厂小老板。
过海关时,孙科长说我 100 块成本的样品是爱马仕,让我补交 1000 万关税。
我抵押房产凑齐了钱。然后转身向警察走去——"报警,我价值 3000 万的爱马仕被掉包了。"
```

## 3. 标签选择指南(番茄算法)

| 主标签 | 推荐 genre | 次标签候选 |
|-------|-----------|-----------|
| 言情 | ancient_sweet / urban_sweet_ceo | 甜宠/虐恋/双强/追妻/重生 |
| 悬疑 | abyss/crime 类 | 烧脑/反转/心理/犯罪 |
| 都市 | modern_reversal / family_ethics / urban_sweet_ceo | 爽文/反转/逆袭/女强/家庭 |
| 古言 | ancient_BE / ancient_sweet | 虐恋/权谋/重生/穿越/宫斗 |
| 末世 | apocalypse_heroine | 异能/大女主/系统/科幻 |
| 家庭 | family_ethics | 爽文/复仇/亲情/反转 |

**标签组合原则**:主标签决定在番茄的主分类入口露出;次标签决定算法推送相似阅读偏好。**2-3 个精准标签比 5 个泛标签效果好**。

## 4. 首章 Hook(番茄算法核心)

番茄阅读留存率在第 1 章决定。首章硬指标:

- **字数**:600-900 字
- **信息密度**:≤900 字必须塞下主角身份 + 极端冲突 + 悬念钩子
- **Hook 类型**:从 `prompts/patterns/hook-types.md` 的 4 种里选 1(标签化):`hook_type: H1|H2|H3|H4`
- **Hook 强度**:≥9/10(按 hook-types.md 4 维评分)
- **首章末钩子**:对白悬念 / 动作未完 / 真相半露 三选一

模板:
```
[第 1 句极端冲突陈述, ≤25 字]

[句 2-5 身份/场景补足, 全短句]

[句 6-10 第一个具体矛盾展开]

[句 11-15 钩子, 留一个未解的问号]
```

## 5. 章节切分(番茄日更)

番茄短篇若 ≥8000 字,切为 10-20 章日更:

- 每章 500-800 字(中位 650)
- 每章末一个钩子(A 级:对白悬念/动作未完/真相半露)
- 每 3 章至少 1 个付费级卡点(情绪峰值+信息未完全揭露)

产物:
- `stories/{slug}/final-chapters/ch01.md` ~ `ch{NN}.md`
- `stories/{slug}/final-chapters/_chapters-map.md`(章字数+钩子摘要表)

## 6. 直接投稿版正文格式

`final.md` 必须直接可投,不再保留内部审稿标记:

- 标题后、第一章前必须有 2-5 段开篇导语。
- 第一段必须以 `导语：` 开头。
- 导语内容只写故事卖点:主角处境、极端冲突、反击承诺。
- 正文必须一句一段,每个自然段最多 1 个句末标点(。！？!?；;)。
- 正文不得出现 `【付费节点】`、`付费节点`、`付费卡点`、`paywall` 等内部标记。
- 付费节点只在剧情上自然强化,通常落在章末“证据半露 / 真相卡住 / 反击刚启动”的句子上。

## 7. 付费节点地图（投稿包内部）

投稿包必须附一张节点地图,但正文不显式标注付费点:

```markdown
## 付费节点地图（直接投稿版）

正文不显式标注付费点，节点已自然落在章末或强悬念句上。

| 节点 | 位置 | 自然卡点 |
|---|---|---|
| 1 | 第 4 章末 | [证据半露/真相卡住/反击刚启动的章末句] |
| 2 | 第 8 章末 | [自然卡点句] |
| 3 | 第 12 章末 | [自然卡点句] |
```

节点数量不少于 `ceil(正文字符数 / 3500)`。

## 8. 发布前 checklist

- [ ] 标题 ≤30 字,含情绪词,无 AI 过渡词
- [ ] 标题后有 `导语：` 开篇导语,且导语不是创作说明
- [ ] 简介 90-120 字,结构正确,不剧透
- [ ] 2-3 个精准标签
- [ ] 首章 Hook 强度 ≥9/10
- [ ] 每章 500-800 字
- [ ] 正文一句一段,无多句挤在同一自然段
- [ ] 每章末有钩子
- [ ] 每 3000 字至少 1 付费级卡点
- [ ] 投稿包含 `付费节点地图（直接投稿版）`
- [ ] 正文不出现 `【付费节点】`、`付费节点`、`付费卡点`、`paywall`
- [ ] 全文无 AI 违禁词(全局 + genre 专属)
- [ ] 反转机制保真度 C5 全过
- [ ] 金句密度对齐 I4 ±15%

全部 ✅ → 可发布。
