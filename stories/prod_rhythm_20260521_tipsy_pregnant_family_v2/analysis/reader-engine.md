# Reader Engine

## 目标读者

- 番茄女性向短篇读者。
- 喜欢带球跑、先婚后爱、豪门真少爷、白月光误会、男主追妻但不真虐女主的读者。
- 喜欢弹幕吐槽和“读者嘴替”参与感的轻爽甜宠读者。

## 黄金前三百字引擎

| 钩点 | 原文执行 | 读者反应 |
|---|---|---|
| 怀孕 | “刚查出怀孕” | 孩子什么时候告诉男主 |
| 离婚 | “递来一份离婚协议” | 男主是不是渣 |
| 破产 | “我破产了，这是最后一笔钱” | 真破产还是假装 |
| 弹幕 | “白月光回国了” | 弹幕是不是原著真相 |
| 替身 | “原来我是替身？” | 女主会怎么反应 |

## 追读循环

1. 弹幕提出一个看似确定的判断。  
例：“男主怕是假装破产，为的就是甩掉女配。”

2. 现实立刻给出反证。  
例：离婚协议全给女方，男主眼眶红。

3. 女主因为微醺反射弧，没有立即追问。  
例：忘了说怀孕，忘了发消息。

4. 读者替她着急。  
例：弹幕刷“女配你倒是说话啊”。

5. 下个场景继续放新证据。  
例：搬砖工资、工地血泡、产检报告、B超单、文件袋。

## 付费卡点模型

| 字段 | 原文卡点 | 可迁移方式 |
|---|---|---|
| 2500-3500字 | 白月光上门、女主怀孕消息再次没发出、男主仍提醒吃饭 | 外部挑衅和男主照顾证据并置 |
| 5000-6500字 | 产检撞见男主受伤，产科报告被看见 | 私密真相在公共场合暴露 |
| 6500-8000字 | 男主误会孩子没了并吐血 | 情绪峰值卡在“他听到了吗” |
| 8500-10000字 | 弹幕抛“京城许家” | 身份真相只露关键词 |
| 10000-11500字 | 文件袋揭示许家和三年前真相 | 连续两层反转释放 |
| 12000字后 | 老宅、宋清音退场、求婚 | 安全感和仪式感偿还 |

## 爽点来源

- 迟钝反杀：女主不吵不闹，却让挑衅者拳头打进棉花。
- 深情确认：男主每次看似要离开，都会用行动证明仍在爱。
- 误会解除：读者焦虑越久，B超单和“从来不是”释放越强。
- 身份跃迁：从工地搬砖到百年世家，视觉落差大。
- 公开偏袒：女主进入老宅后不是受审，而是被安排院子、离厨房近、随时能吃。
- 圆满生子：龙凤胎是带球跑题材的高甜终局奖赏。

## 读者期待管理

必须每章至少满足一项：
- 一个误会推进。
- 一个男主深情证据。
- 一个弹幕误导或剧透。
- 一个白月光/豪门外部阻碍被压制。
- 一个身份信息增量。
- 一个甜宠补偿动作。

禁止连续两章只写日常甜宠无新信息。甜宠必须和悬念、身份、误会、护短绑定。
