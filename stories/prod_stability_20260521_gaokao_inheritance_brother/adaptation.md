# 高保真设定重置室

## 改编目标
保留源文最值钱的四根骨架：
1. 开篇必须同时砸下“高考继承规则异常+独生女却有弟弟+前三世死亡样本”。
2. 中段必须靠实物线索与封闭空间，把“找不存在的弟弟”升级成付费级谜题。
3. 终局必须仍是“弟弟不是外部人物，而是主角被封存的男性自我”。
4. 结尾必须给出可被旁人看见的接纳兑现，而不是口头原谅。

## 三套投稿方向

### A案 教培豪门·样板校区密室版
- **一句话前提**  
  县城最成功的高考教培集团创始人去世后，留下一条荒诞遗嘱：只有外孙女和“失踪弟弟”里高考分更高的人，才能继承集团股份与教育基金；可她明明是独生女，而且前三次轮回里，全家都死在找弟弟的路上。
- **新鲜点**  
  把“遗产”从现金改成“教培帝国控制权+奖学金基金”，与高考场域天然咬合；把老宅密室换成停用样板校区的器材库暗层，视觉更现实、更适合番茄家庭伦理悬疑。
- **核心载体**  
  爷爷→教培帝国掌门姥爷；老宅→旧校区；密室→器材库暗层/心理辅导室后仓；催眠→家庭心理顾问+药物性记忆封锁。
- **风险**  
  教培背景若写太行业化会拖节奏；需避免把心理咨询写成反派职业工具。

### B案 海边民宿家族·台风避难屋版
- **一句话前提**  
  海滨民宿连锁老板临终立下遗嘱，规定外孙女必须和失踪弟弟比高考分，谁赢谁拿走海景酒店与海外信托；但她是独生女，前三世一家人每次试图钻空子，都会在台风夜离奇暴毙。
- **新鲜点**  
  把密室换成海边避难屋，把死亡压迫和台风、停电、海潮结合，氛围强。
- **核心载体**  
  老宅→海边祖宅；书房密室→防风避难夹层；律师→遗产托管人；催眠→长期镇静药+创伤性失忆。
- **风险**  
  气氛很强，但“高考+民宿产业”绑定度略弱；稍不注意会偏灵异惊悚。

### C案 梨园世家·后台升降台版
- **一句话前提**  
  戏曲世家掌门人死后立遗嘱，要外孙女和“弟弟”比高考分，赢的人继承祖传戏楼和文旅公司；她明明是独生女，却在第四次轮回里被逼回到废弃戏楼，掀开后台升降台下埋着的另一套人生。
- **新鲜点**  
  用“生角/旦角”的表演身份折射被压抑的性别自我，审美辨识度高。
- **核心载体**  
  老宅→祖传戏楼；密室→后台升降井与服装库；爷爷偏爱→偷偷允许主角练生角；接纳仪式→以真实身份登台谢幕。
- **风险**  
  象征意味最强，但容易一眼看出主题；番茄受众里部分读者会嫌“戏曲设定离生活远”。

## 选定方向
**选 A案。**

### 选择理由
- **神髓保真最高**：高考、排名、遗产控制权、家庭压迫天然一体，不需要硬改源文的发动机。
- **逻辑闭合最稳**：教培豪门最能解释“为什么全家把分数看得比命还重”，也最能支撑姥爷用遗嘱逼家人直面秘密。
- **番茄适配更强**：县城学霸、教培豪门、心理咨询室、停用校区，这些元素比戏班和海岛更贴近大众认知。
- **新鲜度够但不飘**：不是简单换壳，而是把“高考”从背景抬成设定内核。

## A案执行重置

### 世界观重置
故事发生在一座教育内卷极强的三线城市。主角是全市状元热门、教培集团唯一公开继承人。姥爷生前打造了本地最大的升学帝国，从封闭集训营到高端志愿规划一条龙，既是家族财富来源，也是全家共同信仰。  
因此那条遗嘱才不只是分钱，而像一场“谁更配代表这个家族神话”的终极裁决。

### 人物重置
- **主角**：外冷内绷的女学霸，表层身份是“最标准的别人家女儿”，底层驱动力是想活下去，也想弄明白家里到底在藏什么。
- **姥爷**：嘴硬、护短、懂教育规则也懂人心，遗嘱像诅咒，实则是最后一次偏爱。
- **母亲**：教培集团现任总经理，表面强势理性，实则被妹妹往事刺穿，最怕“历史重演”。
- **父亲**：集团法务合伙人，平时温和，关键时刻总站在母亲那边，把“家和正常”看得比真相更重要。
- **心理顾问/医生**：不是单纯洗白或作恶，而是曾配合家长“保护性封存记忆”，后期转为帮助主角找回记忆。
- **律师/遗产执行人**：守着旧校区暗层钥匙的人，知道姥爷真正的布局。

### 场景重置
- **老宅**改为姥爷第一所起家的停用校区，保留旧教室、样板宿舍、奖杯墙。
- **书房密室**改为旧心理辅导中心后方暗层仓库，门禁密码与一个旧日期相关。
- **门后景象**不再是纯“男性器官猎奇展示”，而是更贴近现实的“生角式男装、束胸/义乳废弃物、激素用药记录、改名草稿、手写自述、体检咨询单”等一整套自我求证痕迹。
- **结尾补偿场**改为升学宴/成人礼现场，父母以真实姓名和性别表达公开站台。

### 机制保真
- **M6 多层递进反转**  
  第一层找外部私生子；第二层怀疑姥爷或父亲藏子；第三层发现全家被共同封口；第四层翻到“弟弟其实是被埋掉的我”。
- **M2 身份反差爆发**  
  前70%都在找一个外部男性，后30%才发现那些线索全都指向主角自己的另一身份。
- **M5 温度反转曲线**  
  姥爷旧日偏爱越暖，越反衬父母中段崩溃有多疼；而父母后期必须用现实动作偿债，才能把情绪拉回来。

## 表达边界
- 不把性别认同写成猎奇机关，而写成被家庭长期压抑的真实自我。
- 不把父母洗成“完全无辜”，他们确实造成了严重伤害；但也不给脸谱式恶人结局，而是让他们用行动补偿。
- 不把治疗、手术、改名写成轻飘“变身爽文”，重点是活下来、被承认、重新拥有选择权。
- 不在前半段用议题名词直接点题，一切都包在追查、证据、死亡循环里。
- 结尾必须让“接纳”有可视化支付：医疗安排、法律文件、公开站台、亲友预沟通，而不只是哭着道歉。
