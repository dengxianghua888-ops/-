# Soul Contract

## 读者与文本签的契约
这篇文卖给读者的不是“正确价值观”，而是一个更狠的承诺：你先陪我看一个离谱到近乎灵异的遗嘱死局，我会在中后段告诉你，这个局不是为了猎奇，而是为了把一个被全家埋掉的真实自我重新挖出来；而且我不会只让你疼，我最后一定给你补回来。

## 必须兑现的五个承诺
1. **规则承诺**  
   前段既然设定了遗嘱和托梦杀局，后面必须解释清楚这套压迫为何存在，不能让爷爷一直只是“恶灵工具人”。
2. **悬疑承诺**  
   既然题面是找弟弟，答案必须足够反常识，且回看前文所有异常都能成立。
3. **情绪承诺**  
   父母中段的排斥必须够痛，否则后段接纳不值钱；但结尾也必须有具体补偿，否则会像单纯消费议题创伤。
4. **主角承诺**  
   主角不能只是被动被揭真相，她必须主动回老宅、主动找线索、主动要求解催眠，读者才会站她。
5. **善意承诺**  
   爷爷、医生、父母最终都要落回“想让她活下去”的善意层，哪怕方法错、伤害重，也不能写成纯恶。

## 读者默认接受的伤害上限
- 可以接受三世暴毙、吊死、自毁、创伤性排斥。
- 可以接受母亲曾想把主角送去“改造”，前提是后文必须拆出她的代际创伤。
- 不可接受结尾还把主角继续丢在未被接纳状态。
- 不可接受把“弟弟=我自己”写成廉价猎奇，不给前史因果和情感逻辑。

## 契约中的关键爽点
- 从“根本没有弟弟”到“弟弟其实就是我自己”的终极翻面。
- 从“爷爷逼死全家”到“爷爷是在用最后阴德救我”的立场翻面。
- 从“父母看似爱我”到“父母其实伤我最深”再到“父母终于学会爱我”的温度翻面。
- 从“高考状元+五千万遗产”的世俗成功，转到“终于做回真正的自己”的精神成功。

## 最怕违约的地方
1. 过早透出“性别认同真相”，会直接废掉前半段搜索引擎。
2. 把父母写成纯恶，会砍掉后半段最值钱的情绪回升。
3. 把结尾写成口头和解，不给手术、成人礼、亲友祝福这些可见支付，读者会觉得白虐。
4. 把爷爷写成全知旁白式解释器，会削弱他作为“偏爱驱动者”的人物温度。

## 仿写时必须守住的灵魂
- 不是“我有秘密”，而是“全家为了不面对这个秘密，已经把自己逼进死局”。
- 不是“主角赢了”，而是“主角终于不必再把活着和做自己当成二选一”。
- 不是“真相曝光就结束”，而是“真相曝光后，家人要拿现实行动重新学会爱她/他”。
