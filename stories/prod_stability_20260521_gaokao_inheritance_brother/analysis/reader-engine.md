# Reader Engine

## 核心驱动总览

| 引擎 | 启动位置 | 驱动问题 | 为什么有效 |
|------|---------|---------|-----------|
| 高概念引擎 | 第1节前半 | 独生女为什么要找弟弟才能继承遗产？ | 冲突一句即懂，点开成本低 |
| 死亡循环引擎 | 第1节中后半 | 为什么三种解法都死？第四世还能活吗？ | 立刻把题目从“找人”升级为“求生” |
| 错误推理引擎 | 第2-4节 | 爸爸私生子？爷爷私生子？门后有人？ | 每次猜错都能继续翻页 |
| 记忆缺口引擎 | 第3-7节 | 主角忘了什么？为什么答案说不出口？ | 让外部谜案转成内部谜案 |
| 情绪反噬引擎 | 第5-9节 | 父母为什么会厌恶她？主角做错了什么？ | 读者从猎奇切到共情，不容易弃文 |
| 补偿兑现引擎 | 第10节 | 真相后能否被接纳、被命名、被祝福？ | 让后段从压抑转成高满足收尾 |

## 读者翻页动力分段

### 第一段：点击欲（0-1000字）
- 卖点：遗嘱、五千万、高考、独生女、弟弟不存在。
- 机制：高密度违和设定，不让读者有喘息空间。
- 关键效果：读者先上钩，不先思考价值判断。

### 第二段：生存欲（1000-3000字）
- 卖点：前三世都死过，第四世再错还会死。
- 机制：每个方案都被爷爷托梦封死，制造绝对压迫。
- 关键效果：读者不是在“看家务事”，是在“看怎么逃命”。

### 第三段：拆谜欲（3000-6000字）
- 卖点：老宅、书房、泥雕机关、秦律师、门后景象。
- 机制：物证接力，角色知道一点、读者知道一点，但完整答案始终被截断。
- 关键效果：形成典型付费区停留。

### 第四段：情绪坠落欲（6000-8000字）
- 卖点：原来前三世多半是自毁，原来弟弟就是主角自己。
- 机制：先翻灵异因，再爆身份因。
- 关键效果：读者从“猜谜成功”瞬间切到“心被扎透”。

### 第五段：补偿欲（8000字后）
- 卖点：父母能不能学会爱真实的孩子。
- 机制：道歉不是终点，必须看见手术、成人礼、祝福、改名。
- 关键效果：让读者愿意在评论区输出“值了”“终于被看见了”。

## 付费卡点设计复盘
1. **密室开启前**  
   卖“门后一定有弟弟或真相”。
2. **答案卡在嘴边**  
   卖“为什么她说不出来”。
3. **催眠被揭一半**  
   卖“忘掉的不是线索，是无法承受的过往”。
4. **自杀回放**  
   卖“前三世死亡认知被推翻”。
5. **弟弟=我自己**  
   卖“身份反转最终章”。
6. **父母接纳是否真实**  
   卖“有没有现实支付，不是嘴上和解”。

## 评论区高概率触发点
- “原来爷爷不是恶鬼，是最爱她的人。”
- “看到‘给我做个催眠吧，我想变成一个正常人’直接破防。”
- “最怕的不是被骂，是被最爱的人逼着否定自己。”
- “幸好结尾不是嘴上原谅，是真做了手术和成人礼。”

## 改编时的保留优先级
1. 必保前300字的设定轰炸。
2. 必保中段门后景象+说不出口的硬卡点。
3. 必保“灵异因被推翻”先于“身份因被揭露”的双层翻案顺序。
4. 必保结尾具体补偿动作，否则整篇从爆款变成议题作文。
