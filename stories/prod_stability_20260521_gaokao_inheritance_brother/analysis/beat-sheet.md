# Beat Sheet

## 全文概况
- **总字数**: 约9150字
- **节拍数**: 14
- **核心母题**: 一个被催眠掩埋真实自我的高考状元，为了逃离爷爷遗嘱制造的死亡循环，主动追查不存在的弟弟，最终找回自己也找回家人的爱。
- **情绪模式**: 违和悬疑 → 死亡压迫 → 追查升级 → 记忆反噬 → 身份爆开 → 高补偿治愈
- **Hook 类型**: H3 预言/违和式
- **快节奏锁定**: 是
