# Style DNA

## 体感判定
- 类型：番茄古言虐爽短篇
- 快节奏锁定：**是**
- 锁定说明：仿写不得用解释性长段、流程清单、情绪总结替代现场交锋。必须持续用“对白短句 + 动作后果 + 下一刀更狠”的推进法。

## 语言执行特征

### 1. 句法
- 以短句为主，常见 8-18 字直砸。
- 长句只在“情绪控诉连续列罪”时出现，用来形成滔滔不绝的审判感。
- 句子连接词少，更多依靠换行完成推进。

### 2. 对白
- 对白占比极高，核心冲突几乎都通过当面对话完成。
- 对白不是闲聊，而是“身份判词、感情判词、罪证判词”。
- 高频句式：
  - 反问句：“那我呢？”
  - 二次确认句：“你知道？”
  - 冷处理句：“不能。”
  - 判词句：“这里不需要你。”

### 3. 叙述镜头
- 近景身体感强：腹痛、冷汗、颤抖、泪水、跪、摔、踹、灌。
- 叙述几乎不空转，动作后立刻出后果。
- 画面以“室内对峙/门前跪地/婚礼正堂/宫门/小院”这些强舞台空间为主。

### 4. 情绪表达
- 情绪不靠抒情段，而靠事实堆压。
- 常见做法：
  - 先给残忍事实
  - 再让角色说出更残忍的话
  - 最后用身体反应钉死痛感
- 典型链路：被弃 -> 争取 -> 再受辱 -> 认清 -> 公开清算

### 5. 金句系统
高传播句不是文学句，而是可截图的价值宣判句。
- “流产死不了人，你好自为之吧。”
- “本公主来恭贺陆世子新婚。”
- “你烧毁小院，杀死我孩子的时候可曾见过旧情？”
- “活着远比死去要痛苦的多。”
- “没有了谁，太阳都会照常升起。”

这些句子的共同点：
- 主谓清楚
- 不拐弯
- 可以单独截屏传播
- 兼具剧情信息和立场裁决

## 爆款节奏配方
1. 前 300 字内必须丢出“隐瞒身份 + 另娶别人 + 我怀孕了”这种三连信息。
2. 每个情绪节点都要落到可见动作上，不能只说“她很难过”。
3. 每当读者以为已经到底，就再补一刀更狠的新事实。
4. 高潮段不要抒情，要把旧债一条条报出来。
5. 结尾不靠大哭大闹，而靠平静拒绝制造高级感。

## 禁区
- 禁止把婚礼揭身份写成大段铺陈礼制说明。
- 禁止把女主疗伤写成慢散文。
- 禁止让男主后悔后获得大量倾诉篇幅，避免洗白。
- 禁止把受苦改写成轻飘回忆，必须现场呈现。
- 禁止结尾软化成“各自安好”，本篇需要明确的道德裁断。

## 仿写保持项
- 高对白率
- 强舞台场景
- 短句砸脸
- 每章至少一个可传播金句
- 每章至少一次“旧债被重新点名”
