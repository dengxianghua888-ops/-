# Scene 05

叶东辰没走。

隔着门板他的声音变了调：「苏念！你不是最善良的吗？你就这么看着她去死？」

荒谬到极点只会让人想笑。

我真笑了。

上辈子他也这么说过。先说顾瑶「矫情」「不用管她」，等我真不管了，就变成「你怎么这么狠心」。

同一个套路，用了两辈子。

「苏念你给我开门！你知不知道她手上全是血——」

我坐在沙发上没动。

门突然从外面被推开。

妈拎着菜回来了。

她看了一眼门口站着的叶东辰，脸色沉下来。

「你是谁？在我家门口嚷什么？」

「阿姨，顾瑶她——」

「我不管什么顾瑶王瑶。」妈把菜往地上一放，声音压得很低但每个字都带刀：「我女儿在家里好好的，你算什么东西上门来逼她？」

叶东辰张了张嘴。

「走。再不走我叫人了。」

他看了我一眼，转身走了。

妈把门关上，插好门闩，转过来拍拍我的肩：

「乖乖，谁年轻时候没碰上过两个不是东西的人。过了这坎就好了。」

她不知道全部真相。但她的直觉精准得像一把手术刀——不需要知道为什么，只需要知道谁在伤害她女儿。

我没做错任何事，除了瞎了眼信错了人。

两天过去了。志愿确认完毕，爸亲手按的确认键。

我以为最难的部分过去了。

班主任的电话在下午四点打来。

「苏念，有人举报你伪造贫困证明骗取助学金。教育局审计组明天到校核查，你做好准备。」

我攥着手机，指关节发白。

顾瑶。

她偷不走我的名额了，就要毁掉我的资格。
