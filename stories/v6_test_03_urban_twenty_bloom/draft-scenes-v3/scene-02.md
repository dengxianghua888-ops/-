# Scene 02

我盯着屏幕上那个闪烁的光标，手指没有发抖。

十八岁的手，指节细瘦，指甲缝里还有昨晚帮妈洗衣服留下的皂渍。

我输入原始密码。进了。

改密码。截屏。保存。退出。

给爸发短信：「爸，明天您必须亲自来学校，和我一起确认志愿。谁叫你都别信，只信我。」

三十秒。这辈子的命运锁死了。

我靠在椅背上，看着窗外的操场。

顾瑶正从小卖部走过来，手里拿着两瓶酸奶。一瓶草莓味，我的。她每次都记得我喜欢草莓味。

上辈子我感动了三年。

现在想来，她记住我的口味不是因为在乎。是怕我去小卖部时看到她刷卡消费的金额。

她每次「帮我带」，都是在切断我独自消费的机会。

原来说的是反话。

体贴其实是监控。节省其实是隔离。

「念念！」顾瑶跑过来，酸奶递到我面前，「给你，草莓的。」

我没接。

她愣了一下，笑容还挂着：「怎么了？不舒服？」

「顾瑶。」我看着她，「你妈上个月发的朋友圈，新提的黑色SUV。贫困生家里开得起五十万的车？」

她笑容没变，但瞳孔缩了。

右手下意识往口袋里摸——想藏手机。

原来小丑一直是我。三年友谊，三年关心，三年「念念你太节省了别老吃食堂」——是怕我在外面吃饭时被人看到真正的穷，对比出她在装。

叶东辰从教室那头走过来，眉头微皱：「念念，你今天怎么——」

我转头看他。

他被我的眼神钉住了。

这个人，上辈子替顾瑶改了我的密码，让我与唯一的定向名额失之交臂。现在他还站在我面前演好男友。

「你们俩配合得不错。」我站起来，「可惜我密码已经改了。」

顾瑶脸上的血色一寸一寸褪干净。

我转身走了。

身后传来她拔高的声音：「苏念！你今天怎么了？我们不是最好的姐妹吗？」

面具还没舍得摘。

但我已经不在那个剧本里了。
