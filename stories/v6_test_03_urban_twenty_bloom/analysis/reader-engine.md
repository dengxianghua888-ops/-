# Reader Engine：《二十年花开荼蘼》

## 核心驱动力模型

本篇的读者粘性来自**三引擎并行**：

### 引擎 1：信息差优越感（持续供能）

读者和女主共享上辈子的记忆，看着施害者在不知情的情况下表演/陷害——产生"我比你聪明"的优越感。

- 供能段：每次宋攸宁/钟然自以为得逞时
- 代表句："原来小丑一直是我。"——读者内心：现在小丑是他们了

### 引擎 2：代偿保护欲（情绪基底）

女主上辈子失去父母，读者知道"这辈子必须保住"——每次父母出现在危险边缘，读者的保护欲被激活。

- 供能段：父亲倒下、母亲心脏手术
- 代表句："上一世，我签的是我妈的死亡通知单和遗体火化同意书。"

### 引擎 3：递进清算快感（爽感阶梯）

每清算一个人/一件事，读者爽感升一级台阶，永远有"下一个"在等。

- 台阶1：切断关系+踢裆
- 台阶2：保住志愿表
- 台阶3：揭穿记者+洗清冤屈
- 台阶4：钟然入狱
- 台阶5：宋攸宁瘫痪
- 台阶6：拒绝钟然忏悔

## 付费卡点分析

**最佳卡点1（~3000字）**：校长室被诬告，记者冲入，女主被四面围攻
- 读者状态：愤怒到极点，必须看女主怎么破局
- 付费转化力：9/10

**最佳卡点2（~4500字）**：父亲倒下，母亲心脏病发，女主独自面对
- 读者状态：恐惧+心疼，必须确认父母能活
- 付费转化力：9.5/10

**最佳卡点3（~5500字）**：钟然重生后说"我都想起来了"
- 读者状态：好奇+警惕，必须看女主的回应
- 付费转化力：8/10

## 情绪消费路径

```
愤怒（知道真相）→ 爽（切断关系）→ 恶心（宋攸宁摊牌）→ 
爽（踢裆+回家）→ 心疼（回忆父母之死）→ 紧张（被诬告）→ 
窒息（四面围攻）→ 绝望（父亲倒下）→ 冷爽（揭穿记者）→ 
释放（手术成功）→ 痛快（钟然入狱）→ 唏嘘（钟然之死）→ 
轻盈（与父母旅行）
```

## 留存因子

1. **不完美结局**：钟然之死不是单纯的"恶有恶报"，有人性复杂度——引发讨论/二刷
2. **可代入性**：高考志愿、闺蜜背叛、父母疾病——都是现实中可能发生的事
3. **金句传播性**："我不是她""我爸妈只生我一个""小三情妇二奶你喜欢哪个"——适合截图传播
