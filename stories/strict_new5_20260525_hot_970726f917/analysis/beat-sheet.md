# Beat Sheet

## 节奏总览
- 主线模型：`异常发现 -> 孤证劝逃 -> 社死升级 -> 灾变实锤 -> 旧案揭底 -> 重返死局 -> 源头摧毁 -> 宇宙级尾钩`
- 主要机制：`M6 / M7 / M2`
- 节奏判定：`快节奏短篇，强钩高密度推进`

| Beat | 位置 | 证据锚点 | 发生了什么 | 情绪强度 | 信息差 | 读者期待 | 章尾钩功能 | 机制 |

## Beat 结构结论
- 最强连续三连击：
  - `撕卷反目`
  - `跳楼逃生`
  - `空气墙实锤`
- 中段最大抬升：
  - 从“我是不是疯了”抬到“整个考点被时间规则吞没”。
- 终局优势来源：
  - 不是战斗力，而是`规则知情 + 规则豁免 + 行动先手`。
- 结尾额外红利：
  - 单篇事件已完结，但主角身份并未封顶，天然适合系列化。
