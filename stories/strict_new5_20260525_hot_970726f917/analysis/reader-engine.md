# Reader Engine

## 核心成瘾回路
`微小异常 -> 极端选择 -> 全员误判 -> 代价加码 -> 灾变实锤 -> 主角正名 -> 真相升级 -> 主角执行终解 -> 新宇宙尾钩`

## 读者为什么停不下来

### 1. 异常足够小，代价足够大
- 只慢一分钟，本应不值得。
- 但主角直接放弃高考，读者会被迫追问：她到底知道什么，才敢这么做。

### 2. 主角一直在输钱
- 丢高考资格。
- 丢老师信任。
- 丢同学好感。
- 丢闺蜜关系。
- 丢父母理解。
- 丢社会评价。
- 她越惨，读者越想等“她是对的”那一下回本。

### 3. 群体误判制造强代入愤怒
- 监考代表制度压迫。
- 考生代表同龄人误解。
- 闺蜜代表情感背刺。
- 警察代表公权误读。
- 父母和家长代表道德审判。
- 误判面越全，正名时释放越大。

### 4. 真相不是一次给完，而是按层投喂
- 第一层：钟慢了。
- 第二层：所有表都慢了。
- 第三层：倒计时继续回退。
- 第四层：空气墙出现。
- 第五层：十二年前也发生过。
- 第六层：时光机与助理。
- 第七层：主角是系统宿主。
- 这种信息投喂方式让每次翻页都有新增量。

### 5. 每个阶段都有新的“现在怎么办”
- 劝人失败，怎么办。
- 闺蜜不走，怎么办。
- 被警察抓住，怎么办。
- 跳出考场还不安全，怎么办。
- 空气墙炸不开，怎么办。
- 真相知道了却进不去，怎么办。
- 进去了却无法杀人，怎么办。
- 老问题刚解决，新问题立刻顶上。

## 爽点发动机
- 爽点 A：`我宁可毁掉自己，也不陪你们一起死。`
- 爽点 B：`你们都说我疯，结果现实先疯给你们看。`
- 爽点 C：`官方、炸弹、直升机、挖掘机全失效，我的话成了唯一有效信息。`
- 爽点 D：`我不是来证明自己清白，我是回来解决问题的。`
- 爽点 E：`本篇不是终点，主角层级还在继续上翻。`

## 读者情绪曲线
```yaml
start:
  emotion: "困惑 + 窒息"
middle_1:
  emotion: "愤怒 + 委屈 + 替主角着急"
middle_2:
  emotion: "打脸快感 + 更大恐慌"
late:
  emotion: "真相震撼 + 行动期待"
ending:
  emotion: "任务完成释放 + 世界观继续上钩"
```

## 传播句型
- “只有我知道考场已经是死局。”
- “他们都说我疯了，直到空气墙真的出现。”
- “我放弃高考，不是因为怕考不上，是因为再晚一分钟谁都走不掉。”
- “高考只是表层，真正吞人的，是乱掉的时间。”

## 仿写时如何维持引擎不熄火
- 每 800-1200 字必须出现一次新的证据升级或关系崩塌。
- 任何解释段都必须服务于“下一步怎么救”。
- 所有配角台词都要推动误判、施压或真相升级，不能闲聊。
- 主角每一次“失去”，都要换来读者更强的“她一定要赢”的投注。
