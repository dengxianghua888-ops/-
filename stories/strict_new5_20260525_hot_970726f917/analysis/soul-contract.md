# Soul Contract

## 这篇文和读者签的契约
读者点开这篇文，不是在买“时间机器设定”，而是在买下面四件事：

1. 一个本可赢的人，愿不愿意亲手毁掉自己的赢面去救别人。
2. 一个被全世界误判成疯子的人，最后会不会被现实证明是唯一清醒者。
3. 规则异常会不会从小到大、从怪到更怪，越滚越失控。
4. 主角不仅要证明自己对，还要亲自回到死局把所有人救出来。

## 读者默认接受的核心承诺
- 开篇承诺：`异常是真的，不是女主精神失常。`
- 中段承诺：`所有羞辱、误判、社死都会在后面被现实打脸。`
- 深层承诺：`主角知道的东西足够大，足以解释她为什么敢毁掉高考。`
- 终局承诺：`她不会只做预言者，她会做执行者。`
- 续看承诺：`这一局结束后，还有更大的局。`

## 绝不能违约的点
- 不能让“钟慢一分钟”最后只是误会或乌龙。
- 不能让主角放弃高考显得不值，必须证明这是唯一正确选择。
- 不能让群体太早转信，否则“全世界都骂我疯子”的爽点坍塌。
- 不能让闺蜜背刺没有痛感，她必须先短暂相信，再在关键处不信。
- 不能让空气墙出现后只是单纯围观，必须迅速把局势升级到“官方也没办法”。
- 不能让旧案只为解释服务，旧案必须给当前行动提供解法。
- 不能让结尾只靠别人救场，主角必须亲自重返封锁区。

## 读者最在乎的不是谁对谁错，而是谁扛住了
- 监考老师、警察、家长错得越理直气壮，后面的正名越爽。
- 主角代价越真，读者越会接受她的偏执。
- 所以这篇文的灵魂不是“聪明”，而是“即使被全世界误解，我也要把该做的事做完”。

## 仿写时必须保留的灵魂温度
- 主角要急，但不能乱。
- 主角要委屈，但不能哭着求信。
- 主角要善，但不是圣母式解释机器。
- 主角要背负旧创伤，但不陷入自怜。
- 结尾要有完成任务后的短暂松气，但不能彻底安稳，因为她的人生本来就不只这一局。

## 最容易写偏的风险
- 写成科普悬疑：灵魂会变冷。
- 写成校园霸凌：世界规则层会变窄。
- 写成群像求生：主角孤证感会变弱。
- 写成纯系统爽文：考场牺牲的现实重量会消失。
- 写成父母闺蜜忏悔文：节奏会塌，爽点会偏。
