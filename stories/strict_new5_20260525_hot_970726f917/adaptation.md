## 选定方案：C

### 为什么选 C
1. 它保留了“微小异常撬动巨大牺牲”的第一爆点：只慢一分钟，却要毁掉近在眼前的人生上升通道。
2. “女飞行员提前批终选”自带强秩序、高门槛、前途压迫感，能替代高考的现实重量。
3. 航训中心、塔台、旧航站楼、模拟舱、跑道封控这些载体，天然适合承接时间错乱、空气墙、重返封锁区、直捣装置源头。
4. 不会一眼看出原故事，但仍能完整保住“孤证女主被全员骂疯，最后用灾变打脸”的灵魂合同。

## 核心改造

### 新故事一句话
民航女飞行员提前批终选当天，塔台主钟比女主胸前飞行表慢了一分钟。她当场砸掉自己的终选资格，也要逃出旧航站楼，因为三分钟后，这里会再次变成十二年前吞掉整批试飞学员的时间灾区。

### 外壳替换重点
- 高考考场 -> 民航招飞终选航训中心
- 监考/老师/警察/家长 -> 考官、航医、安保、候选人家属、机场公安
- 挂钟/手表/铃声 -> 塔台主钟、胸前飞行表、广播口令倒计时
- 校长/助理 -> 航训中心主任 / 塔台总调度
- 时光机 -> “相位校时核心”实验装置
- 科研基地旧案 -> 十二年前民航时间导航试验站事故
- 重返考场 -> 重返封锁旧航站楼与地下导航机房
- 系统尾钩 -> 女主完成“时序灾变回收任务”，进入更大任务线

## 审校提醒
- 前半程必须写足“她越解释越像疯子”，不能太早给任何权威站台。
- 第一轮实锤必须是空气墙/封控场显形，不是人物口头解释。
- 旧案揭底必须直接服务终局解法：女主为何知道三分钟规则、为何能二次入墙、为何知道源头在地下导航机房。
- 终局必须是女主亲自返场，不可改成外部救援解决。
- 尾钩要抬到更大的连续任务宇宙，但本次航训中心危机要完整闭环。

## 敏感表达边界
- 不写航空系统现实操作细节到可模仿层面，偏虚构“相位校时”灾变。
- 不渲染血腥肢解，重点放在时间错位、封锁、追悔和规则恐怖。
- 不把主线写成阴谋科普或硬核航空科教，悬念和情绪始终优先。
- 不引入恋爱线稀释节奏，女主核心魅力是先知、决断、执行力。
