# Tension Ledger：张力账本

## 1. 总张力结构

这篇文的张力不是靠悬疑谜底，而是靠“错误选择的成本持续滚大”。

张浩每做一次占便宜选择，都会生成新的债：

1. 不认500全包价值。
2. 主动退房。
3. 舍不得包车。
4. 接受黑民宿。
5. 要员工垫付。
6. 忽视员工安全。
7. 甩锅主角。
8. 持刀报复。

每笔债都在后文被现实清算。

## 4. 信息差账本

### 信息差 1：价格构成

- **张浩知道**：散客400，自己500。
- **主角/读者知道**：500包含门票、三餐、接送、导游、小食券和项目。
- **释放点**：老人团公开说500很划算。

### 信息差 2：房源替补

- **张浩以为**：退30间房会让酒店空一整个五一。
- **主角/读者知道**：百人团早就急需房源。
- **释放点**：王队长带一百人进店。

### 信息差 3：市场稀缺

- **张浩以为**：有的是酒店求着他们住。
- **读者逐步知道**：公交少、房价涨、酒店满、千元房秒光。
- **释放点**：新闻推送和一路客满。

### 信息差 4：员工忍耐值

- **张浩以为**：员工会继续听他安排。
- **读者知道**：员工饿、冷、病、花钱，怨气积累。
- **释放点**：小林遇险后集体爆发。

### 信息差 5：主角边界

- **张浩以为**：他哭求、加价到1000，主角会救他。
- **读者知道**：主角在巴掌后已经切断关系。
- **释放点**：主角拒绝并拉黑。

## 5. 章尾钩类型库

原文适合拆章时使用以下钩子：

1. **价格反转钩**：张浩刚退房，王队长电话接通。
2. **资源到场钩**：门口传来百人团声音。
3. **交通困境钩**：司机说只剩20个座位。
4. **黑市规则钩**：民宿老板说“嫌贵就别住”。
5. **涨价钩**：第二天房费涨到800。
6. **安全事故钩**：雨夜草丛窜出男人。
7. **求助钩**：张浩深夜拨通主角电话。
8. **报复钩**：张浩被开除后说要报复。
9. **法律钩**：菜刀落地，警察赶到。

## 6. 张力维护原则

- 每次张浩短暂得意后，必须立刻进入更大现实成本。
- 每次主角被质疑后，必须有第三方替主角证明价值。
- 每次出现价格数字，都要和后续更高数字形成对照。
- 每次员工忍耐，都要累积到后续反噬。
- 每次张浩甩锅，都要让他失去一个现实支点。
- 终局必须由法律而非主角私刑完成。
