## 必改 1：补齐平台标题与简介

建议在正文正式稿前补：

```md
# 五一露营嫌我贵？可我有百人研学团

简介：五一音乐节当天，老客户周凯嫌我 680 元团建套票贵，拿 480 元裸营位价逼我退差价，还当众动手威胁差评。我按合同给他退订，转身接下被我拒过的 120 人亲子研学团。周凯以为离开我能省钱，没想到接驳、黑营地、安全事故和公司追责，一笔一笔都算回了他自己头上。
```

理由：
- 平台评审要求覆盖标题/简介。
- 简介需点明价格矛盾、退订反转、后续反噬，不要只写口号。

## 建议 3：修正 scene-10 钩子证据一致性

当前：
```md
女员工发来的定位停在服务区后巷，电话里只剩一句发抖的“周经理，救我”。
```

问题：
- 正文前文是群语音：“有个喝醉的人一直跟着我。”
- “电话里只剩一句”缺前文支撑。

建议改为：
```md
女员工发来的定位停在服务区后巷，群语音里只剩发抖的一句：“周经理，有人一直跟着我。”
```
