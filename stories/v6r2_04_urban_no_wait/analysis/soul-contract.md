# Soul Contract — 《余生不候》

## 一、与读者的灵魂契约

### 核心承诺

> "你为渣男付出的每一分钱、每一滴泪、每一次卑微，都会以加倍的代价从他身上讨回来——不是靠你哭求，而是靠你转身。"

### 承诺兑现清单

| 情绪债务 | 兑现方式 | 兑现位置 |
|----------|----------|----------|
| 四年付出被一句"舔狗"定性 | 肖奈破产，姜氏讨债 | 第10章 |
| 领证日被公开羞辱 | 镜像原话当场回敬 | 第1章 |
| 闺蜜背刺 | 江柔失去生育能力+被社会抛弃 | 第8-9章 |
| 伪造假证的侮辱 | 真证在全家面前碾压 | 第6章 |
| 被要求穿伴娘服 | 盛大婚礼登热搜 | 第5章 |
| 揉头发的控制姿态 | 肖奈只能远远看着不敢靠近 | 第10章 |
| "离了我你什么都不是" | 肖奈一无所有叫"大嫂" | 第10章 |

### 绝不违约条款

1. **女主不能原谅**——哪怕肖奈跪下、哭泣、破产，女主的回应只能是"平静"或"不在乎"
2. **新关系不能是工具**——肖珩必须是真爱（有伏笔支撑），不能是女主的报复工具
3. **代价不能轻描淡写**——施害者的结局必须具体可触（破产到什么程度、不孕是医生确诊的）
4. **爽感不能靠暴力**——全程是逻辑碾压、事实碾压、地位碾压，不是打架

## 二、人设灵魂锁

### 姜晚（女主）

**灵魂核心**：曾经全情投入不计回报，一旦清醒就绝不回头

**行为准则**：
- 不解释（"过去了就是过去了"）
- 不控诉（从不当众数落肖奈的罪行）
- 不得意（碾压时保持平静，不夸耀）
- 不犹豫（做了决定就执行到底）

**禁止行为**：
- 哭着问"你为什么这样对我"
- 主动找肖奈对质/吵架
- 对江柔说"你也配"之类的攻击
- 在新关系中提起旧爱

### 肖奈（渣男）

**灵魂核心**：把女主的付出当空气，失去后才发现她是氧气

**崩塌曲线**（不可压缩）：
1. 得意期："她能怎样，还不是回来"
2. 困惑期："她怎么不回消息了"
3. 震惊期："她真的嫁我哥了？"
4. 崩溃期：当面哭、失眠、跟踪
5. 臣服期：叫"大嫂"、说"欠你的会还"

**禁止行为**：
- 一步到位的醒悟（必须逐层递进）
- 暴力报复（只能是无力+悔恨）
- 被洗白（可以成长，但永远不被原谅）

### 肖珩（新男主）

**灵魂核心**：看见了她的好却选择等待，等到她清醒才出手

**行为准则**：
- 用行动说话，不用语言表白（记得龙井、三个月前备婚纱、劳斯莱斯接亲）
- 护犊但不越界（"以前的事不提了"——不替她出头让她难堪）
- 有底线地对弟弟（给50万但必须还债）

### 江柔（闺蜜反派）

**灵魂核心**：因嫉妒而背叛，因背叛而失去一切

**结局不可修改**：
- 失去生育能力（物理性不可逆）
- 被社会标签困住（"洗脚妹"传言）
- 新关系因不孕被抛弃
- 真心忏悔但得不到原谅

## 三、情感节奏契约

### 爽感输出节奏

```
每1000字：至少1个微爽点（台词回旋/证据落地/旧爱吃瘪）
每2500-3000字：1个大爽点（身份揭露/公开碾压/全面崩溃）
全文：4个爽感高峰（镜像反击/婚礼碾压/家宴揭露/终局清算）
```

### 压迫-释放比

- 压迫不超过连续2章（超过读者会弃读）
- 每次释放的强度必须 > 前一次压迫的强度
- 释放不能是"想象中的"，必须是"当场兑现的"

### 结尾契约

- 不能大团圆欢庆
- 不能开放式（读者需要确认女主过得好）
- 必须是"平静+留白"——女主已翻篇，旧爱永远走不出来
- 最后一句必须有诗意收束感
