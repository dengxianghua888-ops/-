# 源文拆解：货主坑我超载罚三千，我拉走一吨沉香他疯了

## 基本判定

- 题材：现代反转，底层职业维权爽文。
- Hook：H1 倒叙冲突式。
- 标题公式：T1 因果反转式为主，T4 数字对比式辅助。
- 核心机制：M1 死环反杀 + M3 因果回旋反讽 + M6 多层递进反转。
- 源文长度：11421 字。
- 情绪曲线：低价接单受辱 → 超载罚款 → 被砸车扣车 → 封号污名 → 家人被威胁 → 举报黑货 → 刑事升级 → 官方清算 → 职业尊严回甘。

## 黄金 Hook 拆解

前 300 字完成四连击：顺路低价接单、实际三吨超载、罚款扣分、货主性别羞辱。P2-P8 用“2吨”“大几百万”“2000砍到500”“3吨”“罚款3200，扣6分”把经济冲突和规则陷阱压实；P11-P16 用“女司机”“自己不看合同怪谁”“不然我就告你抢劫”制造强烈愤怒；P19-P20 直接给出爽点预告：“卸到2吨整”“认认真真按合同办事”。

Hook 的关键不是惨，而是让读者立刻知道：反派拿合同欺负人，主角马上要用合同反杀。

## 爆款基因

1. 规则压迫有现实感：合同、罚单、平台封号、征信、律师函都是真实读者能理解的压迫工具。
2. 主角反击不靠身份：她没有隐藏富豪身份，所有优势来自职业经验、暗线记录仪、证据保存和冷静选择机关。
3. 反派恶意持续加码：性别羞辱、砸车、平台举报、人肉、骚扰母亲、贿赂、威胁手脚，债务不断堆高。
4. 爽点释放有官方背书：林业局、交通执法、公安、法院、媒体、交警支队逐步介入，让清算可信。
5. 回甘落在职业尊严：结尾不是暴富，而是保养重卡、签正规年度合同、继续上路。

## 锁定层

- 锁定“低价接单 + 数字陷阱 + 合同压迫 + 额外高价值货物”结构。
- 锁定主角冷静、克制、会取证，不写情绪崩溃式反击。
- 锁定反派从嚣张到求饶再到崩溃的身体落差。
- 锁定家人被威胁作为中段最强情绪债。
- 锁定“官方流程一步步清算”的现实爽感。

## 可替换层

货物品类、执法机关、平台名称、城市路线、罚款金额、母亲场景、最终合作客户都可换；但每个替换物必须承担同等功能：能制造数字错位、能被文件固化、能被官方鉴定、能引发刑事或行政清算。

## 改编风险

- 若删掉平台封号和骚扰母亲，读者只会觉得是普通货物纠纷，情绪债不足。
- 若让主角靠后台或富人身份解决，会破坏底层职业维权的爽感。
- 若非法货物证据来得太突然，会像机械降神；必须提前埋“为什么他死活不露面”“装车录像”“额外一吨未标注”。
- 若结尾只写判刑，不写母亲洗污名和职业回暖，回甘不完整。
