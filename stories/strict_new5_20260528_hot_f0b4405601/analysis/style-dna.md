# Style DNA

## 开篇结构分析

- **opening_structure**: conflict_first
- **判断依据**: 第一行交代“老婆喝多叫我去接她”，第三行即进入妻子醉话羞辱，前 10-15 行没有冷静剧透完整故事链，而是直接抛出婚姻冲突与离婚决定。
- **开篇逻辑链**: 接妻子 -> 妻子醉话说男主没本事 -> 赘婿/免费劳动力羞辱 -> 榴莲旧账浮出 -> 男主决定离婚。
- **非 conclusion_first 原因**: 没有提前写“离婚后她悔疯/我年薪百万/儿子求我”等完整 payoff，只给即时冲突。

## 快节奏锁定

源文是快节奏短篇。仿写不得用解释性长段、流程清单、情绪总结替代现场交锋。所有关键变化必须落在可见动作、对白、物证或第三方见证上。

## 句式 DNA

- **主句长度**: 多数 8-22 字，短句后接一两句解释。
- **常用推进式**:
  - “我刚 X，就听见 Y。”
  - “原来……”
  - “这就是……”
  - “谁告诉你们……？”
  - “不是 X，是 Y。”
- **高频冲突句式**:
  - “你也配？”
  - “你凭什么？”
  - “你本来就不如……”
  - “我不会原谅你。”
  - “跟我有关系么？”

## 对话 DNA

- 对话不是闲聊，基本都承担三种功能：羞辱、逼迫、打脸。
- 反派对白口语化、短促、带价值判决。
- 男主前半对白少而硬，后半对白冷而准。
- 直接对白常独立成行，制造移动端阅读节拍。

## 金句模板

1. **身份反夺**: “我是为爱入赘，不是只能入赘！”
2. **证据砸脸**: “你女儿买的金手表戴在你养子的手上。”
3. **边界宣告**: “这世界上不是每一句对不起都能换来没关系！”
4. **旧话回敬**: “其实你也挺不如别人家的孩子的。”
5. **终局切割**: “以后宋雨橖的事都不用告诉我了！”

## 禁用风格

- 禁止大段心理分析替代吵架现场。
- 禁止用“我心里五味杂陈”等空泛表达。
- 禁止古风宿命词、霸总油腻词、AI 味转折词。
- 禁止让反派长篇忏悔，悔恨必须通过跪、哭、求复合、失业、失宠等行动呈现。
