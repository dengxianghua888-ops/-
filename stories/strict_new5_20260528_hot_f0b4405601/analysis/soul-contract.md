# Soul Contract

## 读者承诺

让读者看到：一个被妻儿岳家嫌弃、被当成免费劳动力的男人，撤回十年付出后，不靠哭诉，不靠复合，而是用真实能力、事实证据和冷静边界，把所有低估他的人逐个打回现实。

## 神髓一句话

不是“赘婿突然暴富”，而是“被家庭消耗的强者撤回价值后，寄生者集体崩塌”。

## 情绪契约

| 必须让读者感到 | 对应写法 |
|---|---|
| 心寒 | 妻子、儿子、岳家连续站队养弟 |
| 憋屈 | 男主为家付出十年，却被一个榴莲否定 |
| 愤怒 | 岳父打人、岳母诬陷、妻子动手 |
| 蓄爽 | 男主交出药箱、课程表、饮食禁忌 |
| 爽 | 金表、买房、报警、工程师身份逐层打脸 |
| 边界快感 | 儿子和前妻求原谅均失败 |
| 自由余味 | 男主调去总部，关机，睡醒开启新生活 |

## 锁定机制

### M2 身份反差爆发

男主前半被定义为“月薪一万销售、赘婿、没本事”，后半必须用专业能力、收入、房产、职场称呼逐步推翻。身份揭露不能一次完成，至少两层：财产层和职业层。

### M3 因果回旋反讽

所有关键羞辱必须回旋：

- “不如小天” -> “你也挺不如别人家的孩子的。”
- “赘婿活不下去” -> “我是这里的业主。”
- “对不起”想换复合 -> “不是每一句对不起都能换来没关系。”
- “免费劳动力” -> 男主撤回照护后全家崩盘。

### M5 温度反转曲线

前半必须写男主确实爱过、付出过、期待过妻子维护自己。中段写他情感归零。后半妻儿回头时，他只履行法律责任，不再给情感兜底。

### M6 多层递进反转

反转层级必须递进：

1. 生活层：男主离开后睡懒觉、租房重启。
2. 能力层：AI 系统卖三百万，年薪百万。
3. 财产层：全款买房，打脸捡垃圾羞辱。
4. 法律层：妻子打人被拘留赔偿。
5. 价值层：前妻下跪、儿子求收留，男主拒绝。
6. 未来层：调总部年薪三百万，彻底离城。

## 禁改项

| 禁改项 | 原因 |
|---|---|
| 妻子亲口说“没本事/赘婿/免费劳动力” | 这是全文羞辱母句 |
| 儿子背刺父亲 | 这是最痛的亲情债 |
| 家务照护清单 | 证明男主真实价值不只是赚钱 |
| 公开证据打脸 | 番茄读者需要第三方见证的爽感 |
| 报警不和解 | 体现男主边界和现实清算 |
| 前妻求复合被拒 | 兑现标题“悔疯”但不回头 |
| 儿子求收留被拒 | 兑现“不再被亲情绑架” |

## 可替换项

- 榴莲可换，但必须是“本该给孩子/家庭关键成员”的高痛感资源。
- AI 职业可换，但必须前文有学历、技能、长期压抑伏笔。
- 金表可换，但必须能公开验证归属。
- 豆浆过敏可换，但必须由养弟照护失职或恶意触发。
- 调总部可换，但必须是离开旧城市、进入更高平台。

## 失败判定

若男主复合、原谅儿子、或反派仅靠口头道歉就获得缓和，神髓失败。若后半翻身无前文能力伏笔，只写中彩票、继承、系统奖励，神髓失败。
