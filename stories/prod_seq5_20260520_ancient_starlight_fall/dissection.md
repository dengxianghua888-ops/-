# 源文拆解：《纵有星光坠落时》

## 基础判断

- 题材：都市豪门甜爽 / 追妻火葬场 / 先孕后婚
- 字数：7012 字
- Hook：H1 倒叙冲突式，高压关系场直接开局
- 标题公式：古言对仗式，现代故事用“星光坠落”做诗意包装
- 核心爽点：旧爱误判女主价值，男二与傅家用公开身份、婚姻承诺、资本能力完成补偿式反杀
- 情绪曲线：公开羞辱 → 带孕隐雷 → 二次贬低 → 豪门正名 → 金句回旋 → 财权清算 → 新生余味

## Logline

沈闻被七年旧爱顾呈阳轻视、羞辱、误判为冷战求和，她带着孕检报告转身找傅宴，傅家全族下聘公开认她，最终在婚礼股市战中让顾呈阳亲眼看着她成为傅太太，并看着顾家破产。

## 黄金前 300 字 Hook

开篇第一句就是关系爆点：“傅宴！你敢招惹她，我一定跟你鱼死网破。”读者立刻知道有三角关系、争夺、失控前任。随后傅宴反手提出交换：“我把沈闻还给你，你把她给我”，顾呈阳先推江盈盈又拽回，暴露他的自私与摇摆。章尾钩落在“封锁全市酒店”，让读者追问：沈闻和傅宴到底有没有发生关系？顾呈阳会不会查到？

Hook 强度：8.6/10。优点是冲突极快、人物站位清楚；弱点是“5/6”章节残留会干扰沉浸，改编时应删除。

## 反转机制清单

### M2 身份反差爆发（关系身份 + 男二能力变体）

- 表层低位：顾呈阳认定沈闻“丢人”“不被傅宴挑中”，证据句：“他傅宴再不济，也不是不挑不拣的。”
- 第一层揭露：傅宴出场并已拿到孕检报告，“从你出医院开始，你的检验报告就已经在我的桌上了。”
- 第二层揭露：傅家全族站起、彩礼聘单、月子营养单、不动产协议齐上桌。
- 第三层揭露：傅宴在生日宴公开宣布：“我跟沈闻订婚，八天后请大家喝喜酒。”
- 第四层揭露：婚礼股市战中，傅宴十五分钟填窟窿，二十分钟让顾家破产。

### M3 因果回旋反讽

- 施害者原句：“沈闻，这场冷战你赢了。”
- 反身回敬：“她只是要跟我结婚了，但冷战你赢了，你应该高兴的。”
- 功能：把顾呈阳的自我中心逻辑原样反打。他以为女主所有行动都是冷战策略，最后“赢冷战”变成他失去女主的判词。

### M5 温度反转曲线

- 温度正峰：七年旧情由女主亲口确认，“我有一段谈了七年的感情，他都不肯跟我结婚。”
- 温度归零：顾呈阳在泳池与年轻姑娘嬉闹，又把女主回国解释成争风吃醋。
- 温度负值：订婚公布后他失控追问：“沈闻，我们不是在冷战吗？”
- 注意：源文的“正峰”主要靠回忆陈述，缺少具体温柔场景；改编若要强化 M5，应补一处旧日承诺或照顾细节。

### M6 多层递进反转

- Layer 1 情节层：沈闻回国不是找顾呈阳，是确认怀孕并找傅宴。
- Layer 2 身份层：傅家当场拿出聘单、月子安排、不动产协议，认沈闻和孩子。
- Layer 3 公开层：生日宴上傅宴宣布订婚，顾呈阳从掌控者变成旁观者。
- Layer 4 权力层：婚礼股市战反杀，傅宴二十分钟让顾家破产。
- Layer 5 价值层：沈闻接受新的生活秩序，结尾落在“种子总会生根发芽”。

## 锁定层

必须保留“女主不解释地转身”“前任持续误判”“男二家族主动正名”“公开订婚打脸”“冷战金句回旋”“婚礼级终局清算”。这些是读者爽感的骨架，换题材时只能换载体，不能降级为私下和解或口头宠爱。
