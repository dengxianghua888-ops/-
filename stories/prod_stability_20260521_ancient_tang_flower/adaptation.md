# 高保真设定重置室

## 改编目标
保留《棠花落尽不相逢》的商业灵魂，不保留原文可被一眼识别的壳层道具。必须继续成立的链路是：
- 开篇公开背叛，且发生在女主应被郑重对待的重要日子
- 女主异常冷静，反常到让所有人不安
- 前世记忆解释“她为什么不闹了”
- 抽身计划具备倒计时和可执行性
- 丈夫与孩子形成双重背叛
- 中段出现一次不可逆的“生命级放弃”
- 男主在彻底失去后才知道真相
- 重逢不复合，赎罪不兑换爱情

## 候选方案

### A案｜漕盐世家 + 河祭替身 + 水路假殁
- `premise`
  - 女主是盐商世家嫡女，嫁给掌漕运与盐引的都转司少卿。庶妹长期以“体弱、懂事、替姐姐分忧”为面具，蚕食她的婚姻与亲子关系。五周年祭河大典当日，丈夫为救卷入私盐风波的庶妹公然失约，女主平静转身，暗中与“水殓档”签下假殁契。最终在运河闸口的一换一中，丈夫与儿子共同选择庶妹，女主借河祭沉船局“死”在众人眼前。
- `优点`
  - 水路、盐引、祭河、沉船与假殁天然统一，码头一换一能无缝迁移为“闸口劫持”
  - 古言壳更稳，番茄读者接受度高
  - “水殓档”可替代假死机构，不出戏
- `风险`
  - 若漕盐制度写太细会拖节奏
  - 要避免写成权谋文，需要始终以情绪压强为主

### B案｜药王谷外嫁 + 灾疫配药 + 山洪殉身
- `premise`
  - 女主出身医药世家，嫁给边郡都督。妹妹伪装成长期病弱的试药人，借“救人”“配药”“解疫”不断侵占丈夫与孩子的依赖。五周年施药宴上，丈夫为护妹妹名声当众弃她；后续母忌、雷雨、寿宴污名层层加码。终局改为山洪夜的药车换人，丈夫与儿子先保妹妹，女主坠入断崖洪流完成假死，再于异邦医馆重生。
- `优点`
  - 妹妹“病弱”“用药”与女主不能吃海鲜、抽血旧伤等情绪债易重写
  - 海外新生可改为边境医馆，治愈感更自然
- `风险`
  - 药与疫容易碰高敏议题，表达边界要稳
  - 山洪替代码头虽成立，但视觉记忆点略弱于水路交易

### C案｜织造局姻亲 + 贡缎诬案 + 火场替焚
- `premise`
  - 女主是江南织造世家出身，嫁给督造司使。庶妹以“替姐姐试样、替霍家应酬”为名，逐步取代她在府中与孩子心中的位置。五周年贡宴当日，丈夫为庶妹卷入私贡风波而缺席。女主预约“焚籍脱身”，准备借贡仓火场假死。高潮改为押送贡缎途中的渡桥截杀，丈夫与儿子先救庶妹，女主在焚仓中被认定身亡，后于海贸织坊改名新生。
- `优点`
  - “贡缎”“火场”“焚籍”有古风辨识度
  - 生日宴污名可丝滑改成贡宴失德案
- `风险`
  - 火场假死与后续确认尸身需要更强证据补丁
  - 若处理不慎，容易和常见宅斗织造文撞壳

## 选择结果
选择 `A案`。

### 选择理由
- 神髓保真最高：水路交易、闸口换人、沉船假殁，能完整继承“码头一换一 + 跳海死遁”的不可逆情感死刑。
- 机制承载最顺：M5 的温度反转可通过“旧日河灯誓言”与“雷雨失约”形成回旋；M6 的多层反转可由“祭河失约 - 闸口弃选 - 假殁成真 - 异乡重逢不认”自然递进。
- 新鲜度足够：从常规侯门/王府壳切到“漕盐世家 + 水殓档”，既古言熟口又不容易一眼看出原故事。
- 番茄适配强：河运、私盐、祭河、闸口劫持都具备强画面、快节奏与公开羞辱场景，利于短篇爆点推进。

## 核心替换方案

### 角色替换
- 女主：从常规侯门夫人重置为盐商嫡女、精于账册与水路规制的当家主母
- 男主：从泛权势男主重置为都转司少卿，掌漕运、河闸与盐引调度
- 妹妹：从病弱白月光型侵入者重置为“寄养归府的庶妹”，以弱柳扶风和识水性、懂祭仪为伪装
- 儿子：保留“被驯化成刺”的功能，改为自幼常由庶妹陪在船队与河祭场合，被误导更深
- 新男主：改为江南外洋商路上的海舶主兼异地安置人，提供安静可靠的新世界样本

### 场景替换
- 五周年宴会：改为祭河大典兼家宴
- 雷雨墓园：改为母亲河灯祭日的堤岸雷雨夜
- 生日宴污名：改为盐号庆功宴上的失德流言与账册栽赃
- 码头一换一：改为运河闸口被水匪截船，一换一赎人
- 海外新生：改为南洋商埠的女学账房与香料行，不重资产设定，只保留“重新活”

### 机制载体替换
- 假死机构：改为“水殓档”
  - 专替失踪者、逃命妇人与不能见光的人做“溺亡身契”
- 死亡确认书：改为官府勘验的溺亡簿册与河尸认领记录
- 挡枪：改为火铳或袖弩挡杀，保留“他终于真正护住她一次，但太晚”
- 拍卖会/黑道壳：改为私盐、河闸、走水货与水匪交易链

## 机制保真校验

### M5 温度反转曲线
- 前温度峰值仍需真实成立：
  - 男主年轻时曾在河匪手里救下女主
  - 曾在河灯夜许诺“今后每场风雨，我都陪你”
  - 婚初共同整顿盐号、点灯看账的旧温柔必须具体
- 温度归零必须连续、不可洗白：
  - 三次都为庶妹出头，而且每次都有“为了你名声/为了大局”的自我合理化
  - 雷雨河堤再次失约
  - 闸口一换一时他与儿子同时选庶妹
- 温度负值阶段：
  - 他疯狂捞人、清算真凶、挡杀赎罪都能写
  - 但所有补动作都只能强化“迟了”，不能改判

### M6 多层递进反转
- Layer 1：
  - 女主不是忍让，而是联系水殓档，启动溺亡脱身
- Layer 2：
  - 闸口换人，丈夫儿子共同放弃她
  - 女主沉河完成关系死亡
- Layer 3：
  - 男主后知后觉发现庶妹才是私盐局与污名局总导演
- Layer 4：
  - 异乡重逢，女主否认身份
  - 最终挡杀也只能换来“多谢，不回头”

## 敏感议题边界
- 亲子背叛：
  - 重点写“被长期诱导后的刺痛”，不把篇幅转成育儿教育文
- 庶妹恶性：
  - 必须是长期蓄谋型加害，但不写低俗性羞辱，不靠露骨性暴力推动
- 假死与溺亡：
  - 以戏剧化叙事处理，不写细致自伤教程，不提供模仿路径
- 走私与水匪：
  - 只作为外部高压场，不展开犯罪操作细节
- 终局赎罪：
  - 男主可死、可伤、可废，但都不是复合筹码
