## 句法节奏

原文主要靠短句推进，平均句长约16-17字。叙述段多为一行一个动作或一个判断，几乎不做长段心理解释。

高频句式：

- 事实短句：“租金涨了百分之四十。”
- 动作短句：“我挂了电话，走进电梯。”
- 冷处理短句：“好。”“照做。”“不用明天。现在就打。”
- 砸脸揭示：“签名是：苏念。”
- 反讽收束：“感谢老东家的不杀之恩。”

## 对话风格

对话占比高，约四成以上。冲突主要通过对话推动，不靠旁白解释。

反派对话特点：

- 口语化羞辱：“嫌贵？”“你吓唬谁呢。”
- 规则压迫：“押金流程要走三个月。”
- 阶层轻蔑：“跟这种底层人计较什么。”
- 失控反问：“他们……他们是一家的？！”

女主对话特点：

- 短、冷、准。
- 不解释动机，只下指令。
- 高潮处用判断句而不是控诉句。

代表模板：

```text
“行。我明天就搬。”
“安抚客人。退单的双倍赔偿。”
“不用明天。现在就打。”
“你不知情，就是最大的失职。”
“我现在不是万象城的租户。我是这里的股东。”
```

## 爽文金句密度

金句不密集堆砌，而是在关键转折处落刀。约每千字0.75句。

可复用金句类型：

| 类型 | 原文例句 | 功能 |
|---|---|---|
| 尊严判断 | “留在这里，只会被人当狗踩。” | 把搬迁从经营选择升为尊严选择 |
| 反噬预告 | “爬得越高，摔得越惨。” | 给林娇娇埋报应钩 |
| 制度批判 | “你不知情，就是最大的失职。” | 把周总从旁观者变成责任人 |
| 主题升维 | “女人不是男人的附属品。” | 陆父线的价值观核心 |
| 结尾收束 | “生活，从来不会亏待那些死扛到底的人。” | 番茄式正向尾音 |

## 画面与资产词库

原文商业质感来自具体名词，不来自抽象形容词。

高频资产：

- 空间：三楼、一楼中庭、四楼健身房、五楼电竞馆、万象城、LED屏、货梯、走廊。
- 物件：合同、烟灰、保温杯、黑卡、咖啡机、商用烤箱、账单照片、手机录像、股权认购书。
- 数字：租金40%、装修30万、押金50万、预付款100万、客流40%、客流暴跌七成、空铺率60%、股权15%。

写作规则：每个反击都要有可见物件承载，避免写成“她动用关系解决了”。

## 情绪控制

女主几乎不崩溃。情绪表达方式是动作和决策：

- 被断电：不骂人，安排双倍赔偿。
- 被羞辱：不争吵，扫名片进垃圾桶。
- 被锁货梯：不求人，留下烤箱。
- 被周总威胁：起身送客。
- 被陆父压迫：推出股权文件。

这类冷静感是核心爽点。改编时不能让女主长篇哭诉，否则会破坏“冷处理反杀”的风格DNA。

## 章节尾钩模式

原文常用三种尾钩：

1. 反讽承诺钩  
   “明天一定给你腾干净。”

2. 公开处刑钩  
   “感谢老东家的不杀之恩。”

3. 新幕后钩  
   “叫对方‘陆总’。”

每个尾钩都不是单纯悬疑，而是推动读者期待下一轮报应。
