## 主角

### 林烨(主角 / 受害者 / 灵魂线视角承载者)

- **标签**: 隐忍受害者 / 林家亲生少爷 / 沈梦茹丈夫 / 熊猫血同源
- **核心姿态**: 克制 + 决绝 + 哀而不求
- **情感曲线**:
  - 起点: 已麻木(失去八个孩子的累积创伤)
  - 妥协点: 看着血肉模糊的骨血点头(Beat 3)
  - 微反抗: 拔针扑向林梓轩(Beat 7)
  - 自决: 反握裁纸刀刺心(Beat 8)
  - 离场视角: 灵魂上升,冷眼俯瞰(Beat 9-16)
  - 重生姿态: 小恶趣 + 享受补偿(Beat 17)
- **关键金句**:
  - "我累了。我想一个人待会儿。"
  - "何须歃血,把命还给你们。"
  - "过期的深情连狗屎都不如。"
- **不可替换**: 灵魂视角 + 自我了断的主动性 + 不报复也不挣扎的姿态
- **可替换**: 林家少爷身份 → 古代府邸嫡子 / 家族继承人

## 主反派

### 沈梦茹(妻 / 系统受骗者 / 终极悔悟者)

- **标签**: 京圈女总裁 / 高定职业装 / 沈氏集团掌门 / 八次主动流产
- **核心机制**: M5 温度反转载体——用最温柔的语气下最残忍的命令
- **情感曲线**:
  - 起点: 完全相信"系统",为攻略目标牺牲一切
  - 残忍峰值: 命令融合九个胚胎做药剂
  - 转折: 调监控看到裁纸刀逼断亲(Beat 11)
  - 复仇执行: 林家覆灭+林梓轩毁容
  - 终极崩溃: 林梓轩临死前揭穿没系统
  - 自毁: 电锯锯人+安眠药
- **关键金句**:
  - "老公真乖。我就知道你是最顾全大局的。"
  - "孩子没了,以后科技发达了我们还能再想办法。"
  - "听好,从今天起,你是林烨。"
- **温度反差关键段**: 一边让丈夫签谅解书,一边用嘴唇贴他额头
- **不可替换**: 加害时的温柔 + 终局的彻底崩溃 + 真心相信"系统"的愚蠢
- **可替换**: 总裁身份 → 古代正妻 / 王妃 / 当家主母

### 林梓轩(假少爷 / 真凶 / 系统骗局制造者)

- **标签**: 假少爷 / 二十年寄生 / 变声器谎言制造者 / 楚楚可怜表演者
- **核心机制**: M8 道德模糊承载——所有惨剧的幕后伪装
- **情感曲线**:
  - 表面: 被系统逼迫的可怜攻略者
  - 真实: 冷血操纵者,买变声器+特效药制造"系统"
  - 第一次失控: 用输液架砸主角下腹
  - 临死自曝: 嘲讽沈梦茹真凶就是她自己
  - 双重死法: 自毁脸 + 沈梦茹电锯
- **关键金句**:
  - "梦茹姐,我好怕,那个东西看起来好恶心。"
  - "全靠这套伪装,我才阉了你,从你手里抢走了一切。"
  - "是你亲手把他逼上绝路的!"
- **不可替换**: 谎言核心(假规则) + 临死自曝 + 双重死法
- **可替换**: 假少爷身份 → 古代假皇子 / 假世子 / 假替身

## 次反派

### 林依然(姐 / 共谋者 / 偏心野心家)

- **标签**: 林家长女 / 福星迷信者 / 高利贷牺牲品
- **核心机制**: 道德绑架链——用亲情逼主角妥协
- **情感曲线**:
  - 起点: 跳楼相逼+居高临下嫌弃
  - 残忍峰值: 用主角二十岁生日礼物(裁纸刀)逼断亲
  - 反噬: 双腿粉碎+乞讨+被假弟弟当街唾弃
  - 终局: 一口黑血昏死
- **关键金句**:
  - "你享受林家二十年少爷的身份,你一个大男人,少二两肉又死不了!"
  - "拿起这把刀,歃血断亲!"
- **偏心动机**: 大师算命称林梓轩八字旺林家——典型迷信式自欺
- **不可替换**: 偏心来自迷信 + 用礼物逼断亲 + 落街成乞丐
- **可替换**: 长姐身份 → 古代嫡姐 / 嫂嫂 / 婶娘

## 工具人

### 主治医生 / 私人医生 / 保镖 / 黑市医生

- **功能**: 推动情节(执行抽骨髓/制血清/整容),不参与道德判断
- **风格**: 冷峻、面露难色但执行命令
- **可替换**: 古代太医 / 黑市郎中 / 府兵

## 系统(伪)

- **本质**: 林梓轩用变声器录的几句话 + 沈梦茹的偏执笃信
- **功能**: 全文最大谎言,Beat 13 揭穿
- **古代等价**: 假天命 / 伪卜辞 / 替身命格(可由家族大师/巫师/钦天监伪造)

## 真系统

- **功能**: 在主角自插心脏后启动清算,接收沈/林依然悔恨值献祭,送主角去平行世界
- **现身位**: Beat 9 + Beat 16-17
- **古代等价**: 神明 / 因果 / 阎罗
