# 创作笔记 — 漱玉九殇·骨肉成灰

## 一、改编思路

本作改编自 ancient_be_winter_dream 语料(原作《残梦不暖九冬寒》),保留三大反转机制(M4 灵魂线视角 / M5 温度反转 / M8 道德模糊)的等价载体,将世界观从"现代豪门 + 系统反讽"重置为"大梁王朝 + 国师卜骨伪天命",彻底脱离现代医疗器械与系统术语外壳,代之以古代占卜文化、玉佩机括、太医院判等等价物。

## 二、关键改编决策

### 2.1 伪权威系统的等价置换
- 原作: 系统机械音 + 录音笔变声器
- 改编: 国师卜骨爻辞 + 玉佩内藏声机簧
- 设计理由: 古代占卜在大梁朝文化语境中拥有与现代"系统提示"等价的权威感,玉佩机括属古代精巧机关,可承接"录音笔自爆"的戏剧功能。

### 2.2 仪式凶器的回旋
- 原作: 二十岁裁纸刀 (姐姐成人礼)
- 改编: 二十岁加冠玉笄 (长姐加冠礼)
- 设计理由: 加冠是古代男子成年礼,长姐赠笄具仪式感; 玉笄锋利可作刺心凶器,兼具凶器属性与情感羁绊。

### 2.3 极致剥夺的等价升级
- 原作: 九胚胎送实验室熬血清
- 改编: 八胎冰窖标本 + 今晨堕胎合炼"九阴血参丸"
- 设计理由: 古代秘药文化天然吸纳"丹药入血" 这种极端配方,九阴血参丸命名兼具古风与器官隐喻。

### 2.4 公开羞辱债的偿还方式
- 原作: 全网直播
- 改编: 京畿三十六行行会传影 (暗哨网 + 传影玉镜)
- 设计理由: 古代权贵社交圈是封闭等级网络,"行会传影" 比单纯"通报"更有现代直播的粉碎力,同时不破坏古风。

### 2.5 反派双自毁的仪式感强化
- 原作: 沈梦茹电锯 + 安眠药
- 改编: 漱玉郡主破甲长锯 + 鹤顶红
- 设计理由: 鹤顶红为古言文学经典毒物,破甲长锯比电锯更具古代战阵冷兵器感。

## 三、文风 DNA 应用

### 3.1 句式
- 严格遵守 ancient_BE 文风 DNA: 平均句长 11-14 字,实测 12.3 字
- 破句一刀式: 每段 1-3 句,每句 ≤25 字 (对话外)
- 卜骨爻辞独占段: 用引号短破折号格式,与原作【】系统提示等价

### 3.2 词汇
- 器官隐喻保留: 阉割 / 心头血 / 骨血 / 根骨 / 命根子
- 古言遗痕加强: 玉笄 / 卜骨 / 魂引 / 承运 / 续命 / 天命
- 现代词全数替换: 监控 → 暗哨密报, 直播 → 行会传影, 输液架 → 鎏金烛台

### 3.3 称谓
- 老公 → 夫君
- 老婆 → 妾身 / 郡主
- 阿姐 → 长姐 / 阿姐
- 总裁 / 老板 → 郡主 / 主母

## 四、机制承载点设计

### M4 灵魂线视角 (Beat 9-16)
- 触发: Beat 8 主角反握玉笄刺心
- 视角位置: 王府正堂梁上
- 关键观察: 漱玉抱尸狂叫(Beat 9-10) → 谢家覆灭与谢明姝乞讨(Beat 12) → 萧迟玉佩自爆(Beat 13) → 漱玉踹门听全场(Beat 14)
- 收束: Beat 16 漱玉电锯锯人 + 鹤顶红自尽 → 卜骨清算面板出现

### M5 温度反转曲线
- 第一峰 (Beat 4): 漱玉郡主吻眉心叫"夫君真是体己"
- 第二峰 (Beat 10): 漱玉抱尸归府,擦血换月白锦袍,自扇耳光至唇角流血
- 谷底 (Beat 8): 主角自插玉笄,"何须刺血。我把命还给你们便是。"
- 回响 (Beat 16): 漱玉服毒前望梁求恕

### M8 道德模糊结尾 (Beat 17)
- 主角内心独白完整保留原作金句"变着花样地作威作福"
- 不升华、不原谅、不反思
- 平行世界给真实的健康躯体,而非精神救赎

## 五、付费卡点设计

按番茄短篇付费节奏切分 8 章,设置 3 个付费卡点:

- 卡点 1 (Beat 5): "你一个堂堂男儿,少二两骨血又死不了" — 最大羞辱压力点
- 卡点 2 (Beat 8): "何须刺血。我把命还给你们便是" — 主角主动离场
- 卡点 3 (Beat 13): "全靠这套伪作,我才阉了你" — 终极谎言曝光

## 六、爆款神髓合约校验

✅ 一句话承诺: 看主角在极致错付后抽身或死亡,迫使施害者迟来的悔悟变成惩罚 — 完整兑现
✅ 错付虐恋债: 前 50% 充分铺设,后 50% 完整偿还
✅ 公开羞辱债: 萧迟易容直播至京畿三十六行行会
✅ 价值补偿债: 平行世界健康躯体 + 护短世家爹娘
✅ 主角姿态: 克制、决绝、哀而不求
✅ 道德坐标: 反派长期冷待主角,主角只是在对方规则内追回应得的公平

## 八、敏感处理

- 阉割描写: 用古代医学语境"截除根骨""下身"含蓄处理,不写解剖细节
- 流产/堕胎描写: 用"失了骨肉""停胎""鲜活胎儿"等词,不写血腥工具
- 易容/酷刑: 集中在 Beat 8-9, 用"鬼参液""压声咒""木枷樊笼"古风词汇,降低现代器械感
- 道德模糊: 平行世界结尾保留"变着花样作威作福",符合 ancient_BE 受众期待,不做圣母化处理
