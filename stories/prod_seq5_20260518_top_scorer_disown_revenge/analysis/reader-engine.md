# Reader Engine

## 首钩引擎
前300字连续抛出三个问题：
1. 为什么省状元当天会被断亲？
2. 真千金到底是谁？
3. 主角为什么突然报警说全家被灭门？

对应原文证据：
- “高考746分成为省状元当天我回家报喜”
- “算起来你只是假千金”
- “我要举报海庭湾别墅34号全家被灭门”

## 核心续读问题链
| 阶段 | 读者问题 | 原文触发 | 推动方式 |
|---|---|---|---|
| 开局 | 家人是真抛弃还是有隐情？ | 断亲书、退婚信、空别墅 | 先让读者相信抛弃成立 |
| 门外 | 哥哥哪里不对？ | “看清来人的那一瞬间” | 遮蔽具体证据 |
| 警方搜查 | 尸体为什么找不到？ | “没有任何尸体痕迹” | 技术检测反压主角 |
| 假家人登场 | 他们到底是真是假？ | 神态语气和亲子鉴定都无异常 | 多重可信证据伪装 |
| 直播 | 主角会不会毁掉前途？ | “直播报假警” | 公共审判放大代价 |
| 顾教授反转 | 她写了什么？ | “看到那行字后，顾教授迅速按下对讲机” | 关键信息延迟公开 |
| 夜视模式 | 血迹为什么只在夜视下显现？ | “狰狞的绿点” | 引出螯合剂 |
| 终极藏尸 | 尸体到底在哪里？ | “申请拆迁队” | 空间谜题升级 |
| 庭审 | 反派凭什么还这么狂？ | “法律能把我们如何吗？” | 等公开判死刑 |
| 结尾 | 主角如何活下去？ | 名校争抢 | 价值选择收束 |

## 情绪驱动循环
```yaml
loop:
  - 施压: 亲人/警方/网友/反派否定主角
  - 主角加码: 报警/赌前途/直播/拆楼/起诉
  - 证据失败: 检测无异常、DNA无异常、尸体无踪
  - 细节破局: 夜视、螯合剂、墙体凸起、纹身
  - 公开打脸: 顾教授增援、直播转向、庭审判决
```

## 爽点触发器
- 身份高光爽：省状元身份让主角的“脑子好用”合理化。
- 被低估爽：警方、网友、假家人都把她当缺爱疯子。
- 知识破局爽：螯合剂中和鲁米诺效应，专业能力成为武器。
- 公开打脸爽：直播间人数从质疑到等待警方通告。
- 终极反转爽：尸体不是没藏，而是藏成了整栋房子。
- 法律清算爽：反派从“找证据呀”到“五人全部死刑”。

## 读者情绪债清单
- “她考了746分，却没人抱她”。
- “她被叫假千金，被退婚，被当成纠缠者”。
- “她明明报警救真相，却差点被拘留”。
- “她被全网骂拿死全家起号”。
- “她最后发现家人从未抛弃她，而是死在她身边”。

## 完读动力
完读动力来自双线并行：
- 悬疑线：尸体在哪里，假家人怎么骗过检测。
- 情绪线：家人到底有没有爱过她。

两条线在第8章合并：“尸体在墙里”同时回答悬疑，“断亲书是遗言”同时偿还情绪。
