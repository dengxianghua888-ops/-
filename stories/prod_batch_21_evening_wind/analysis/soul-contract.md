# Soul Contract — 《晚风别忆旧时人》

## 读者承诺

看被闺蜜和男友双重背叛的独立女性，不哭不闹地在公开场合让施害者现出原形，然后看他们亲手选择的"幸福"如何变成互相折磨的牢笼，最终在主角彻底放下的平静中完成情绪清算。

## 情绪债清单

### D1 · 信任背叛债（核心债）
- **债务人**: 许知意 + 傅涵之
- **累积**: 25年友谊 + 无上限副卡 + 工作安排 + 住所提供 → 在主角的家、主角的床上背叛
- **偿还形式**: 婚礼公开曝光 + 社会性死亡
- **偿还时机**: 全文45%位置

### D2 · 恩将仇报债
- **债务人**: 许知意
- **累积**: "你拥有的一切都可以分给我" + "这是你欠我的" + 摘围裙牵手离开
- **偿还形式**: 失去全部社交圈、跪求不得、最终在超市做收银员
- **偿还时机**: 55%-80%逐层偿还

### D3 · 虚伪保护债
- **债务人**: 傅涵之
- **累积**: 以"她活不下去"为由出轨 + "别闹脾气"的上位者姿态 + 撤资威胁
- **偿还形式**: 名声崩塌 + 事业失败 + 被许知意窒息式纠缠 + 烂醉求回不得
- **偿还时机**: 55%-90%逐层偿还

## 爽点因果链

```
施害者种因: 傅涵之说"她离开我活不下去"（M3种子句）
     ↓
主角被迫接受，出国离开
     ↓
许知意果然全面依赖傅涵之（因果兑现）
     ↓
依赖变成窒息：翻手机、查行程、视频确认
     ↓
傅涵之说"受够了，她就是个疯女人"
     ↓
主角冷静回旋："那是你自己选的。当初你说她离开你活不下去。现在她离不开你了，你应该高兴。"
     ↓
死环：离婚→许知意无处可去；不离→互相折磨
```

## 道德坐标

- **读者站主角的理由**: 主角是纯粹的付出者/保护者，从未亏欠任何人；施害者享受了她全部的善意后反手捅刀
- **反派违反的规则**: 信任不可滥用、恩情不可忘、背叛必须付出代价
- **道德边界**: 主角的反击方式是公开真相（非捏造），切断关系（非报复），平静前行（非毁灭对方）——她没有变成施害者

## 主角姿态

- **前期**: 震惊但克制，不哭不闹不求
- **中期**: 冷静计划，证据型反击（保存出轨照片用于婚礼）
- **后期**: 彻底放下，面对跪求和纠缠保持平静，不动摇
- **核心姿态关键词**: 体面、克制、不回头、"不在乎了"

## 神髓禁改项

1. 双重背叛的"双线"设定不可降为单一出轨
2. 主角的付出者/保护者身份不可削弱
3. 公开曝光场景的画面冲击力（需要一个"舞台"）
4. M3金句回旋必须在文中出现
5. M5温度曲线的三段完整性
6. 施害者最终互撕的因果闭环
7. 主角结尾的"平静放下"姿态（不是愤怒复仇）
8. 情绪物理化的克制表达方式

## 可替换项

1. 具体职业和商业场景
2. 友谊的具体年限和起源故事
3. 曝光的具体技术手段
4. 新恋人的人设和出场方式
5. 地理背景（英国/城市可换）
6. 许知意的前夫背景
