# Reader Engine — 《晚风别忆旧时人》

## 读者心理操控模型

### 开篇（0-15%）: 代入 + 信息差建立
- **代入点**: 为朋友付出一切的善良女性（普遍共鸣）
- **信息差**: 读者通过男友抱怨暗觉许知意不值得，但主角还在维护
- **操控手法**: 先让读者对许知意产生轻微反感 → 后续背叛时愤怒加倍

### 中前期（15-40%）: 愤怒累积 + 无力感制造
- **读者状态**: 替主角愤怒，但看她受制于人情和威胁
- **操控手法**: 每次主角试图反击都被压制（"别闹脾气""给你三天考虑"）
- **目的**: 压得越狠，后续反击越爽

### 高潮（40-55%）: 情绪释放 + 正义执行
- **读者状态**: 终于！解气！
- **操控手法**: 婚礼场景的"舞台"设计让所有人见证真相
- **目的**: 单对单反击不够爽，必须是公开处刑

### 后期（55-90%）: 因果闭环可视化
- **读者状态**: 看施害者自食恶果的舒适感
- **操控手法**: 逐层展示后果（股价→名声→人际→婚姻→精神），层层递进不一步到位
- **目的**: 爽感持续释放而非一次性耗尽

### 收束（90-100%）: 升华 + 新生
- **读者状态**: 释然、羡慕、认同
- **操控手法**: 新恋人代表"真正好的爱情长什么样"，对比加强主角选择的正确性
- **目的**: 离开时读者带走的是"我也值得更好"的认同

## 读者期待管理

| 位置 | 读者想知道 | 故事给了什么 | 延迟策略 |
|------|-----------|-------------|---------|
| 15% | 她会分手吗？ | 没有——傅涵之先说"是我的问题" | 被动接受 |
| 25% | 她会原谅吗？ | 没有——"不问自取那是偷" | 态度明确但无行动力 |
| 35% | 她会被打压倒下吗？ | 一个月后收到婚礼邀请 | 时间跳跃制造悬念 |
| 45% | 她会在婚礼做什么？ | 大屏曝光！ | 延迟到场才揭晓手段 |
| 70% | 她会原谅回头吗？ | 绝对不会 | 每次跪求都被冷静拒绝 |

## 付费拉力点设计

1. **第一付费墙（~15%）**: 回家撞破后，"什么时候开始的？"——读者必须知道答案
2. **第二付费墙（~35%）**: 傅涵之威胁撤资后，婚礼邀请到来——读者要看她怎么反击
3. **第三付费墙（~50%）**: 婚礼曝光刚完成，社会后果待展开——读者要看施害者怎么惨
4. **第四付费墙（~75%）**: 施害者上门跪求，金句回旋即将落地——读者要看最后一刀
