# 写作蓝图 — 奶奶的退休金·亲情伦理

## 全局设定

| 项目 | 原文 | 新作 |
|------|------|------|
| 标题 | 我穷得吃不起饭，妈妈却说每月给我三千 | 奶奶说每月给我两千，可我的卡里永远只有二十块 |
| 主角 | 杨琛(男大学生) | 林小禾(女大学生) |
| 亲人 | 妈妈(被蒙蔽) / 爸爸(偷钱元凶) | 奶奶(被蒙蔽) / 大伯母(偷钱元凶) |
| 寄生者 | 堂哥杨锵(开跑车) | 堂姐林雯雯(用奢侈品) |
| 钱的来源 | 妈妈公司赚的 | 奶奶退休金 |
| 数字锚 | 每月3000→实到30 | 每月2000→实到20 |
| 触发点 | 学费未交 | 学费未交 |
| 真相载体 | 定时转款到爸爸银行卡 | 定时转款到大伯母银行卡 |
| 奢侈品 | 布加迪跑车(堂哥) | 爱马仕包+贵族学校(堂姐) |
| Genre | family_ethics | family_ethics |
| 机制 | M3+M5 | M3+M5 |

## 违禁词加载
- **全局硬性违禁 + family_ethics额外违禁**:
  - "毕竟是一家人/血浓于水" → 0容忍
  - "我终于理解了他的苦" → 0容忍（和解套路）
- **句式**: 平均句长14-18字, 对话40%+, 第一人称女主

## 逐Beat映射

### Beat 1（~800字）情绪8.0
白粥咸菜 + 堂姐朋友圈晒奢侈品 + 打电话被骂
"奶奶，这个月生活费……真的有点少……"→ 被大伯母抢过电话痛骂

### Beat 2（~700字）情绪8.5
胃病晕倒 + 看病没钱 + 打电话求助再被骂
"没钱你看什么病？！我不是刚转了2000吗？"

### Beat 3（~600字）情绪7.5
送外卖遇到堂姐——堂姐提着爱马仕从商场出来，路过外卖车
堂姐对闺蜜说"奶奶对我真好，什么都给我买"

### Beat 4（~800字）情绪9.0
回家被大伯母当众羞辱+跪在门口
奶奶心疼但被大伯母操控"这孩子花钱大手大脚，不教训不行"

### Beat 5（~600字）情绪8.5
顿悟+揭穿线索："那个月花三万买包的钱，是从哪来的？"

### Beat 6（~1000字）情绪10
银行查真相——定时转款→大伯母账户→堂姐消费
奶奶的表情从震惊→心碎→铁青

### Beat 7（~1000字）情绪9.5
奶奶反击清算——把大伯一家从房子里赶出去
大伯母闹事，奶奶一句话封死："我活着的时候，房子姓林。我死了，也姓林。"

### Beat 8（~800字）情绪9.5
堂姐朋友圈被扒+社会舆论反转
大伯一家狼狈退场

### Beat 9（~500字）情绪7.0
奶奶道歉+祖孙和解留白
"奶奶老了，眼花了，认不清身边的人。但奶奶心里，永远只有你一个。"
