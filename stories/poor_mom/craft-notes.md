# 仿写手记 — 《奶奶说每月给我两千，可我的卡里永远只有二十块》

## 基本信息
| 项目 | 值 |
|------|----|
| 原文 | 我穷得吃不起饭，妈妈却说每月给我三千 |
| 仿写 | 奶奶说每月给我两千，可我的卡里永远只有二十块 |
| Genre | family_ethics |
| 机制 | M3(因果回旋) + M5(真相延迟引爆) |
| 审校 | PASS ✅ |

## 改编策略

### 换了什么
- **亲人关系轴**: 妈妈→奶奶(被蒙蔽者)；爸爸→大伯母(偷钱元凶)
- **主角**: 杨琛(男)→林小禾(女) — 女主视角在family_ethics更有共鸣
- **寄生者**: 堂哥(开跑车)→堂姐(奢侈品+保时捷)
- **数字锚**: 3000→20→2000→20 — 同一套"假转账"结构
- **清算方式**: 妈妈离婚→奶奶赶走大伯一家 — 老人的觉醒更震撼

### 没换什么（锁定层）
- **M5 五层真相剥开**: 完全保留"卡里没钱→确实转了→定时转走→真凶账户→消费证据"的悬疑链
- **M3 金句回旋**: "每月两千"/"拿小禾当亲闺女"的原句被逐句回敬
- **9Beat情绪曲线**: 高度对齐
- **核心场景**: 食堂白粥/晕倒/外卖遇到寄生者/当众被打/银行查流水——全部保留

### 核心创新
1. **奶奶-孙女线**比原文更虐心——老人被蒙蔽更无辜，觉醒后的愤怒更有力量
2. **大伯母**作为偷钱元凶比原文"爸爸"更具道德冲击——她是外人，却堂而皇之地偷了三年
3. **收尾金句**："小禾，到了没有？" / "到了，奶奶。" / "这两个字，我等了两年。"——比原文的"交给时间"更温暖、更有力
