# Soul Contract — 海关说我的破包是爱马仕

## 读者承诺

读者打开第一段就是想看："小老板被基层公权力借助 AI 系统强行碾压到借高利贷之后，怎么用对方的红章文书反过来把对方钉死"。承诺三件事：

1. **被压迫到极限**：主角真的倾家荡产，老婆要卖房，家底全填进去，不能开外挂提前救场。
2. **反杀必须无解**：用对方亲手开出的盖章文书锁住对方，二选一死环逻辑严密到读者一秒识别"这下完了"。
3. **福报升华**：不是单纯惩恶，结尾要让"被碾压的特征"反向变成"被追捧的卖点"。

```
↓

```

## 道德坐标

- 主角站位："我是本分生意人，被逼到悬崖只能拉对方一起跳"
- 反派违反规则：伪造系统数据 + 滥用职权 + 借公章敲诈 + 职务侵占洗钱
- 读者投射："如果我是他我会怎么做" → "至少敢借钱凑钱不被吞下去"

## 主角姿态

- 隐忍但清醒：愤怒不内心控诉，靠身体反应（"冷到骨头缝里"）
- 破釜沉舟：不是一时冲动，是借钱过程里就开始构思反杀
- 克制复仇：不动手不骂街，靠程序+证据
- 留白结尾：阳光打在相框上，抿一口茶轻笑——不喊口号

## 神髓禁改项（C0）

1. 主角必须真的借钱真的把"罚款/税款"交清，不能靠外力提前救援。
2. 死环必须用对方亲手开出的盖章文书。
3. M3 回旋金句必须在开头与结尾两处使用同一句式。
4. 反派只能锁定外包公司/个别蛀虫，不黑化执法系统。
5. 主角不动暴力，反杀工具只能是程序+证据。
6. 结尾必须福报升华，不能停在单纯复仇。

## 可替换项

- 物品载体（包/车/瓷器/工程机械……）
- 执法窗口（海关/质检/车检/电监/水务……）
- 外包公司名称、地点、人物姓名
- 关键金句的具体词序（保留 M3 回旋句式即可）
- 福报形式（爆单/订单接到手软/被收购都行，必须与本职业务强相关）
