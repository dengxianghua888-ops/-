# Reader Engine — 海关说我的破包是爱马仕

## 读者心理操控点

| 阶段 | 读者状态 | 主角应做 | 信息差 |
|------|---------|----------|--------|
| 0-300 字 | 抓住"X 是 Z 那就按 Z 赔吧"的逻辑悖论好奇 | 倒叙 H1：把"交完钱转身报警"先抛出来 | 读者知道结果但不知道怎么走到那一步 |
| 300-1500 字 | 替主角愤怒：明明是冤枉，为什么交不了？ | 反派一步步加码恐吓 | 读者不知道这是系统化敲诈 |
| 1500-3000 字 | 读者开始绝望：是不是真的要交了？ | 蹲台阶借钱、抵押房产、网贷 | 读者怀疑主角是不是真的要认栽 |
| 3000-4500 字 | 主角刷卡那一刻读者跟着失血 | 刷卡完税，要求印明细 | 读者还不知道这是反杀武器 |
| 4500-6500 字 | 读者一秒醒：原来在等这一刻！ | 当众抖出完税单报警 | 死环锁死，读者爆点释放 |
| 6500-8500 字 | 读者跟着集体翻盘 | 缉私介入，受害商户作证 | 系统性腐败被扒 |
| 8500-10000 字 | 读者跟着福报满足 | 通报判刑、网店爆单、相框上墙 | 反向兑现开头伏笔 |

## 信息差管理

- 主角始终知道真相（包是 90 元/只），反派以为系统挡得住一切。
- 读者跟着主角视角，但比主角少一步：读者要等主角"要求把'爱马仕'印到完税单上"那一刻才反应过来这是反杀。
- 反派最后才知道——盖章那一刻就是末日。

## 共情锚点

- 蹲台阶打电话借钱：每个有家有业的读者都见过/做过这个动作。
- 抵押房产：触发读者最大的"全家家底"恐惧。
- 老婆配合卖房：把恐惧从个人扩到家庭。
- 围观议论指点：触发"被冤枉的全社会注视"压力。

## 留白与节制

- 不写主角内心控诉。
- 不让主角在反派面前流泪。
- 不写血腥/暴力。
- 结尾不喊"正义到来"，靠物象（阳光、相框）说话。

## 跨场景钩子链

```
柜台对峙 → 蹲台阶借钱 → 刷卡完税 → 走向警察 → 死环锁死 → 缉私上门 → 团伙落网 → 通报判刑 → 网店爆单 → 相框上墙
```

每一段落必须留下一个未释放的信息钩，逼读者继续往下翻。
