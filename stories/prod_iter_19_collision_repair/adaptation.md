# Adaptation — 汽修厂说我的货车是报废车

## 选定方案：A 汽修厂报废线

### 一句话设定

义乌-杭州货运个体司机张磊，把跑了 10 万公里的福田货车送进合作汽修厂做大保养，被借"机动车安全检测中心 AI"硬判 D 类报废、强收 30 万安全整改费，否则扣车+企业禁运三年+征信拉黑。张磊抵押房产+网贷凑齐 30 万，在拿到盖了红章的整改完税单后转身向市经侦报案：30 万好车在汽修厂被监守自盗调包成报废车。死环锁死后扯出三年截留 4700 万的系统性敲诈案。

### 主角

| 项 | 设定 |
|----|------|
| 姓名 | 张磊 |
| 年龄 | 36 |
| 职业 | 义乌-杭州小货运个体司机，名下有一家三人小货运公司"磊运快递" |
| 家庭 | 妻子林桂芬，怀孕 5 个月；父亲卧床 |
| 性格 | 跑车十年的老司机，话不多，事情上钻牛角尖 |
| 反杀动机 | 这台货车是全家口粮，借钱已经把家底掏空 |

### 反派

| 角色 | 身份 | 傲慢值 |
|------|------|--------|
| 赵卫东 | 东方汽修厂主管，外包负责保养+预检 | 9 |
| 陈志国 | 机动车安全检测中心外包查验员 | 8 |
| 通达检测科技公司 | 三年截留 4700 万的总公司 | — |

### 核心物件

- 主角车：白色福田双排小货车，10 万公里，刚换过新水箱
- 死环载体：盖了"机动车安全检测中心"红章的"D 类报废整改完税单"+"事故车回收凭证"
- 福报伏笔：开头反派一句"你这破车焊得真扎实，AI 都把它当事故车了"，结尾媒体反向报道"做工太好骗过 AI"

### 核心反转链

```
被判 D 类报废 → 被恐吓扣车+禁运 → 借钱 30 万 → 要求把"D 类报废、3 次撞击、残值 3 万"
            印到完税单上盖红章 → 转身向经侦报案"30 万好车被监守自盗调包"
            → 死环锁死（要么伪造公文，要么职务侵占） → 群体作证 → 团伙落网
            → 通报判刑 → 货车配件厂订单爆单 → 相框上墙
```

### M1 死环结构

```
如果赵卫东承认这台是报废车：
  → 检测公文真，则报销价 3 万必须付给主角，但只给了主角 8000；
  → 检测中心存在系统性篡改 AI 阈值的伪造公文行为，伴随敲诈勒索 30 万。

如果赵卫东承认这台是好车：
  → 那盖章核定的"D 类报废、残值 3 万"就是伪造国家机动车安全检测公文；
  → 30 万整改费没有合法依据，构成敲诈勒索；
  → 现在主角的 30 万好货车在你仓库里失踪，构成监守自盗+职务侵占。
```

无论选哪一支，赵卫东+陈志国+通达检测都得坐牢。
