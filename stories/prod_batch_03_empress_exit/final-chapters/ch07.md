# 第七章

最后一夜，南帐送来急报。

乌兰珠命危。

她躺在软榻上，身边摆着三只暖炉，帐中香膏甜得发腻。

她唇上抹了淡红，却偏要闭着眼，装得气若游丝。

老祭司跪在榻前，“侧妃福运被冲，需正妃心头血，混最后一枚雪铃粉，方能续命。”

我扑到拓跋赫脚边，“父王，你看不出来吗？

她屋里这么暖，她没有命危！”

拓跋赫扶起我，声音哑着，“只取一点血。”

又是只。

只一双眼。

只一点血。

只一个孩子。

阿娘坐在床边，白布覆眼，脸上没有表情。

“取完之后呢？”

她问。

拓跋赫说：“我会护住你。”

阿娘笑了一声，“你护过什么？”

他脸色一沉，“阿泠，别在这时候任性。”

医官捧来短刀。

我比谁都快，扑过去要抢。

指尖刚碰到刀柄，阿娘已经伸手。

她看不见，却准确握住了那把刀。

“阿娘！”

我抱住她的胳膊。

她把我推开，动作很轻。

我却像被推到很远的地方。

“阿宝，活下去。”

老祭司急道：“正妃，快取血！”

阿娘面向乌兰珠，“你想要我的命？”

乌兰珠闭着眼，唇角却动了一下。

阿娘又转向拓跋赫，“你想要王子，想要福运，想要两边都不失。”

拓跋赫上前一步，“把刀给我。”

阿娘摇头。

“不给了。”

她握紧短刀，刺向自己心口。

没有尖叫。

只有最后一枚雪铃猛地震响，像雪夜里裂开的冰。

我爬过去，想按住她的伤口。

她却先把一小片碎铃粉塞进我掌心。

那粉冷得灼人。

“藏好。”

“阿娘，别睡。”

她摸不到我的脸，只摸到我的发顶。

“没有下一个了。”

雪铃在她腕上粉碎。

拓跋赫终于慌了，跪下去抱她，“阿泠！

阿泠！”

阿娘没有再应。

她不是献祭。

她是不要再给了。

那一瞬，帐顶的狼神旗无风自落。

祭司们跪了一地，说这是不祥。

拓跋赫却只顾着掰阿娘的手，像只要把她手指掰开，就还能从掌心里找出一枚新铃。

他找不到。

阿娘把最后的命契断在自己身上。

八个王子，八次续命，雪瞳和心血，全被她一刀一刀还给王庭。

轮到第九次，她终于不肯给了。

我跪在她身边，听见帐外有人报喜，说乌兰珠眼疾止住了疼。

拓跋赫没有让那人滚。

他抱着阿娘，脸上全是迟来的惶然，可他身后的人还在等下一道赏令。

我伸手去碰碎铃，指腹被粉末冻得发疼。

那一点疼救不了阿娘，却让我知道，命契是真的断了。

最后一枚雪铃粉碎。

最后一枚雪铃粉碎，我才知道她连哭声都留给了我。
