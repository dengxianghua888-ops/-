# 源文爆款基因拆解

## 基本判断

- **原文标题**: 娘亲脱离世界后，父皇悔疯了
- **正文长度**: 11960 字
- **题材定位**: 古言 BE / 后宫复仇 / 追妻火葬场 / 系统离场
- **标题公式**: T3 生死悖论式
- **Hook 类型**: H3 预言/违和式
- **核心卖点**: 娘亲被皇权、亲族和系统共同工具化，女儿亲眼见证不可逆离场，十年后用皇权清算所有人。

## 一句话爆款引擎

被好孕系统送进后宫的娘亲，为绝嗣皇帝生下八个皇子后被贵妃和亲族逼到绝境；她只剩三日倒计时，女儿在她死后跪叫仇人“母妃”，蛰伏十年成为皇太女，用证据和皇权让父皇在绝嗣真相里悔死。

**Hook 执行模板**

1. 第一段先给不可逆伤害：第八个皇子被溺死。
2. 第二段给反常行为：娘亲“不闹了”。
3. 第三段给施害者偏袒：父皇说“让她出出气就好了”。
4. 第四段把宫宴羞辱升级为公开践踏。
5. 第五段揭隐藏规则：穿越者、好孕系统、三日倒计时。

## 标题公式拆解

**标题: 娘亲脱离世界后，父皇悔疯了**

- **公式 ID**: T3 生死悖论式
- **结构**: 亲人离场事件 + 权力者迟来悔疯
- **点击点**:
  - “娘亲”锁定亲情虐点。

- **不可丢失的标题信息**: 娘亲不可逆离场、父皇迟来悔悟、古言皇权关系。

### M4-like 变体说明

原文不完全命中标准 M4 灵魂线视角。娘亲不是前20%死亡，也没有亡魂旁观。它借“三天倒计时 + 死后不可追回 + 活人事后知情”承担 M4 的情绪功能。

**改编提示**: 可保留为“不可逆离场倒计时”，不要强行改成亡魂自述，除非后续蓝图决定整体换成灵魂复仇。

## 改编锁定层

- 保留“倒计时 + 离场不可逆 + 迟来悔悟”的三角结构。
- 保留女儿视角，不要让母亲自己完成复仇。
- 保留父皇的伪温柔：他不是纯暴君，他的温柔服务于更残忍的索取。
- 保留反派三方：宠妃、皇帝、亲族，不能合并成单一恶人。
- 保留“认贼作母”的长期伪装。
- 保留后半证据链，不要让复仇只靠毒杀。
- 保留结尾的冷感权力，不要写成无负担甜爽。

## 最易写垮的点

1. **把父皇写成单纯坏人**  
   原文毒点是“他偶尔温柔，却每次都选择贵妃”。若只写暴虐，M5温度反转会变浅。

2. **让娘亲反复解释太久**  
   原文只给她几次短促爆发，很快熄灭，重点是“她不再求了”。

3. **复仇缺少十年成本**  
   后半爽感来自“她真的忍了十年、布了十年”。不能让证据凭空出现。

4. **结尾过度洗白或团圆**  
   父皇不能被原谅，娘亲不能回来，女主的胜利必须带血。
