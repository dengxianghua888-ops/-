# Soul Contract 爆款神髓合约

## 核心神髓

这不是单纯“女儿替母复仇”的故事，而是“被当成生育工具的母亲终于不再被索取，女儿把母亲受过的每一刀都记成账，十年后用皇权逐项收回”。

## 读者承诺

读者进入故事，是为了看到：

1. 娘亲为什么突然不闹了。
2. 父皇到底错过了什么。
3. 宝儿如何在无力年纪活下来。
4. 她为什么要认仇人为母。
5. 十年后她怎样把贵妃、孟家、父皇一个个送进报应。
6. 父皇悔悟时为什么已经毫无意义。

## 必须保留的情绪关系

| 关系 | 神髓要求 | 禁改原因 |
|---|---|---|
| 娘亲与宝儿 | 母女必须是真爱，娘亲的最后愿望是宝儿活下去。 | 复仇正当性来自母女情，不是权力欲。 |
| 娘亲与父皇 | 父皇必须有过温柔或承诺，但每次关键选择都牺牲娘亲。 | M5温度反转需要“曾经似乎有情”。 |
| 娘亲与孟家 | 亲生父母必须背叛她，并偏袒假千金。 | 扩大情绪债，从爱情背叛升级到血亲背刺。 |
| 宝儿与贵妃 | 宝儿必须被迫叫她母妃，并长期伪装乖顺。 | M3回旋称呼的核心载体。 |
| 宝儿与权力 | 宝儿必须从唯一皇嗣升维为皇太女/新帝。 | 后半爽点依赖身份与权力反转。 |

## 锁定机制

### M5 温度反转曲线

- **正温/伪温**: 父皇披大氅、握娘亲的手、承诺“下一个皇子”。
- **归零**: 他一次次选择贵妃，夺女、剜眼、取血。
- **负温**: 娘亲死后，他求她起来，最终知道真相悔死。

**合约**: 父皇不能从头到尾只有暴力。他必须用温柔话术做残忍决定。

### M6 多层递进反转

1. 娘亲不是普通妃子，是穿越者和好孕系统宿主。
2. 父皇不是能生，是绝嗣。
3. 宝儿不是可怜孤女，是唯一继承人。
4. 贵妃不是可怜小产者，是全部旧案操盘者。
5. 宝儿不是乖顺养女，是十年布局的皇太女。
6. 胜利不是私仇，是新帝登位。

**合约**: 反转必须层层升维，不能只保留一个“贵妃被打脸”。

### M3 因果回旋反讽

- “母妃”从羞辱称呼变成处刑称呼。
- 贵妃逼娘亲剜眼，自己眼疾加重。
- 贵妃逼娘亲取血，自己骨毒入髓。
- 孟家把宝儿当筹码，最后被宝儿用谋逆罪清算。
- 父皇想要皇嗣，最终知道自己亲手逼死所有皇嗣来源。

**合约**: 每个主反派的惩罚必须对应他施加过的伤害。

### M8 道德模糊结尾

- 宝儿赢了，但她不是天真孩子了。
- 惩罚极狠，权力带血。
- 玉玺冰凉，登基不是幸福团圆，而是代价后的掌权。

**合约**: 结尾不要写成轻快复仇爽完。必须留一点冷意。

## 不可替换的情绪债链

1. 第八个皇子死，父皇偏袒贵妃。
2. 娘亲刚生产完被逼参加宫宴受辱。
3. 娘亲被罚跪雪地。
4. 外祖父母当众辱骂亲生女儿。
5. 宝儿被过继给贵妃，母女分离。
6. 贵妃伪造宝儿伤痕，反咬娘亲虐女。
7. 娘亲为护女被廷杖。
8. 娘亲为护女被剜眼。
9. 娘亲被逼取心头血，自刺离场。
10. 娘亲尸身被草席裹走。
11. 宝儿跪叫仇人母妃。
12. 宝儿十年后逐项清算。

任何改编若删掉 5、8、9、10、11 中任意两项，神髓会塌。

## 必须兑现的爽点

| 前债 | 后偿 |
|---|---|
| 父皇说“下一个皇子” | 他知道没有娘亲就永远没有下一个。 |
| 贵妃夺走宝儿 | 宝儿用“母妃”称呼骗她十年。 |
| 贵妃假中毒逼剜眼 | 宝儿让她真眼疾、真骨痛。 |
| 孟家拿宝儿当筹码 | 宝儿用孟家罪证抄家灭族。 |
| 父皇草草处理娘亲尸身 | 贵妃被罚跪陵前赎罪。 |
| 父皇不信娘亲时间不多 | 他临死才知道她最后只有三日。 |
| 所有人都说娘亲有罪 | 宝儿用供状和账册证明罪在他们。 |
| 娘亲没能回家 | 宝儿接过玉玺，替她夺回选择权。 |

## 可改但要等价的资产

| 原资产 | 可替换为 | 等价条件 |
|---|---|---|
| 好孕系统 | 神谕、秘术、血契、灵根、血脉咒 | 必须制造“男方误以为自己有能力，实际全靠女方”的反讽。 |
| 三日倒计时 | 三盏命灯、三枚魂印、三次钟响 | 必须可视化递减。 |
| 皇帝绝嗣 | 王爷无嗣、宗门血脉断绝、部族王无继承人 | 必须让女主/母亲成为唯一延续来源。 |
| 贵妃假中毒 | 假病、假失明、假流产、假诅咒 | 必须用于逼母亲牺牲身体。 |
| 账册供状 | 血书、密折、玉简、军报、旧案卷宗 | 必须支撑公开清算。 |
| 玉玺 | 兵符、凤印、掌门令、王座 | 必须是最终权力物象。 |

## 绝对禁区

- 禁止父皇洗白成被完全蒙骗的无辜者。他有选择，他选择了贵妃。
- 禁止娘亲复活或回家后再回来团圆。
- 禁止宝儿中途原谅贵妃、父皇或孟家。
- 禁止男主/爱情线抢走母女复仇主线。
- 禁止把复仇写成单纯下毒成功，必须有证据链和权力链。
- 禁止淡化剜眼、取血、草席裹尸。
- 禁止把“母妃”这个称呼删掉，它是最强回旋载体。
- 禁止让结尾变成无代价幸福生活。

## 改编成败判断

成功版本必须让读者在结尾同时感到三件事：

1. 爽：所有债都还了。
2. 痛：娘亲永远回不来。
3. 冷：宝儿赢了，也被这场复仇锻造成新的掌权者。
