## 一句话定性

短句密集、痛感具象、对白强推动；用儿童第一人称的冷静旁观，把宫斗虐点写成一笔一笔记账，后半再以皇太女的温柔话术完成清算。

## 句式 DNA

| 句式 | 原文证据 | 功能 |
|---|---|---|
| 极短句砸点 | “没有下一个了。”、“一天。”、“我在笑。” | 在情绪峰值处突然降速，让读者心口一沉。 |
| 重复递进 | “三变成了二。”、“二变成了一。” | 倒计时变成章节推进器。 |
| 温柔话术反杀 | “母妃莫怕，儿臣已经命人去寻天下名医了。” | 表面孝顺，实际让读者知道清算将至。 |
| 肉身物理化 | “十根手指在青砖上抓出刺目的血痕。” | 情绪不靠喊，靠身体损伤。 |
| 冷静宣判 | “谋逆。”、“是时候收网了。” | 后半爽点以短判词推进。 |
| 悔悟崩塌 | “青鸾……朕错了……” | M5温度反转终点。 |

## 对话模式

**对话占比 30.9%**，属于古言 BE 中偏高。对白不是闲聊，主要承担三种功能：

1. **反派压债**
   - 父皇：“青衣毕竟是你妹妹，让她出出气就好了。”
   - 外祖母：“你要把孟家的脸面往死里丢才甘心吗？”
   - 太医：“唯有以下毒之人的双眼生生剜出做药引。”

2. **娘亲断念**
   - “娘错了，彻底错了。”
   - “这无情的孟家，还有这个凉薄的男人……他们根本没有心。”
   - “萧逸，我成全你们！”

3. **女儿清算**
   - “他们欠我们的，我会拿回来。”
   - “母妃，是外祖父和外祖母。”
   - “父皇别急，重头戏还在后面。”

## 叙述温度

| 阶段 | 叙述温度 | 表现 |
|---|---|---|
| 前1-4章 | 冰冷目击 | 女儿不大量控诉，只记录母亲被怎样一步步逼死。 |
| 第5章 | 冷化转折 | 草席裹尸后，女儿不哭不闹，跪叫“母妃”。 |
| 第6-8章 | 低温蛰伏 | 十年布局用平静陈述带过，压住复仇焦躁。 |
| 第9-10章 | 温柔处刑 | 话越温柔，惩罚越狠。 |

## 高复用锚句

| 锚句 | 类型 | 可改编功能 |
|---|---|---|
| “没有下一个了。” | 信息差短句 | 用一句话压碎反派幻想。 |
| “三变成了二。” | 倒计时钩 | 每次伤害后让时间减少。 |
| “他们欠我们的，我会拿回来。” | 复仇誓言 | 主角从受害者转执行者。 |
| “娘错了，彻底错了。” | 断念金句 | 让被害者主动收回情感。 |
| “萧逸，我成全你们！” | 离场金句 | 把死亡写成拒绝继续被索取。 |
| “母妃。” | 回旋称呼 | 认贼作母的耻辱，后文变成处刑称呼。 |
| “是时候收网了。” | 爽点启动 | 长线布局转清算。 |
| “父皇别急，重头戏还在后面。” | 清算节奏 | 一层一层揭真相。 |

## 意象与身体词库

| 类别 | 高频词/意象 | 功能 |
|---|---|---|
| 冷意 | 雪、冰冷、寒风、凉、残灯 | 母亲被冷待，皇宫无温度。 |
| 血肉 | 血、心口、眼眶、骨头、指甲、嘴唇 | 把情绪债具象成可见伤口。 |
| 宫廷器物 | 大氅、玉盘、白瓷碗、草席、玉玺 | 每个器物都承担身份落差。 |
| 声音 | 丧钟、惨叫、呜咽、山呼 | 前半是受害者惨叫，后半是权力山呼。 |
| 视觉 | 透明面板、白绫、血洞、没干的血迹 | 系统和酷刑都被视觉化。 |

## 节奏 DNA

1. **每章至少一个强事件**
   - 第1章夺女，第2章伪伤，第3章剜眼，第4章取血死亡，第5章跪叫母妃。

2. **前半每次伤害都推动倒计时**
   - 三天、两天、一天、面板粉碎。

3. **后半每次清算都回扣前债**
   - 眼疾回扣剜眼，慢毒回扣取血，绝嗣真相回扣八个皇子，玉玺回扣唯一继承人。

4. **短句在章末承担钩子**
   - “一天。”
   - “是时候收网了。”
   - “五马分尸。”

## 文风禁区

- 不要把女儿写成现代爽文嘴替。她的狠要藏在礼数、称呼和权力程序里。
- 不要用大段心理分析代替身体动作。原文靠“指甲嵌进石缝”“血痕”“草席”传情绪。
- 不要把父皇台词写得全程暴躁。原文最毒的是温柔地逼人去死。
- 不要删掉沉默段。娘亲“不闹了”“没回话”“没动”是核心风格。
- 不要把结尾写热闹庆功。玉玺是冰凉的，胜利有代价。
