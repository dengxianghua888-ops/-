# Reader Engine 读者心理引擎

## 目标读者

- 喜欢古言虐渣、追妻火葬场、系统离场的女频读者。
- 喜欢前半极虐、后半集中清算的爽虐型读者。
- 能接受儿童视角复仇和长期蛰伏。
- 对“被工具化的母亲”“偏心亲族”“迟来悔悟无用”有强情绪需求的读者。

## 核心读者承诺

你会看到一个被当成生育工具的女人，在最后三天被所有人逼死；她的女儿没有当场崩溃，而是跪在仇人面前叫“母妃”，活成他们最想要的棋子，再用这枚棋子的身份掀翻整盘棋。

## 情绪驱动链

1. **怜悯**
   - 娘亲刚生产失子，却被要求继续忍。
   - 读者先站到娘亲和宝儿身边。

2. **愤怒**
   - 父皇、贵妃、外祖父母三方一起逼迫。
   - 每个反派都有具体恶行，恨意不分散。

3. **窒息**
   - 三天倒计时不断缩短。
   - 读者知道来不及，角色还在索取。

4. **触底**
   - 剜眼、心头血、自尽、草席裹尸。
   - 娘亲不可逆死亡，情绪债到最高点。

5. **冷静期待**
   - 宝儿跪叫“母妃”。
   - 读者意识到她要长期装乖。

6. **安全感回升**
   - 绝嗣真相让宝儿成为唯一筹码。
   - 读者开始相信她有赢面。

7. **爽感释放**
   - 皇太女收网，证据链、军权、慢毒同时落下。
   - 每个前债都有对应偿还。

8. **余痛留存**
   - 玉玺落手，娘亲仍回不来。
   - 结尾不轻飘，留住长尾记忆。

## 读者爽点来源

1. **不是当场嘴炮，而是十年隐忍**
   - 读者喜欢长期压抑后的高倍偿还。

2. **不是泛泛报应，而是对应报应**
   - 剜眼对应眼疾，取血对应骨毒，夺女对应“母妃”反讽。

3. **不是误会解除，而是罪证公开**
   - 供状、账册、谋逆、私兵给复仇合法性。

4. **不是父皇后悔就结束，而是父皇后悔也没用**
   - 火葬场的爽点在不可挽回。

5. **不是女主被救，而是女主掌权**
   - 玉玺落手完成终极代偿。

## 读者痛点来源

- 娘亲明明只想陪宝儿最后三日，却连这点愿望都被剥夺。
- 父皇每次“心软”都只停留一瞬。
- 外祖父母对亲生女儿没有半点信任。
- 宝儿年纪太小，却被迫学会忍。
- 娘亲死后连体面都没有。
- 复仇成功时，最该看到的人已经不在。

## 改编时的读者承诺核验

- 前300字必须让读者知道“她快离开了”。
- 前30%必须至少两次倒计时递减。
- 前50%必须完成不可逆离场。
- 中段必须让主角表面顺从仇人。
- 后40%必须集中清算，不要再新增无关支线。
- 结尾必须出现权力物象，且父皇必须死在真相之后。
