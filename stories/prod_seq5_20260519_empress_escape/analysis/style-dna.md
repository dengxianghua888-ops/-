## 叙述口吻

第一人称强主观吐槽。

核心语气：怕死、嘴快、好色但有底线、正义感强、心软但不软弱。

典型句式：

- “我也哭了。”
- “我真的很谢。”
- “我服了。”
- “这恋爱脑没救了。”
- “我忍不了一点。”

这些句子短、白、反应快，像女主即时弹幕，负责把宫廷权力场降维成轻喜剧。

## 句法结构

高频使用短句 + 断句 + 突然转折。

常见结构：

1. 先给结论：  
   “好消息：楚临终于去香灵殿了。”
2. 再反手补刀：  
   “坏消息：他把我也一起带上了。”
3. 用极短句落笑点：  
   “我真的很谢。”

源文不靠长段心理描写推动，而靠动作、对话、吐槽三连推动。

## 对话 DNA

对话占比高，约 36%。人物关系主要在对话中推进。

对话功能分布：

| 功能 | 例句 | 作用 |
|---|---|---|
| 误会升级 | “您不打算进去愤怒一下吗？” | 把宠妃苟合写成喜剧 |
| 暧昧反撩 | “意儿，想不想抱没穿衣服的？” | 帝王反差破冰 |
| 情绪审判 | “重来一次，还会骗我吗？” | 中段信任崩塌 |
| 边界确认 | “我想出宫一段时间，可以吗？” | 女主选择权上线 |
| 危机宣告 | “你生或者她肚子里的孩子生，二选一。” | 大结局峰值 |

## 喜剧手法

### 1. 高权力低俗化

把皇权、朝堂、洞房、谋反写成日常闹剧。

证据：

- “金銮殿直接变成了菜市场斗殴现场。”
- “方法是：钻狗洞。”
- “尚衣局全员懵圈。”

效果：古言门槛降低，番茄读者可以轻松进入。

### 2. 身体喜剧

高频动作：撅屁股、横抱、颠两下、钻狗洞、顺拐、撸头发、撕衣服。

身体喜剧承担亲密推进功能，尤其适合写男女主暧昧而不油腻。

### 3. 物件回旋

黄连茶、狗洞、信件、衣服规格、玉石都不是一次性道具，而是反复回旋。

- 黄连茶：治恋爱脑 → 赔罪自罚。
- 狗洞：追洛灵 → 被女主封宫拒绝。
- 信件：楚嫣旧信 → 长线暗恋证据。
- 衣服：撕不坏 → 专门做成一撕就烂。

## 情欲表达尺度

源文情欲写法是“大胆动作 + 喜剧遮羞”。

不是纯欲风，而是用女主的荒唐脑补消解暧昧压力。

典型表达：

- “我想撕你衣服。”
- “翻身坐上去，他在下...”
- “一夜没叫水。一夜没停。”

写法规则：可以直给，但必须用女主吐槽或荒唐动作托住，避免变成沉重肉欲。

## 金句密度

金句/爆点句约 2.2 条/千字。

代表句：

- “疯批男主只有在话本里才拥有爱，在现实中只会永失所爱。”
- “伤害过后谈深情，太虚伪了。”
- “后位我都捡漏了，多捡漏你一个不多。”
- “有见过把人骂死的吗？没有吧。”
- “我就喜欢她看不惯我，又骂不死我的样子。”

金句分两类：

- 喜剧型：用于爽和轻松。
- 价值型：用于中后段清算男主。

## 节奏 DNA

每 800-1200 字出现一次关系状态变化。

关系推进链：

怕他 → 被他撩 → 同情他 → 哄他 → 亲他 → 睡他 → 怀孕 → 发现被骗 → 拒绝他 → 被软禁 → 他放手 → 她离宫 → 她回头。

每次变化都有一个可视化事件承载，不用空泛心理过渡。

## 禁止仿写偏差

- 不能把女主写成端庄隐忍型皇后。
- 不能把楚临写成纯冷酷霸总式帝王。
- 不能把洛灵写成恶毒女配主线。
- 不能长篇解释权谋设定。
- 不能删除喜剧道具，否则甜宠会变干。
- 不能让软禁轻飘飘过去，必须有“放手”作为修复动作。
