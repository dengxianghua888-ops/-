# Soul Contract

## 一句话灵魂

她不是被皇权驯服的皇后，而是一个想跑就跑、想爱才爱的野路子姑娘；他不是靠权势留下她，而是在失控后学会放手，才换来她自愿回头。

## 核心情绪契约

读者期待的不是单纯甜宠，而是：

1. 开局荒诞好笑。
2. 中段暧昧上头。
3. 甜到高处后必须狠狠揭开“被算计”的伤。
4. 男主必须为伤害付代价。
5. 女主最后必须主动选择，而不是被孩子、皇权、责任绑回去。

## 女主契约

沈知意的魅力必须保留：

- 怕皇帝，但不是弱。
- 好色，但有底线。
- 嘴毒，但心软。
- 会医会武，有实际行动能力。
- 可以爱楚临，也可以离开楚临。
- 怀孕后仍然是行动主体，不是生育工具。

原文证据：

- “皇上，要不臣女抱您上床躺着？”
- “武力八成，下毒十成，试试？”
- “我信。但我想出宫一段时间，可以吗？”
- “所有我爱的人都在宫中。我肯定是要跟他们在一起的。”

## 男主契约

楚临的魅力来自反差，不来自压迫。

必须同时成立：

- 表面：帝王、冷脸、能布局。
- 内里：委屈、黏人、红眼、早就暗恋。
- 错处：欺骗女主，把她和孩子放入政治计划。
- 修复：承认错误，失控后醒悟，最终放她离宫。

关键判断：他可以犯错，但不能一直理直气壮。若不写“放手”，男主会从甜宠恋爱脑变成压迫者。

## 感情契约

爱情成立的顺序不能乱：

1. 女主先怕他。
2. 女主发现他不像传闻那样高不可攀。
3. 女主同情他的“宠妃失恋”。
4. 女主在喜剧亲密中生出欲望。
5. 女主在洛灵怀孕后真正心疼他。
6. 女主因骗局收回信任。
7. 男主放手后，女主才重新评估他的爱。
8. 女主因危机主动回宫。

不能直接从“他喜欢她”跳到“她原谅他”。

## 洛灵契约

洛灵不是常规恶毒女配。

她的功能是：

- 前期制造宠妃假象。
- 中段制造情敌挑衅和喜剧冲突。
- 后段揭开楚临骗局，推动女主清算。
- 结尾用假谋反和南疆归属收束政治线。

她可以讨嫌，但不能真正抢走男主情感重心。她越像情敌，后续“盟友/工具人”反转越爽。

## 权谋契约

权谋只能服务关系，不可喧宾夺主。

政治线的正确功能：

- 解释楚临为何假宠洛灵。
- 制造女主怀孕后的信任崩塌。
- 提供结尾假谋反高压场。
- 逼女主主动回宫，证明她选择楚临。

政治线的错误写法：

- 大篇幅写叛军战略。
- 让洛灵和冥天压过男女主。
- 把女主写成被动等待营救。
- 把结尾写成严肃夺权。

## 必须兑现的爽点

| 爽点 | 兑现方式 |
|---|---|
| 荒诞爽 | 朝堂群架、太傅捡漏、皇权被喜剧化 |
| 反差爽 | 冷帝王变委屈恋爱脑 |
| 暧昧爽 | 横抱、撕衣、初吻、梦外失控 |
| 清算爽 | 三碗黄连茶三问，男主必须回答 |
| 追妻爽 | 软禁失败，放手离宫 |
| 真心爽 | 旧信、太傅证词、楚嫣助攻 |
| 选择爽 | 女主主动回宫，不是被抓回宫 |
| 圆满爽 | 生女儿，帝王沦为妻女奴 |

## 结尾契约

结尾必须轻，不可 BE，不可道德阴影过重。

最后的情绪应该是：

- 危机解除。
- 洛灵离场。
- 女主生产。
- 楚临身份彻底反转成家庭奴。
- 读者带着“闹了这么久终于甜稳了”的释放感离开。
