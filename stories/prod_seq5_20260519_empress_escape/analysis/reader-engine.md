# Reader Engine

## 目标读者

番茄古言甜宠读者，尤其偏好：

- 轻喜剧宫廷。
- 先婚后爱。
- 帝王反差萌。
- 女主主动、嘴硬、会撩。
- 中段有误会和追妻，但结局必须甜。

## 入坑引擎

### 前 300 字任务

源文前 300 字完成三件事：

1. 极端荒诞：百官奉旨打群架抢后位。
2. 结果反差：皇后之位被太傅捡漏。
3. 女主困境：她怕皇帝，怕到想哭。

读者点击后的第一反应不是“好虐”，而是“这怎么回事”。这种荒诞疑问比传统宫斗更轻，更适合甜宠开局。

## 情绪投喂节奏

源文采用“轻喜糖点密集投喂 + 中段信任大刀 + 结尾反转回甜”。

| 阶段 | 字数占比 | 投喂类型 | 读者感受 |
|---|---:|---|---|
| 0-15% | 开局荒诞、洞房错位 | 新奇、好笑、想追 |
| 15-40% | 香灵殿、黄连茶、狗洞、初吻 | 暧昧、上头、男主反差萌 |
| 40-55% | 梦外失控、圆房、怀孕 | 高甜兑现 |
| 55-70% | 孩子计划、三问、拒绝离宫 | 信任坠谷、追妻期待 |
| 70-85% | 小师弟、软禁、放手、离宫 | 虐点与男主代价 |
| 85-100% | 旧信、假谋反、主动回宫、生女 | 真心证明、危机释放、团圆 |

## 微钩设计

源文几乎每 800-1200 字给一次微钩。

高复用微钩：

- 误送洞房：“皇帝不是该去宠妃那里吗？”
- 香灵殿苟合：“宠妃偷人，皇帝为何不怒？”
- 女主密谋杀奸夫：“她真敢动手吗？”
- 黄连茶：“恋爱脑能治好吗？”
- 狗洞：“帝王还能更丢脸吗？”
- 初吻：“她是赌气还是心动？”
- 怀孕道贺：“洛灵为什么知道？”
- 三问：“他还会骗她吗？”
- 小师弟来带她走：“她会不会逃？”
- 假谋反：“洛灵真反了吗？”

## 付费卡点

适合切付费的高强钩：

1. 第 8 节：香灵殿内传出苟合声。  
   读者必须继续看皇帝反应。

2. 第 22 节：洛灵怀孕，楚临求女主爱他。  
   情敌怀孕 + 男主脆弱，关系即将转正。

3. 第 25-26 节：洛灵说“你的孩子就是我的孩子”。  
   强悬念，直接带出政治骗局。

4. 第 27 节：三问后楚临回答“会”。  
   信任崩塌，追妻火葬场正式开门。

5. 第 31-32 节：楚临说“除非朕死”并软禁女主。  
   情感低谷，读者等他付代价。

6. 第 36 节：洛灵起兵，楚临被囚。  
   女主主动回宫前的终局危机。

7. 第 37 节：洛灵给出生死二选一。  
   最高压卡点，下一秒反转。

## 读者安全感

这篇能承受中段伤害，是因为前文给了足够安全垫：

- 男主从未真正爱洛灵。
- 女主始终有嘴、有手、有判断力。
- 洛灵更像喜剧工具人，不是恶毒情敌。
- 软禁后男主没有赢，而是失败并放手。
- 结尾女主是主动回去，不是被追回去。

改编时若削弱任何一项，读者会从“追妻爽”转为“憋屈”。

## 爽点密度公式

```yaml
reader_engine_formula:
  hook: "荒诞权力场 + 被动封后"
  early_sugar: "误会宠妃 + 帝王反差 + 女主吐槽"
  mid_peak: "初吻/圆房/怀孕"
  rupture: "孩子计划揭露 + 男主承认会骗"
  firepit: "小师弟刺激 + 软禁失控"
  redemption: "放手离宫 + 旧信证明"
  final_payoff: "假谋反逼回宫 + 主动选择 + 生女团圆"
```

## AI 味规避

必须避免：

- 用旁白解释“她其实已经爱上了他”。
- 用长段心理独白替代亲密事件。
- 让男主用“我都是为了天下”洗白。
- 让女主用一句“我理解你”快速原谅。
- 把洛灵写成脸谱化恶女。
- 把结尾战争写成正经权谋大戏。
