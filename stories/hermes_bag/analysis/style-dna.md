# 文风 DNA

## 一句话风格定性

"硬朗口语化叙述，以短促有力的动作句和大量精准对话驱动情节，带有强烈的'草根反击'网文基因，节奏极快，段落切碎到几乎像分镜脚本。"

## 定量特征

### 句式

- **平均句长**: 约 18 字（偏短，网文特征明显）
- **长短句比例**: 约 3:7（短句占绝对主导）
- **偏好句式模板**:
  1. 短促动作句：「我猛地往后退了一步，避开他的手。」
  2. 反问+判断句：「怎么？想毁灭证据？！」
  3. 内心独白用陈述直击：「一千万，卡得太精准了。正好是一个小微企业砸锅卖铁能凑出来的极限。」
  4. 环境/声音一句收尾：「"滴——交易成功。"POS机吐出长长的凭条。」
  5. 转折反差句：「我没有走向提货的后门，而是转身走到了大厅的正中央。」
- **忌用句式**: 
  - 长复句（超过 40 字的从句嵌套）
  - 书面化抒情独白
  - 说教式总结

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 比喻（具象化） | 高频 | "像一柄大锤，精准地砸碎了我所有的防御" | 情绪可视化 |
| 反讽/回旋 | 核心 | "科技执法嘛，电脑怎么报，你就怎么坐牢吧" | 以其人之道还治其人之身，爽感共鸣 |
| 动作替代情绪 | 高频 | "他几乎是扶着柜台才勉强站稳" | 用身体反应替代抽象情绪词 |
| 数字锤击 | 中频 | "三年时间，受害商户两百余家，涉案金额四千多万" | 用精确数字营造冲击力 |
| 对比/反差 | 高频 | "一千万，就这么轻飘飘地划走了" | 金额的沉重 vs 划走的轻飘 |

### 对话

- **对话占比**: 约 40%（高，是推动情节的核心引擎）
- **对话风格**: 犀利、精准、有攻击性
- **对话功能**: 
  - 70% 推动情节/制造冲突
  - 20% 展示性格
  - 10% 信息传递
- **对话特征**:
  - 单句对话 ≤ 15 字居多
  - 大量使用反问句
  - 对话前常有 1 句动作或表情描写
  - 高潮对话会"拔高音量"
  - 善用"..."表示犹豫或颤抖

### 叙述

- **人称视角**: 第一人称限知（"我"）
- **叙述温度**: 冷峻但不疏离（冷在语调，热在情感）
- **距离感**: 贴身（读者完全代入主角视角）
- **时态**: 过去式为主
- **叙述节奏**: 动作 → 反应 → 内心一句收尾（三拍子）

### 用词

- **色温倾向**: 偏冷（"冰冷""惨白""凉了""冷汗"）
- **书面/口语比**: 3:7（强口语化）
- **高频词族**: 
  - 身体词：发抖、发麻、冷汗、脸色
  - 动作词：拍、砸、摔、拽、瞪、逼
  - 金属感词：咔嚓、滴、哐
- **AI 高频词检测**: 原文偶有使用"深吸了一口气""眼神里闪过"等表达，但频率极低且有上下文支撑，不构成AI味

### 标点

| 标点 | 使用频率 | 功能 |
|------|---------|------|
| "！" | 极高频 | 情绪强调，每个高潮对话必有 |
| "……" | 中频 | 犹豫/颤抖/语气中断 |
| "？" | 高频 | 反问/质疑，攻击性武器 |
| 破折号"——" | 中频 | 解释补充/语气转折 |
| "，" | 短促 | 句子切碎，呼吸急促 |

## 代表性原句（Top 5）

1. **"逻辑的死环，在这一刻彻底扣死。"** — 体现极简判断句的力量感
2. **"一千万，就这么轻飘飘地划走了。"** — 体现数字+反差的冲击力
3. **"我突然不觉得愤怒了。取而代之的，是一种冷到骨头缝里的清醒。"** — 体现情绪转折的精准表达
4. **"红色的印泥还是湿润的。"** — 体现细节控、画面感极强
5. **"孙科长，晚了。科技执法嘛，电脑怎么报，你就怎么坐牢吧。"** — 体现回旋反讽的极致爽感

## 反面教材（绝对不能出现的表达）

### 句式禁区
- 长句抒情："站在人生的十字路口，他感受到了命运的沉重与无常……"
- 总分总结构："综上所述，这件事让他明白了三个道理……"
- AI式过渡："与此同时""值得注意的是"

### AI 味违禁词
- "然而"（原文一次都没用）
- "总而言之"
- "不禁"
- "宛如命运的齿轮"
- "眼中闪过一丝复杂"
- "嘴角微微上扬"
- "心中涌起一股XX"
- "不由得"
- "缓缓地"（高频使用时）

### 本作品额外违禁
- "他心想"式的内心旁白标签（原文直接写内心独白，不加标签）
- 过度使用形容词堆砌
- "仿佛""好像"连续使用
