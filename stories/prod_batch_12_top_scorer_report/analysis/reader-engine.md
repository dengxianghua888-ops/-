# Reader Engine

## 目标读者

源文服务的是偏好现代反转、家庭背叛、悬疑破案、证据型爽文的读者。读者想看的不是主角哭着被爱，而是主角在所有人不信她时，用证据把局面翻回来。

## 阅读驱动力

### 1. 认知悬疑

核心问题连续变化：

- 家人为什么断亲？
- 门铃里到底看见了什么？
- 尸体在哪里？
- 假亲人为什么能通过DNA？
- 鲁米诺为什么查不出血？
- 主角为什么要拆整栋别墅？
- 凶手真实身份是谁？

每个问题被回答时，都会抛出更大的问题。

### 2. 情绪代偿

读者替主角承受羞辱：

- 被假父母失望指责
- 被未婚夫道德审判
- 被警方怀疑报假警
- 被网友骂蹭热度
- 被法庭上的反派嘲讽贪钱

后文逐项偿还，形成“你们刚才怎么骂她，现在就怎么被证据打脸”的快感。

### 3. 专业崇拜

源文让主角的聪明变得可见。她不是靠作者开挂，而是通过具体按钮、具体药剂、具体检测逻辑破局：

> 夜视模式 → 绿点血迹  
> 螯合剂 → 鲁米诺失效  
> 墙体凸起 → 尸体位置  
> DNA异常 → 黑客篡改

读者会觉得“她真配当状元”。

### 4. 公开审判

直播和法庭让爽点被围观。围观群众越多，翻盘越有价值。源文多次写直播间人数上涨、评论区质疑，是为了让后续反转具备公共清算感。

## 钩子节奏

| 区间 | 钩子 | 功能 |
|---|---|---|
| 前300字 | 状元、断亲、退婚、灭门报警 | 点击钩 |
| 第1章末 | 门锁被撬 | 危险钩 |
| 第2章末 | 状元押前途请求复查 | 赌注钩 |
| 第3章末 | 警方要拘留主角 | 误判钩 |
| 第4章末 | 顾教授喊现场有杀人犯 | 翻盘前钩 |
| 第7章末 | 主角要求拆整栋别墅 | 尸体位置钩 |
| 第9章末 | 裴队长称知道真实身份 | 终局身份钩 |

## 爽点兑现方式

源文采用“先压低，再公开抬高”的兑现法：

1. 先让主角孤立无援。
2. 再让权威误判她。
3. 然后让她拿出一个小细节。
4. 细节引出专业解释。
5. 专业解释撬动大证据。
6. 大证据交给法律执行。

这种兑现方式适合番茄短篇，因为每一段都有可感知进展。

## 读者最不能接受的漂移

- 主角靠哭求获得帮助。
- 反派被感化或忏悔后轻判。
- 真相靠偶然发现，而不是主角主动推理。
- 亲人真的抛弃主角，后文没有“保护性遗书”反转。
- 警方被写成彻底无能或反派同伙。
- 专业知识只做装饰，不影响证据链。
