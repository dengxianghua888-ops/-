# Phase 3 改编设定重置室

## 改编目标
在不破坏《余生不候》灵魂合同的前提下，做一次“高保真、强平台适配、低撞壳”的设定重置。核心不改的是：

- 民政局夺证 + 女主当场换证
- 现任必须是前任哥哥，且更高位、更克制、更早动心
- 家宴认大嫂必须是核心翻盘点
- 前任必须情感线之外再塌至少两条现实线
- 结局必须不复合、不回收，女主稳定上岸

## 三套投稿方向

### A. 高端酒旅世家线
一句话：被酒旅集团二公子在民政局用“私生子上户口优先”羞辱后，女主当场嫁给执掌家族基金的大哥，随后在老宅家宴、婚礼接亲和项目回款里把旧爱打成笑话。

优点：
- 豪门老宅、庄园婚礼、家宴认嫂天然顺手
- 婚礼空城、劳斯莱斯接走、长辈站队都很好写
- 前任事业反噬可落到酒店项目、文旅债务、供应商追款

风险：
- 酒店/庄园外壳和同赛道常见文较近
- 若项目线写多，容易沾商战流水账

### B. 非遗珠宝世家线
一句话：珠宝设计师女主被珠宝世家二少在民政局夺走户口本，让怀孕助播先领证，她反手嫁给掌管家族拍卖行与家办的大哥；之后用婚戒、假证、家宴认嫂、设计版权与预付款追偿，把旧爱和闺蜜一起埋进自己挖的坑里。

优点：
- 戒指、婚戒、定制珠宝、拍卖晚宴、家族老宅都能天然承载婚恋爽点
- “谁配戴那枚戒指”“真结婚证 vs 假证”“设计稿/版权/垫付款追偿”都很有道具记忆点
- 现任高位感更强，能做成老钱克制型掌权哥哥
- 家宴认嫂、公开站队、供应链追债都顺滑

风险：
- 需要控制珠宝行业信息量，避免写成行业百科
- 闺蜜若设成助播，要避免过分直播行业化稀释婚恋主线

### C. 医疗器械家族线
一句话：女主替未婚夫撑起医疗器械渠道四年，却在领证日被他推开，让怀孕的招商主管先上；她当场嫁给掌握集团核心牌照的大哥，后续在家宴、招采、公章、回款和行业封杀里完成清算。

优点：
- 前任事业线崩塌逻辑强，现实代价够硬
- 假证、公章、回款、资质追责都能形成强证据反杀
- 高位现任的执行力容易成立

风险：
- 医疗赛道天然偏重，容易压坏短篇情绪速度
- 一旦写细会偏法律/商业，不够番茄“关系爽”

## 最终选择：B. 非遗珠宝世家线

### 选择理由
B 方案在“神髓保真”“平台爆点”“新鲜外壳”之间最均衡。

它最适合保住原作的五个核心满足：
- 民政局夺证时，婚戒与户口本能形成更强羞辱道具
- 女主四年付出可具体化为设计稿、垫资、陪酒拿订单、品牌冷启动
- 现任大哥可自然升级为掌拍卖行、家办与主品牌的真正继承人
- 家宴认嫂可挂钩老钱家族礼制，公开身份压制更强
- 前任现实清算可落到设计侵权、供应商欠款、预付款追偿、品牌资金链断裂，既现实又不拖沓

### 题面焕新句
“领证当天，他把我设计的婚戒戴到了闺蜜手上；我笑着挽住他大哥，去领了真的那本证。”

## 选中方案详细设定

### 世界观定位
- 城市：沿海新一线城市
- 家族属性：老牌珠宝世家，兼有拍卖行与家族办公室
- 女主身份：被低估的主设计师兼品牌操盘手
- 前任身份：二房二少，靠女主和家族资源做轻奢副牌
- 现任身份：前任亲哥，主品牌接班人，拍卖行实控人，早有心意但长期克制
- 闺蜜身份：副牌直播助播/买手，经由女主带入圈子，后与前任暗通款曲并怀孕

### 爽点保留方式
- 民政局场面不改，只替换羞辱道具为“婚戒”“假证”“孕检单”
- 婚礼羞辱不改，但可改为“让女主交出主婚戒、穿备用礼服、把她设计的主场让给别人”
- 家宴认嫂不改，升级为珠宝世家老宅晚宴，长辈当众点名“你大嫂”
- 事业追偿不写大商战，集中在三件事：
  - 设计版权归属
  - 垫付款和订单回款
  - 供应商与渠道债务集中上门

### 现任人设校准
现任不能是捡漏。他必须：
- 早就看见女主价值
- 早就留存她真正署名的设计手稿
- 在民政局不是临时英雄，而是顺水推舟地接住
- 后续每次偏爱都靠行动兑现：领证、发证、接亲、认嫂、追债、正名、给位置

### 前任与闺蜜反噬路径
前任：
- 先失控于“她怎么真嫁我哥了”
- 再失控于“家里真把她当大嫂”
- 再失控于“她留下的设计和渠道我根本撑不住”
- 最后事业资金链断裂、婚育关系崩塌、在年夜饭被迫改口

闺蜜：
- 先得到抢来的位置
- 再发现自己戴不稳那枚戒指，也坐不稳那把椅子
- 孕产/婚育线反噬要写成现实失控与关系破裂，不写成恶意羞辱女性生育
- 最终失名声、失位置、失依附

## 核心替换映射

### 角色
- 女主“姜晚” -> 珠宝主设计师“沈知微”
- 前任“肖奈” -> 珠宝副牌负责人“裴承屿”
- 现任哥哥“肖珩” -> 主品牌继承人兼拍卖行掌舵者“裴砚衡”
- 闺蜜“江柔” -> 女主亲手带进公司的直播助播“林妍”
- 前任父母 -> 珠宝世家长辈，重礼制、重门面、重家族传承

### 场景
- 民政局 -> 保留
- 婚礼庄园 -> 珠宝世家合作的海边美术馆婚礼
- 肖家老宅家宴 -> 裴家藏玉老宅晚宴
- 公司讨债 -> 副牌资金链爆雷、供应商堵门、设计版权追偿
- 年夜饭终局 -> 裴家除夕家宴，称呼落定

### 道具与线索
- 户口本 -> 保留
- 假结婚证 -> 仿制结婚证 + 官宣朋友圈截图
- 婚纱 -> 女主亲自参与设计的主婚纱与主婚戒
- 讨债凭据 -> 垫付款流水、设计底稿存档、供应商对账单、渠道回款通知
- 朋友圈双证 -> 两本真证同框 + 主婚戒特写

### 机制载体
- M2 身份反差 -> 从“副牌打工人舔狗”到“裴家长媳、主品牌女主人、被公开偏爱的设计总监”
- M3 因果回旋 -> “我和谁领证都一样”回敬为“反正你们是亲兄弟，我和谁领证不都一样”
- M5 温度反转 -> 四年真心和陪跑，对照现任长期无声偏爱
- M6 多层递进 -> 换证、真结婚、婚礼接走、家宴认嫂、版权追偿、年夜饭改口

## 敏感表达边界
- 怀孕、流产、难孕等内容不作为“坏女人活该”的直白羞辱句使用
- 反派反噬重点放在抢来的关系不稳、欺骗败露、现实失控、利益反噬
- 不渲染具体医疗疼痛，不写过度血腥或产科细节
- 婚姻关系冲突重在尊严与秩序，不走雌竞互撕口水战
- 女主终局重心是位置、边界、事业与平静，不是靠踩另一个女人证明自己
