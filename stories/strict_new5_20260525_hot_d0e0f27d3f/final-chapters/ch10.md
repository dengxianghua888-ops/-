# 第10章

我到副牌公司时，前台的咖啡机正咕噜作响。

小姑娘抱着一箱样册，手忙脚乱，连杯盖都扣反了。

她一抬头看见我，眼神先亮了一下，又很快缩回去。

下一秒，旋转门被人推开。

三个供应商带着文件袋进来，后面还跟着两个渠道商。

鞋跟声一阵一阵，直接压过了前台音乐。

“裴总人呢？”

“今天必须给个说法。”

“货我们先前是看沈总监面子才发的。”

办公区里的人全停了，有人拿着工牌不敢刷卡，有人假装低头回消息。

还有两个实习生抱着布样，站在打印机边不动。

裴承屿从会议室出来时，领带还歪着。

他看见我，眉头先皱了起来。

“知微，你来干什么？”

我把墨镜摘了，顺手放到前台桌面。

“路过，看看。”

“顺便听听，你怎么解释。”

最前面的渠道商把合同往台面一拍。

“解释什么？”

“以前不是沈总监垫的吗，现在怎么断了？”

旁边那位接得更快。

“订货会的场地、模特、物料，不都是她先压着？”

“你一句裴家会结，我们才跟到现在。”

裴承屿脸色沉了沉。

“流程在走，裴家不会不管。”

“大家别堵在这里，去会议室谈。”

“谈了两轮了。”

“你每次都说再等等。”

“等谁，等沈总监再替你签一次字？”

有人低低吸了口气，前台那杯咖啡终于满了，溢出来一圈褐色水痕。

没人去擦，我靠在前台边，只看着他。

从头到尾，我一句多余的话都没接，这次，我也没打算替他圆。

电梯门叮地一声开了。

裴砚衡的法务带着文件进来，黑色公文包扣得很紧。

“裴承屿先生，请签收。”

他一把扯过来，第一页只有一行加粗标题。

那法务声音平平：“即日起，裴家主品牌及相关账户，不再为副牌任何新增义务提供担保、垫付与背书。”

“已通知各合作方。”

裴承屿指节一下收紧。

“谁让你们送来的？”

法务看了他一眼：“裴总。”我没说话，只把那份通知往他眼前推回去半寸。

意思已经够清楚了，这一次，没有人会替他收残局。

最前面的供应商先反应过来，他从文件袋里抽出催款函，啪地拍上裴承屿胸口。

纸页弹开的那一下，整个前台都听见了。

裴承屿下意识抬头，失声喊了我的名字。
