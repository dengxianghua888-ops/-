# 高保真设定重置 — 《纵有星光坠落时》

## 选定方案：A · 直播电商设定

### 核心前提

苏念为陈奕从零打造全网第一带货直播间，六年幕后策划让他坐拥三千万粉丝。他在品牌晚宴上当众说她"不过是顺手带的助理"，并力捧新签约女主播方颖。苏念一个月前已怀孕——孩子是季霄的。季霄表面是直播间天天刷火箭的游戏宅男，实为千亿直播平台「星潮」的实际控制人。

陈奕封杀苏念在所有MCN的入驻资格，想把她困死在行业里。苏念不解释、不哭闹，转身走进季霄的世界。平台年度盛典直播中，季霄后台一键撤销陈奕全部品牌合作授权——十五分钟蒸发其全年GMV，二十分钟让其公司资金链断裂。当晚所有人才知道，这个打游戏的二世祖，是整个直播生态的操盘手。

### 选定理由

1. **新鲜度最高**：直播电商设定贴合2024-2026番茄核心读者日常认知，但极少被用于甜宠/身份反差类短篇叙事
2. **神髓保真度最高**：M2（身份反差）、M3（因果回旋）、M5（温度反转）三条机制无损适配
3. **番茄契合度最高**：「一键下架」的数字化碾压比股市做空更直观、更可视化，符合目标读者快爽需求
4. **逻辑闭合**：平台实控人对入驻主播的生杀予夺权在现实中完全成立，无需额外解释

### 机制落地预览

| 原文机制 | 新载体 | 碾压可视化 |
|---------|--------|-----------|
| M2·身份反差 | 游戏宅→平台实控人 | 后台操作界面/实时数据大屏 |
| M3·因果回旋 | 封杀MCN入驻→一键撤销品牌授权 | "你封我的入驻资格，我封你的生意" |
| M5·温度曲线 | 六年不给名分→一月领证→盛典碾压 | 从"顺手带的助理"到"季总夫人" |

### 情绪债结构

| 债项 | 具体表现 |
|------|---------|
| 六年不给名分 | 陈奕从不公开苏念身份，对外称"团队功劳" |
| 当众贬低 | 品牌晚宴上说"她能有今天全靠我平台" |
| 第三者压迫 | 方颖三天就被公开力捧为"最佳合伙人" |
| 封杀控制 | 联合所有MCN拉黑苏念，想让她无处可去 |

### 彩礼仪式对应

原文「傅家红纸字迹未干/老太爷奋笔疾书」→ 季家总部顶层会议室：长桌铺满红色文件夹，最里面季家老爷子正用钢笔签最后一份股权转让书——平台5%股份，写的是苏念的名字。

### 关键金句回旋设计

- 原文「今天赚的钱，都算你的彩礼」→「今天下架的GMV，都算你的聘礼」
- 原文「认识江盈盈不过三天，他就求了婚」→「认识方颖不过三天，他就官宣合伙人」——用陈奕自己的标准打脸

## 落选方案简述

### B · 建筑设计设定
女主为旧爱事务所画了六年获奖方案，被当众称为"助理设计师"。新男主表面玩帆船赛车，实为城投集团操盘手。在设计峰会上撤走旧爱全部在建项目投资。**落选原因**：建筑行业离目标读者日常较远，碾压场景缺乏即时数字可视化。

### C · 美妆配方师设定
女主研发出旧爱品牌全部爆品配方，被公开称为"打下手的"。新男主表面收藏香水，实为全球最大原料集团继承人。在品牌上市仪式上断供原料致股价暴跌。**落选原因**：供应链断供的碾压过程不如A方案即时可视，需要更多商业解释段落，会拖慢节奏。
