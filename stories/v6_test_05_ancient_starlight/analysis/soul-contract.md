# Soul Contract — 《纵有星光坠落时》

## 灵魂约定：这篇文的内核承诺

> **给每一个在亲密关系中被定义为"不值得"的读者，一场不靠哭闹、不靠解释、只靠转身选择更好的人来完成的价值证明。**

## 不可违反的灵魂规则

### 规则 1：女主永远不解释
- 被贬低不反驳（"算了"）
- 被质疑不证明（"我是来找傅宴的"说两次，不加论据）
- 被误解不纠正（让傅宴自己替她揭晓）
- **违反信号**：女主说出"你误会了""让我解释""其实是这样的"→ 灵魂流失

### 规则 2：新男主用行动替代言语
- 不说"我爱你"→ 全家备好彩礼等在厅里
- 不说"我保护你"→ "把人放进来"一句话全场让路
- 不说"我有钱"→ 20分钟碾压对手至破产
- **违反信号**：傅宴用长段落表白/解释自己的感情→ 灵魂流失

### 规则 3：旧爱的崩塌必须是自找的
- 封锁酒店→自己被做空（自己的手段反噬）
- 当众贬低→当众被碾压（自己选择的战场）
- 婚礼搞事→婚礼上破产（自己挑的时机）
- **违反信号**：旧爱因外力（车祸/被举报/第三方介入）而失败→ 灵魂流失

### 规则 4：权力展示必须视觉化/数字化
- 不用"很有钱"→ 用"屏幕上红色数字变绿"
- 不用"很有势力"→ 用"乌泱泱的地方突然腾出空地"
- 不用"全家认可"→ 用"红纸字迹还没干透""老太爷奋笔疾书"
- **违反信号**：碾压只在对话中被描述而无视觉场景→ 灵魂流失

### 规则 5：节奏不可松懈
- 全文无一段>3句的纯心理描写
- 场景切换用一句话完成
- 高潮段落（Beat 5-7）每句≤15字
- **违反信号**：出现>5句的内心独白段/情绪分析段→ 节奏崩塌

## 情绪合约

| 阶段 | 读者应有感受 | 触发机制 |
|------|------------|---------|
| 开篇 | 好奇+微爽（她居然有人护着） | 傅宴的强势护送 |
| 中段 | 窒息+愤怒（他凭什么这样对她） | 顾呈阳连续贬低 |
| 高潮前 | 期待+紧张（傅宴要出手了） | 傅宴登场的气场 |
| 高潮 | 狂喜+震撼（太爽了！） | 傅家彩礼+婚礼碾压 |
| 结尾 | 满足+温暖 | "今天赚的钱都算你的彩礼" |

## 禁区清单

- 女主求复合/回头看旧爱
- 旧爱洗白/良心发现
- 新男主无缘无故深情（必须有行动支撑）
- 女主靠哭/靠美色/靠撒娇获得好处
- 任何"我不配""他为什么选我"的自我贬低
- 空洞的内心抒情（"我的心像被刀割"）
