# Reader Engine — 《纵有星光坠落时》

## 核心驱动力分析

### 驱动力 1：信息差期待（占比 40%）

读者始终比某些角色知道更多，产生"等他知道真相"的迫切感：

| 信息差 | 持续时间 | 揭露方式 | 爽感级别 |
|--------|---------|---------|---------|
| 女主怀孕 | Beat 2-5 | 傅宴替她揭示 | 8/10 |
| 孩子是傅宴的 | Beat 3-6 | 当众宣布订婚 | 9/10 |
| 傅宴的真实能力 | 全文-Beat 7 | 20分钟碾压 | 10/10 |
| 傅家已备好一切 | Beat 5-6 | 走入正厅全员等候 | 9.5/10 |

**引擎机制**：每个信息差都在"读者知道 → 期待揭露 → 揭露时的爽感"三段闭环中运转。

### 驱动力 2：情绪债积累（占比 30%）

顾呈阳在Beat 4中连续5次贬低女主，每次都加码一层：
1. "刚回来就找我的人，不好吧？"（傲慢）
2. "电话不接微信不回，真行啊"（控制欲）
3. "别演了"（不信任）
4. "他傅宴再不济也不是不挑不拣的"（人格贬低）
5. "是，你现在说这些难道不丢人吗？"（公开羞辱）

**引擎机制**：每多一层贬低，读者对"碾压回来"的渴望就强一分。债务越高，偿还时爽感越强。

### 驱动力 3：身份谜团（占比 20%）

傅宴全程"不像正经人"的反差：
- 吹口哨、嘻嘻笑、"哪有功夫啊姐姐"
- 每年生日"醉生梦死"
- "傅家二世祖"的标签

vs 偶尔闪现的反差信号：
- "检验报告就已经在我的桌上了"（信息掌控力）
- "把人放进来"全场让路（权力辐射）
- "傅家为什么百年不衰"（家族底蕴暗示）

**引擎机制**：读者不断修正对傅宴的认知，每次修正都是微型爽点。

### 驱动力 4：关系升级期待（占比 10%）

从"一夜情" → "怀孕" → "协商" → "求婚" → "全家认可" → "公开官宣"的阶梯式升级，每一步都超出预期。

## 停不下来的微观机制

### 句末钩子密度
- 平均每15-20行一个微型悬念
- "车门拉开，让我意外的是"→ 必须看下一行
- "他的话没说完，我就把那张卡掰了"→ 必须看反应
- "一道慵懒的声音从远处传来"→ 必须看是谁

### 期待管理
- 每次给出答案的同时制造新问题
- 例：怀孕确认（答案）→ 但没打傅宴电话（新问题）
- 例：傅宴求婚（答案）→ 八天后婚礼顾呈阳怎么办（新问题）
