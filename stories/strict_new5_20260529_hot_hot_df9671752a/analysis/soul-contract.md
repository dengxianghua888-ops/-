# Soul Contract

## 一句话神髓

被误认为娇气废物的末世吉祥物，其实是镇压尸潮和自身怪物人格的封印核心；当反派用“人人平等”和“弱肉强食”毁掉她的人类自我后，女主用同一套规则把全基地推回真正末世。

## 读者承诺

读者必须得到三层满足：

1. 憋屈满足：女主前半所有“娇气”都被证明不是矫情。
2. 爽感满足：雷铁男必须亲眼看见自己亲手放出怪物。
3. 余味满足：女主赢了，但她不再是完全无害的小公主。

## 不可破坏的因果链

```text
女主被宠、爱干净、喝奶茶、穿裙子
→ 圣域稳定，尸潮被安抚
→ 雷铁男误判为特权和废物
→ 奶茶被打翻、裙子被毁、血衣污染
→ 女主人性封印断裂
→ 陆野揭开零号/女王真相
→ 女主撤去庇护
→ 雷铁男在自己的弱肉强食规则里崩塌
→ 女主建立新秩序，但危险余味保留
```

## 情绪债合约

| 债 | 必须偿还方式 |
|---|---|
| 奶茶被毁 | 结尾恢复奶茶供应，并让“没人敢说她搞特殊” |
| 裙子被毁 | 以红色女王袍升级，不只是换衣服，而是身份加冕 |
| 圣域被误解 | 万尸下跪，证明丧尸不是弱，而是怕她 |
| 老王头被踩断腿 | 女主必须保下老王头，展示清算有道德边界 |
| 被挂旗杆献祭 | 女主必须撤去庇护，让施害者直面无保护末世 |
| 弱肉强食口号 | 雷铁男必须在“强者求生”中被数量级碾压 |

## 主角姿态合约

- 前半：柔软、怕疼、爱干净、求饶，但一直在忍。
- 觉醒点：不是“变强”，而是“锁断了”。
- 后半：冷、短、审判式。
- 终局：保留善者，清算恶者，建立新秩序。
- 余味：她仍喜欢奶茶，但脾气已经回不去了。

## 反派合约

雷铁男不能被洗白。她的核心功能是把“正义口号”变成施暴工具。

必须保留的反派原话类型：
- 人人平等。
- 不养闲人。
- 末世只留强者。
- 让女主见现实。
- 为集体牺牲。

后半必须逐一回旋。

## 道德边界

女主可以残酷，但不能无差别。文本必须保留以下分层：
- 主犯雷铁男：重罚。
- 起哄、动手、帮忙献祭者：清算。
- 沉默但流泪、不敢看者：可保留。
- 老王头和阻拦者：必须保护。

## 神髓禁改

- 禁改“娇气即封印”。
- 禁改“污染媒介导致崩坏”。
- 禁改“旗杆公开献祭”。
- 禁改“万尸下跪”这一位格爆点。
- 禁改“反派规则回旋”。
- 禁改“红色女王袍 + 新秩序余味”。
