# Reader Engine

## 目标读者

- 喜欢现代反转、重生避坑、规则反杀的番茄短篇读者。
- 对“好心被讹”“道德绑架”“网暴反噬”“学校/单位甩锅”有强烈现实共鸣。
- 偏好主角冷静、不圣母、有证据、有后手。
- 能接受主角带一点道德冷感，但不能接受主角主动违法害人。

## 阅读驱动力

| 驱动力 | 源文执行 | 读者心理 |
|---|---|---|
| 受害共情 | 前世十年照顾、父母被网暴、爱情失去 | “凭什么好人要被拖死？” |
| 重生改命 | 回到第一次请求买冰箱 | “这次千万别答应。” |
| 规则爽点 | 让学生走后勤流程 | “对，就该按流程。” |
| 坏人自作聪明 | 女生举报、学校开除 | “她们以为赢了，其实完了。” |
| 关键证人失联 | 退群拉黑出国 | “现在知道找他了？” |
| 公开处刑 | 直播、弹幕、监控 | “让所有人都看看真相。” |
| 制度清算 | 教育厅、警方、校长入狱 | “不只骂人，还要真付代价。” |
| 人生补偿 | 回家、爱人、读博 | “他终于拿回自己的人生。” |

## 上瘾循环

1. **风险出现**：周小月请求、李婷投诉、学校谈话、事故爆发。
2. **主角不解释**：他不抢着澄清，反而退一步。
3. **反派加码**：举报、开除、直播、甩锅。
4. **读者焦虑**：这会不会又变成前世？
5. **责任反弹**：加码行为先砸到反派自己身上。
6. **新证据悬置**：主角似乎知道更多，但暂时不放。
7. **公开爆炸**：直播间/调查组/监控完成释放。

## 读者必须持续知道的问题

- 主角这次会不会又心软？
- 谁会替主角背上冰箱责任？
- 李婷找不到主角后怎么办？
- 周小月到底是不是无辜？
- 监控为什么“坏了”？
- 主角手里到底有什么证据？
- 学校会不会继续甩锅？
- 主角最后能不能拿回爱情和人生？

## 评论区触发点

- “就该走流程，别乱好心。”
- “李婷不无辜，她先网暴别人。”
- “周小月太会装了。”
- “学校才是最恶心的。”
- “主角不救场太爽了。”
- “监控邮件这一手绝了。”
- “幸好他跑得快。”

## 改编时的读者流失点

- 主角解释太多，会削弱冷静撤离爽感。
- 反派太早露馅，会削弱后段监控反转。
- 李婷写得过于无辜，会让读者对她死亡不适。
- 周小月只靠哭，不给主动拔插头证据，会显得惩罚过重。
- 学校不被清算，会让制度怒气无处释放。
- 结尾不补偿女友线，会让前世最大遗憾未还清。
