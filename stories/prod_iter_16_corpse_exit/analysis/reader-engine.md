# Reader Engine

## 目标读者

- 偏爱家庭伦理复仇、追悔火葬场、真假少爷、系统脱离的番茄读者。
- 能承受前半段高压虐主，期待后半段集中清算的读者。
- 喜欢“证据证明清白”而不是口头解释的读者。
- 对亲情偏心、孩子认贼作父、爱人背叛有高情绪反应的读者。

## 爽点引擎

源文爽点不是主角亲手反杀，而是“不可追回 + 证据反噬”。主角死前越无力，死后证据越有力；施害者越晚相信，追悔越痛。

关键循环：

1. 主角说出真相。
2. 亲人否认并加重羞辱。
3. 系统倒计时提醒读者：忍耐有终点。
4. 主角死亡，彻底退出关系。
5. 证据证明主角每一句都是真的。
6. 施害者再也找不到被原谅的对象。

## 平台适配结论

番茄适配度高。原因是首章冲突密度强、每千字都有新伤害或新证据、死亡卡点明确、追悔不可逆。风险在于前半段虐感过强，改编时必须用倒计时和“即将离开”的确定性托住读者，避免纯受虐空转。
