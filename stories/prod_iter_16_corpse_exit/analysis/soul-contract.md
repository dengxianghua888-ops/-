# Soul Contract

## 核心契约

读者进入这篇文，是为了看一个被所有亲密关系联合践踏的人，终于用不可追回的死亡证明自己没有撒谎。契约的关键不是“主角复仇成功”，而是“他不再给任何人补偿他的机会”。

## 主角灵魂位置

- 身份：被夺走家庭位置的真少爷。
- 表层标签：背尸人、脏、晦气、精神不稳定、小三、撒谎精。
- 真实标签：长期受害者、孩子亲生父亲、被亲人用爱之名折磨的牺牲品。
- 最终姿态：不争辩、不原谅、不回头，死亡后冷静旁观。

## 读者情绪契约

| 契约项 | 必须满足 | 原文落点 |
|---|---|---|
| 委屈必须被确认 | 主角说过的每一件事后文都要被证据证明 | L354-L359 视频证据坐实真实伤害 |
| 爱不能补救死亡 | 追悔只能成为惩罚，不能成为和解 | L431-L442 妻子死亡、姐姐疯癫 |

| 主角不能主动洗白施害者 | 死后旁观，不替任何人开脱 | L222-L225 |
| 清算不能太轻 | 长达六年的伤害必须对应不可逆后果 | L418-L430、L431-L442 |

## 灵魂底线

这篇的灵魂不是“误会解除”，而是“迟来的真相已经没有收件人”。任何改编都不能让主角在结尾重新接纳家庭、爱情或孩子。主角一旦回头，标题中的“离开后她们疯了”就失效。

## 情绪价值

- 替读者完成“我说的是真的”的确认。
- 替读者拒绝“他们也是为你好”的道德绑架。
- 替读者惩罚偏心、控制欲和认贼作父。
- 替读者保留不可追回的尊严：死亡不是求关注，而是退出她们的审判体系。

## 禁止漂移

- 禁止把姐姐写成单纯被骗的好人，她是六年折磨的设计者。
- 禁止把妻子写成只是被蒙蔽，她主动夺走孩子和名分。
- 禁止让父母用出家、哭泣获得赦免。
- 禁止让孩子用“我错了”换回亲情。
- 禁止把假少爷变成可怜替身，他必须是主动加害者。
