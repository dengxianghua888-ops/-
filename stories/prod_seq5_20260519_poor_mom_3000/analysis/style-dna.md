## 句式骨架

1. 数字砸脸：先给声称数字，再给实际数字。  
证据：L42“这个月三千生活费”；L45“新到账的30块”；L68“到账‘三千块’，实际只能用三十元”。

2. 冷静反问：主角不哭闹，用问题逼对方自证。  
证据：L183“那钱在哪儿呢？”；L186“有本事一一对账吗？”；L316“这辆近千万的车，是怎么来的？”

3. 公开审判短句：重要爽点拆成短句，让读者逐步看清。  
证据：L353-L360“到账三千元 / 两千七百元被定时转走 / 尾号9087 / 那是我爸的银行卡尾号”。

4. 家庭羞辱对白：反派语言必须粗暴具体。  
证据：L61-L62“撒谎都不带打草稿”“这破大学还不如不念”；L169“整天出去鬼混”。

5. 回旋收束：结尾把前文物象还给施害者。  
证据：L446-L447“连三十块都赚不到”“汤泡饭的滋味”。

## 叙述口吻

- 第一人称受害者视角，前期以“忍、饿、羞”为主。
- 叙述冷静，不大量抒情，痛感靠物件和数字承担。
- 情绪爆点多由对话打出，旁白负责补刀和转场。
- 主角不是主动谋划型复仇者，而是被逼到公开羞辱后开始证据反击。

## 高频有效物件

| 类型 | 物件 | 功能 |
|---|---|---|
| 生存 | 汤泡饭、免费汤、过期胃药、包子、外卖单 | 证明主角真的穷 |
| 数字 | 30、30.58、42.58、3000、2700、960万、9087 | 让冤屈可量化 |
| 证据 | 银行APP、缴费提醒、转账记录、车行电话、银行流水 | 让反击不靠吵架 |
| 权力 | 家门指纹锁、公司岗位、媒体镜头、律师电话 | 推动家庭冲突社会化 |

## 可复用金句模式

- “每月三千，可我卡里只有三十。”
- “你说给我转钱了，那钱在哪儿呢？”
- “这辆近千万的车，是怎么来的？”
- “这个家，我说了算。这个公司，也是。”
- “他终于体会到，当初我走投无路，就着食堂免费汤泡饭的滋味。”

## 仿写注意

- 保留短段落和高频换行，尤其证据揭露段。
- 反派辱骂要具体到钱、学费、鬼混、脸面，不能抽象成“你不懂事”。
- 主角反击时少用狠话，多用数字、单据和公开提问。
- 结尾不要写“我释怀了”，应写边界和伤痕。
