# 非阻断正文修订建议

1. CH03 章末“私吞学费”建议提前铺垫。  
   当前前文主要冲突是药费、生活费、住宿费，学费线到 CH14 才明显出现。可在 CH02 或 CH03 加一句学校财务/实习费用欠缴提示，或把 CH03 hook 改成“承认私吞生活费”。

2. CH04 银行合作自助终端建议更保守。  
   当前终端可显示“亲属授权变更记录”和代办人姓名，便利度偏高。建议改为：终端只显示“未成年开户曾有监护人代办/需柜台调档”，父亲抢身份证仍能暴露异常。

3. CH08 车行核验尾号建议降低合规风险。  
   当前车行经理直接确认付款卡尾号9087。建议改成白栀报出“9087”请求经理只确认是否匹配，或由母亲/律师发起维权核验，车行只回“与你提供的尾号一致”。

4. 医院与白氏口腔总部关系建议统一一句设定。  
   当前有急诊输液室、医院食堂、口腔总部、总院门口等元素。建议在前文补一句“我实习的白氏综合院区”或“母亲旗下医院有综合急诊”，避免读者疑惑口腔医院为何有急诊输液室。

5. 中后段句式可微调。  
   CH08-CH12 证据推进很密，连续“我把/我问/我说”较多。可少量合并动作句，让证据链更像现场推进而非清单复述。
