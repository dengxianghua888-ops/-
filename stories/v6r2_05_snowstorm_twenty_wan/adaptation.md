# 高保真设定重置：选定方案

## 选定方案：B — 古籍修复师 × 医院护工

### 核心设定

| 原设定 | 新设定 | 保真逻辑 |
|--------|--------|-----------|
| 钢琴教师沈念歌 | 古籍修复师程书衡 | 同为精细手艺+艺术灵魂型职业 |
| 齐衍深装病骗钱 | 顾深舟装肝硬化晚期骗肝移植手术费 | 装病骗局保留,升级为需巨额手术费的重症 |
| 夜场驻唱 | 深夜医院陪护工 | 同样有社会偏见+合法+消耗身体 |
| 翡翠镯(外婆传承) | 清代紫石端砚(外婆传承,磨墨修书四十年) | 同为不可替代的传承物件+情感载体 |
| 陆晚月(精算型操控) | 姜漪澜(精算型操控) | 双面性保留：楚楚可怜→真面目暴露 |
| 赵鸣川(火锅店朋友) | 方砚青(笔墨纸张店老板,女性) | 朋友角色+信息揭露通道 |

| 救命恩情=工地塌方 | 救命恩情=洪灾救人 | 载体更换,骗局结构不变 |

### 撞见场景重构

女主在B栋3楼做护工,凌晨3点被护士派去A栋6楼取特殊药膏。电梯门打开——顾深舟穿着深灰西装外套,和一个女人手挽手站在走廊尽头。他仰头大笑,声音在空荡的医院走廊里回荡。

女主手里的药膏盒子没有掉。她攥住了。

"你怎么在这儿？"他笑容僵住。

"我在这里做护工。给你挣治病的钱。"

姜漪澜偏过头,声音温柔得像刀片裹棉花:"她挣的钱,有一半转到了我的卡上。"

### 多层递进反转(M6)

| 层级 | 位置 | 内容 |
|------|------|------|
| Layer 1·情节层 | 30% | 撞见+装病骗局曝光:体检报告全正常,肝功能无异常 |
| Layer 2·经济层 | 45% | 三个月"医药费"全转给姜漪澜;外婆端砚被典当;账户余额217元 |
| Layer 3·社会层 | 60% | 姜漪澜把女主做护工照片发业内群:"程书衡沦落给人擦屎"→委托流失→工作室关门 |
| Layer 4·真相层 | 75% | 方砚青揭穿:防汛档案显示顾父洪灾当天根本不在现场——救命恩情是编的 |
| Layer 5·价值层 | 90% | 咖啡馆定性："刀不是谁递给你的。你自己拿起来的。" |

### 温度陷阱设计(M5)

- **正峰闪回**：婚礼上他把端砚放进锦盒递给她,"这是你外婆留给你的,我帮你保管"
- **温度归零**：深夜护工回来桌上一碗粥+贴在枕头旁的膏药→不是心疼,是怕她太累后查真相
- **温度负值**：他在图书馆对面坐了一下午/翻到她的修复日志肩膀抖/"是我的错"

### 因果回旋(M3)

- 顾深舟当初说"做护工丢人"嫌她让他没面子 → 后来他在修复中心外面坐了一整天(自己成了卑微的那个)
- 姜漪澜安排人偷拍女主做护工 → 同样的偷拍手段最后反噬到她自己
- 顾深舟用"名声"威胁 → 方砚青冷笑:"现在知道找了"

### 物件闭环

| 物件 | 出场 | 翻转 | 终局 |
|------|------|------|------|
| 端砚 | 外婆磨墨四十年 | 被典当,摆在姜漪澜书房 | 碎片留在桌上,女主没拿走 |
| 婚戒 | 戴着 | 摘下,包进白纸 | "物归原主" |
| 修复刀 | 手稳如山 | 手抖握不住 | 考核当天不抖了 |
| 端砚铭文拓片 | 压在日记本里 | 翻到时肩膀抖 | 情感炸弹延迟引爆 |

### 技能丧失→回归路径

**丧失**：长期搬运50-80kg病人 → 手腕关节劳损+消毒液侵蚀 → 手指细微震颤 → 无法做毫米级裱糊

**谷底**：考核前一周,手腕骨裂(搬病人时扭到)

**回归**：缠着绷带完成宋版残页修复实操。考官看她的手:"你确定？"她只说了一个字:"嗯。"

### 结局

顾深舟在国家图书馆门口坐了一下午。透过玻璃看她在修复室里,弯腰,手很稳。他没有进去。

陌生号码发来一条消息:"你修的那页残卷,入选了年度十大修复案例。"

她嘴角轻轻动了一下。不是给谁的回应。是给自己的。

## 落选方案简述

### A — 调香师 × 代驾
女主是独立调香师,男主装心脏病,女主深夜做代驾挣手术费。传承物件为外婆手调的绝版老香水(最后5ml)。撞见场景:代驾送客到会所停车场,看见丈夫搂着别人出来。技能丧失:嗅觉疲劳。面试:国际香精集团调香师选拔。

**落选原因**：代驾→嗅觉丧失的因果关系偏弱(需要额外解释长期睡眠不足+汽车尾气导致嗅觉退化),逻辑闭合度不及B方案。

### C — 手工银饰师 × 闪送骑手
女主是手工银饰设计师,男主装脑瘤,女主深夜做闪送骑手。传承物件为外婆传的清末錾刻银胸针。撞见场景:送单到高档小区,门一开丈夫在里面。技能丧失:长期骑车颠簸+冻手导致关节炎。面试:国际珠宝品牌设计师选拔。

**落选原因**：闪送骑手在近期网文中出现频率高,新鲜度不足;银饰师题材与已有爆款存在联想风险。
