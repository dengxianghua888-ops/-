# Reader Engine：读者驱动引擎分析

## 目标读者画像

**核心群体**：18-35岁女性，都市打工人/大学生
**阅读场景**：通勤地铁、深夜睡前、午休碎片时间
**情感状态**：经历过或目睹过感情中的不对等付出

## 读者心理驱动力（按优先级排序）

### 驱动力1：代入性窒息（前60%）
- **机制**：读者代入女主视角，感受系统性被辜负的窒息
- **设计**：压迫链每1000字加码一次，不给喘息
- **生理反应目标**：胸口发闷、攥手机、想骂人
- **关键钩子**：每次想到"她为什么不走"→继续读下去

### 驱动力2：清醒离场的代偿快感（60-70%）
- **机制**：读者在现实中可能做不到如此干脆的离场，通过女主完成代偿
- **设计**：离场动作极简（五个字/删除/拉黑/消失），不给施害者任何表演机会
- **生理反应目标**：长出一口气、拍桌子说"好"
- **关键钩子**："她真的走了"→但他会怎么反应？

### 驱动力3：追悔不及的报复性满足（70-85%）
- **机制**：不需要女主出手报复，只需要展示男主追不到的过程
- **设计**：每个追寻场景都以"被拒绝"结束，且拒绝方式越来越温和=越来越无望
- **生理反应目标**：嘴角上扬、"活该"、但又有一丝心疼
- **关键钩子**：真相一层层揭开→看他承受不住

### 驱动力4：重建的治愈补偿（85-100%）
- **机制**：读者需要确认"她真的好了"
- **设计**：用职业成就（面试通过）+亲情回归（回家）+自我认同（给自己微笑）三重确认
- **生理反应目标**：鼻酸、温暖、"值得"
- **关键钩子**：最后那条短信——他还在，但她已不需要了

## 完读率设计

### 付费墙位置建议
1. **第一付费点（~2500字）**：陆晚月低声说"你挣的钱有一半转到了我卡上"——信息差引爆
2. **第二付费点（~5000字）**：齐衍深当着所有人护陆晚月走——公开羞辱
3. **第三付费点（~7000字）**：赵鸣川推出牛皮纸袋"救命之恩是编的"——真相炸弹

### 微钩设计（每800-1200字一个）
- 物件悬念：翡翠镯去向→账户数字→日记本→旧照片
- 人物悬念：赵鸣川欲言又止→林娜为什么来找→方姐为什么冷笑
- 情感悬念：排骨汤是谁送的→他为什么在楼下等→照片背面写了什么

## 禁忌雷区（踩中即流失读者）

1. **女主回头复合** → 前面所有压迫白承受了，读者会骂作者
2. **圣母式原谅** → "我原谅你因为你也不容易"——读者最恨
3. **靠新男人翻身** → 削弱女主独立性，变成换皮依附
4. **过度暴力血腥** → 本文的爽不来自暴力，来自"冷静的力量"
5. **无逻辑金手指** → 突然冒出闺蜜是总裁/继承遗产等
6. **男主洗白过快** → 他的痛苦必须足够长，否则"凭什么原谅"
7. **把陆晚月写成蠢** → 她是精算师，写蠢了男主就更蠢
