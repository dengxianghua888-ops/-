# StoryForge Phase 3：高保真设定重置室

## 产线结论

本轮生成 3 套投稿方向，选择 **方案 B：海岛婚礼直播事故 + 珠宝修复师学术升维**。

选择理由：

- 保留原故事神髓：生死关头被丈夫放弃、第二天离婚、真千金替嫁、断亲断婚、价值升维、舆论反扒、追妻失败。
- 重置表层载体：从“综艺落水 + 十八线演员 + 耶鲁计算机”改为“海岛婚礼直播事故 + 珠宝修复师/材料科学研究者 + 海外文保实验室”。
- 新鲜度更强：婚礼直播天然具备公开羞辱、影像传播、亲友围观、商业联姻压力，适合番茄短篇强开局。
- 逻辑闭合更稳：女主婚内照料丈夫的“按摩治腿”可自然转化为“康复护理 + 修复伤腿旧表/义肢配件”，女主学术能力可落到“材料修复、文保、珠宝鉴定”。
- 爽点仍集中：她不是靠新男人翻身，而是用证据、履历、作品和直播原片重建价值。

## 方案 A：豪门周年宴沉船直播 + 医工康复女主

### Premise

女主顾南栀是被顾家找回的真千金，却被迫替假千金顾晚意嫁给车祸后腿伤的陆承砚。三年婚姻里，她一边学康复医学，一边照料陆承砚的伤腿，还用自己设计的辅助支具让他重新站上商业舞台。

顾晚意回国后，借“周年游艇宴直播”重回陆承砚身边。宴会突遇小型游艇侧翻，顾南栀和顾晚意同时落海。陆承砚当着直播镜头先抱走顾晚意，留下顾南栀被船桨暗流卷入水下。

第二天，顾南栀带着离婚协议出现。她不解释，不哭闹，只说：“陆承砚，昨晚你救谁是你的选择，今天我走，是我的选择。”

离婚后，她进入海外医工康复实验室，成为智能义肢项目核心成员。顾晚意利用直播片段塑造“被妹妹抢走丈夫”的受害者形象，却被顾南栀分批放出替嫁聊天记录、婚内护理记录、康复设计署名、顾晚意海外造假履历。陆承砚终于发现自己失去的不是妻子，而是把他从残废阴影里拉出来的人。

### 优点

- 医工康复与“治腿付出”高度贴合。
- 丈夫失去女主后腿伤反复，悔恨具备身体惩罚感。
- 身份升维有专业壁垒。

### 风险

- 医工设定解释成本偏高，短篇里容易显得硬。
- 若写过多医学细节，会拖慢番茄节奏。
- 女主价值可能被误读成“照顾型妻子”，需强化她的科研主体性。

## 方案 B：海岛婚礼直播事故 + 珠宝修复师学术升维

### Premise

女主许知夏是许家失散多年的真千金。假千金许明珠不愿嫁给车祸后腿伤、性格阴沉的傅寒舟，许家便让刚认回来的许知夏替嫁。婚后三年，许知夏既照顾傅寒舟的伤腿，也替他修复母亲遗留的古董胸针、旧怀表和一批傅氏拍卖行濒临毁损的珠宝藏品。

她表面是被群嘲“靠婚姻上位”的小众珠宝修复博主，实际曾是国内顶尖材料学院的高分生，因替嫁中断学业，私下仍在做金属疲劳、宝石修复与文物保护研究。

许明珠回国后，傅寒舟替她补办一场“迟来的海岛婚礼发布会”，名义上是品牌联名直播，实则把许知夏这个正妻晾成笑话。婚礼外拍时，海边玻璃栈道坍塌，许知夏和许明珠同时落海。傅寒舟跳下去，第一时间抱住许明珠游向快艇。许知夏被婚纱拖住下沉，水灌进肺里时，只看见傅寒舟护着许明珠离开的背影。

第二天，许知夏把离婚协议放到傅寒舟桌上。傅寒舟说：“明珠不会水，我只是先救她，你连这种醋都吃？”  
许知夏平静回答：“她不会水，所以你救她。我差点死了，所以我不要你。很公平。”

离婚后，她搬走、断亲、出国，进入佛罗伦萨文保实验室参与王冠修复项目。许明珠借婚礼直播剪辑卖惨，称许知夏才是插足者。许知夏不争辩，只分批公开替嫁聊天记录、结婚证离婚证、傅氏藏品修复署名、旧论文、录取通知、实验室项目名单。舆论从骂她“捞女”转向追问许明珠的学历造假、海外抄袭、珠宝赝品交易和许家偏心。

傅寒舟追到国外时，许知夏已经完成第一件公开展品修复。她身边的新男主不是霸总，而是文保实验室项目负责人周砚白。他第一次动心不是因为她漂亮，而是看见她手上长期修复留下的裂口，看出她替傅寒舟修过无数件旧物，也被旧婚姻磨损过。

最终，许知夏不复婚、不回许家。许明珠因造假和赝品交易塌房，许家拍卖行被调查，傅寒舟余生反复看那段海岛直播原片，困在自己亲手放弃她的那片海里。

### 核心改造

- “综艺落水”改为“海岛婚礼直播事故”。
- “十八线小演员”改为“小众珠宝修复博主”。
- “京大/耶鲁计算机”改为“材料学院/海外文保实验室”。
- “按摩治腿”保留为“康复护理 + 修复旧物 + 记住生活细节”。
- “微博证据”改为“直播原片 + 公证聊天记录 + 修复署名 + 实验室官网名单”。
- “海外黑料”改为“学历造假、抄袭、赝品交易、霸凌实习生”。

### 为什么选它

1. 婚礼直播比综艺更有伦理羞辱：丈夫替假千金补办婚礼，本身就是公开背叛。
2. 珠宝修复与真假千金天然互文：假千金叫“明珠”，真千金才是真正能修复珍宝的人。
3. 文保实验室升维更有新鲜感：不是常见娱乐圈/霸总科研模板。
4. 旧物修复能承载婚内温度：她修复他母亲遗物、旧怀表、胸针，后期这些物件反向折磨他。
5. 直播原片可反复作为证据和悔恨刑具：适合多层舆论反转与追妻火葬场。

## 方案 C：公益救援直播山洪 + 建筑结构女主

### Premise

女主林听晚是真千金，被迫替假千金林若棠嫁给腿伤后的江行屿。她表面是建筑事务所边缘助理，实际曾是顶尖高校结构工程方向学生，因替嫁中断学业。婚后三年，她替江行屿做康复训练，也帮江氏公益项目审过多处建筑隐患。

林若棠回国后，以公益大使身份加入江氏山区助学直播。山洪突发，临时吊桥断裂，林听晚和林若棠同时坠入急流。江行屿第一时间拉住林若棠，留下林听晚被冲向下游。

第二天林听晚递离婚协议，离婚后重回结构工程领域，加入国际灾害建筑研究项目。后续她用项目记录、桥梁预警邮件、替嫁证据、林若棠公益造假账本完成多层反转。

### 优点

- 山洪吊桥比落水更具危机感。
- 结构工程女主能承载专业价值。
- 公益造假容易形成舆论反噬。

### 风险

- 灾害救援题材涉及公共安全，敏感度高。
- 男主“先救谁”的选择可能被救援条件稀释，必须写成明确价值选择。
- 番茄读者对建筑专业爽点接受度略低于婚恋/珠宝/娱乐舆论。

## 机制保真设计

### M3：因果回旋反讽

原机制：  
男主把生死抛弃说成“她不会水，你吃醋”；女主用“离婚了与你无关”反向废掉关系规则。

新执行：

- 傅寒舟：“明珠穿着婚纱，她不会水，我只是先救更危险的人。”
- 许知夏：“她不会水，所以你救她。我差点死了，所以我不要你。很公平。”
- 傅寒舟后期解释许明珠和自己没什么。
- 许知夏回敬：“你们有没有什么，和我这个前妻有什么关系？”

审校要点：

- 女主台词必须短、冷、事实化。
- 不能让她长篇控诉。
- 不能让傅寒舟的解释显得合理。

### M5：温度反转曲线

原机制：  
婚内照料正温度 → 落水归零 → 后期负温度悔恨。

新执行：

1. 正温度：
   - 许知夏替傅寒舟做腿部康复记录。
   - 她修好傅母留下的旧胸针。
   - 她记得傅寒舟每次阴雨天要换哪副护具。
   - 傅寒舟曾带她去旧货市场找碎宝石，关系短暂升温。

2. 归零：
   - 海岛婚礼直播坍塌。
   - 他抱着许明珠上快艇。
   - 她被婚纱和碎玻璃拖进海里。
   - 她看到他离开的背影，心死。

3. 负温度：
   - 傅寒舟找不到护具记录，腿痛复发。
   - 旧胸针再次松脱，无人能修。
   - 他反复看直播原片。
   - 他用高价请人复刻许知夏的修复痕迹，却怎么都不像。

审校要点：

- 早期温情不宜过长，用具体物件和动作带过。
- 后期悔恨不能浪漫化，要写成刑罚。
- 旧物必须反复出现，成为“修不回关系”的象征。

### M2：身份反差爆发

原机制：  
低估身份 → 舆论污名 → 学术价值多层揭开。

新执行：

1. 表层低位：
   - 网友骂许知夏靠傅家流量做珠宝博主。
   - 许明珠粉丝称她抢婚、抢资源、抢姐姐人生。
   - 许家暗示她“没受过完整教育，上不得台面”。

2. 第一层揭露：
   - 她发出替嫁聊天记录和结婚证、离婚证。
   - 证明许明珠才是逃婚者。

3. 第二层揭露：
   - 傅氏拍卖行旧藏修复记录出现她的签名。
   - 行业内账号认出她曾修复过濒毁胸针。

4. 第三层揭露：
   - 材料学院老师公开她当年高分、论文、竞赛。
   - 实验室官网出现她参与王冠修复项目的名单。

5. 第四层揭露：
   - 她在国际文保展上署名发布成果。
   - 傅寒舟看到她站在聚光灯下，不再是任何人的替代品。

审校要点：

- 不能一次性爆完。
- 身份升维必须靠女主旧能力和持续努力。
- 新男主不能给她安排履历。

### M6：多层递进反转

新反转阶梯：

1. 首反转：落海后第二天离婚。
2. 断联反转：搬离傅宅，拿走必要财产和个人修复笔记。
3. 亲情反转：许母施压失败，被拉黑。
4. 舆论反转：直播剪辑污名化，许知夏发第一批证据。
5. 价值反转：修复署名、论文、实验室名单分批曝光。
6. 道德反转：许明珠学历造假、赝品交易、霸凌塌房。
7. 情感反转：傅寒舟追到国外被拒。
8. 终局反转：许知夏事业与新爱稳定，傅寒舟被旧物和原片困住余生。

审校要点：

- 每 15%-20% 必须有一次新信息升维。
- 舆论反转要分批，而不是一条长微博解决。
- 傅寒舟悔悟必须由证据触发，不可突然深情。

## 敏感议题表达边界

1. 落海事故：
   - 可写濒死、呛水、窒息、求生本能。
   - 避免过度血腥和细致自残式描写。
   - 必须明确是丈夫选择造成的情绪创伤，不写成纯意外误会。
