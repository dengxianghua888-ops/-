# Beat Sheet：原文逐段工程拆解

> 说明：每个 Beat 都包含原文证据、情绪强度、信息差、读者期待、章尾钩功能与反转机制。情绪强度 1-10，10 为最高。

## Beat 1：落水抛弃 + 离婚协议开局

- 位置：开篇至“嗯，签吧！”
- 原文证据：
  - “综艺里，我和姐姐都失足落水。”
  - “而我的老公霍霆，不假思索地跳入水里救起了姐姐。”
  - “留下我差点沉入湖底的时候才被工作人员救上岸。”
  - “第二天，我把离婚协议书交给霍霆的时候。”
  - “我平静地看着他的眼睛，‘嗯，签吧！’”
- 情绪强度：9.5
- 信息差：
  - 霍霆以为女主是在吃醋。
  - 女主已经把这件事定义为婚姻死亡。
  - 读者暂时不知道姐姐是谁、为什么丈夫先救她。
- 读者期待：想看女主是不是真的离婚，霍霆会不会后悔。
- 章尾钩功能：用“签吧”完成首钩，直接承诺女主不纠缠。
- 机制：H1、M3、M5
- 执行价值：爆款开头必须保留此类“生死抛弃 + 冷静止损”组合。

## Beat 2：领证离婚 + 财产落袋 + 女主情绪断电

- 位置：“我和霍霆平静地领了离婚证”至“真好，我可以开始为自己而活了。”
- 原文证据：
  - “我和霍霆平静地领了离婚证。”
  - “离婚了，就是离婚了，不是亲人，更没法当朋友。”
  - “我银行卡的余额，那些不开心又转瞬即逝。”
  - “只要了两千万。”
  - “真好，我可以开始为自己而活了。”
- 情绪强度：8
- 信息差：
  - 霍霆以为离婚不代表断联。
  - 女主清楚离婚就是关系彻底终止。
  - 读者知道女主正在从情感关系切换成生存安全。
- 读者期待：她拿到钱后会如何重启人生？霍霆会不会不适应？
- 章尾钩功能：从“婚姻结束”转向“新生活开始”。
- 机制：M3、M5
- 执行价值：女主“不争财产但确保安全”的清醒感，是独美爽点基础。

## Beat 3：真千金身世 + 替嫁债建立

- 机制：M2、M3、M6
- 执行价值：真假千金不是装饰，而是舆论反转的核心证据链。
