# 读者引擎：《老公给我妈下药后，我杀疯了》

## 一、目标读者画像

### 主力读者（70%流量）

- **人群：** 25-40岁已婚女性
- **核心经历：** 经历过或正在经历婆媳矛盾、丈夫立场模糊
- **阅读心理：** 在现实中无法反击的愤怒，需要在故事中被代偿
- **代入方式：** 直接代入女主视角，把自己的婆婆/丈夫投射到角色上
- **付费触发点：** "她到底怎么反击的？我要看到婆婆跪下那一刻"

### 辅助读者（30%流量）

- **人群：** 18-25岁未婚女性
- **核心心理：** 对婚姻恐惧+对"清醒女性"的崇拜
- **阅读心理：** 恐婚情绪的验证+看"姐姐怎么处理"
- **代入方式：** 旁观者崇拜视角
- **付费触发点：** "这个女主太飒了，我要看她怎么全身而退"

## 二、读者情绪操控图谱

### 阶段1：共情建立（0-20%）

**操控手段：**
- 网帖的"群体恶意"触发读者义愤
- 母亲的善良+脆弱触发保护欲
- 丈夫的"表面体贴+背后下手"触发恶心感

**读者内心独白：** "这种男人怎么会存在？她妈太可怜了"

### 阶段2：愤怒积累（20-50%）

**操控手段：**
- 婆婆的恶行每次升级一档（骂人→踢人→剃女儿头）
- 丈夫永远在和稀泥（激发"窝囊废"厌恶）
- 邻居的误解制造"全世界都不帮她"的孤立感
- 帖子评论区的"群众在线看热闹"=读者自己在看

**读者内心独白：** "够了够了，快反击啊！""再不动手我要气死了"

### 阶段3：期待释放（50-70%）

**操控手段：**
- 真相确认（牙膏）给读者一个"终于！"
- 设局引婆婆入住=读者知道猎物进了圈套
- 半夜切菜=第一口气出来了

**读者内心独白：** "来了来了！""太爽了，继续！"

### 阶段4：高潮释放（70-90%）

**操控手段：**
- 灌粉末=物理宣泄
- 金句回旋=逻辑高潮
- 面粉反转=意外惊喜+确认女主不是坏人
- 丈夫崩溃=情绪释放

**读者内心独白：** "啊啊啊太爽了！""面粉！她太聪明了！""活该活该"

### 阶段5：余韵满足（90-100%）

**操控手段：**
- 婆婆跪求（权力彻底反转）
- 因果结局（丈夫被虐=命运清算）
- 女主成功（正义得胜的确认）

**读者内心独白：** "太解气了""分享给闺蜜"

## 三、付费卡点设计

| 卡点位置 | 读者情绪状态 | 为什么必须付费 |
|---------|------------|-------------|
| Beat 6末（帖子再更新确认丈夫） | 愤怒值满格 | "她到底怎么反击？我必须看到" |
| Beat 8末（设局完成+攥紧料瓶） | 期待值爆表 | "计划要开始了！不看我死" |
| Beat 11前半（灌粉末） | 宣泄初爽 | "然后呢？丈夫什么反应？" |
| Beat 12末（丈夫跳楼） | 震撼 | "结局是什么？离婚了吗？" |

## 四、读者留存钩子设计

### 微钩（每800-1200字一个）

- **帖子更新钩：** 每次帖子更新都是一个"天哪他又说什么了"的钩子
- **婆婆恶行钩：** 每个新恶行都让读者想看"这笔账什么时候算"
- **丈夫双面钩：** 每次丈夫的假体贴都让读者想看"她什么时候撕破脸"
- **女主反应钩：** 女主每次忍住不发作，读者都在等"什么时候忍不了"

### 大钩（3000字级别）

- 帖子楼主身份确认 → 真的是她老公
- 下药途径确认 → 牙膏里的精神类药物
- 灌粉末事件 → 正面对决
- 面粉真相 → 二次反转

## 五、情绪禁区

| 禁区 | 原因 |
|------|------|
| 女主哭泣超过2句 | 破坏"清醒飒爽"人设，读者代入感崩塌 |
| 婆婆获得任何同情 | 读者的愤怒需要有明确出口，不能被稀释 |
| 丈夫真心悔过 | 会让读者犹豫"要不要原谅"，破坏爽感 |
| 旁观者理中客 | "两边都有错"式发言会激怒读者 |
| 女主依赖外力 | 破坏"靠自己"的核心爽感 |
