# Reader Engine — 《东瓶西镜放，恨不能遗忘》

## 核心驱动力
**信息差窥视欲**：读者知道女主是公主，但男主不知道——这个信息差从第一段就建立，持续到高潮爆发。读者始终在期待"什么时候揭穿"。

## 情绪引擎三级
1. **一级引擎（即时）**：心疼+愤怒——每一次男主的冷漠/残忍都在积累
2. **二级引擎（中期）**：期待反杀——"她什么时候爆发"的持续牵引力
3. **三级引擎（全局）**：公正感——施害者必须被惩罚，且惩罚方式必须与罪行对称

## 付费拉力点
- 男主宣布另娶后女主说"若我说我也门第相当呢"——读者想知道她的底牌
- 杀子后女主喊出"我是昭宁公主"被忽视——读者急切想看他知道真相的反应
- 天灯升起——读者确认反击开始，急切往下
- 大婚现场"公主殿下驾到"——高潮开启，绝不能停
- 林楚楚爆出孩子非男主的——双重打击叠加，需要看完全过程

## 读者状态管理
| 阶段 | 读者状态 | 操控手段 |
|------|---------|---------|
| 开局 | 震惊+心疼 | 怀孕喜讯瞬间翻转为被抛弃 |
| 压迫段 | 愤怒+焦急 | 每次男主出场都加重罪行 |
| 布局段 | 期待+紧张 | 天灯+暗探=反击倒计时 |
| 高潮 | 爽+释放 | 身份揭露+金句清算+男主跪地 |
| 结尾 | 治愈+唏嘘 | 父女团聚+田园重建+冷拒男主 |
