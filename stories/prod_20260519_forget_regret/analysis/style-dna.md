# Style DNA — ancient_BE 古言虐恋

## 数值指标
- **平均句长**: 28 字
- **对话占比**: 35%
- **问号密度**: 每千字 4.2 个
- **金句密度**: 每千字 1.8 句（回旋式为主）
- **叙述视角**: 第一人称（女主）
- **时态**: 过去式为主，高潮段切现在式

## 句式特征
- 短句用于心理冲击："可他只是抿唇淡淡道"
- 长句用于情绪铺陈和场景渲染
- 对话精炼，男主台词冷淡平静、女主台词带哀求转决绝
- 大量使用"我"开头的心理独白

## 情绪物理化
- "如坠冰窟" / "鼻尖忽的一酸" / "身体不住的颤抖"
- "能清晰的感受到孩子从我身体里溜走"
- "指甲嵌入掌心"
- "泪水晕湿了龙袍"

## 金句模式
- 回旋式："公主的凤冠也配得" → 凤冠给了别人 → 真公主戴冠驾到
- 对仗式："你烧毁小院的时候可曾见过旧情？"
- 冷静反问式："即便不是本公主，换成寻常女子，世子就可以囚禁杀子了吗"

## 节奏型
- 前半段（虐心段）：短-长-短节奏，短句制造冲击，长句铺陈压迫
- 高潮段（反杀段）：一口气不停歇的密集对话+动作
- 收尾段：长句舒缓，留白意象

## 禁忌
- 不用现代词汇（手机/公司/地铁等）
- 不用"杀疯/笑疯/怼/KO"等网络用语
- 不用AI味词汇
