# Dissection — 《东瓶西镜放，恨不能遗忘》

## Genre
ancient_BE（古言虐恋）

## Core Mechanism
M5 温度反转 + M3 因果回旋 + M2 身份反差 + M8 道德模糊结尾

## Structure Summary

全文分四大板块：
1. **开局揭伤（0-15%）**：三年恩爱被"另娶"一句打碎，男主宣布另娶门第女
2. **压迫升级（15-55%）**：烧院→囚禁→杀子→灌红花→逼爬天梯，温度持续下坠
3. **反杀高潮（55-75%）**：大婚现场公主驾到，身份碾压，金句回旋全部情绪债
4. **惩罚与留白（75-100%）**：男主失去一切，女主回归父皇，田园重建但不接纳男主

## Key Tension Points
- 男主说"公主凤冠也配得" → 把凤冠换给别的女人
- "流产死不了人" → 对比父皇心疼"瘦了"
- "只要你不闹到主母前面" → 大婚现场公主直接碾压主母
- 男主让女主爬天梯为情敌求符 → 男主自己跪在宫门外求见被拒

## Emotion Curve
极热（三年恩爱）→ 断崖下跌（另娶宣布）→ 持续降温（杀子/灌药/天梯）→ V型反弹（大婚揭身份）→ 冷静留白（不和解的田园）
