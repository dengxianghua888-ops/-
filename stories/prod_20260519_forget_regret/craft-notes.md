# Craft Notes — 凤翎误，三年负

## 核心创作决策

1. **身份替换**：公主→镇国公嫡女。保留权力碾压感的同时避免原文雷同。镇国公"首辅+武将"双重身份确保权力等级够高。

2. **信物系统**：凤冠→凤翎步摇（成对设计）。"祖母遗物仅此一对"的设定让步摇在大婚现场成为身份铁证，同时保留了"只配你戴"的回旋金句。

3. **极致体罚**：九千九百九十九阶→百里石阶。保留了"一步一叩"的身体痛感和精神摧残，用具体的物理细节（膝盖磨破/指甲全断/血迹连成线）替代数字堆砌。

4. **联络信号**：七色天灯→三盏红灯笼。更隐蔽、更合理（可被包装为婚礼彩头诱韩若挂出），逻辑自洽度高于天灯。

5. **结尾留白**：保留了"给一碗粥"的动作——这个细节既不是心软也不是决绝，而是"你不值得我恨了"的最高姿态。

## 机制保真检验

- M5 温度反转：五级下坠完整（恩爱→另娶→杀子→灌药→天梯）✓
- M3 因果回旋：步摇承诺→送人→真主人佩戴现身 ✓
- M2 身份反差：村妇→镇国公嫡女，仪仗+冠服+令牌三重视觉确认 ✓
- M8 道德留白：不杀不和解，竹庐重建但永不接纳 ✓

## 可复用经验
- 古言BE的paywall card应集中在压迫段（前60%），让读者在最愤怒时付费
- 身份碾压场景需要仪式感（仪仗/冠服/侍女/宣言），不能只靠对话
- 结尾"一碗粥"类的小动作比长篇大论更有留白力量
