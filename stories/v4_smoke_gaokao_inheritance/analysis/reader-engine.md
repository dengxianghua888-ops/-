# Reader Engine

## 读者心理路径

1. **好奇**: 遗嘱要求不存在的弟弟，读者想解谜。
2. **紧张**: 前几世死亡说明规则不是玩笑。
3. **代入**: 父母彼此怀疑又护着主角，降低纯恐怖感。
4. **不安**: 老宅记忆和密室让读者察觉父母也在逃避。
5. **愤怒**: 父母想再次催眠主角，读者站到主角一侧。
6. **疼痛**: 真相揭开，读者理解主角为何崩溃。
7. **回甘**: 家庭接纳，新名字落地，爽感从打脸转为释怀。

## 爽点类型

- 解谜爽：每个错误答案排除一个方向。
- 规则爽：遗嘱关键词被主角重新解释。
- 情感爽：父母公开补偿，主角不再被藏起来。
