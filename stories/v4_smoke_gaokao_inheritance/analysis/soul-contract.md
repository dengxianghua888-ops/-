# Soul Contract

## 读者承诺

让读者先被荒诞遗嘱钩住，再被循环死局压住，最后跟主角一起发现：谜面里的“弟弟”不是别人，而是主角被全家亲手封存的真实自我。

## 情绪债

| 债务 | 累积方式 | 偿还方式 |
|---|---|---|
| 死亡威胁债 | 三次错误解法都付出生命代价 | 找到真正谜底后循环停止 |
| 亲情隐瞒债 | 父母知道门后真相却阻止主角 | 父母主动道歉、公开支持 |
| 身份否定债 | 主角被催眠，被迫忘记自己 | 主角取回名字与选择权 |
| 长辈遗愿债 | 爷爷用最后力量设置谜题 | 主角真正“找回弟弟” |

## 爽点因果链

遗嘱说“找到弟弟” -> 全家按血缘找失败 -> 主角按记忆找 -> 密室证明“弟弟”是主角自我 -> 主角夺回解释权 -> 父母用行动补偿。

## 神髓禁改项

- 荒诞条件不可改成普通寻找亲人。
- 核心反转必须来自身份和记忆，不可改成普通私生子。
- 父母必须有爱，也必须承认伤害。
- 结尾必须以主角的新名字收束。
