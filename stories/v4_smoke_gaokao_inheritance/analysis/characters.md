# 角色图谱

## 主角

- **原功能**: 高考顶尖生，被遗嘱和遗忘记忆推向真相。
- **心理底色**: 怕拖累家人，怕被父母厌恶，也怕再一次失去自己。
- **成长线**: 求生 -> 找线索 -> 质问 -> 接纳真实自我。

## 父亲

- **表层**: 爱女儿，遇事先护家人，嘴硬但心软。
- **暗层**: 对父亲死亡有怨，对旧记忆有逃避。
- **转变**: 从“再催眠一次”到承认自己当年说错话。

## 母亲

- **表层**: 强势、护女、情绪反应快。
- **暗层**: 曾因亲人身份议题留下创伤，把恐惧投射到主角身上。
- **转变**: 从控制主角变成支持主角选择。

## 爷爷/外公功能位

- **功能**: 最早接纳主角的人，设置谜题推动全家面对真相。
- **情感**: 爱不是替主角决定，而是给主角留空间。

## 律师/医生功能位

- **律师**: 规则载体，保证遗嘱条件不可随意篡改。
- **医生**: 记忆闸门，揭示催眠、遗忘和二次逃避。
