# Reader Engine

## 1. 总体发动机
这篇文的阅读推进，不靠设定新鲜度，靠五个高频发动机并行运作：

1. **旧爱误会发动机**
2. **夺权打脸发动机**
3. **商圈封杀破局发动机**
4. **第三人/舆论刺激发动机**
5. **终局名分兑现发动机**

## 2. 旧爱误会发动机
### 输入
- 三年前逃婚
- 男主嘴硬记仇
- 女主误以为男主先不爱了
- 双方都掌握半截真相

### 输出
- 每次见面都带电
- 读者持续判断“到底谁更委屈”
- 哪怕只是同车、同桌、同楼道，都能生钩子

### 执行方式
- 不让两人长时间平静沟通
- 每次想说开时，都插入：
  - 工作电话
  - 新合作
  - 第三人闯入
  - 旧账被提
  - 身体越界

## 3. 夺权打脸发动机
### 输入
- 女主手里有遗嘱/股权/继承权
- 反派轻视她、质疑她、排斥她
- 股东处于观望状态

### 输出
- 快速爽感
- 女主不是空心恋爱女主的确认
- 读者对后续项目突破有耐心

### 执行方式
- 一次打脸不够，必须连续：
  - 夺总裁位
  - 抢办公室
  - 赶人出房
  - 逼停副总
  - 拿下项目
- 每次打脸都伴随更大阻力，避免爽感稀释

## 4. 商圈封杀破局发动机
### 输入
- 女主名声差
- 江氏势大
- 商圈人人观望，不敢站队

### 输出
- “她明明有能力却处处碰壁”的压迫感
- 合作一旦谈成，就会带来超额爽感
- 商战线具备持续阅读价值

### 执行方式
- 先让读者相信她真的谈不成
- 再用男主暗护/长辈旧情/女主胆量破一个口子
- 一次只破一个口，不一次性打通全局

## 5. 第三人/舆论刺激发动机
### 输入
- 白芷然、赵星儿、裴如嫣等女性角色
- 路人议论、新闻热评、圈层群聊
- 长辈与股东的评价体系

### 输出
- 压缩叙事成本
- 快速制造误会
- 让主角关系永远处于被观看状态

### 执行方式
- 每逢关系要升温，就让第三人或舆论介入
- 每逢事业要顺了，就让圈层偏见追上来
- 每逢读者以为某女配只是工具人，就赋予她一点私人立场

## 6. 终局兑现发动机
### 输入
- 婚纱
- 晚春
- 戒指
- 结婚证
- 长辈和解
- 孩子

### 输出
- 情绪彻底落地
- 补偿前文所有误会与分离
- 让读者离场时觉得“这对终于值了”

### 执行方式
- 不是一章突然结婚
- 而是逐个回收旧物与旧约：
  - 晚春
  - 设计婚纱
  - 领证
  - 公开
  - 婚礼
  - 孕育孩子

## 7. 付费点布置逻辑
这篇文的付费欲，主要靠以下几类断点：

### A类：关系临界点
- 强吻前
- 真相快说开前
- 误会扩大前
- 旧情回温又被打断前

### B类：事业翻盘点
- 董事会夺权前
- 合作签约前
- 股东站队前
- 机密失窃真相将明前

### C类：生死级钩子
- 跳海
- 失忆
- 消失
- 重伤
- 海外重逢

## 8. 为什么这篇文能长
因为它不是单线消耗，而是不断切换“读者此刻最急什么”：

- 前期急：她怎么夺位
- 中期急：他到底爱不爱
- 中后期急：林家到底在谋什么
- 后期急：他们还能不能活着在一起
- 终局急：会不会公开结婚、有孩子

这让每一段都有新的主要问题，不会陷入重复撕扯。

## 9. 改编时最值得复刻的引擎组合
推荐保留以下组合：

```yaml
reader_engine_combo:
  primary:
    - 旧爱误会拉扯
    - 女主事业夺回
    - 商圈封锁破局
  secondary:
    - 第三人刺激
    - 长辈立场变化
    - 舆论围观压力
  final_payoff:
    - 真相翻案
    - 名分公开
    - 婚礼/孩子/未来延续
```

## 10. 最易失速的地方
- 误会解释过早：中段直接塌
- 商战写太细：甜虐爽文变行业文
- 男主护得太明显：张力消失
- 女主连续吃瘪太久：读者焦躁流失
- 结局只给复合不给公开：读者会觉得被骗

## 11. 最终结论
这篇文的核心引擎，不是单纯“钓系总裁很会撩”，而是：

**女主每往前夺回一步人生，男主就更接近一次真心暴露；男主每暴露一次真心，女主的事业也就更有机会破局。**

两条线互相点火，这才是它能一路读下去的根本原因。
