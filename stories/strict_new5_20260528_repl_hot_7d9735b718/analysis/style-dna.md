# Style DNA

| 指标 | 估算值 | 工程含义 |
|---|---:|---|
| 平均句长 | 15.8 字 | 极短句推进，少长复句 |
| 平均可视行长 | 15.4 字 | 手机端阅读压力低 |
| 短行率（<=16字） | 0.58 | 大量断行制造快切 |
| 长行率（>=40字） | 0.03 | 几乎不用解释性长段 |

| 弹幕/评论行率 | 0.00 | 无弹幕评论结构 |

## Opening Structure

```yaml
opening_structure: conflict_first
opening_summary_lines: 0
hook_type: H1_life_detail_conflict
```

源文不是 conclusion_first。前 10-15 行没有冷静剧透完整故事链，而是直接进入吃面场景，通过一句备注制造异常，再用一周后的会员号完成实锤。

开篇链条：
- 极小异常：丈夫熟练备注“小份那碗不要香菜”。
- 主角纠错：“忘了我最爱吃的就是香菜？”
- 延迟实锤：一周后小姑娘报出同一会员号。
- 身份爆点：“这卡，是我老公的电话号码。”

## 快节奏锁定

源文属于快节奏短篇。仿写不得用解释性长段、流程清单、情绪总结替代现场交锋。

必须保留：
- 短行。
- 快切。
- 对话压迫。
- 证据一条条递出。
- 女主少哭诉，多确认、多反问、多清算。

禁止替代：
- “我很崩溃很痛苦”的心理总结。
- 大段婚姻史回忆。
- 以旁白解释小三为什么坏。
- 用抽象成长感悟代替判决书、转账、会员号、聊天记录。

## 句式偏好

1. 生活动作开句：
   - “我一顿。”
   - “我循声打量起她。”
   - “我紧紧握住手心。”

2. 短对白互逼：
   - “怎么回事啊？”
   - “你说话啊！”
   - “我们离婚吧。”

3. 冷静判词式短句：
   - “太晚了。”
   - “晚了。”
   - “离婚，是定局。”

4. 证据列举式控诉：
   - “你给她充两万会员，带她到处旅游，给她买名牌包。”
   - “却每月只给我八千，还要我养活你妈和女儿。”

## 章节节奏

- 第1章：异常 + 实锤 + 小三怀孕。
- 第2章：VIP空间 + 电话宠爱。
- 第3章：朋友圈 + 前妻谎言 + 婆婆十万。
- 第4章：第二个家 + 丈夫撞见 + 女主摊牌。
- 第5-7章：对峙、辩解、小三反转、反派互咬。
- 第8-9章：司法和生活结果收束。

## 机器写作约束

- 每 600-900 字必须出现新证据。
- 每 1000-1500 字必须出现一次身份或关系翻转。
- 女主情绪用动作承载：筷子掉地、指甲嵌肉、冷笑、甩开手。
- 丈夫崩塌必须有身体反应：僵住、发抖、跪下、脸白、气若游丝。
- 小三转反必须从“甜”切到“狠”，不能提前解释。
