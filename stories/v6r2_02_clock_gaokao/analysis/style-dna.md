# Style DNA：《只因时钟慢了一分钟，我放弃了高考》

## 开篇结构分析

- **opening_structure**: `conflict_first`
- 直接进入高考考场冲突场景，第一句就是异常事件发生
- 无前置摘要，无背景铺垫，无心理独白引入
- 第一行即冲突："高考考场上，分发试卷的铃声响起，可墙上的钟却慢了一分钟。"

## 快节奏锁定 ⚠️

**本文为快节奏短篇，仿写严禁：**
- 用解释性长段替代现场交锋
- 用流程清单（"首先…其次…最后…"）描述事件
- 用情绪总结（"她感到很痛苦"）替代具体动作/生理反应
- 用心理独白长段替代对话冲突
- 任何超过3行的纯描写/纯心理

## 核心节奏特征

### 1. 短句砸脸节奏
每个情绪高点都用≤15字的短句密集轰炸：
```
我毫不犹豫地离开座位。
我必须逃离这里。
因为我的手表也慢了一分钟。
```

### 2. 对话+动作交替
从不让对话连续超过3轮不带动作/心理插入：
```
闺蜜气得一巴掌打在我的脸上：
"田可，你在干什么..."  ← 对话
脸上火辣辣地疼。       ← 生理反应
但和心里的痛比起来却不值一提了。  ← 心理（短）
```

### 3. 独立行强调
关键信息/转折一定独占一行：
```
教室安静一瞬。
但没人离开座位。
```
```
三分钟，到了。
```
```
墙不见了。
```

### 4. 群体声音碎片化
用2-3句短台词代表群体意见，不用"大家纷纷表示"：
```
"马上就要考试了，她怎么站起来了，她想去哪？"
"她是不是想要把考题带出去作弊？"
"赶紧把她带走，别影响我们考试！"
```

### 5. 物理化情绪
不说"她很紧张/她很痛"，用身体反应：
- "额头冷汗滴落"
- "攥紧了拳头，指甲深深地嵌进肉里"
- "脸上火辣辣地疼"
- "我急得满脸通红，声音也颤抖得不像话"

## 叙述视角

- **第一人称限制视角**
- 主角知道危险但不说具体是什么→制造悬念
- 读者和主角同步但比其他角色多知道"她是对的"→制造焦急感
- 唯一一次视角跳出：第5章家长视角发现班主任消失（伏笔）

## 禁止出现的词汇/结构

| 类别 | 禁用 | 替代 |
|------|------|------|
| AI连接词 | 然而/此外/不仅如此/与此同时 | 但/可/不/直接转折 |
| 抒情泛化 | 她感到绝望/痛苦涌上心头 | 用具体动作/生理反应 |
| 解释性旁白 | 原来是因为…/这是因为… | 让事实说话 |
| 时间副词堆砌 | 就在这时/突然之间/转眼间 | 直接写发生的事 |
| 形容词堆砌 | 无比沉重的/难以言喻的 | 删除，用事实 |
