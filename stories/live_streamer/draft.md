# 她嫌我三十五岁还做美食博主太掉价，我转手把她捧的人按在地上摩擦

　　我签下韩峥的时候，他连一万粉都没有。
　　一个人扛着三脚架，蹲在路边摊拍炸串的特写，剪辑用的是盗版软件，水印都没去干净。
　　我帮他接了第一个探店广告，垫了制作费，自掏腰包买了全套拍摄设备。
　　三年，前后投了四百多万。
　　他从一万粉涨到了八百万。
　　可他从不在公开场合承认我们认识。
　　每次行业聚会碰见，他扫我一眼就转头，跟不认识一样。
　　我以为他就是这种性格——闷，不爱社交，不擅表达感谢。
　　直到年夜饭。
　　继妹沈柔柔笑嘻嘻地说她请了一个"超有名的美食博主"来家里吃饭。
　　门开了。
　　韩峥站在门口，手里提着两瓶拉菲。
　　素来面无表情的人，笑得嘴角都快咧到耳根子。
　　他给我爸递烟，跟后妈聊养生，甚至蹲下来帮沈柔柔家的猫换猫粮。
　　连保姆都主动加了微信，客客气气打了声招呼。
　　我端着杯子想跟他搭句话。
　　他脸上的笑瞬间消失了。
　　侧过身去，用只有我能听见的音量说了一句：
　　"沈姐，你也不看看自己什么岁数了。三十五了还到处说自己做MCN的，我替你尴尬。"
　　沈柔柔在旁边嘻嘻笑。
　　"姐，他跟我说过，他最怕那种花了点钱就觉得自己是老板娘的粉丝。每次打着合作的旗号骚扰他。你知道是谁吗？"
　　我笑了笑。
　　低头在手机上打了行字，发到工作群里：
　　"韩峥那个年度代言，取消。换人。"
　　群里安静了三秒。
　　有人问换谁。
　　我刷了一下博主列表，目光停在一个灰色头像上。
　　姜屿。
　　跟韩峥同年出道，前五年势均力敌。
　　直到三年前韩峥遇到了我。
　　他被压了三年，压出了一身的沉。
　　我见过姜屿一次。
　　行业论坛上有人把红酒碰洒在我外套上，我下意识看韩峥——他猛地转头跟旁边的品牌总监聊天，当没看见。
　　是姜屿拿自己的围巾帮我擦的。
　　问我需不需要换衣服，然后站在休息室门外等了二十分钟。
　　那次我顺手帮他牵了一条面包品牌的探店线。
　　韩峥知道后，拉黑了我半个月。
　　想到这儿，我打字：就姜屿吧。
　　群里立刻炸了。我没再看。


　　饭局还在继续。
　　韩峥坐在沈柔柔旁边，给她夹菜，温柔地讲他最近探店的趣事。
　　我爸笑得前仰后合。
　　沈柔柔得意地看了我一眼，故意开口。
　　"我记得姐姐跟韩峥也是熟识啊，怎么没见你们说话？"
　　韩峥放下筷子，看都没看我。
　　"不认识。"
　　三年砸了四百万，换来一句不认识。
　　我没吭声，起身去了卫生间。
　　出来时迎面撞上韩峥。
　　他皱着眉，压低声音：
　　"沈茵，我不知道你是什么目的，但你别在我朋友面前装熟。"
　　"柔柔都告诉我了——你妈当年是小三，你爸在原配去世前就跟她搞到一起了。"
　　"你现在占着这个家，良心不痛吗？"
　　我看着他的脸。
　　没解释。
　　他转身走了，步子很快，像怕被我蹭上晦气。
　　晚上，韩峥发了条动态——"今天心情好，八点开播。"
　　以前他每次开播，我都提前半小时进直播间，开场先刷九十九个嘉年华。
　　今天我没去。
　　手机弹出助理的消息："跟姜屿的年度合作敲定了。他想加您微信当面道谢。"
　　我回了个"可以"，关灯上床。
　　门外传来沈柔柔的敲门声和尖细的嗓音："姐，韩峥都开播了你怎么不去捧场？"
　　我拉开门。
　　"韩峥直播，跟我有什么关系？我跟他又不认识。"


　　第二天。
　　姜屿的年度品牌合作官宣了。
　　三个品牌联名——面包、咖啡机、麻辣调料。
　　探店福利比韩峥当年的还猛半折。
　　全网沸腾。
　　所有人都在猜姜屿攀上了哪路金主。
　　韩峥那边——死一般的寂静。
　　他的商务团队到现在都没通知这周的探店选题是什么。
　　晚上八点，姜屿按时开播。
　　我刷了十分钟礼物。
　　而韩峥的团队发文——"本周探店直播因身体原因取消。"
　　姜屿的直播在线人数突破六十万。
　　他穿着干干净净的白T恤，一家一家地讲探店心得。不耍帅，不摆架子，遇到弹幕提问就认认真真回答。
　　开播前，他给我发了一万八千字的内容策划书。精确到每分钟该说什么、展示哪个产品。
　　流水跳表——三千万，五千万，八千万，过亿。
　　那一瞬间弹幕礼花铺满了屏幕。
　　姜屿的声音开始发抖："谢谢沈姐……谢谢大家……"
　　三个小时后直播结束，热搜第一。
　　我退出直播间，发现私信爆了。
　　韩峥的粉丝涌进来骂得铺天盖地。
　　"贱女人，有了韩峥还去勾搭别人！"
　　"水性杨花，沈茵你不要脸！"
　　有人去问韩峥怎么看。
　　他淡淡回应："有些人花点钱就觉得人家该跟她怎么样。挺吓人的。"
　　马上，我的照片被人扒出来，P上遗照，配文"老女人""花钱买男人的疯子"。
　　网暴铺天盖地，韩峥不做声。
　　就好像没看见一样。
　　我没废话，让法务拟了律师函，转发后关了手机。
　　刚到家，沈柔柔冲过来。
　　"姐！你为了让韩峥吃醋，做到这个地步？疯了吧？"
　　她把手机往我脸上怼："谁让你给韩峥发律师函的！马上撤回！下场直播你双倍补偿他！"
　　我一巴掌拍开她的手。
　　"你在教我做事？"
　　她脸上的得意消失了，换上一抹怨色，但没敢再说。
　　我上楼翻看数据。
　　这一晚效果不错——姜屿涨粉五十万，品牌方很满意。
　　一个连锁茶饮品牌联系我，想让姜屿做全年品牌大使。
　　我约两方来公司签合同。

　　第二天一大早到办公室——两个不速之客。
　　沈柔柔："姐，我把韩峥喊来了。你当面道个歉。"
　　韩峥坐在沙发上，端着纸杯咖啡，下巴微抬。
　　等着我过去。
　　我刚要说话，沈柔柔眼尖瞥到我手里的合同。一把夺过去。
　　她眼睛亮了。
　　"原来你是故意的——先利用姜屿跟韩峥对打，等话题度炒起来，再拿大牌合同砸脸！"
　　韩峥看见合同上的品牌名，脸色缓了一度。
　　他接过来毫不犹豫签了自己的大名。甩在我桌上，冷笑一声。
　　"这个代言我能拿下，是我自己有实力。跟你没有半毛钱关系。别往自己脸上贴金。"
　　我皱眉："这个合同不是给你签的。"
　　韩峥嘲讽地看着我。
　　"少装了。没有我你什么都不是。"
　　沈柔柔在旁边附和："是啊姐，你就别装了。你那么捧韩峥哥哥，没他你都活不下去——"
　　我以前确实对韩峥有过好感。
　　我捧他，一是因为他内容确实好，二是我的商业判断。
　　但远远不到什么活不下去的地步。
　　韩峥签完起身要走。
　　"我不需要不重要的人的道歉。"
　　两人走后，我让法务重新拟定合同。
　　快到签约时间，姜屿紧张地问："沈姐，我是要跟韩峥一起做品牌大使吗？"
　　我愣了一下——看手机才知道，韩峥发了条动态。
　　是他伪造的品牌合作海报。
　　我犹豫了一下，还是私信了他一条："那个合同不是给你的，涉及侵权，建议撤。"
　　他的回应方式——是直接发了一条微博，截图艾特我。
　　"就因为我没选择你，你就想毁了我的事业？一个处心积虑倒贴了三年的女人，做人要有底线。"
　　评论区炸了。
　　紧接着，沈柔柔也发了一条。
　　"过去的事就过去了，我和妈妈只想一家人和和睦睦。"
　　配了一张她和我爸、后妈的全家福。
　　没有我。

　　品牌方的官微两个小时后动了。
　　直接艾特姜屿："欢迎本年度品牌大使@姜屿•味蕾笔记。"
　　紧接着第二条，艾特韩峥。
　　"您未经授权使用我方品牌信息构成侵权，请立即删除，否则将依法追究。"
　　我手机被打爆了。
　　电话那头韩峥的声音像劈了叉："沈茵！你闹够了没有！"
　　"我闹？"
　　"两个小时前我劝你删海报。是你自己不听。"
　　"现在品牌方已经发了律师函。对了，你引导粉丝网暴我的证据，法务也整理好了。"
　　"沈茵！"他破防了，声音发抖。
　　"你非要这么狠？我不过是跟柔柔关系好——"
　　我直接挂断。

　　姜屿的签约仪式当晚播出。
　　全平台热搜第一。
　　直播结束后他赶了过来，站在我办公桌前深深鞠了一躬。
　　"沈姐，没有您就没有我的今天。"
　　我只说了一句："好好干，别让我失望。"
　　他眼眶通红，递过来一份已经签好字的合同。
　　我接过来，惊了一下——终身经纪合同。
　　"你这是要跟我绑一辈子？"
　　姜屿语气认真："只要沈姐要我一天，我就干一天。什么时候不要我了，我马上走。"
　　我犹豫了一下，还是推了回去。
　　"这不是小事——"
　　他急了："我是认真的，姐。我跟韩峥不一样。没有您，就绝对没有我。"
　　我看着他那张认真到发红的脸。
　　掏心掏肺对韩峥三年，换来一句不认识。
　　随手拉了一把的人，拿出一辈子来还。
　　我拿出签字笔。


　　到家时快三点了。
　　别墅里灯火通明。
　　我推开门，一个杯子砸碎在脚边。
　　沈柔柔站在客厅中央，眼睛通红，浑身发抖。
　　"你知不知道你做了什么！韩峥现在被全网嘲，商务全掉了！你怎么能这么对他！"
　　她冲到我面前，手指头快戳到我脸上。
　　"你明知道那个合同是韩峥的，为什么给姜屿？你就是故意的！看不得韩峥跟我好！"
　　我看着她歇斯底里的样子，突然觉得可笑。
　　"沈柔柔，你是不是忘了，这是谁的家？"
　　她一愣。
　　"你是不是也忘了，韩峥今天能有八百万粉，是谁三年一口一口喂出来的？"
　　她脸白了一瞬，但很快又昂起下巴："那是韩峥自己有本事！你不过出了点钱——"
　　我点头："行，他有本事。那就让他用自己的本事渡过这关吧。"
　　转身要上楼。
　　"沈茵！"她在身后尖叫。
　　"你现在马上去求韩峥原谅！公开道歉！否则你从这个家滚出去！"
　　我停了。
　　缓缓转身。
　　"你让我滚？"
　　"对！爸爸和妈妈都讨厌你！"
　　"是吗？"
　　我看向楼梯上走下来的两个人。
　　"爸，陈阿姨，你们也这么觉得？"
　　我爸脸色阴沉。
　　陈雅芬赶紧去拉沈柔柔："柔柔别乱说！"
　　"我没乱说！"沈柔柔甩开她。
　　"妈，她把韩峥害成什么样了！他是我朋友！她今天必须给说法！"
　　她顿了顿，眼里闪过恶毒的光。
　　"还有，你手上公司的股份，分一半给我妈。这些年她为这个家付出这么多。"
　　我忍不住笑出了声。
　　在所有人没反应过来的时候——
　　啪。
　　一记耳光，狠狠扇在她脸上。
　　陈雅芬尖叫："你敢打柔柔！"
　　"打了，怎么了？"
　　我爸的视线从我身上划过去。
　　走到沈柔柔面前——又是一巴掌。
　　陈雅芬懵了。
　　"你竟然伙同外人欺负你姐姐。这巴掌打的是你吃里扒外。"
　　沈柔柔哭得喘不上气。
　　我爸看着她，语气平静得可怕。
　　"沈柔柔，你姓沈，是因为我让你姓沈。这个家姓沈，是因为茵茵妈妈创的业。公司的股份，全在茵茵名下。我没资格给，你更没资格要。"
　　陈雅芬腿一软。
　　"老沈，你什么意思……"
　　"搬出去。西区有套公寓，你们先住着。以后我会去看。"
　　"要么——离婚。"
　　客厅里安静了。
　　沈柔柔终于反应过来，尖叫："爸！她三年给一个男人花了四百万！迟早败光家产！"
　　我爸看了她一眼。
　　"有件事你一直不知道。公司是茵茵妈妈创办的。她去世后股份全留给了茵茵。棉棉——茵茵怎么花她的钱，是她的自由。"
　　陈雅芬和沈柔柔呆呆地站在原地。
　　我转身上楼。
　　"爸，你的人自己处理。我累了。"
　　身后传来崩溃的哭声和语无伦次的求饶。


　　三个月后。
　　韩峥的侵权案开庭那天，我坐在旁听席最后一排。
　　他走进来的时候，西装皱巴巴的，头发也没打理，眼下两团乌青。
　　整个人像老了五岁。
　　律师在前面翻来覆去说"非主观恶意""信息核对失误"。
　　法官问韩峥有没有补充。
　　他站起来，目光扫过旁听席，突然定住了。
　　他看见了我。
　　那一瞬间，他的眼神里不是愧疚。
　　是疯狂的愤恨。
　　"是她。"他指着我的手在发抖。
　　"是沈茵设局害我！她把合同递给我签，就是等着我犯错——"
　　法官敲了敲桌子："被告请控制情绪。"
　　他没控制住。
　　声音越来越大："你们知道她是什么人吗？她追了我三年，砸了四百万！就因为我不理她——"
　　律师死命拽他袖子，他甩开。
　　"沈茵！"他隔着法庭冲我喊，眼眶通红。
　　"你满意了吗！你现在满意了吗！"
　　法警上前按住他。
　　他从怒吼变成嘶哑："你毁了我……你毁了我你知不知道……"
　　眼泪掉下来，砸在被告席的桌面上。
　　那个曾经连正眼都不瞧我的人，在法庭上哭得像个孩子。
　　判决结果：三百万赔偿，公开道歉，全网置顶三十天。
　　走出法院的时候，记者围上来。
　　"韩峥，你会向品牌方和沈茵女士道歉吗？"
　　他抬起头，嘴唇哆嗦了半天。
　　"我不会道歉的。我没有错。是她欠我的。"
　　第二天这段话被剪成短视频，全网播放量破亿。
　　评论清一色嘲讽——
　　"人家砸四百万捧你三年，你连个好友都不加，谁欠谁？"

　　韩峥的账号被平台限流。
　　粉丝后援会宣布解散。
　　沈柔柔搬出去之后租了个四十平的小公寓。
　　她也试着做美食博主——买了灯、买了设备，对着镜头笑："家人们，今天教你们做芝士蛋糕。"
　　弹幕飞过来。
　　"这不是那个继妹？"
　　"你妈抢别人老公你还有脸出来？"
　　她咬牙继续播，但评论越来越难听。
　　一个月后她关了账号，去了一家小公司做行政。月薪五千，挤地铁上班。

　　而我坐在公司办公室里，签着姜屿下季度的独家合作。
　　桌上的冰美式还冒着凉气。
　　手机震了一下。
　　姜屿发来消息："沈姐，今晚直播新系列，我紧张。您能在直播间待一会儿吗？就看着就行。"
　　后面跟了个举手的表情包。
　　我笑了笑，回了个"好"。
　　他秒回三个感叹号。
　　我放下手机，看向窗外。
　　楼下的咖啡店排着长队，阳光落在玻璃幕墙上，反光刺眼。
　　那些曾经让我难过的人和事，全过去了。
　　未来还长着呢。
