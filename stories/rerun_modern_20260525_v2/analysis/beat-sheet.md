# Beat Sheet 节拍器

## 全文概况

- 总字数: 约 13200 字
- 节拍数: 12 幕
- 核心母题（Logline）: 一个普通工厂老板因十盒发霉盒饭被海关诬成走私犯，在失去事业和家庭后，用对方盖章定性反向索赔并掀翻腐败链条。
- 情绪模式: 极致误判打压 → 家庭事业崩塌 → 冷静取证 → 死环反杀 → 公共正义扩散

- **hook_strength**: 9.2/10

## 节拍密度检测

- 平均每 1100 字一个节拍
- 微冲突密度: 每 700-900 字一次
- 大转折密度: 每 1200-1600 字一次
