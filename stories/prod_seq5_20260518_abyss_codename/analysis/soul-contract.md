# Soul Contract

## 读者签下的隐形契约

读者点进这篇文，不是为了看传统刑侦流程，而是为了看一个被严重低估的年轻女性，用专业能力走进危险中心，并且一次次证明：罪犯以为自己在挑选猎物，其实早就被她反向锁定。

## 主角灵魂

沈夜的核心不是“天才少女”，而是“站在深渊边缘但不坠落的人”。

她理解罪犯的逻辑，但不认同罪犯。她能看懂控制欲、杀戮快感和反社会人格，也能在对方试图把她拉成同类时，清楚划线：

“他们享受杀人，我享受抓人。”

## 情绪底线

- 她可以冒险，但不能鲁莽。
- 她可以冷，但不能麻木到无正义感。
- 她可以接近深渊，但不能被写成享受杀戮。
- 她可以使用诱饵战术，但必须有证据目标和救人目标。

## 爽感契约

每一次危险逼近，都必须兑换成一次专业反制。

- 凶手唱歌装鬼 -> 她判断是倒放情歌。
- 室友翻衣柜 -> 她用头发位置反证。
- 凶手夜闯宿舍 -> 她提前注射制敌。
- 程砚秋自曝罪行 -> 她提前开启录音。
- 画师把她当艺术品 -> 她回敬自己是“抓艺术品的人”。

## 道德契约

本文不能把犯罪写成迷人艺术。凶手可以有审美化语言，但文本必须通过沈夜把它拆穿为控制、虐待、杀戮和自恋。

程砚秋说“死亡是最永恒的定格方式”，沈夜不能被这套话术吸引。她必须把这句话变成证据，把说话的人送进警车。

## 结尾契约

结尾不能给彻底安稳。因为“深渊”是系列型主角，案件结束只是阶段性释放。真正的余味来自：

- 当前案子已破。
- 受害者被看见。
- 主犯被抓。
- 但更深的网络仍在暗处。
- 沈夜会继续查。

这就是“她代号深渊”的灵魂：她不是从黑暗中逃出来的人，她是主动回头盯住黑暗的人。
