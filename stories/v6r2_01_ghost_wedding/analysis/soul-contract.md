# Soul Contract：灵魂契约

## 核心承诺

> 本文的灵魂是"冷静的愤怒"——不是失控的哭喊，不是复仇女神的疯狂，而是一个被彻底伤透的女人，带着清醒的脑子、确凿的证据、完整的逻辑，在公共场域逐笔清算。

## 灵魂条款（不可违反）

### 条款1：冷静人格
女主的愤怒从不以"崩溃"形式出现。她可以打耳光、可以冷笑、可以一句话刺穿，但绝不哭着求解释。
**底线**: 全文女主流泪不超过1次，且必须是"哽了一下"而非嚎啕。

### 条款2：量化清算
每一笔情感债务必须有数字或具体事件对照。不能用"他对她比对我好"这种抽象陈述，必须是"六位数镯子vs无戒指""八万八vs一千八""百万分红vs月交一万五"。
**底线**: 全文至少5组量化对比。

### 条款3：公共羞辱场域
清算必须发生在公共空间（婚礼/法庭/宴会），有围观者作为道德放大器。
**底线**: 核心清算段必须有≥3句旁观者反应。

### 条款4：法律武器结尾
复仇不靠暴力、不靠新男人、不靠家族势力，靠法律程序完成终极制裁。
**底线**: 必须有明确的法律判决结果。

### 条款5：母子新生收束
结尾不苦大仇深，用日常细节（积木/灯光/儿子笑容）完成情绪着陆。
**底线**: 最后300字必须有具体的母子互动场景。

### 条款6：不原谅
女主绝不原谅渣男，绝不复合，绝不因孩子妥协。
**底线**: 全文不出现"原谅""再给一次机会""为了孩子"等妥协台词。

## 灵魂禁区

| 禁止行为 | 原因 |
|----------|------|
| 女主哭求/崩溃/撒泼 | 破坏"冷静愤怒"的灵魂底色 |
| 新男人救场 | 削弱女主独立人格 |
| 渣男真心悔悟 | 消解仇恨张力 |
| 圣母式原谅 | 违背读者情绪需求 |
| 暴力复仇（下毒/雇凶） | 偏离"法律武器"路线 |
| 孩子被用作筹码 | 触犯读者底线 |
| 抽象情绪描写 | 违背"量化清算"原则 |

## 灵魂签名

"一个活人被宣告死亡——那她就以死人的姿态，来收割活人的命。不是物理的命，是社会性死亡的命。"
