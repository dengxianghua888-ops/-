## 三、快节奏锁定

**标注: 快节奏锁定生效**

本文为快节奏短篇（8400字/9章），仿写不得：
- 用解释性长段替代现场交锋
- 用流程清单列举事件（"她先做了X，然后做了Y，接着做了Z"）
- 用情绪总结替代具体场景（"她很难过"→必须写出"心里像被人拿钝刀子来回捅"）
- 用心理独白替代动作和对话（内心戏必须立刻转化为行动或对话）

## 四、开篇结构分析

**opening_structure**: `conflict_first`

源文属于"冲突先行"型开篇：
- 第1-3行直接进入冲突核心（偶遇发小→听到"前妻短命""再婚"）
- 无任何前置摘要、背景介绍或人物描写
- 前5行完成冲突建立+信息差注入

**不是** `conclusion_first`（无剧透摘要），**不是** `dialogue_first`（以叙述而非对话开篇，但对话在第3行即出现）

## 五、叙述声音特征

### 人称与视角
- 严格第一人称限制视角
- 女主视角兼具"当事人"和"冷静观察者"双重身份
- 情绪通过身体感受外化（"血液凉透""心像被捅个窟窿""耳朵嗡嗡"），而非直接抒情

### 句式特征
- **短句为王**: 核心打击句均≤15字（"周瑞阳，你脏了。""假的。"）
- **断句节奏**: 大量单行段落，形成视觉锤击效果
- **对话驱动**: 信息揭露主要通过他人对话（偷听→伴娘闲聊→当面对质）
- **反问链**: 高频使用反问积累情绪压力

### 禁忌清单
- 无环境描写抒情（不写天气、风景、氛围铺垫）
- 无文学比喻堆砌（唯一比喻都是日常化的："心像被捅个窟窿"）
- 无旁白式评论（不出现"命运""宿命"等大词）
- 无时间线倒叙（严格顺叙，信息差靠角色对话自然流出）

## 六、段落结构模式

### 信息揭露段（Ch2-3 核心模式）
```
1. 他人说话（揭露新信息）
2. 女主内心一击（身体感受，1句）
3. 闪回对比（当年丈夫对自己说的话，直接引语）
4. 真相刺痛（原来+反转，1-2句）
```

### 公开清算段（Ch5-8 核心模式）
```
1. 女主陈述事实（短句连击，每句≤20字）
2. 对方反应（动作/表情，1句）
3. 旁观者反应（宾客议论，1-2句）
4. 女主追击（新一轮事实/质问）
```

### 收束段（Ch9 模式）
```
1. 法律结果（简洁陈述）
2. 日常细节场景（儿子搭积木）
3. 金句收束（照应主题，1句）
4. 意象留白（万家灯火/窗户）
```
