# 高保真设定重置室

## 目标共识
本轮改编不动灵魂公式，只重置壳层表达。必须死守的骨架是：

`册后大典坠崖 -> 假护真弃 -> 三年高强度污辱性放逐 -> 偷听真相心死 -> 新宠假孕连环压脸 -> 更高规格靠山兵临城下公开接人 -> 前任追悔失国失命 -> 女主在新秩序里被正名、被珍重、被托底`

不可动点：
- 开篇必须仍是“封后当天 + 权威污蔑 + 男主假护真弃”三连钩。
- 女主必须真受辱三年，且是社会性羞辱，不可软化成冷宫禁足。
- 旧男主必须主动做恶，不能洗白。
- 女主知真相后必须绝不回头。
- 新男主必须带“更高规格体系”当众接走她。
- 旧男主结局必须是爱、权、国、命多重崩塌。

## 三套投稿方向

## A案：海祭王朝版
**一句话设定**
把“亡国灾星”改为“噬潮祸女”，把国师改为司潮监正，把青楼改为“罪籍歌舫”，把南疆铁骑改为“靖海黑舰”，整体气质从宫廷后宫虐恋，刷新成祭海王朝+海权压境。

**核心壳子**
- 册后大典：海祭封后礼，王都万民观潮
- 污蔑载体：司潮监以潮骨签、海灯逆燃判她为噬潮祸女
- 放逐场域：官营歌舫“听澜坊”，兼具乐籍、献舞、陪酒、囚水牢
- 新男主体系：东海都护府，黑舰压港，十万靖海军锁京江
- 女主高规身世：前朝镇海相遗孤，早被海国太后收为义郡主

**优点**
- 新鲜度高，视觉强，封后礼和舰队压城都更有画面。
- “歌舫”能平替青楼，既保留羞辱感，又有水域意象统一。

**风险**
- 海祭、潮签、舰队等元素稍新，需要控制名词密度。
- 若写过玄，会削弱番茄短篇直给虐爽感。

## B案：雪原天授版
**一句话设定**
把皇朝换成农牧复合王庭，把国师换成大巫祝，把亡国灾星换成“食月凶星”，把青楼换成“王庭官妓帐”，把南疆将军换成“朔北狼主”，走风雪王庭+边军压境路线。

**核心壳子**
- 册后大典：天授封后，祭月登台
- 污蔑载体：大巫祝借月蚀天象定她为食月凶星
- 放逐场域：罪籍舞帐，供使臣、贵胄取乐
- 新男主体系：朔北狼骑二十万南下，金帐压边
- 女主高规身世：故相遗女，幼年被朔北可汗认作义女

**优点**
- 风雪、月蚀、狼骑都很番茄，接受度高。
- 兵临城下和婚礼抢人天然顺手，爽感稳。

**风险**
- 与常见北境/草原文距离不够大，容易显得只是换皮。
- “官妓帐”若处理不好，会偏粗砺，影响女主后续高规抬升的精致感。

## C案：礼乐王朝版
**一句话设定**
保留中式宫廷熟悉度，但把迷信载体改为“凤仪失律”，把青楼改为“罪籍教坊司”，把南疆将军改为“西川节镇”，形成礼制坍塌+边镇入京的版本，最稳、最贴番茄。

**核心壳子**
- 册后大典：奉天殿册后礼，百官朝贺
- 污蔑载体：太史令借“凤钟三裂、玄鸟坠阶、命盘冲国运”定她为祸国失仪之身
- 放逐场域：教坊司下辖“罪乐署”，兼舞伎、酒宴、刑惩、水牢
- 新男主体系：西川节度使统玄甲军三十万，奉“迎回将军夫人”军令逼宫
- 女主高规身世：先帝旧相遗孤，六年前已被西川王府记入义女册、封安宁郡主
- 外敌/亡国载体：并非简单敌国来打，而是旧男主为追人荒废朝局，失西陲三镇，引发社稷崩盘

**优点**
- 熟悉宫廷语境，最好落地，最适合一万多字番茄短篇。
- “教坊司”“太史令”“节度使”都天然顺嘴，不需过多解释。
- 既有新意，又不会一眼看出原故事的南疆皇帝模板。

**风险**
- 新鲜度不如海祭版炸，但胜在稳定。
- 若太史天象写得太旧，会显得传统，需要把“凤仪失律”写成礼制政治工具，而非单纯迷信。

## 选中方案：C案 礼乐王朝版

### 为什么选它
- 它最稳地保住“古言虐爽 / 追妻火葬场 / 身份反杀”的读者预期。
- “太史令 + 教坊司 + 西川节镇”比“皇帝+国师+南疆将军”有新鲜感，但不会让读者读设定。
- 女主三年受辱、男主假护真弃、强军抢人、旧爱失国失命，这四根大梁都能丝滑保留。
- 最关键的是，它能把“灾星迷信”升级成“礼制政治工具”，让旧男主的主动作恶更狠、更脏、更清醒。

## 选中方案执行要点

### 人设重置
- 女主从“准皇后/青楼弃妃”重置为“将册太子妃的罪相遗孤/后入罪乐署的乐伎”。
- 旧男主从“薄情皇帝”重置为“新帝/储君继位后亲掌朝局的帝王”，强调他不是被迫，是主动拿她祭局。
- 新女配从“白月光宠妃”重置为“礼部尚书之女/后宫新贵”，更利于假孕、礼制压脸、凤冠抢位。
- 新男主从“南疆将军”重置为“西川节度使”，既有军权也有婚配资格，且能带出边镇义女高规托底。

### 爆点场面保留法
- 开篇仍是册后礼当场坠毁，但改成“凤钟三裂、太史定罪、帝王抱她说保命，转头将她打入罪籍三年”。
- 青楼羞辱保留为“教坊宴舞、官宴点伎、水牢、杖责、拖街、雨跪”。
- 真相暴击保留偷听场，但改为旧男主亲口承认：为了压下她父族旧案、稳住新贵外戚、坐实天命，故意买通太史做局。
- 兵临城下保留婚礼现场截断，但改为“西川玄甲军入京，点名迎回将军夫人兼安宁郡主”。
- 终局保留“拦婚下跪 + 追悔失控 + 社稷崩塌 + 女主新婚怀孕”。

### 三大机制如何落地

#### M5 温度反转曲线
前段必须真写他曾护她、救她、许她后位，让读者先信一点，再被他的亲手出卖捅穿。后段所有“我爱你”都必须与更重伤害同步出现，形成迟来深情作废感。

#### M6 多层递进反转
反转顺序不能乱：
1. 女主先知真相，情感抽离。
2. 假孕栽赃把情绪压到底。
3. 婚礼压脸完成谷底。
4. 西川军逼宫公开抢人。
5. 女主义女/郡主身份揭开。
6. 女配假孕奸情与虐待链回炸。
7. 旧男主追人误国失命。

#### M2 身份反差爆发
女主前半程必须被钉死在“罪籍乐伎”“灾星”“废人”坐标上，后半程再由“西川王府义女 + 将军夫人 + 郡主仪制出嫁”完成规格翻盘，不能太早泄底。

## 敏感表达边界
- 三年羞辱重点写名分坠落、规训惩罚、社会性贬损，不做细节性色情描摹。
- 暴力场面写打脸、杖责、拖行、雨跪、水牢即可，避免过度酷刑奇观化。
- 假孕、后宫倾轧、教坊受辱都服务情绪债，不可写成恶趣味猎奇。
- 新男主对女主的救援与婚配，重点写尊重、托底、正名，不写强占式救赎。
- 旧男主的悔恨只保留惩罚功能，绝不写成可被共情的洗白情圣。
