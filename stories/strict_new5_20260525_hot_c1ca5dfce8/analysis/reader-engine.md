# Reader Engine

## 读者为什么会一直往下划
因为每一次“他说爱她”，都会紧跟一次更狠的伤害；而读者清楚地知道，后面一定会来一个更大的人把她接走。

## 四个驱动轮
### 1. 屈辱驱动
- 青楼、肚兜、银子砸身、锁链拖街、雨跪、藤条。
- 全是可视化羞辱，不是抽象受苦。
- 读者被迫替女主记账。

### 2. 真相驱动
- 三年前国师局是真是假。
- 皇帝到底爱不爱她。
- 陆清沅怀的到底是谁的孩子。
- 女主寄给南疆的信会换来什么。
- 这些问题都不是悬空，而是很快兑现，形成连续付费点。

### 3. 权力翻盘驱动
- 前半段所有人都能踩她。
- 中段开始，忽然出现一个“连皇帝都不敢碰”的人来接她。
- 坐标切换越彻底，爽感越强。

### 4. 替代满足驱动
- 女主不是靠旧男主回心转意翻身。
- 她是被新秩序重新选中、重新珍视。
- 这比“旧爱认错”更能满足番茄读者。

## 关键留存点
| 区段 | 留存抓手 |
|---|---|
| 开篇 0-300 字 | 封后即灾星，皇帝假护真弃 |
| 300-1500 字 | 三年青楼后偷听真相，女主不等了 |
| 1500-3500 字 | 新欢压脸、醉客爆料、假孕栽赃 |
| 3500-5500 字 | 拖街跪雨鞭打，情绪谷底 |
| 5500-7500 字 | 铁骑压境，将军接人，第一次大付费点 |
| 7500-9000 字 | 假孕与奸情反噬，皇帝内爆 |
| 9000-10500 字 | 回南疆正名赐婚，婚礼拦轿追妻 |
| 10500+ | 失国失命，女主怀孕收束 |

## 爽点分发方式
- 小爽点：每次女主冷声回击、每次皇帝被堵住、每次陆清沅露馅。
- 中爽点：旧爱失控、文武百官逼皇帝退步、南疆皇帝亲自托底。
- 大爽点：
  - 铁骑入城接人
  - 婚礼当众拒绝前任
  - 前任失国失命
  - 发簪被随手赏人

## 读者最买单的三件事
- “迟来深情不值钱”
- “更强者当众接走女主”
- “前任不但失去她，还失去自己最在乎的一切”

## 易掉读风险
- 若中段羞辱太长而翻盘信号太弱，读者会疲。
- 若南疆线铺得不够早，铁骑压境会像外挂。
- 若结尾还让女主为旧男主动容，前面所有爽点会回吐。

## 仿写时的引擎保真要求
- 前 15% 必须埋下旧爱承诺与外部靠山至少各 1 个。
- 中段每次辱点升级，都要给读者一点“快要翻了”的预兆。
- 新男主必须在读者心中形成“安全、强、公开站队”三连印象。
- 最终收束必须是“旧爱彻底作废，新生关系自然成立”。
