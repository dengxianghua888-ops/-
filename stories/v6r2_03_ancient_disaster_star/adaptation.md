# 高保真设定重置 · 适配方案

## 选定方案：C · 靖安王府石矿线

### 核心前提

靖安王楚怀璟以爱为名买通府中相师诬陷正妃苏若棠为"煞星命格"，将其贬入王府辖下采石苦坊三年。大漠赤鹰部首领凌霄寒率八万骑兵兵临城下，以断绝盐铁商路相胁，逼楚怀璟交出"首领夫人"。

### 方案优势

1. **视觉辨识度**：大漠黄沙+赤鹰旗帜 vs 原文南疆绿意，场景气质完全不同
2. **屈辱载体升级**：石矿苦坊的碎石磨手、铁索锁足、烈日暴晒具备古言新鲜感，比青楼更适合规避平台敏感审核
3. **权力结构差异化**：藩王（非皇帝）→ 大漠部族首领，跳出"帝王负心"的直觉联想
4. **信息炸弹等价替换**："靖安王因旧伤导致不育" 完美对标原文"不能人道"，柳如烟的孩子同样形成逻辑死环

### 人物映射

|--------|--------|----------|
| 傅临渊（帝王） | 楚怀璟（靖安王） | 拥兵一方的藩王，年少有为但刚愎；对女主有真情却方式扭曲 |
| 姜妩（废后） | 苏若棠（正妃） | 将门之后，被贬入石矿三年仍不跪不求 |
| 萧烬辞（将军） | 凌霄寒（赤鹰部首领） | 大漠部族首领，沉默寡言但行动碾压 |
| 陆清沅（白莲） | 柳如烟（青梅侧妃） | 人前柔弱知礼，人后指使矿监加刑 |
| 国师 | 钱术师（府中相师） | 被银两收买伪造星象命格 |
| 南疆皇帝 | 赤鹰部老首领（凌霄寒之父） | 早年认女主为义女，形同父辈庇护 |

### 核心信息炸弹

**楚怀璟不育之秘**：早年战场旧伤导致无法生育。柳如烟腹中之子必非楚怀璟血脉。此信息由女主在石矿期间从矿工闲谈中偶然获知（等效原文"醉酒客人"）。

### 情绪架构保真

- **前60%（石矿三年）**：碎石磨手至见骨 → 矿洞暗室禁食 → 铁索拖行示众 → 烈日罚跪 → 柳如烟碰瓷栽赃
- **情绪转折**：烽火狼烟升起那一刻
- **后40%（大漠救赎）**：赤鹰骑兵兵临城下 → 奸情揭露 → 楚怀璟崩塌 → 大漠新婚 → 最终对峙 → 楚怀璟失城亡命
- **结局温度**：女主将白玉匕首随手赏给马夫——"夫君赠我赤金弯刀，这把旧物，你拿去削马蹄吧。"

## 淘汰方案简述

### 方案A · 少年帝废后入掖庭+北境铁骑

帝王废后贬入掖庭浣衣局，北境世子率铁骑南下。结构与原文过于相近（帝→帝，南疆→北境），一眼可辨原故事骨架。

### 方案B · 摄政王药庄试毒+禁军围府

摄政王将正妃贬入药庄试毒三年，禁军统领携天子金令围府。权力结构差异化好（非帝王vs帝王），但"药庄试毒"的物理感偏内伤，不如石矿的可视化肉体折磨能快速唤起读者共情。
