# Reader Engine 读者心理引擎

## 核心读者画像

**目标读者**：18-35岁女性，番茄小说核心用户
**阅读场景**：通勤碎片化/睡前追文
**核心诉求**：代入感+情绪补偿

## 心理引擎拆解

### 引擎1：替代性愤怒

**触发机制**：读者代入女主视角，目睹不公却无法反击
**燃料**：每一次帝王的"深情但伤害"、陆清沅的"柔弱但阴毒"、围观者的"冷漠或帮凶"
**释放阀**：萧烬辞出场→女主冷静拒绝→帝王跪地

**设计要点**：
- 屈辱必须是"明明不该发生"的（她没做错任何事）
- 围观者的"帮凶"态度放大不公感（百姓砸烂叶、侍卫嘲讽）
- 帝王的"自以为是"比单纯的恶更让人愤怒

### 引擎2：信息差优越感

**触发机制**：读者知道真相，看着角色在错误中越陷越深
**燃料**：
- 读者知道帝王不能人道→看陆清沅碰瓷假孕
- 读者知道女主已联络萧将军→看帝王还在耀武扬威
- 读者知道帝王的"深情"是假→看帝王还在骗

**释放阀**：每一次信息差被引爆（醉酒客说真相、奸夫供述、女主当面揭穿"不能人道"）

### 引擎3：地位反转快感

**触发机制**：曾经高高在上的人跪在曾经被践踏的人面前
**关键场景对照**：

| 前期 | 后期 |
|------|------|
| 女主跪在雨中 | 帝王跪在轿前 |
| 女主被扇耳光 | 帝王被马蹄踏 |
| 女主被游街示众 | 帝王被百姓唾骂 |
| 女主在青楼为妓 | 帝王失国亡命 |
| 女主发簪被嫌弃 | 帝王发簪被赏赐婢女 |

### 引擎4：安全感补偿

**触发机制**：在极致不安全感后，获得"被无条件珍视"的体验
**关键场景**：
- 萧烬辞颤着手上药（温柔具象化）
- 南疆皇帝称"孩子"（父爱补偿）
- 公主规格出嫁（身份尊重）
- "将军府所有资产皆交予你一人管理"（经济安全感）
- "从不需要靠别人的脸色而活"（独立宣言）

### 引擎5："不原谅"的爽感

**触发机制**：读者厌倦"圣母原谅"套路，渴望"冷酷到底"
**关键设计**：
- 女主说"两清"而非"我恨你"——恨还有余情，两清是真的死了
- 发簪赏赐婢女——不是扔掉（扔掉=还在意），是真的无所谓
- 怀孕新生——她的人生已经翻篇，你的死活与我无关

## 付费卡点设计原则

基于以上引擎，最佳付费卡点：
1. **信息差即将引爆但未爆**：铁骑喊话"将军夫人"→但未说明谁是将军夫人
2. **权力碾压开始但未完成**：萧烬辞出场→但帝王还没反应
3. **女主即将反击但被打断**：她正要说"不能人道"→被帝王扇耳光打断
4. **帝王即将崩塌但尚未崩塌**：奸夫被带来→但还没开口

## 读者情绪曲线

```
情绪值(-10到+10):

Beat 1:  -3 (信息压缩，紧张)
Beat 2:  -5 (对峙开始，愤怒升温)
Beat 3:  -8 (假孕碰瓷，极度愤怒)
Beat 4:  -9.5 (雨中罚跪，窒息顶峰)
Beat 5:  -8 (凤冠事件，持续高压)
Beat 6:  +8 (铁骑救场，爽感爆发)
Beat 7:  +7 (奸情揭露，解气)
Beat 8:  +6 (南疆甜蜜，温暖)
Beat 9:  +9 (当众拒绝，极致爽感)
Beat 10: +8.5 (帝王惨死+怀孕，圆满)
```
