# Soul Contract 灵魂契约

## 本文的灵魂是什么？

**一句话内核**：用物理化的屈辱堆叠到读者窒息，再用碾压式的权力救赎让读者在爽感中呼出那口气。

## 不可违背的灵魂条款

### 条款1：女主的尊严线

女主从头到尾**没有跪过任何人的心**。
- 被罚跪：身体跪了，精神没跪
- 被打：不哭不求，只冷笑
- 被侮辱：用冷静陈述回击，不用情绪崩溃
- 最终拒绝：不是"我恨你"，而是"我们两清了"

**仿写红线**：女主在任何时刻不得出现"求求你""我错了""给我一次机会"的示弱。

### 条款2：帝王的"真爱陷阱"

帝王对女主确实有感情——这是痛感的核心来源。
- 如果帝王纯渣无情→痛感降维为"渣男被打脸"，档次下降
- 帝王的悲剧在于：他有爱，但他的爱配不上她
- "关心却伤害""想保护却推入深渊"的矛盾必须贯穿

**仿写红线**：不可将帝王写成纯恶无情的工具人，必须有"他确实爱过"的铺垫。

### 条款3：爽感的节奏公式

屈辱:爽感 = 6:4（字数比）
- 前60%持续加压，读者被压到极限
- 后40%逐层释放，每层对应清偿一项情感债
- 最终释放不是"大爆发"而是"冷静离场"——比欢呼更有力量

### 条款4：权力碾压的具象化

救赎不是"有人帮她说话"，而是**物理级别的权力展示**：
- 三十万铁骑（数字碾压）
- 十座城池相胁（筹码碾压）
- 公主制度出嫁（身份碾压）
- 马蹄踏帝王（物理碾压）

**仿写红线**：不可用"口头威胁"替代实力展示，权力必须落地为可见的物理行为。

### 条款5：结局的"不原谅"

女主最终不是"含恨离去"，而是"平静地不在乎"。
- 发簪随手赏赐婢女=帝王的全部深情一文不值
- "轻点，小心伤了孩子"=她的人生已彻底翻篇
- 没有回头看、没有感慨、没有"如果当初"

**仿写红线**：结尾不可出现女主对帝王的任何情感余波（哪怕是一声叹息都会削弱爽感）。

### 条款6：陆清沅的"双面人"写法

陆清沅在人前人后必须有明显差异：
- 人前：柔弱、自我牺牲、"姐姐我不介意"
- 人后：嫉妒、狠辣、"凭什么他想着你"
- 被揭穿时：受害者话术翻车

**仿写红线**：反派女不可写成单维度的"嚣张恶毒"，必须有"伪善外衣"的层次。

## 灵魂校验清单

- [ ] 女主全程维持"冷静/讽刺/不在乎"的姿态？
- [ ] 帝王有至少2处"真心但错误"的描写？
- [ ] 前60%的屈辱是物理化的（可见的伤、可触的痛）？
- [ ] 后40%的爽感是权力化的（可量化的力量）？
- [ ] 结局是"平静归零"而非"宣泄报复"？
- [ ] 反派女有"伪善"和"暴露"的双面展示？
- [ ] 群众态度有前后翻转对照？
