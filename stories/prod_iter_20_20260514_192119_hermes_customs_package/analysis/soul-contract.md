# 爆款神髓合约 · 海关爱马仕案

## A. 读者承诺
读者点开标题"海关说我的破包是爱马仕，那就按爱马仕赔吧"，期待获得：
- **被精准看见的爽感**：作为小生意人/打工人，对'权威+科技外衣'的敲诈式管理，长期憋屈无处发泄
- **规则反吞规则的智识爽感**：不靠拳头、不靠关系、不靠运气，只靠对方亲手盖的章
- **结构对称的金句快感**：原话回敬

## B. 情绪债（必须累积+必须清算）
| 累积 | 清算 |
|---|---|
| 一千万天降税单（个人 vs 系统） | 缴款单作为催命索反咬施害方 |
| 拒绝核实 + 五点查封最后通牒 | 缉私局介入封锁服务器 |
| 围观羞辱'活该被逮' | 同一批围观者觉悟控诉自己被坑 |
| 砸锅卖铁的房产/网贷/求人 | 一千万原数退还 + 举报奖励 + 工厂爆款 |

## C. 爽点因果链
1. 施害方亲口定性"三千万爱马仕"+"系统不会错"+"科技执法"
2. 主角不否认，反而盖章备份这份定性
3. 主角当众把同一份盖章定性反向兑现成"那这真品三千万的货呢"
4. 施害方被锁进二选一死局：承认假货 = 伪造公文敲诈；承认真品 = 监守自盗
5. 缉私介入查后台，揭出系统性掠夺
6. 主角原话回敬"电脑怎么报，你就怎么坐牢吧"

## D. 道德坐标
- 读者站主角因为：他是规则信徒不是规则破坏者，他没作弊、没行贿、没暴力，只是把对方的规则原样兑现
- 反派违反的规则：篡改 AI 阈值、滥用职权拒绝核实、用查封企业胁迫、对公账户做低截留——四宗罪叠加，是制度蛀虫
- 旁观者的觉悟构成额外正义性

## E. 主角姿态
- 克制+规则信徒+破釜沉舟
- 不哭、不闹、不歇斯底里、不靠男性救场
- 关键拐点是'冷到骨头缝里的清醒'而非'怒火中烧'
- 结尾不复仇式炫耀，只用一句同结构句送对方坐牢

## F. 神髓禁改项（C0 红线）
1. 施害方先开口定性"三千万爱马仕"是死环成立的前提，必须保留
2. 主角缴款后大厅当众报警是情绪反转拐点，必须保留
3. 盖章完税单作为关键物证地位必须保留
4. 结尾'电脑怎么报，你就怎么坐牢吧'同结构句必须保留（M3 闭合）
5. 全程主角自救，不能引入男性 boss/警察伴侣/前夫等救场
6. 结尾静止物象（相框/破包/完税单）必须保留
7. 反派违反规则需至少包含'伪造公文 + 敲诈勒索 + 职务侵占'三宗

## G. 可替换项
- 商品具体形态、地理背景、施害方姓名/官职名称、金额具体数字、围观人物身份、爆款转化渠道、结尾静物的具体陈列形式

## H. 兑现风险
- 风险 1：写手把'科技执法'金句改散了（影响 M3 闭合）→ 写手必须照镜子原文摘录
- 风险 2：把主角写成情绪化哭闹型 → 偏离主角姿态
- 风险 3：让男性角色（缉私局长/律师）抢功 → 偏离读者承诺
