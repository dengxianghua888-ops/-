我打开通讯录，翻到老李。

老李，把厂里这个月的流动资金转我账户。八百万。今天五点前。

老李在电话那头愣了三秒：徐子，你疯了？厂里发工资的钱呢？

我说：先转。我后天还。还不上算我入股那部分股权折给你。一比一。

他顿了一下：好。

我翻到合伙人小王。小王，那块给二期厂房的土地，押给你姨夫那家融资。两千万。今晚到账。

小王骂了一句：你给我整这出？

我说：我妈在医院。我没退路。

小王骂完，说：行，押。明天把土地证扫描件发我。

我翻到我自己的网贷app。八张额度卡。我一张一张点开。九十八万、一百二十万、五十万、八十万、六十万、四十万、三十万、二十万。一共四百九十八万。我一笔一笔确认放款。

我翻到我妈住院押金账户。我打给护士站：王姐，我妈那笔押金先借我用一下。明天补回来。

护士姐姐在那头沉默：徐阳，你妈呼吸机得续。

我说：今晚我补。

她说：你说话算话。

我说：算。

我合上手机。三小时过去，台阶上太阳从直射移到斜射。我膝盖发僵。

我刷新银行app。对公账户余额：30,012,847.00。

我合上app，从台阶上站起来，膝关节嘎嘣响一下。我抖了抖裤腿，把销毁单从胸口拿出来，又看一遍那个电子签。

我推开旋转门，重新走进鉴定大厅。

财务柜台前，财务专员看见我，按了下耳麦：徐先生到。

周明远从里间办公室探头出来，嘴角带着那种看猎物的笑。

我说：钱我交。

他说：聪明。

我说：但销毁单上有几个字，必须改。

三千万到账。我没接货，先开口要一张东西。

我先借的那笔。

护士姐姐又打过来：徐阳，押金那笔，你妈这边主治医生问了一句。

我说：王姐，您告诉医生，明天补。她今晚的呼吸机不停。

她说：好。

挂掉电话，我朝楼里走。旋转门转了半圈停下。前台姑娘看见我，又按了一下耳麦。

候鉴区那三位，黑卫衣女、米色西装的二代、夫妻店两口子，眼神跟着我从门口移到柜台。

二代收藏者朝我点了一下头。

我点回去。

冲锋衣男人也朝我点头。低马尾女人站起来朝财务柜台让了半步，把空位让给我。

大厅里安静得只剩空调的嗡嗡声。
