# 创作笔记 — hermes_customs_package · 真鉴堂改编版

## 改编核心
- 主载体：海关 → 民营二手奢侈品鉴定平台真鉴堂
- 红章载体：完税单 → 鉴定书+销毁单 PDF（同电子签同公章）
- 公权力载体：缉私 → 市场监管局奢侈品打假专案组
- 三千万数字与"按真品赔"反语机制完整保留

## M1 死环
鉴定书与销毁单走同一电子签栏位、同一红章。
- 承认真品 → 监守自盗（员工把寄存的真品换出去）
- 承认假货 → 鉴定造假+敲诈勒索（用错误鉴定结论强收销毁费）
两路都坐牢。
