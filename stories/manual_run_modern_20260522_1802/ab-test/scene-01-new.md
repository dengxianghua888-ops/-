# 红章

导语：他只是做手工皂的，工坊不到两百平，员工三个人。

稽查队长盖下去的红章，案值三百万。

可那枚章，终将成为另一把刀的刀柄。

## 第 1 章 红章

后来想起这天，我先想起那只手。
不是张松的脸。
是他袖口磨毛的稽查制服。
是他按章的时候手腕抖了一下。

那年我二十八。
做手工皂三年。
百货店供货加直播零售。
养一家三口，三个员工，一间不到两百平的小工坊。

那天上午十点四十。
我在后头给冷制皂脱模。
阿德在直播架前切皂。
弹幕轻飘飘的：颜色好看、闻着香、再来一组。

门帘被人一把掀开。

"林承？"

"我是。"

三个人。
中间那个最高，胸牌写张松，市监稽查队长。
眉心一道深纹。

"市场监督管理局例行核查，配合。"

我点头。
他们直奔工作台。
十袋样品按住，咔咔几声全拍了照。
模子下方的水汽都没擦。

"这是原料供应链合同。"
我从抽屉抽出一摞。
"还有省质检院的初检——"

张松看都不看。
从小李手里接过一叠纸。
预打印好的。
最上面四个字：行政处罚决定书。

那叠纸角落整整齐齐。
像来之前就在车上压平了一路。

"你这个'纯天然'，按虚假宣传定。"

"队长，我有检测——"

"至少误导消费者百万级。"

他翻到签字栏。
红色印泥已经备好。
案值估算三百万元。
那一行像盖在我胸口的暗痕。

PH试纸盒被他小腿一蹭，掉到桌脚。
啪。

"队长，能不能——"

"签了，复议是你的权利。"

阿德小声叫："老板……"

我没回头。
张松手腕抖了一下，把章按下去。

稽查员把盖了红章的决定书递到我面前——三百万。
