# 文风 DNA

## 一句话风格定性

现代反转爽文的冷硬短句风：用具体物件、金额、程序文件和身体反应堆压迫，再用盖章证据和短句逼问完成反杀。

## 加载 genre 默认值

- genre: modern_reversal
- 默认基线: 第一人称、短句为主、对话 35%-45%、现代社会物件密集、逻辑反杀优先于抒情。
- 本文差异: 家庭伦理损失更重，结尾带公共正义升华，篇幅后 25% 用慢节奏补偿。

## 定量特征

### 句式

- 平均句长: 约 17-22 字
- 长短句比例: 短句 72% : 长句 28%
- 偏好句式模板:
  1. “我 + 动作 + 具体物件。”
  2. “你要是 A，那就 B；你要是 C，那就 D。”
  3. “不是 X，是 Y。”
  4. “数字 + 后果”: “关了整整37天。”
  5. “一句话单独成段”: “我卸了气。”
- 忌用句式: 大段议论、华丽抒情、抽象心理总结、连续排比形容词。

### 修辞

| 修辞手法 | 出现频次 | 典型用法（引用原文） | 效果 |
|---------|---------|-------------------|------|
| 数字压迫 | 高频 | “37天”“12.5公斤”“14.6亿”“有期徒刑十二年” | 让荒诞具备现实硬度 |
| 物理化痛感 | 高频 | “我的心口像被人插了一刀” | 把家庭崩塌落到身体 |
| 反讽回旋 | 中高 | “既然你们认定它是白松露菌种……” | 把对方规则反向砸回 |
| 二选一逼问 | 中 | “你要是看清楚了……你要是没看清楚……” | 形成死环爽点 |
| 物件锚定 | 高频 | 盖章说明、检测报告、计算器、三百块、锦旗 | 避免空泛正义 |

### 对话

- 对话占比: 约 43%
- 对话风格: 短促、逼问式、程序化、带压迫感
- 对话功能: 推动情节 50%，展示权力关系 30%，制造爽点 20%

### 叙述

- 人称视角: 第一人称
- 叙述温度: 前冷后热，反杀段冷，结尾升温
- 距离感: 贴近主角体感
- 时态: 过去式为主，关键场景即时化

### 用词

- 色温倾向: 冷色为主，结尾略转暖
- 书面/口语比: 3:7
- AI 高频词检测: 原文偶有“最终”“正义终将来临”偏总结句，但主体避开“然而”“总而言之”等强 AI 味词。
- preferred_imagery_in_source: 头罩、铁桌、惨白灯、红章、计算器、三百块、银行流水、法槌、锦旗、纸盒。

## 代表性原句（Top 5）

1. “案子撤了，人放了。公司散了，家没了。” — 体现短句对仗和代价反讽。
2. “请问刷卡还是转账？” — 体现冷幽默式降维反杀。
3. “他只要一盒长毛的米饭和图册里一张模糊的照片，就能拿出规则的法宝，把我们像蚂蚁一样碾碎。” — 体现权力压迫的核心隐喻。
4. “你要是看清楚了……那你是什么居心？你要是没看清楚，那你凭什么在这个位置上待十五年？” — 体现死环逼问。
5. “我不能让这些人一直咽。” — 体现结尾价值升华，短而有力。

## 反面教材（绝对不能出现的表达）

- 抽象正义大词连续堆叠，如“命运终于奏响公平的乐章”。
- 反派良心发现、自我忏悔式解决。
- 主角靠吵赢或打赢，而非证据和规则反杀。
- AI 味违禁词: “然而”、“总而言之”、“宛如命运的齿轮”、“眼中闪过一丝复杂/暗芒”、“深吸一口气”、“不禁”、“心中涌起”。
