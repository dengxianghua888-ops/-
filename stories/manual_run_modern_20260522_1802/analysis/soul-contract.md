# 爆款神髓合约模板 (V4)

## 1. 读者承诺

- **一句话承诺**: 读者将看到一个被公权傲慢毁掉人生的普通人，用对方亲手盖章的规则完成冷静反杀。
- **读者愿意追读的理由**: 前半的压迫极端具体，读者相信主角只要拿到证据，就能让反派为每一句傲慢付出代价。
- **最终必须兑现的体验**: 反派被法律清算，主角获得补偿并把个人冤屈转化为帮助更多人的公共正义。

## 2. 情绪债

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|---------|-----------|---------|-------------|
| 亚纶把馊饭定成白松露菌种 | Beat 1-2 | 荒诞、憋屈 | 用“白松露菌种”定性反向索赔 |
| 拒看小票和订单截图 | Beat 2-3 | 愤怒、无力 | 大厅公开逼问其专业能力和居心 |
| 戴头罩、控制主角、制造公共污名 | Beat 3 | 羞辱、恐惧 | 更高权力当众带走亚纶 |
| 把妻女带进审讯室逼认罪 | Beat 4 | 心痛、恨 | 亚纶被审讯、被逼交代 |
| 导致公司停摆、家庭破裂 | Beat 5 | 绝望、心疼 | 赔偿到账、工厂重开，但婚姻裂痕保留 |
| 长期坑害普通旅客 | Beat 9-10 | 公愤 | 专项调查、批捕、重审、退赔 |
| 贪污罚款中饱私囊 | Beat 10 | 恶心、恨 | 受贿罪判刑，牢里失去特权 |

## 3. 爽点因果链

```text
施害者种因: 亚纶用经验主义和权力傲慢，把普通盒饭定成三千万白松露菌种，并拒绝一切反证。
主角表面承受: 主角被刑拘三十七天，卖厂卖房、妻离女散，被迫认罪但保留律师、公证和检测要求。
规则反身应用: 主角要求海关出具盖章说明，再按对方“白松露菌种、案值三千万”的逻辑索赔十四点六亿。
崩塌/清算: 亚纶被迫在公开场合回答“看清楚/没看清楚”的死环，其他受害者现身，腐败链被查。
余味/补偿: 亚纶判刑，受害者退赔，主角重开工厂并设立法律援助点。
```

## 4. 道德坐标

- **读者站队对象**: 赵明辉、妞妞、被错误处罚的普通人。
- **反派必须被惩罚的理由**: 反派不是单纯看错，而是利用公权、专业话语和恐惧成本剥夺普通人的解释权，并从中牟利。
- **主角可被允许的狠度边界**: 可以索赔、曝光、推动调查、追究刑责；不能伪造证据、私刑报复、伤害无辜。

## 5. 主角姿态

- **核心姿态**: 前期慌乱求证，中期被逼隐忍，后期冷静死磕。
- **语言姿态**: 短句砸脸、逻辑逼问、冷幽默索赔。
- **行动姿态**: 先被压到绝路，再拿程序文件锁死对方，最后推动制度清算。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|-------------|
| 低价值日常物被定成高价值违禁物 | 荒诞落差是点击和爽点根基 | 开篇必须同时出现日常物和高额罪名 |
| 盖章/书面/系统记录固化载体 | M1 死环必须依赖硬证据 | 反杀前必须有主角主动索要并拿到凭证 |
| “你看清楚/没看清楚”的二选一逼问 | 高潮爽点来自逻辑闭环 | 高潮必须有显式二选一追责句 |
| 家庭事业真实崩塌 | 没有重债就没有重爽 | 至少包含事业、亲情/婚姻、名誉三类损失 |
| 群体受害者站出来 | 使故事从个人复仇升维 | 后半必须有至少两个外部受害案例 |
| 结尾法律援助/公共回馈 | 完成价值余味 | 结尾必须有帮助他人的具体行动 |

|-----------|------|-------------|

## 8. 失败预警

- **最容易丢的神髓**: 把反杀写成主角“证明自己没错”，而不是“用对方的错误定性反向锁死对方”。
- **一旦丢失会导致**: 爽点从逻辑反杀降级为普通洗冤，读者付出的憋屈得不到暴击偿还。
- **写作时补救方式**: 补一个由反派或机构亲手出具的文件，并在高潮加入二选一死环陈述。
