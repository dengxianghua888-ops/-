# 创作手记：红章

## 改编策略

源文为盒饭走私案题材的爆款短篇，核心机制是"死循环反杀+因果回旋镖"——行政权力的自证行为反过来成为对抗权力的证据。改编保留了这一底层逻辑结构，但将场景从海关/走私转移到市监稽查/手工皂工坊，避免了题材敏感性问题，同时保持了"小人物 vs 制度性压迫"的情感张力。

## 机制移植

| 源文机制 | 改编实现 |
|----------|----------|
| M1 死循环反杀 | 对手自己盖章认定的300万案值 → 变成行政诈骗的定罪证据 |
| M3 因果回旋镖 | 盖章行为本身 = 行政造假的实锤 |
| M6 阶梯式升级 | PPT恐吓→视频胁迫→封条→计算器对峙→汗中签字→法槌判决 |

## 文风控制

- 保持源文的第一人称克制叙述者视角
- 感官锚点贯穿全文：PH试纸盒、红章、计算器
- 句式以短声明句为主，模拟源文节奏
- 对话密度控制在 quote_line_rate 0.536（源文阈值 0.538 以内）

## 平台适配

- 15章结构，每章580-870字符，适合手机端滚动阅读
- 5个付费卡点分布在张力峰值位置
- 章末钩100%覆盖，每章结尾留一个悬念句
- 一句一段格式，方便番茄平台排版
