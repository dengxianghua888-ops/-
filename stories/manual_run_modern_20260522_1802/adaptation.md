# 改编方案三选一

## 候选 A（推荐入选）：市监虚假宣传案 · 电商小老板

### 一句 logline
做手工皂的小老板林承被市监稽查队以"虚假宣传'纯天然'"为由查封店铺、罚没三百万、致家庭破裂；获释后他逼监管局出具盖章决定书，再按对方"误导消费者百万级"的认定逻辑反手起诉，撕开稽查队和某竞品的串通腐败链。

### 神髓映射

| 神髓项 | 源文 | 改编后 |
|--------|------|--------|
| 低价值物 | 十盒发霉盒饭 | 十袋手工冷制皂样品 |
| 高价值定性 | 走私白松露菌种、案值三千万 | 误导消费者重大、案值三百万 |
| 公权场景 | F国海关 | 市场监督管理局稽查支队 |
| 反派身份 | 老海关亚纶 | 老稽查张松（市监稽查队长，与某网红洗护品牌私下结款） |
| 固化载体 | 盖章说明书+案值定性 | 行政处罚决定书+稽查报告（明文写"误导消费者损失估算三百万"） |
| 家庭损失 | 妻子离婚、女儿喊别人爸爸 | 妻子带女儿回娘家、女儿在视频里说"妈妈说爸爸是骗子" |
| 死环逼问 | "看清/没看清" | "你认定的'误导'数据是真的吗？真就证明你与举报人串通；假就证明你三百万决定书造假" |
| 群体受害者 | 拼图、咖啡豆等普通物 | 同区另一家手工香薰、儿童棉袜、有机果干店主，均被同一稽查队按相同套路定性 |
| 终局补偿 | 工厂重开+免费法律援助点 | 店铺重开+小微商户合规咨询站+一线工商样品检测公益基金 |

### 评分

- 神髓保真: 9.2 / 10
- 新鲜度: 8.6 / 10（电商监管题材近一年讨论度高，但"反手用决定书索赔"角度未见）
- 番茄适配: 8.8 / 10（小老板群体共情、监管痛点话题度、家庭线足够浓）
- 逻辑闭合: 9.0 / 10（市监决定书可作为反向法律工具，与海关赔偿同构）
- 平台敏感: 7.5 / 10（涉及政府监管，需用市监而非高敏感的税务/公检法系统，且反派必须落到"个人腐败"而非"系统性问题"）

### 风险

- 必须把腐败定位到"稽查队长个人+和竞品串通"，避免触碰"系统性政府腐败"红线
- 行政决定书反向起诉需要法律细节自洽，需引入"国家赔偿法+行政诉讼"双线
- 手工皂样品稽查的"监管真伪"细节要查：是否真有"误导消费者"作为行政违法，需用《反不正当竞争法》《消费者权益保护法》语言（已查证可行）

## 候选 B：平台风控洗钱案 · 网约车司机

### 一句 logline
网约车司机陈伟收到平台"涉嫌洗钱、流水定性三百万"封号通知，被冻结提现、被妻索取离婚、女儿改口叫别人爸爸；他逼平台出具书面定性，再按"洗钱犯罪"定性反手起诉平台敲诈勒索，撕开平台风控外包给某第三方公司、按封号赎金提成的腐败链。

### 神髓映射

- 低价值物：日常网约车流水（最大单笔不过五百元）
- 高价值定性：被算法判定"涉嫌洗钱、案值三百万"
- 公权场景：互联网平台风控（非政府公权但具有同等剥夺解释权的能力）
- 固化载体：平台书面《风控冻结决定书》+客服盖章回执
- 群体受害者：外卖骑手、家政阿姨、跑腿员（被同一外包风控公司套路）

### 评分

- 神髓保真: 8.6 / 10（公权迫害感弱于市监，因为平台不是政府）
- 新鲜度: 9.0 / 10（平台风控话题极热，未见同结构反杀）
- 番茄适配: 8.5 / 10
- 逻辑闭合: 8.0 / 10（平台书面决定书的法律强度弱，反手起诉的爆发力降级）
- 平台敏感: 8.5 / 10（避开政府题材，但不能直接点名某真实平台）

### 风险

- 平台不是公权，"傲慢/不可置疑"的公共代入感会比海关弱一档
- 反手索赔需要走民事而非行政赔偿，"对方亲手盖章的规则反向使用"的力度被稀释
- 网约车司机的家庭线饱和度不如电商小老板（房贷+员工工资+厂房法拍三重压力）

## 候选 C：海关查税案 · 跨境电商卖家

### 一句 logline
跨境电商卖家苏珂因一批日用品被海关认定为"奢侈品税号3404"，补税八十万、滞纳金三百万、刑拘三十天；获释后她按对方"奢侈品定性"逻辑要求海关赔偿被错扣货款的"奢侈品同档利息"，并掀开海关旧人靠改税号收红包的链条。

### 神髓映射

- 低价值物：跨境日用品（牙膏、护手霜）
- 高价值定性：奢侈品税号 3404
- 反派身份：老海关税号鉴定员
- 固化载体：海关《税号认定书》+滞纳金缴纳通知

### 评分

- 神髓保真: 9.0 / 10（与源文最贴近）
- 新鲜度: 7.0 / 10（跟源文同为海关题材，差异化不足）
- 番茄适配: 8.0 / 10
- 逻辑闭合: 8.8 / 10
- 平台敏感: 7.0 / 10

### 风险

- **致命问题：题材与源文同为海关，新鲜度不达标，违反"新鲜度不足或一眼看出原故事不可选"。直接淘汰。**

## 入选决定

**选 A：市监虚假宣传案**

- 神髓保真 9.2 ≥ 8.5 ✅
- 逻辑闭合 9.0 ≥ 8.5 ✅
- 新鲜度 8.6（领域换皮到电商监管，最大限度避开海关）✅
- 番茄适配 8.8（小老板共情、监管话题度、家庭线浓）

候选 B 因法律强度被稀释而降级；候选 C 因新鲜度不足直接淘汰。

## 敏感议题边界

- 反派必须是"个人腐败+与竞品串通"，不得描绘为"系统性政府失职"
- 监管法律细节用真实条款（《反不正当竞争法》第 8 条、《行政处罚法》第 6 章），但虚化具体行政区划
- 不点名任何真实电商平台/品牌
- 处罚链条最终落到刑事追诉（受贿、滥用职权），由市监督察部门主动调查启动，避免主角"以民告官胜诉"的法律不确定性
- 主角不可对反派施加私刑或人格侮辱性报复

## 机制保真清单（M1 / M3 / M6）

### M1 死环反杀
- 载体：林承拿到的《行政处罚决定书》明文写"误导消费者损失估算三百万元"+张松手书签字
- 死环结构：在大厅当众展开决定书，逼张松回答："这三百万的'误导消费者'金额，你是按真实数据评估的吗？"——是真，则证明他与举报人勾结私获消费者数据；不是真，则证明他三百万定性书造假，伪造行政公文。

### M3 因果回旋反讽
- 关键金句要由 writer 至少回旋 2 次：
  - 张松定性时："虚假宣传，按这个流水量级，至少误导消费者百万级。"
  - 反杀时（林承复述并加码）："既然你认定我'误导消费者百万级'，那就按你认定的损失乘上你给我贴的'三百万案值'罚没期数，算总赔偿三个亿。"
- 结尾还要有最后一次回旋：林承在援助站门口对前来感谢的小商户说："以后他们认定你什么，你就让他们盖章；他们盖什么章，你就让他们按什么赔。"

### M6 多层递进反转
- 层 1：盖章决定书反索赔三个亿（个人对个人）
- 层 2：另外三户类似受害店主（手工香薰/儿童棉袜/有机果干）现身举证（个人到群体）
- 层 3：市监督察银行流水曝光张松和某竞品 CEO 的"赞助费"流水（群体到腐败链）
- 层 4：援助站成立，林承把私人复仇升维为公共申诉机制（清算到价值升华）
- 每层间隔 ≈ 全文 18% 长度（约 2400 字），落在 Beat 7-12

## 写作时绝对不能丢的细节

1. 林承前期必须慌乱地解释"我家手工皂确实是天然的，PH 试纸/原料供应链都能查"，被张松无视——情绪债"拒看证据"必须保留
2. 团团必须在某场景对林承喊出"叔叔"或"妈妈说你是骗子"——情绪债"亲情撕裂"必须落到具体动作
3. 留置点环境必须有"惨白灯+冷地砖+铁桌"的物理化压迫
4. 第 7 幕反索赔必须有"打开计算器、把决定书拍在台面"的具体动作
5. 第 8 幕死环必须有完整的两支二选一句式
6. 第 9 幕至少出现两个外部受害者证人（不止一人，要"群体"）
7. 第 11 幕判决必须有"受贿+滥用职权"两个罪名+具体刑期
8. 结尾必须有"具体物件+具体人感谢"的余报（援助站门口的锦旗、被援助过的某老板娘的拥抱）
