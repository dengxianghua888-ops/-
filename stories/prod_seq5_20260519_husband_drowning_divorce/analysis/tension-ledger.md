# Tension Ledger：张力账本

## 总览

原文张力来自七条债务线并行推进：

1. 婚姻债：霍霆生死关头选择沈琳琳。
2. 亲情债：沈家牺牲真千金成全假千金。
3. 价值债：女主被误判成十八线、拜金、抢人。
4. 舆论债：沈琳琳抢先塑造受害者叙事。
5. 付出债：女主照顾霍霆三年却被理所当然。
6. 白月光债：沈琳琳占位、抢资源、装无辜。
7. 悔恨债：霍霆迟来醒悟但永远无法补偿。

每条线都走“建债 → 加息 → 爆雷 → 偿还”。

## 分阶段张力增长

### 阶段 1：首钩高压

- 位置：L8-L14
- 强度：10/10
- 张力事件：综艺落水，丈夫救姐姐，女主递离婚协议。
- 功能：立刻让读者站女主。
- 必须保留：不假思索、头也不回、差点沉湖、平静签字。

### 阶段 2：离婚后的关系误判

- 位置：L16-L37
- 强度：7.5/10
- 张力事件：霍霆以为还能送她、还能当朋友。
- 功能：展示男方误判，展示女主边界。
- 关键句：“离婚了，就是离婚了。”

### 阶段 3：原生家庭债补全

- 位置：L38-L55
- 强度：8.8/10
- 张力事件：真千金被冷待，替沈琳琳嫁给车祸后的霍霆。
- 功能：让“姐姐”不只是情敌，而是长期资源掠夺者。

### 阶段 4：温度正峰蓄能

- 位置：L68-L88
- 强度：7.5/10
- 张力事件：女主真心照料霍霆，两人曾像普通夫妻。
- 功能：给后期霍霆悔恨提供燃料。
- 关键物：按摩手法、小蛋糕、电影、湖边散步、恢复的腿。

### 阶段 5：沈琳琳回归侵占

- 位置：L89-L116
- 强度：8.4/10
- 加息方式：扑怀、父母撮合、进娱乐圈、抢代言、被误认为霍夫人。
- 功能：让读者等女主停止忍耐。

### 阶段 6：核心爆雷

- 位置：L117-L138
- 强度：10/10
- 张力事件：霍霆救沈琳琳，不救女主。
- 功能：把婚姻债从情感偏心升级为生死抛弃。
- 关键感官：不会游泳、以为他来救我、沉入湖底、车子离去。

### 阶段 7：断亲断联

- 位置：L139-L154
- 强度：8.7/10
- 张力事件：沈母来电不是关心，而是责怪离婚影响家族利益。
- 爽点动作：清算、拉黑删除、买机票。
- 功能：从婚姻止损扩展到原生家庭止损。

### 阶段 8：出国重建

- 位置：L155-L167
- 强度：7.8/10
- 张力事件：女主申请学校，进入耶鲁和实验室。
- 功能：在复仇前先重建主体价值。
- 隐性张力：国内还不知道她真正能力。

### 阶段 9：前夫失序 + 新男主识别

- 强度：8.5/10

- 功能：新旧男性价值观正面对比。

### 阶段 10：舆论压迫

### 阶段 15：国外追妻失败

- 位置：L283-L305
- 强度：9.7/10

- 爽点：霍霆终于低头，但没有资格。

### 阶段 16：长期火葬场

- 位置：L306-L348
- 强度：9.3/10

## 张力控制禁忌

1. 不要太早爆出所有证据。
2. 不要让霍霆太早彻底后悔。
3. 不要让女主出国后频繁被前夫拉扯。
4. 不要让沈琳琳只靠网友骂几句就结束。
5. 不要让沈家父母占用过多忏悔篇幅。
6. 不要让新男主早于女主自我重建成为主导。
7. 不要用“误会解除”替代“价值选择清算”。
8. 不要把长期火葬场写成深情守候。
