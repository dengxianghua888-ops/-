## 叙事风格

原文是番茄女频短篇爽文语体：第一人称、强事件驱动、短段密集、情绪明确但不长篇自怜。它的优势不是文采复杂，而是“动作快、证据密、悔恨长”。

核心结构是：

```text
受伤 → 止损 → 回溯建债 → 重建人生 → 证据反杀 → 追妻失败 → 余生惩罚
```

## 句法特征

### 1. 开局短句压迫

L8-L14 每句只推进一个事实：落水、丈夫救姐姐、女主差点沉湖、第二天递协议、霍霆误判、女主签字。

仿写约束：

- 首 300 字平均句长 18-24 字。
- 每段 1-3 句。
- 不解释姐姐身世，不铺长背景。
- 第一钩必须是具体事实，不用抽象抒情。

### 2. 女主关键台词短、冷、事实化

代表：

- “嗯，签吧！”
- “不用了。”
- “离婚了，就是离婚了。”
- “你们什么都没有又和我有什么关系呢？”
- “我不喜欢你了，不会和你复婚的。”


### 3. 前夫悔恨段允许长句

后期霍霆视角常用并列回忆堆积痛感：

- 温柔按摩腿。
- 牵手看电影。
- 挖冰激凌递给他。
- 等他下班。
- 看落水视频。

## AI 味规避

禁用：

- “命运的齿轮开始转动”
- “我在绝望中重生”
- “复仇才刚刚开始”
- “他不知道的是”
- “那一刻我终于明白”

优先使用：

- 具体动作：递协议、领证、拉黑、买机票、发证据。
- 具体身体：沉入湖底、眼眶通红、手抖、胸闷、腿疼。
- 具体证据：聊天记录、证件、成绩、论文、视频、证词。
