# Reader Engine

## 目标读者

番茄女频短篇读者，偏好：
- 古言重生复仇。
- 穿越女翻车。
- 嫡庶打脸。
- 皇权碾压伪女主光环。
- 女主不恋爱脑、能掌权、能共治天下。

## 阅读驱动力

### 1. 信息差驱动

读者从第一章就知道女主已经把攻略书送给皇帝，反派不知道。

持续问题：
- 皇帝会不会信？
- 太子哪些行为会被查到？
- 庶妹继续炫耀时，会不会把自己送得更死？
- 女主什么时候亮出真相？

### 2. 压迫债驱动

每次反派羞辱都很具体：
- 关柴房。
- 馊饭泔水。
- 抢玉佩。
- 踹吐血。
- 当众骂疯子。
- 命令乱棍打死。

这些不是苦情铺垫，而是后续公开清算的燃料。

### 3. 公开打脸驱动

读者期待反派在观众最多的时候崩：
- 赏荷宴宾客齐聚。
- 太子正要请旨娶庶妹。
- 温父正要逐女。
- 贵女刚嘲讽女主像下人。
- 圣旨突然落下。

公开性越强，爽感越强。

### 4. 规则反杀驱动

源文的爽点不是“我也有金手指”，而是“我知道你那套金手指在皇权规则里是什么罪”。

读者看到的是规则解释权转移：
- 庶妹眼中：《帝后攻略》是女主剧本。
- 女主眼中：它是未来谋逆路线图。
- 皇帝眼中：它是储君结党营私证据。
- 读者眼中：它是反派自毁说明书。

## 爽点分布

| 阶段 | 读者情绪 | 主要装置 |
|---|---|---|
| 0%-15% | 震惊、期待 | 重生、献书、谋逆封面 |
| 15%-40% | 憋屈、记账 | 柴房、父亲偏心、庶妹炫耀 |
| 40%-55% | 爆爽 | 圣旨到、废太子、庶妹破防 |
| 55%-70% | 权力到账 | 县主册封、掌温家、扶六皇子 |
| 70%-90% | 补刀爽 | 天牢揭真相、宗人府承认算计 |
| 90%-100% | 完成感 | 反派互撕、帝后共治、盛世如愿 |

## 付费卡点建议

1. 第一个卡点：女主御前献书后，皇帝说“朕就给你这个机会。”
2. 第二个卡点：赏荷宴上太子要乱棍打死女主，门外“圣旨到”。
3. 第三个卡点：圣旨废太子后，李玉转向女主恭敬请她入宫。
4. 第四个卡点：女主在天牢问庶妹“你真以为裴明轩爱你？”
5. 第五个卡点：宗人府中太子问“是你？”

## 防流失要求

- 每章末必须有新问题，不要以情绪总结收尾。
- 反派每炫耀一次，后文必须有对应反噬。
- 女主每次冷笑都要接行动或证据，不能只摆姿态。
- 朝政内容只保留能证明女主价值的部分，不能展开成政策论文。
- 庶妹现代词只在崩溃时使用，作为“失控”和“异类”证据。
