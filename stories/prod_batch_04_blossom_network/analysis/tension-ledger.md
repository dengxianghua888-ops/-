## 张力递进规则

1. 每条债务都必须先具体化，再情绪化。
   - 不是“外婆很惨”，而是绸衫、花露水、口罩、信封。
   - 不是“女主想走”，而是签证、航班、SIM 卡、抚养权协议。

2. 男主的悔意必须滞后于女主的离开动作。
   - 女主拿赔偿金后，他才说顾家的钱随意支取。
   - 女主订航班后，他才叫她老婆。
   - 女主出国后，他才读信。
   - 女主不爱后，他才挡枪。

3. 每次白月光获胜都必须埋反噬。
   - 她拿到公司职位，暴露任性压迫。
   - 她住进主宅，暴露鸠占鹊巢。
   - 她装过敏和假抢救，暴露恶意。
   - 她求婚，立刻被 80% 财产条件击穿。

4. 女主的冷静必须越来越强。
   - 前期哭、发抖、抓袖口。
   - 中期拿钱、签协议、订机票。
   - 后期拒绝拥抱、拒绝孩子工具化、拒绝救命复合。

## 未偿还但必须保留的余痛

| 余痛 | 为什么不完全偿还 |
|---|---|
| 顾砚醒失去母亲陪伴 | 如果孩子哭完就和好，前文“脏”和“不要妈妈”的伤害会失重 |
| 顾斯越挡枪 | 救命只能换感激，不能换爱情，否则七年亏欠被廉价抵消 |
| 夏晚星退场 | 她不是唯一罪人，不能让男主把责任全推给她 |
| 外婆病未完全痊愈 | 保留现实质感，让新生不是童话，而是带着伤继续生活 |
| 陈医生和平分手 | 女主的新生不是立刻进入下一段依附关系，而是重新认识自己 |
