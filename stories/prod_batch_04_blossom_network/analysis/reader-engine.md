- 对“孩子伤母”“老人被轻慢”“白月光占位”“男主误判女主会永远等”高度敏感的读者。

## 主阅读引擎：迟到补救循环

原文每 800-1200 字左右制造一次伤害或迟到补救。

循环公式：

```text
女主提出一个很低的需求
→ 男主/孩子/白月光轻慢或截胡
→ 女主受伤但不立刻解释
→ 女主暗中做一个离开动作
→ 男主事后补偿，误以为还能挽回
→ 下一个更严重的伤害到来
```

典型样本：

- 全家福需求 → 男主去接夏晚星 → 女主断念。
- 职场尊严需求 → 夏晚星开除 → 女主拿赔偿金离职。
- 儿子陪太婆拍照需求 → 醒醒嫌脏 → 女主取消孩子签证。
- 外婆最后见面需求 → 男主陪朵朵入学 → 女主爆发。
- 外婆“抢救”需求 → 男主抱夏晚星离开 → 女主彻底无声。
- 领证约定 → 女主飞德国 → 男主民政局扑空。
- 回家请求 → 女主拒绝。
- 挡枪告白 → 女主感激但不爱。

## 读者预期管理

必须让读者一直相信三件事：

1. 女主真的会走，不是用离开逼婚。
2. 男主真的有责任，不是单纯被白月光骗。
3. 结尾真的不会复合，不会用救命恩情强行洗白。

## 改编时的读者引擎锁

- 每个重大虐点后必须给女主一个具体切断动作。
- 每个男主补偿都必须比女主的心理变化晚半拍。
- 白月光的胜利必须越来越像空壳，最后被同一规则击穿。
- 儿子悔悟必须痛，但不能让女主立刻回归母职。
- 外婆必须活着参与女主新生，避免把亲情线写成纯死亡催泪。
