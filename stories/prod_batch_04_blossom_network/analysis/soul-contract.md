# Soul Contract

## 一句话灵魂

她等了七年，终于等到他愿意娶她，却发现这场婚姻只是他给白月光让路的工具；于是她带着唯一真正爱她的外婆离开，让所有迟来的爱都变成无效补偿。

## 读者真正购买的情绪

读者不是为了看“男主其实爱她”，而是为了看：

- 女主终于不再自我欺骗。
- 男主终于知道她有多苦，但已经来不及。
- 孩子终于意识到自己伤害了妈妈，但不能立刻被原谅。
- 白月光的特权和算计被拆穿。
- 女主把旧关系里的伤害，转化成自己和外婆的新人生。

## 情绪合同条款

| 条款 | 必须兑现 | 原文证据 |
|---|---|---|
| 女主曾经真心爱过 | 否则男主悔悟没有重量 | 第 1 节：“我有多想嫁给他。” |
| 男主前期必须足够冷 | 否则火葬场不成立 | 第 2 节：“你外婆，和我关系是？” |
| 白月光伤害不能只靠雌竞 | 她必须实质侵占女主位置 | 第 3 节开除女主；第 9 节删除指纹和密码 |
| 孩子必须造成真实伤害 | 母子债才有切断力度 | 第 7 节：“太婆是捡破烂的！捡破烂的最脏了。” |
| 外婆必须温柔且清醒 | 亲情线是女主重生的根 | 第 19 节：“我的希希，自己就是自己的依靠。” |
| 男主补偿必须迟到 | 爽点来自不可逆 | 第 28 节才知道女主出国和放弃抚养权 |
| 结尾必须不复合 | 否则前文所有伤害被洗白 | 第 34 节：“但是，我不爱你了。” |

## 角色灵魂弧

### 温希

- 起点：七年等待，低自尊，习惯把顾斯越当归宿。
- 破裂点：偷听到“足够听话”和 80% 财产信托。
- 行动线：要赔偿金、丢合同、取消孩子签证、拿戒指、订机票、放弃抚养权。
- 升级点：外婆扔信后，她不再需要被托付给谁。
- 终点：带外婆看世界，设基金，保留善意但不回头。

### 顾斯越

- 起点：傲慢地享受温希的爱，误以为她永远会等。
- 误判：以为钱、职位、戒指、婚姻能安抚她。
- 崩塌：读到外婆信，知道她童年、生产、等待和离开。
- 追悔：追到德国、带孩子来、转 80% 股权、挡枪。
- 终点：得到感激和切割，得不到爱情。

### 顾砚醒

- 起点：被父亲和夏晚星的偏爱环境塑造，嫌弃妈妈和太婆。
- 债务：用“脏”和“不要你做妈妈”刺穿温希。
- 崩塌：读太婆信，知道妈妈生他差点死。
- 限制：哭和后悔不能立刻换回母亲陪伴。
- 终点：女主留资产给他，但不再让他绑住自己。

### 外婆

- 起点：病重，仍想替温希找依靠。
- 细节：擦身、换绸衫、花露水、口罩、两封信。
- 转折：听完温希倾诉后，扔掉托付信。
- 灵魂功能：从“把希希托付给男人和儿子”转成“希希自己就是依靠”。
- 终点：病情稳定，和温希看世界。

### 夏晚星

- 起点：白月光特权拥有者。
- 行动：空降开除、占主宅、装过敏、假抢救、求婚。
- 反噬：同样的 80% 财产条件落到她身上，她立刻暴露算计。
- 功能：不是终极反派，而是男主傲慢和偏爱的照妖镜。

## 结尾灵魂锁

结尾不能写成“男主救了她，所以她动摇复合”。

原文真正的结尾逻辑是：

1. 顾斯越挡枪可以偿还一次生命危险。
2. 但挡枪不能抵消七年无名分、外婆失约、孩子伤害和迟到真相。
3. 女主可以感激，可以分配资产给孩子，可以把钱做慈善。
4. 她不能回到旧关系。
5. 最终的春暖花开属于她和外婆，不属于迟来的爱情。

## 改编禁区

- 禁止把女主离开写成赌气。
- 禁止让男主一句“其实我早爱你”解决问题。
- 禁止让孩子哭一场就重获母亲陪伴。
- 禁止把外婆写死来制造廉价刺激，原文更强的是“外婆活下来，陪女主重建人生”。
- 禁止让白月光成为唯一坏人，男主必须承担主要责任。
- 禁止用救命、给钱、股份转让直接洗白。
