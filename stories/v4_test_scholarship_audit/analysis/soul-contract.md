# 爆款神髓合约

## 读者承诺

看贫困生从奖学金公示第一名，到被逼签退助协议，再用协议里的审计条款翻出整本账，让夺名额的人和护短的人一起被规则反噬。

## 情绪债

- **资格剥夺债**: 主角凭成绩拿到名额，却被熟人规则夺走。
- **公开羞辱债**: 反派把“懂事”“感恩”当压迫话术。
- **公益背叛债**: 本该救人的基金被拿去做人情。

## 爽点因果链

1. 反派种因: 用退助协议逼主角放弃，并留下书面条款。
2. 主角蓄力: 收集签字、录音、公示名单和转账编号。
3. 规则回旋: 按协议第十七条申请专项审计。
4. 爽感释放: 反派无法同时承认协议有效又拒绝审计。

## 道德坐标

读者站主角，因为她没有抢额外利益，只追回凭规则属于自己的公平。

## 主角姿态

冷静、克制、证据型反击。她不哭闹，不求情，只把每一句压迫话术变成证据。

## 神髓禁改项

- 好消息必须撞上剥夺通知。
- 反派必须留下书面规则或系统凭证。
- 主角必须主动触发审计/举报，而不是等别人施救。
- 结尾必须用反派前文话术回旋。

## 可替换项

奖学金可替换为岗位、名额、房源、补贴；地点和职业可换；读者承诺、情绪债和规则回旋不可换。
