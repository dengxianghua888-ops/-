# Scene 05

下午，我拨了沈知微的电话。

响了五声才接。

那边很吵。杯盏碰撞的声音，笑闹声，有个男人的声音离她很近——近得不正常。

"什么事？"

"我在CCU，"我说，"急性心梗，心功能III级。医生说以后大概率不能生育了。"

安静了两秒。

"你现在连这种话都编得出来了？"

我没接话。

她叹了口气，像在处理一个不听话的病人："你现在不是没死吗？别总拿这种事来道德绑架我。我这边忙，先挂了。"

背景音里有人喊："知微姐，快来切蛋糕——"

挂断了。

我盯着天花板两秒。

打开朋友圈。

方逸宁发了一条九宫格。庆功宴。论文获奖。照片第三张，沈知微站在他旁边，手伸过去替他扶正领口。配文："感谢陪伴。来日方长。"

发布时间：昨晚21:47。

那时候我躺在客厅地板上，闻着煤气味。

我退出朋友圈。拨了另一个号码。

"周衡。"

"承安？你出什么事了？"

"帮我准备离婚材料。"

"……你想清楚了？"

"越快越好。"
