# Scene 04

醒来的时候，天花板是白的。

心电监护仪在响。鼻子里插着氧气管。左手背上扎着留置针，固定得很牢。

CCU。心脏重症监护室。

我活了。

主治医生来查房。四十多岁，戴眼镜，表情克制。

"顾先生，你的情况……"他翻了一下病历夹，"急性前壁心肌梗死，大面积心肌坏死。目前心功能III级。"

我没说话。

"后续需要终身服用抗凝药和β受体阻滞剂。"他顿了一下，"另外有一点……这些药物长期使用，会显著影响生殖功能。从目前检查结果看，你以后自然生育的概率，会很低。"

很低。

那两个字掉在病床上，没有声音。

脑子里闪过上个月的一个晚上。

她难得语气温和："等我评完副高，咱们就认真备孕。"

那天之后我偷偷去做了精液检测。A级加B级活力超过百分之六十五。报告压在家里床头柜最底层。

我本来打算这周末告诉她——我们可以了。

现在，这句话永远说不出口了。

床头柜上放着我的随身物品。钥匙串里那个胎心监护仪形状的小钥匙扣，还挂在上面。

买它的时候，店员问我是送人吗？

我说，留着自己用的。
