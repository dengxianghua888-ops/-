# Scene 06

三天后。医院VIP病房。

沈知微来了。

穿着白大褂，胸牌还挂着。"急诊科 主任医师 沈知微"。她总是这样，随时随地提醒别人她的身份。

她看见床头柜上那份离婚协议书，拿起来翻了两页。

冷笑了一声。

"顾承安，你有完没完？"

我没回答。

她把协议举起来。

两半。

纸张撕裂的声音很清脆。

紧接着，四半。八半。

碎纸落了一地。像雪片，落在她白大褂的下摆旁边。

"我说了，等事情忙完再说。你非要这样闹是吧？"

走廊里传来脚步声。

方逸宁端着一杯咖啡走过来，靠在门框上，表情关切而适度。

"承安，何必呢？都一家人。知微姐这段时间也忙，你身体不好就好好养着，有什么话等出院了——"

一家人。

他叫她"知微姐"。他来我的病房。他替她说话。

我看着地上那些碎纸。

原来在她眼里，我差点死在家里，终身药物依赖，自然生育概率低于百分之五——换来的也不过是一句"有完没完"。

我什么都没说。

低头看了一眼碎纸。

然后抬头，看向她。
