# Scene 07

满地碎纸。

胸口反而彻底静了下来。

像图纸上最后一根线落定，结构闭合。没有余量了。

我点点头。

"行。"

沈知微皱眉："你什么意思？"

"不是威胁，"我说，"是通知。"

她还没反应过来。

"那就法院见。"

四个字。说完我就不再看她了。

转头对门口的护士说："麻烦你帮我改一下紧急联系人。"

护士愣了一下："改成谁？"

"周衡。电话我报给你。"我说完顿了顿，看了沈知微一眼，"她不是我家属。"

病房里安静了三秒。

方逸宁手里的咖啡杯轻轻晃了一下。

沈知微的脸色瞬间难看到了极点。

不是愤怒。是意识到有什么东西真的失控了。

"顾承安，你——"

"护士，"我打断她，"联系人改了之后，非家属探视需要我同意，对吧？"

"是的。"

"那从现在起，"我说，"她来，不用让进了。"

沈知微的嘴唇动了一下，但没发出声音。

我重新躺回枕头上，闭上眼睛。

心电监护仪的声音很稳。每一下都很稳。
