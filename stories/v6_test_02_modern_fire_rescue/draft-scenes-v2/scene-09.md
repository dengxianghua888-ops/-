# Scene 09

卧室方向传来开门声。

方逸宁走出来。

他穿着我的白大褂。

领口处绣着名字的位置，被一条白色胶布贴住了。看不见字，但那件白大褂我穿了三年，领口磨损的位置、右袖口沾过碘伏留下的浅黄痕迹——是我的。

他脖子上，挂着一副银灰色听诊器。

管身上刻着三个字。

是我父亲的名字。

血往头顶冲。

"承安，"他微微偏头，语气像在查房，"你的伤还没好吧？别太激动。"

白大褂领口敞开。锁骨侧面有一道暧昧的红痕。他没遮。

"这是我爸的东西。"我的声音很平，但自己能听出来底下有什么在裂开。

"噢，这个？"他抬手摸了一下听诊器，"知微姐说这是旧的，放着也没人用——"

我一步上前，攥住听诊器的管子。

右腿和下腹的手术切口同时被牵扯。疼得眼前白了一瞬。

但我没松手。

他往后仰了一下，扶住门框。眼神变了。不再是温柔关切。

"顾承安，你拽什么？"

我把听诊器从他脖子上摘下来。动作很慢，因为手在抖。

他退了半步，理了理白大褂领子，低声说：

"她不是不信你。她是根本懒得管你。你以为她为什么不接你电话？不是忙。是嫌你烦。"

我攥着父亲的听诊器，指关节发白。

他笑了一下。

门铃响了。

两个人都没动。

门铃又响了一声。然后是敲门声，和一个克制的男声：

"请问是顾承安先生吗？我们是辖区民警，关于您心梗当晚的情况，有一些新发现需要当面告知。"
