# Tension Ledger：《火场求救时，老婆说我在闹脾气》

## 张力收支账本

### 记账规则

- **支出（Spend）**：释放张力的事件（读者获得满足）
- **收入（Earn）**：累积张力的事件（读者获得新的期待/愤怒）
- **余额（Balance）**：当前未释放的张力总量（越高=越想继续读）

## 张力曲线总结

```
余额
400 |              ★Ch4末=375
375 |           ↗    ↗Ch5=385
350 |         ↗         ↘Ch6=350
300 |       ↗
250 |     ↗ Ch3=240        ↘Ch7=220

130 | ★Ch1=130                     Ch8=35
  0 |                                  Ch9=0
    +----Ch1---Ch2---Ch3---Ch4---Ch5---Ch6---Ch7---Ch8---Ch9
```

**规律**：
- 前5章持续积累（只收入不大支出）
- 第6章开始阶梯释放
- 第8章集中倾泻
- 第9章归零

**仿写关键**：张力峰值必须在第4-5章（60%位置），不能提前释放。
