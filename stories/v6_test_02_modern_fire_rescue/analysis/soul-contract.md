# Soul Contract：《火场求救时，老婆说我在闹脾气》

## 核心灵魂契约

**与读者的承诺**：你将看见一个被亲密关系中的权力系统性碾压的人，用冷静、合法、不可逆的方式，让施害者亲手搭建的权力结构成为埋葬自己的棺材。

**情绪契约**：
1. 窒息感（前30%）：读者必须体验"所有求救通道被堵死"的绝望
2. 愤怒感（30-60%）：施害者的傲慢必须层层加码直到"我受不了了"
3. 冷静快感（60-100%）：主角的每一步反击都是精准的、有证据的、不可辩驳的
4. 制度正义感（末尾）：不是私人复仇，是系统对施害者的审判

## 不可违背的灵魂规则

### 规则1：主角永不崩溃

主角可以疼、可以沉默、可以"脑子空了两秒"，但绝不哭泣、绝不乞求、绝不在施害者面前示弱。他的力量来自"冷静到让人心疼"。

**违反信号**：主角说出"为什么""你怎么能""求你"

### 规则2：施害者绝不被原谅

故事的灵魂是"不原谅是合理的"。任何暗示复合、心软、理解的情节都是背叛。

**违反信号**：主角回忆美好时光后态度软化；施害者道歉后气氛缓和

### 规则3：反击必须合法且有证据

主角不使用暴力、不使用阴谋、不使用道德绑架。他的每一步都有法律依据、有物证支撑、有程序正义背书。

**违反信号**：主角做出冲动行为；出现"以暴制暴"情节

### 规则4：伤害必须具体可触

不写"她伤害了我"，要写"我以后很难有自己的孩子了"。不写"他侮辱我"，要写"他穿着我的睡衣，戴着我亡父的银表"。

**违反信号**：出现抽象化伤害描述

### 规则5：清算必须层层递进不回落

一旦开始反击，每一步都比上一步重。离婚<停职<开除<刑责。不允许中间出现"和解""暂缓""退让"。

**违反信号**：清算节奏出现回落或平台期

## 情感配额

| 情感 | 配额占比 | 载体 |
|------|---------|------|
| 窒息/绝望 | 25% | 火场+三通电话 |
| 愤怒/不平 | 30% | 妻子冷漠+竹马亵渎 |
| 冷静快感 | 35% | 每一次短句反击+证据揭露+判决 |
| 释然/新生 | 10% | 最终章 |

## 与原文机制的绑定关系

- M1死环 绑定 规则3（合法有证据）
- M3回旋 绑定 规则1（冷静到极致才有回旋的力量）
- M5温度 绑定 规则2（不原谅，温度只能降不能升）
- M6递进 绑定 规则5（层层加码不回落）
