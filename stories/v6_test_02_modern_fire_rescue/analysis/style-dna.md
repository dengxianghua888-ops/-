## 二、Rhythm Contract（仿写约束）

| 约束项 | 下限 | 上限 | 说明 |
|--------|------|------|------|
| 平均可视行长 | 12 | 20 | 不得出现大段>25字的叙述 |
| 短行率（≤16字） | 0.55 | 0.75 | 必须保持碎片感 |
| 直接对白行率 | 0.28 | 0.45 | 对话是主要叙事载体 |
| 弹幕/评论行率 | 0 | 0.05 | 仅在舆论段可用 |
| 问号密度/千字 | 3.0 | 7.0 | 质问+反问是核心武器 |
| 感叹号密度/千字 | 1.5 | 5.0 | 仅求救段可密集 |
| 单章最少钩子 | 1 | — | 每章结尾必有悬念/反转 |
| 单章最少反问/质问 | 2 | — | 维持读者紧张感 |
| 单章最少证据翻转 | 1 | — | 信息差递进 |

## 三、快节奏锁定

**本文属于快节奏短篇，执行快节奏锁定**：

- 禁止用解释性长段替代现场交锋
- 禁止用流程清单（"首先...其次...最后..."）替代动作推进
- 禁止用情绪总结（"我心里很难过"）替代生理反应
- 禁止用旁白交代替代对话揭露
- 每段叙述超过3行不含对话/动作的，必须打断

## 四、开篇结构分析

**opening_structure**: `conflict_first`

本文采用**冲突直入式**开篇：第一行即进入极端冲突场景（"为了赶去给竹马过生日，消防队长沈知微把我反锁在家里"），无前置摘要、无背景铺垫、无心理准备期。

简介段虽然浓缩了全篇逻辑链，但它的功能是"Hook信息倾泻"而非"conclusion_first"式的冷静剧透——它用的是事件碎片拼贴而非逻辑推演。

**opening_summary_lines**: 不适用（非conclusion_first型）

## 五、句式基因图谱

### 5.1 标志性句式

| 句式 | 出现频次 | 功能 |
|------|---------|------|
| "我+生理反应" | 15+ | 情绪外化（"指尖发冷""脑子空了""眼前发白"） |
| "她/他+冷淡动作+短句" | 10+ | 施害者冷漠展示 |
| "我看着她/他，一字一句" | 5+ | 主角反击前蓄势 |
| "X了Y秒" | 8+ | 时间物理化（"沉默两秒""安静了一秒"） |
| "不是A。是B。" | 6+ | 否定翻转句式 |

### 5.2 段落呼吸模式

```
对话3-5句 → 主角内心/生理1-2句 → 对话3-5句 → 环境/动作1句 → 反击短句1句
```

每个"呼吸单元"约80-120字，全篇保持高度一致的叙事脉搏。

### 5.3 情绪表达禁区

| 禁止 | 替代方案 |
|------|---------|
| "我很愤怒" | "指尖一点点发冷" |
| "我心里涌起一阵悲伤" | "胸口闷得厉害" |
| "我不禁感到" | 删除，直接写动作 |
| "然而" | 用段落换行+短句转折 |
| "那一刻我明白了" | 直接写行动 |

## 六、叙事人称与视角

- **第一人称限制视角**：全程"我"叙述
- **情绪克制型第一人称**：不滥用内心独白，用动作和生理传达
- **信息限制**：主角不知道的（值班群记录），通过律师/警方渠道揭露
- **时态**：过去时为主，关键场景切现在时（增加沉浸感）

## 七、对话风格

| 特征 | 说明 |
|------|------|
| 单句长度 | 对话单句≤20字，极少超25字 |
| 省略 | 大量省略主语（"没有""承认""同意"） |
| 标点 | 对话末尾多用句号而非感叹号（冷感） |
| 施害者腔调 | 居高临下+不耐烦（"有完没完""闹够没有"） |
| 主角腔调 | 冷静+精准+短（"法院见""是通知""都是他们应得的"） |
| 第三方腔调 | 职业化+克制（医生/民警的客观陈述） |
