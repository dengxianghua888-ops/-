# Scene 02

我把手机捡起来，手指几乎握不住。

拨第二个号码——市中心医院急诊分诊台直线电话。

"您好，急诊——"

"急性心梗发作，"我尽量把字咬清楚，"需要绿色通道，心电图ST段抬高，有截图——"

"请问您姓名？"

"顾承安。"

键盘敲击声，然后沉默了两秒。

"顾先生，我看到您档案里有一个标注……"护士的语气变了，变得小心，"系统显示您近期有焦虑症就诊记录，建议您先到精神科门诊——"

"我没有焦虑症。"

"标注是沈主任添加的，我们需要按——"

我挂了。

胸口的铁板又压下去一寸，呼吸越来越浅，像只能吸到肺最顶端那一点空气。

给沈知微发微信：【我心梗发作了，120被你拦了，你打电话让他们来。】

发出去。

已读。

一分钟。

两分钟。

回复弹出来——

【吃了安定就睡吧，别总觉得自己要死。】

我盯着那行字，胸口的疼不是疼了，是冷。

从胸骨正中往外扩散的冷。

不是没人信。

是沈知微先一步，把我从"急性心梗"变成了"焦虑症发作"。

所有通道都被她一个人堵死了。

120堵了。

急诊堵了。

她自己——也堵了。

手指尖开始发紫，视野边缘开始发灰。
