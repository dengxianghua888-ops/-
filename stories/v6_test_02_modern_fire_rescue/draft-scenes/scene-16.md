# Scene 16

最后一次回那套房子，搬走剩余的个人物品。

两箱书，一箱工具，父亲的几件旧物。

房间已经空了大半。

沙发还在，茶几还在，但和我无关了。

我站在玄关，那个当初留宽了二十公分的位置，现在什么都没放。

不是婴儿车，也不是别人的鞋了。

只是一块空地。

最后看了一眼，然后拉上门。

门锁合拢，发出一声很轻的脆响。

下楼，上车，开往新租的公寓。

十二楼，窗户很大，朝南。

打开窗，五月的风从阳台吹进来，带着楼下绿化带里新割的草味。

天光从阳台斜斜照进来，落在空荡荡的地板上。

还没买家具，冰箱是昨天送到的，里面只有水和牛奶。

把电脑架在餐桌上开机。

邮箱里有三封新邮件——新的设计方案竞标通知，下周的现场勘查安排，还有一封同事转来的项目对接函。

都是新的，和过去无关了。

关上邮箱，泡了一杯茶，坐在窗前看着外面的天空发了几分钟呆。

阳光暖得很实在，照在手背上有一点点热度。

我的生活终于一点一点，回到了自己手里。
