# Scene 03

我必须自己去医院。

双手撑地板，胳膊在抖。

膝盖跪起来的瞬间，左胸像被人攥住拧了一把，眼前全白了两秒。

车钥匙在玄关。

我往那个方向爬。

三米的距离像三十米，每动一下心脏就漏跳一拍。

漏跳的那一瞬间，世界是空的。

然后我闻到了——一股不该出现的气味。

煤气。

从厨房方向飘过来。

我停住了。

今天没做饭，出门前检查过燃气阀。

不是单纯心梗发作。

家里还有别的东西在泄漏。

客厅安静了一秒，然后我听见了——极轻的脚步声。

不是楼上，不是空调外机。

是屋里。

厨房通往客厅的过道方向，有什么在移动。

门把手——厨房那扇推拉门的把手，被人从另一侧压了一下。

我死死盯着那个把手，心脏在胸腔里乱撞，痛觉反而退远了——被更原始的恐惧压下去。

压了一下，又松开了。

像试探。

然后脚步声消失了。

我的意识开始模糊，视野从边缘往中间收缩，像隧道越来越窄。

最后看见的画面——手机屏幕亮着，还停在沈知微的对话框上。

那行字："别总觉得自己要死。"

厨房方向，燃气灶的提示音响了一下。

眼前彻底黑了。
