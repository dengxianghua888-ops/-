# Soul Contract — 《东瓶西镜放，恨不能遗忘》

## 核心灵魂契约

> **这篇文的灵魂是：被最爱的人伤到极致后，用最高的身份碾压式清算，再用最冷的"无所谓"让他永远赎不完。**

任何改编/仿写必须保住这三层：
1. **伤害的不可逆性**——不是吵架冷战，是杀子+绝育
2. **清算的公开性**——不是私下对质，是在他最荣耀的场合碾压
3. **不原谅的彻底性**——不是恨，是"你对我已无关紧要"

## 🔒 绝对不可触碰

| 锁定项 | 原因 |
|--------|------|
| 女主永不原谅 | 这是全文的道德立场和爽感核心 |
| 公主身份是自己的而非依附男人 | 读者爽的是"她本来就是"而非"被谁捧上去" |
| 杀子是男主亲手做的 | 如果是意外/他人所为，情绪债力度不够 |
| 清算在公开场合 | 私下清算无法满足"被所有人看到"的读者需求 |
| 父爱补偿段 | 这是读者情绪泄洪口，没有则全文太窒息 |

## ⚠️ 灵魂基调

- **情绪底色**：不是歇斯底里的恨，是"我已经不在乎了"的清醒
- **女主人设**：任性但不傻，能忍但有底线，清算时冷静如水
- **爽感来源**：身份碾压+事实碾压，不是暴力/骂人/撒泼
- **BE的质感**：不是"她死了"的悲剧，是"他活着但永远得不到"的惩罚

## 读者情感路线图

```
愤怒 → 心疼 → 窒息 → 期待（何时揭露）→ 爽到颅内高潮 → 温暖（父女）→ 清醒共鸣（不原谅）→ 余韵（他还在追，她已无感）
```

## 禁止出现的走向

- 女主在清算后心软/犹豫
- 女主靠新男人上位/翻身
- 男主有"合理苦衷"被读者原谅
- "活着比死更痛"的惩罚被削弱为具体刑罚
- 林楚楚变成纯恶配角（她也是受害者的复杂性要保留）
- 父皇是暴君/不爱女儿

## 文体灵魂

- 用**事实**碾压，不用**形容词**碾压
- 用**沉默**表达恨，不用**嘶吼**表达恨
- 用**物理动作**传递情绪，不用**心理描写**传递情绪
- 用**短句节奏**制造压力，不用**长段抒情**制造压力
