# 设定重置报告：《东瓶西镜放，恨不能遗忘》→ 候选方案 C

## 选中方案：画骨成灰终不悔

### 一句话前提
当朝昭阳长公主隐身画都为学徒，被世家少族长以"乡野丫头"相待三年，经历毒墨堕胎、灌废料绝育、滴血画寿字三重压迫后，于青梅册封典礼上以皇家画舫驾临，当众清算永不原谅。

## 核心设定重置

### 身份体系

| 原设定 | 新设定 | 重置理由 |
|--------|--------|---------|
| 公主隐瞒身份做平凡夫妻 | 昭阳长公主隐身画都做画坊学徒 | "画"贯穿全文意象，学徒身份比村妇更有压迫反差 |
| 陆北辰/定北侯世子 | 沈砚卿/丹青世家嫡族长 | 画都世家替换侯府，降维碾压效果一致 |
| 林楚楚/太师府嫡女 | 裴若霜/知州千金、青梅竹马 | 从"太师府"换为地方望族，避免原文痕迹 |
| 凤冠 | 昭阳玉印+五凤朝阳冠服 | 画印是公主独有信物，冠服是揭露媒介 |
| 长安寺/天梯 | 画九千九百九十九幅寿字 | 从物理攀登换为精神肉体双重折磨 |
| 彩色天灯 | 暗藏密码的画作 | 画坊背景下更自然的求救方式 |
| 上京 | 锦川（虚构江南画都） | 全新地理空间 |

### 世界观骨架

锦川是天下画都，以仕女画与工笔花鸟闻名。沈家三代经营"拾翠阁"，是锦川画坛领袖。昭阳长公主少时酷爱丹青，曾为父皇绘《千里江山图》，画技冠绝天下。三年前，她以"阿昭"之名入锦川学画，邂逅沈砚卿，以为找到灵魂伴侣。

## 关键场景重设计

### 开场Hook（前300字）

> 我隐瞒公主身份，在锦川画都做了三年学徒。得知有孕那天，沈砚卿搁下画笔，说他是丹青沈家的嫡族长，三日后要迎娶知州千金裴若霜。
>
> 我说，若我也是名门之后呢？
>
> 他笑了笑：阿昭，你连宣纸和皮纸都分不清的时候，是我手把手教你的。一个画坊学徒，如何配为沈家宗妇？
>
> 我没有告诉他，三岁执笔、七岁入画院、十四岁绘成《千里江山图》的昭阳长公主，从不需要谁来教。

### 大婚清算场景核心

裴若霜册封为正妻的典礼上，锦川码头忽然驶来一艘五凤画舫。龙旗招展，宫女持扇而立。

"昭阳长公主驾到——"

沈砚卿手中的红绸落地。

她身着五凤朝阳冠服，从画舫走下，手持昭阳玉印。锦川满城画师跪伏。

"这方玉印，三年前被某人拿去盖在别人的画上。今日本宫亲自来取回。"

## 新鲜度分析

1. **载体新鲜**："画"作为贯穿意象——毒墨杀子、以血为墨、焚画断情、画印为证，全文每个关键节点都有"画"的参与
2. **压迫形式新鲜**："画九千九百九十九幅寿字"比爬天梯更有文化质感，且"以血为墨"的视觉冲击更适合古言
3. **揭露方式新鲜**：画舫抵达码头的画面感，比"走入侯府"更有仪式感和层次
4. **信号方式新鲜**：暗藏密码的画作被送出，比天灯更契合人物身份
5. **世界观新鲜**：画都设定在古言BE中罕见，辨识度高

## 风险与规避

| 风险 | 规避策略 |
|------|---------|
| "画坊学徒"身份是否足够卑微以制造反差 | 强化"学徒"的低微——端茶磨墨、被呼来喝去、无姓无名 |
| "毒墨堕胎"是否逻辑通顺 | 设定女主每日用特定墨锭练字，男主以"换了更好的墨"掩盖 |
| "画寿字"的物理折磨感是否够 | 强调：跪姿、日夜不停、手指磨烂出血、血混入墨中、两日未食 |
| 画印被拿去用的逻辑 | 男主以为只是一方普通私印，随手给裴若霜"盖着玩" |
