# scene-02

童药堂的门比陆宅正门还厚。沈照棠从午后拍到日头偏西，掌心磨破，门里只落下一句：“夫人回吧，小少爷戒训，不见外人。”

“我是他娘。”她把脸贴到门缝，“阿砚，听见就咳一声。”

门后有铁栓横过来的响声。药工用肩顶住门板，冷着脸：“家主吩咐，谁也不能扰。”

沈照棠从袖中取出信。纸上只有几行字，问阿砚冷不冷，疼不疼，娘来接你。她把信折细，塞进门缝。

一只绣鞋踩住信角。

苏云屏扶着嬷嬷从巷口进来，弯腰抽出那封信，当着沈照棠的面撕成两半。

“孩子在学规矩，姐姐这几句哭话，会坏了他的心性。”

碎纸落到泥水里。门内传来压着嗓子的咳，短促，像被人按住了嘴。

沈照棠跪下去捡纸，膝头磕在石阶上。她抬头：“让我看一眼。只一眼。”

苏云屏退后半步，捂住肚子：“你这样吓我，若孩子有事，谁担？”

陆衡舟的马车停在巷口。他下车，看见沈照棠跪在泥里，脸色立刻沉下去。

“向云屏赔罪。”

沈照棠抬起满是泥的手：“阿砚在咳。他病了。”

“童药堂有药工。”陆衡舟按住她肩，“你先赔罪。”

肩骨被压得发疼。她低下头，额头碰到湿冷石阶：“是我失礼。”

苏云屏把碎信丢进她怀里：“晚了。”

后门忽然开了一线，又被人从里头拉住。有什么东西滚出来，沾着暗红，停在沈照棠手边。

童药堂后门落锁，门缝里滚出一截带血的布条。
