# scene-05

阿砚死后次日，停灵小屋外换了两名嬷嬷。沈照棠抱着孩子昨夜的外衣坐到天亮，起身要进门，嬷嬷伸臂拦住。

“苏姑娘吩咐，屋里阴气重，夫人不能进。”

沈照棠抬手一巴掌打开她，门却从里头上了锁。她听见后窗有木轮声，绕过去时，只看见两个护工抬着白布包走远。

“站住！”

苏云屏从正厅出来，藏到陆衡舟身后，手里捏着一角药囊碎布。

沈照棠扑上去，掐住她脖颈：“阿砚呢？你把他弄到哪儿去了？”

苏云屏被按到柱上，还在笑：“姐姐，你这样子，难怪要进疗养院。”

陆衡舟抓住沈照棠手腕，硬生生掰开。她指甲断在苏云屏衣领里，血从指尖往下滴。

“阿砚尸身不能给你糟蹋。”陆衡舟声音发冷，“你病得更重了。”

“我病？”沈照棠看着他，“昨夜是谁锁了药堂？”

陆衡舟避开她的问句，朝门外喝令：“车呢？”

黑漆疗养院车停到阶前。护工拿出束带，嬷嬷一拥而上。沈照棠撞开一个，转身冲向停灵小屋，用肩把门撞开。

屋里白幡还在，香烛烧到一半。小棺停在正中，棺盖被掀开，里面空空荡荡。

棺底只剩一只碎药囊，绣线被扯烂，像阿砚最后抓不住的手。

沈照棠扑进停灵小屋，却只看见空棺和一只碎药囊。
