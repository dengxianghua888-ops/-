# 爆款神髓合约

## 1. 读者承诺

- **一句话承诺**: 女主被丈夫和寡嫂逼到痛失幼子、假死离场后，男主才知道他亲手毁掉的是唯一爱人和唯一血脉，而女主最终不原谅、不复合。
- **读者愿意追读的理由**: 前半越憋屈，越想看“孩子死因、非亲生、唯一血脉、女主活着”四个真相连续砸向男主。
- **最终必须兑现的体验**: 男主悔不成赎，反派被镜像清算，女主拿回人生主权。

## 2. 情绪债

| 债务来源 | 承载 Beat | 读者情绪 | 必须如何偿还 |
|----------|-----------|----------|--------------|
| 男主让寡嫂凌驾于妻子 | Beat 1-2 | 憋屈、恶心 | 寡嫂孩子非亲生，香火借口崩塌 |
| 女主被囚三年、电击、饿打 | Beat 1, 5, 12 | 心疼、恨男主 | 男主公开认罪，反派被供词反噬 |
| 安安被送少管所受虐 | Beat 1-3, 8-9 | 极致心疼 | 真相由反派亲口说出，男主听见并崩溃 |
| 医院清场导致安安死亡 | Beat 3 | 愤怒、不可原谅 | 男主后知后觉抱骨灰，永远无法补救 |
| 男主亲手开枪 | Beat 6 | 震惊、爽虐期待 | 女主假死成功，男主进入失妻惩罚 |

## 3. 爽点因果链

```text
施害者种因:
霍庭深以香火、名声、仕途为名牺牲妻儿；顾霜儿借寡嫂身份主动虐女主和安安。

主角表面承受:
姜明月从激烈反抗变成异常平静，跪下、照顾孕妇、说“好”，实际已经心死并准备离场。

规则反身应用:
顾霜儿用孩子夺走姜明月的命，最后自己也被夺走见孩子的资格；霍庭深用“家”绑架姜明月，最终亲口承认家是他毁的。

崩塌/清算:
安安尸体、非亲生、弱精症、唯一血脉连续爆雷，男主从权力中心坠入悔恨中心。

余味/补偿:
女主活着、恢复记忆、看清两段关系，最终选择自己的路。
```

## 4. 道德坐标

- **读者站队对象**: 姜明月和安安。
- **反派必须被惩罚的理由**: 顾霜儿不是争宠，而是主动虐童、毁尸骨、制造医疗断路；霍庭深不是单纯被骗，而是每次都亲手选择权力与寡嫂。
- **主角可被允许的狠度边界**: 可以假死、离开、拒绝、揭露、清算；不能亲手伤害无辜婴儿，不能回头复合抵消安安死亡。

## 5. 主角姿态

- **核心姿态**: 前期忍到心死，中期用假死离场，后期清醒拒绝。
- **语言姿态**: 前期少话，关键处短句砸脸；终局不哭喊，只逐条点罪。
- **行动姿态**: 为孩子可以跪、可以冲、可以死；为自己必须离开，不能被任何男人再次定义。

## 6. 神髓禁改项

| 禁改项 | 为什么不能改 | 审校验证方式 |
|--------|--------------|--------------|
| 安安/孩子必须死亡 | 这是男主不可赎罪的根债 | 是否有孩子死亡且男主直接导致救治失败 |
| 男主必须亲手误伤女主 | 假死火葬场必须由他自己扣下扳机 | 是否存在男主主动伤害动作，而非纯误会 |
| 寡嫂必须主动加害 | 读者需要明确恨点，不接受她只是被命运推着走 | 是否有她亲口承认或证据链 |
| 非亲生 + 唯一血脉 | 香火逻辑的最大反讽 | 是否保留血缘骗局和男主生育/继承不可逆损失 |
| 女主最终不复合 | 孩子死亡不能被爱情补偿 | 结尾是否明确拒绝男主 |
| 女主也不归属宋晏 | 新生不是换一个男人托管 | 结尾是否明确“我的路自己走” |
| 火场救命不能抵债 | 救命是真，但祸源仍来自旧债 | 女主是否说清“不欠你”与“不能两清” |

## 8. 失败预警

- **最容易丢的神髓**: 把男主写成“全程被骗的可怜人”，会削弱火葬场。
- **一旦丢失会导致**: 读者不再接受女主不原谅，反而觉得她绝情。
- **写作时补救方式**: 每个关键伤害都让男主亲自做选择，并在后半逐条回放。
- **第二风险**: 把宋晏写成完美归宿。
- **补救方式**: 明确“救她是真，骗她也是真”，终局让女主独自离开。
