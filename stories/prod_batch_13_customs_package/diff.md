# Diff Review

本轮为独立质量评审，不直接修改正文。以下为建议性差异清单，供后续 Writer/Editor 阶段处理。

## 必改项

无 critical 必改项。当前稿件通过 production gate。

## 建议补丁

### 1. 补分章标题

**问题：** 正文对应 15 个 scene，但 `story/draft.md` 中没有显式章节编号或章节标题。平台发布时会削弱章末钩识别。

**建议：**
- 在每个 scene 起点增加短标题或章节号。
- 标题围绕当章钩子，不要剧透全部反杀。

**示例：**
```md
### 1. 三十斤碎茶，被估成两千万

我把三十斤茶样送进平台华东智能监管仓时……
```

### 2. 降低后段程序跳跃

**问题：** “三天后联合通报+退赔到账+订单爆发”节奏偏快。

**建议：**
在通报前补一句程序缓冲：

```md
接下来的三天，我每天补材料、签笔录、核对流水。平台那边也连续发来协查确认，所有异常收费单被临时冻结。
```

### 3. 替换少量抽象总结句

**问题：** “这不是误判，是下套”“这不是一时起意，是一张网”略有总结感。

**建议：**
将判断落到屏幕证据：

```md
屏幕上同一分钟跳出三条话术：拒绝开箱、先缴后复议、冻结货款。三条都被赵启明照着念过。
```

### 4. 补亲情债回收动作

**问题：** 姐姐房本债务前期有力，后期只写转钱，情绪偿还略轻。

**建议：**
在“我先给姐姐转钱”后补短动作：

```md
姐姐没有收语音，只回了一张照片：房本重新放回抽屉，旁边压着父亲那枚旧检测章。
```

### 5. 保持平台边界表达

**问题：** 敏感议题已基本合规，但后续修改需避免扩大为“整个平台作恶”。

**建议：**
保留或强化以下表达：
- “平台总部风控要求保留全部直播录屏”
- “平台官方号发布整改措施”
- “复核两年内全部异常珍品收费”
