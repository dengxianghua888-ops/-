# StoryForge Phase 3：高保真设定重置室

## 目标判断

源文核心不是“离婚后打脸前夫”，而是“慢半拍女主在误会里被男主的行动反复接住”。改编必须保留四根主梁：

- 开局强钩：离婚/解除关系 + 怀孕未说 + 外部剧透误导 + 白月光阴影。
- 中段峰值：产检/孕检误会孩子没了，男主崩溃，随后用检查单释放。
- 后段连爆：男主落魄是假象或被逼，真实身份带来阶层跃迁。
- 终局兑现：白月光被公开切割，正式求婚，孩子安全，家庭圆满。

## 三套投稿方向

### A. 《离婚那天，我忘了说孕检单在包里》

都市轻甜 CEO / 带球跑 / 港城世家 / 剧透弹窗误导。

女主姜梨天生像微醺，反应慢半拍，是小型甜品工作室老板。男主沈聿白表面公司暴雷，主动递离婚协议，把房子、存款、店铺全留给她。姜梨刚拿到孕检单，还没开口，眼前弹出“小说热评弹窗”，说男主青梅回国，她只是替身。她慢吞吞同意离婚，却忘了把怀孕说出口。

离婚后，沈聿白去码头做夜班装卸，手磨破也把工资转给她。青梅林晚棠拿旧合照挑衅，姜梨却只问照片能不能放进宝宝相册。中段姜梨独自产检，被沈聿白撞见。林晚棠故意说她“刚做完手术”，沈聿白误以为孩子没了，当场胃出血。B超单确认胎心后，误会释放。

后段揭开：沈聿白不是破产，而是港城沈家失散继承人。离婚是因为沈家老爷子逼他回去联姻，他怕姜梨被牵连。所谓青梅只是沈家安排的婚约挡箭牌，他从未动心。最终沈家老宅公开认下姜梨，沈聿白切割林晚棠，补办求婚，龙凤胎圆满。

评分：新鲜度 8.3，神髓保真 9.4，番茄适配 9.2，逻辑闭合 9.1。

风险：港城世家、码头装卸与原文“许家/工地”替换幅度有限，若标题仍用“微醺+带球跑+世家”，容易被看出母本。

### B. 《协议解约后，顶级梨园来接我前夫》

都市非遗豪门 / 先婚后爱 / 怀孕误会 / 弹幕读心感。

女主温瓷天生“半拍慢”，喝不喝酒都像微醺，说话软、脑回路歪，是旧戏楼里的戏服修复师。男主陆砚辞曾被她从暴雨巷口捡回家，三年婚姻低调安静。开篇陆砚辞递来离婚协议，理由是“欠债太多，别拖累你”。温瓷刚从医院回来，包里放着早孕单，还没说出口，眼前浮出一排“追文弹幕”：陆砚辞的白月光花旦回国了，她只是替身。

温瓷误会自己挡了别人姻缘，慢吞吞签字。离婚协议却把戏楼产权、存款、保险、未来抚养信托全给她。陆砚辞转身去古城剧场做夜场搭台工，手掌被木刺扎烂，还每天提醒她吃饭、别喝冰桂花酿。白月光秦月眠穿着戏服来戏楼挑衅，说陆砚辞当年爱的是她，温瓷却认真问：“这件戏服袖口开线了，要不要我帮你补？”

中段产检误会发生在老城妇幼。温瓷贫血晕倒，秦月眠故意说她“刚从手术室出来”。陆砚辞以为孩子被拿掉，情绪崩到吐血。温瓷终于把B超单塞给他，胎心仍在。弹幕卡顿后刷出“陆这个姓，不会是梨园陆家吧？”

后段揭示：陆砚辞是百年梨园世家陆家的失踪继承人。家族掌握剧院、文旅集团和非遗基金，他当年被迫离家，后被温瓷捡回。所谓破产，是陆家长辈断他资金逼他回去接班；离婚是怕温瓷和孩子被家族婚约牵连。秦月眠只是陆家推出来的门面花旦和联姻对象，陆砚辞当众否认所有暧昧。

最终温瓷住进陆家老戏楼，面对长辈刁难只问“孕妇能不能先吃碗面”。陆砚辞公开护短，接下陆家剧院与集团，补一场戏台求婚。结尾龙凤胎满月宴，陆砚辞白天管集团，晚上给温瓷煲汤，弹幕承认“原著评论区也看错了”。

评分：新鲜度 9.1，神髓保真 9.2，番茄适配 8.9，逻辑闭合 9.0。

风险：非遗梨园设定需要控制专业描写比例，不能压过甜宠主线；“梨园世家”要写得有钱有权，否则阶层兑现不如传统豪门直观。

### C. 《带球离开后，旧钱家族来认他》

都市甜宠 / 旧钱庄园 / 外卖落魄线 / 直播弹幕误导。

女主阮眠天生脸红慢热，别人急得跳脚，她还像刚醒酒。男主顾知珩主动递离婚协议，说自己投资失败，只能去跑外卖还债。阮眠刚查出怀孕，想说时却看见直播弹幕式剧透：顾知珩的初恋回国，他很快会娶旧钱家族的千金。

阮眠以为自己是挡路的人，带着孕检单离开。顾知珩跑外卖到深夜，雨天摔伤还把钱转给她。初恋盛栀拿订婚请柬挑衅，阮眠却问请柬纸张能不能剪下来做宝宝手账。产检当天，盛栀误导顾知珩“她刚做完手术”，顾知珩以为孩子没了，崩溃到进急诊。B超单释放后，弹幕爆出“顾家庄园”“百年信托”。

真相是顾知珩是沪上旧钱顾家的私生继承人，被家族用债务局逼回去。盛栀是家族安排的联姻对象，顾知珩从未喜欢。后段进入顾家庄园，顾知珩切割盛栀，争回继承权，补求婚，孩子出生。

评分：新鲜度 8.6，神髓保真 9.0，番茄适配 9.0，逻辑闭合 8.7。

风险：外卖落魄线接地气，但与“旧钱庄园”视觉反差太大，需补足家族逼迫逻辑；整体仍接近原文“落魄劳动+世家认回”的骨架。

## 选定方案

选择 B：《协议解约后，顶级梨园来接我前夫》。

理由：

- 保真度足够高：离婚、怀孕、弹幕误导、白月光、落魄劳动、产检误会、身份揭露、公开护短、求婚和圆满都完整保留。
- 新鲜度更强：把“百年世家”从常规京圈豪门改成“梨园世家 + 文旅集团 + 非遗基金”，场景从别墅/工地迁移到戏楼/后台/剧场/老城妇幼，视觉记忆点更明显。
- 女主人设更可爱：戏服修复师天然适配“慢、软、手艺人、关注点清奇”，能自然写出迟钝但不蠢。
- 番茄适配稳定：仍是甜宠、带球跑、误会解除、豪门身份兑现，只是外壳更新，不会偏成行业文。

## 核心替换策略

原“天生微醺”保留精神，不照搬表层词。新女主是“慢半拍的戏服修复师”，她说话像微醺、反应迟、关注点落在布料、针脚、吃饭和宝宝上。她不争吵，但能锁门、拉黑、保留证据、独自产检，不能写成软包子。

原“工地搬砖”替换为“古城剧场夜场搭台”。功能不变：高体力、落魄、手受伤、工资转账、仍照顾女主。视觉更贴合梨园设定。

原“京城许家”替换为“百年梨园陆家”。陆家不能只会唱戏，必须绑定剧院产权、文旅集团、非遗基金、城市地标和家族董事会，保证阶层跃迁够硬。

原“宋清音白月光”替换为“秦月眠，陆家推出来的门面花旦”。她负责误导和挑衅，但不能真的被男主爱过，不能长期占上风。

原“弹幕”替换为“追文弹幕/评论区浮屏”。它仍承担三件事：误导女主、吐槽制造网感、在关键真相处卡顿泄露碎片。

## 机制保留说明

### M2 身份反差爆发

前半让陆砚辞像负债落魄的搭台工，后半揭开他是陆家失踪继承人、剧院和文旅集团真正掌权人。女主从“被替身”误判，反转成他三年前主动靠近的唯一真爱。

审校重点：身份线不能提前说透，只能通过弹幕碎片、陆姓、剧院旧人反应、文件袋逐层泄露。

### M5 温度反转曲线

开局离婚是低温，协议偏女方、工资转账、生活提醒、搭台受伤还送药是回温证据；产检误会和吐血是高峰；B超单、公开护短、求婚完成高甜稳定。

审校重点：男主不能靠嘴说爱，必须每次用行动证明没有变冷。

### M6 多层递进反转

反转顺序必须拆开：

1. 离婚协议不像抛弃，更像托底。
2. 男主落魄却持续照顾女主。
3. 产检误会后确认孩子还在。
4. 陆家身份揭开，离婚是保护。
5. 秦月眠不是白月光，女主才是三年前的蓄意靠近。
6. 老戏楼公开偏袒，正式求婚，孩子圆满。

审校重点：不要把陆家身份、白月光真相、离婚动机一次性解释完。
