# Soul Contract

## 核心灵魂

这篇的灵魂不是“女主复仇”，而是“迟钝女主在所有误会里都被爱稳稳接住”。读者要看的不是她怎么赢白月光，而是她明明慢半拍、不争不抢，却一次次让男主的深情露出证据。

## 不可违约条款

| 条款 | 必须保留 | 违约后果 |
|---|---|---|
| 女主微醺 | 反射弧慢、关注点清奇、语气慢吞吞 | 改成精明复仇女会丢掉原文辨识度 |
| 女主不弱智 | 她迟钝但能判断善恶，会锁酒柜、会去送汤、会拉黑挑衅短信 | 写成傻白甜会惹读者烦 |
| 男主忠犬 | 离婚前后都持续照顾女主，白月光无机会 | 男主若真暧昧，甜宠安全感崩盘 |
| 孩子安全 | 怀孕线只制造误会和后怕，不制造真实伤害 | 流产会触碰市场禁区 |
| 弹幕误导 | 弹幕不能只解说，必须让读者和女主一起误判 | 没有弹幕，悬念密度会下降 |
| 白月光低危 | 她能挑拨，但不能赢，不能造成不可逆伤害 | 白月光胜利感过强会破坏爽点 |
| 身份递进 | 破产搬砖、许家真少爷、掌权人要分层揭 | 一次性解释会失去追读 |
| 圆满结局 | 复婚、孩子、掌权、日常宠爱都要给足 | 开放式不适配这篇读者承诺 |

## 情感债结构

1. 离婚债  
男主递协议，女主怀孕未说。债务不是“抛弃”，而是“他用错误方式保护她”。

2. 替身债  
弹幕和宋清音不断暗示女主是替身。最终必须用“从来不是”“三年前故意被捡”偿还。

3. 孩子债  
男主误以为孩子被打掉，情绪崩溃到吐血。必须用B超单、胎心、手摸肚子、落泪释放。

4. 安全感债  
宋清音多次越界。必须由男主当面说清“没有任何关系”“再出现不会客气”。

5. 仪式债  
开局结婚太糊涂，后来又离婚。必须补正式求婚：“这一次，是余生。”

6. 阶层债  
男主前半落魄搬砖，后半必须兑现百年世家、老宅、掌权和富可敌国。

## 读者情绪契约

- 可以虐男主后怕，不能虐女主尊严。
- 可以让女主误会，不能让男主背叛。
- 可以让白月光挑衅，不能让她占上风太久。
- 可以让豪门有压迫感，不能让孕妇长期受欺负。
- 可以让弹幕误导，最终必须证明弹幕也没完全看懂真相。
- 甜宠必须靠行动，不靠“宠溺”“深情”空泛标签。

## 终局必须给的五段释放

1. 孩子还在：B超单、胎心、男主哭。
2. 不是替身：男主承认三年前就是为女主而来。
3. 身份兑现：许家真少爷回归，破产是家族逼迫。
4. 公开偏袒：老宅安置、挡在身前、切割宋清音。
5. 圆满家庭：重新求婚、龙凤胎、掌权后仍回家煲汤。
