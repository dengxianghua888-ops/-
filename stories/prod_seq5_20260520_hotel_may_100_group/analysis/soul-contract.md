# Soul Contract

## 核心灵魂

这篇的灵魂不是“老板赚了更多钱”，而是“善意有边界，规则会回头”。主角前期已经给足十年老客户低价和解释，反派仍然污蔑、动手、威胁差评，所以读者允许主角冷静切割，并期待反派被真实市场教育。

## 读者签约承诺

读者点进来，是为了看到：

- 一个守规矩的人被不讲理的人羞辱后，不再自证清白。
- 反派每一句占便宜的话，后文都被现实用更贵、更差、更丢脸的方式还回去。
- 主角不圣母，不回头接纳，不为了所谓老客户委屈自己。
- 反派不是被天降报应砸死，而是一步步走进自己选择的后果。
- 最后必须有职业、社会、法律三重清算，而不仅是“他后悔了”。

## 道德底座

主角必须先证明自己不黑心：

- 十年没涨合作价。
- 500全包价低于市场。
- 解释过400散客价只含房费。
- 被打、被骂、被威胁后才切断合作。
- 退房时房费一分不少退给张浩。

反派必须先证明自己不值得被救：

- 偷换价格概念。
- 明知全包服务有价值仍要求400享500。
- 用差评和舆论威胁。
- 裹挟员工做错误决策。
- 出事后先护面子，再甩锅主角。

## 情感债务

| 债务 | 必须偿还方式 |
|---|---|
| 被污蔑杀熟 | 第三方客人公开认证主角价格实在 |
| 被掌掴 | 张浩后文低声下气道歉，最终因暴力被刑拘 |
| 十年客情被践踏 | 主角把房源给更懂感恩的百人团 |
| 低价占便宜 | 张浩被迫支付更高价格，且服务更差 |
| 威胁差评 | 主角不怕曝光，事实站在她这边 |
| 员工被裹挟 | 员工集体倒戈、离职，公司追责 |
| 甩锅主角 | 法律结局证明真正毁掉他的是他自己 |

## 禁止违约

- 不能让主角主动求张浩回来住。
- 不能让张浩只是口头道歉后被原谅。
- 不能把百人团写成主角临时编造的谎言。
- 不能删除“500全包 vs 400房费”的账目核心。
- 不能把后续灾难写成纯巧合，必须和退房、无接送、无住宿、无餐饮、安全隐患形成因果。
- 不能过度美化暴力报复细节，法律收口要干净。
