# 源文爆款基因拆解

## 基本判断

- 源文标题：五一订房嫌贵？可我有百人旅游团
- 题材：现代现实反转 / 小老板规则反杀 / 旅游旺季供需爽文
- 字数：约10501字（去空白、去frontmatter）
- 主卖点：反派把“500全包价”偷换成“比400房费贵”，主角不争辩，直接放他进入真实市场，让他被自己的低价逻辑反噬。
- 核心读者爽点：被污蔑的经营者不用哭求解释，而是用稀缺资源、真实账单、员工倒戈、公司处分和法律清算把恶人压回规则里。

## Hook 拆解

源文采用 H1 倒叙冲突式。

证据：
- 源文行8-13先给极端局面：“五一期间酒店订单激增”“凭什么我们是500块一晚，人家散客却是400一晚”“一巴掌打断”。
- 源文行14-18直接抛出反杀结果：“默默帮他们办理退房”“找到被我拒绝订房的百人老年团”“千元酒店一房难求”。

Hook 工程：
1. 先用“五一酒店订单激增”建立稀缺环境。
2. 用“30间房给十年老顾客”建立主角仁义和后续背叛债。
3. 用“500 vs 400”建立可传播的价格冲突。
4. 用“一巴掌”把争议升级为人格羞辱。
5. 用“百人团+新闻”告诉读者：主角手里有更大的牌，反派马上会错失。

## 标题公式

标题是“T4 数字对比式 + T1 因果反转式问答变体”。

- 数字钩子：五一、百人旅游团。
- 反转问答：嫌贵？可我有更大客源。
- 传播优势：口语化强，一眼看懂冲突，不需要解释设定。
- 改编锁定：标题必须保留“嫌贵/退房/百人团或更大订单”的因果错位。

## 反转机制清单

### M3 因果回旋反讽（主机制）

原文伤害规则：
- 张浩声称“你给别人的价格比我们低”，要求“要么退钱，要么退房”（源文行35、57）。
- 他想以400块房费享受500全包服务：“我就是看中你这儿全包我才过来的”（源文行46-50）。
- 他反复认定“有的是酒店求着我们住”“让她守着空房间哭去吧”（源文行79、135）。

回旋反击：
- 主角真按他的规则退房，转给百人团（源文行75-117）。
- 张浩离开500全包服务后，遇到500破民宿、800涨价、门票餐饮全自费（源文行406-548、594-606）。
- 他最后愿意“哪怕1000块一个人也行”，却已经无房可回（源文行729、739）。

关键等价点：改编时必须保留“反派先定规则，主角照规则执行，反派被自己的规则反噬”。

### M6 多层递进反转（结构机制）

层级递进：
1. 动作层：主角退房并接百人团，张浩以为自己赢了。
2. 市场层：散客不断问房、百人团进场、新闻确认一房难求。
3. 生存层：公交无座、全镇无房、黑民宿又贵又差。
4. 群体层：员工倒戈，民宿被查封，公司开除张浩。
5. 法律层：张浩持刀报复，最终刑拘。

证据分布：
- 百人团订金：源文行104-117。
- 百人团公开入场：源文行255-291。
- 交通与房源反噬：源文行307-356。
- 民宿涨价和员工爆发：源文行522-589。
- 警方查封：源文行689-704。
- 开除与刑拘：源文行768-842。

关键等价点：反转不能只停在“百人团来了”。必须让反派从口头吃瘪，逐层跌到经济损失、群众失信、职业毁灭、法律后果。

### M5 温度反转曲线（商业信任版）

正温度：
- 主角给合作十年的老顾客守价十年，“别家酒店都涨了三倍，我还是给他们500”（源文行36-43）。

归零：
- 一巴掌和差评威胁使“十年的客情碎得稀烂”（源文行68-72）。
- 主角决定“没有任何维护的必要了”（源文行72）。

负温度：
- 张浩雨夜求饶，“我知道错了”“哪怕1000块一个人也行”（源文行728-729）。
- 主角拉黑，员工无人同情（源文行744-763）。

关键等价点：改编必须先展示主角确实给过长期善意，否则后面的拒绝会显得冷血而非爽。

## 非锁定机制

M1 死环反杀未真正命中。源文没有“盖章文书/证据载体/二选一罪名闭环”，高潮也不是法律逻辑陈述，而是市场规则反噬。后续改编不要强行加死环文书，除非新方案明确把M1升级为新增机制。

## 爽点公式

“老客户享受低价善意” → “偷换概念污蔑杀熟” → “动手和差评威胁逼退房” → “主角顺着退房” → “更大订单接盘” → “反派被真实市场教育” → “员工和公司反向审判” → “暴力反扑被法律收口”。

## 改编锁定层

必须保留：
- 明确价格账：400只房费，500全包，后文500/800不包服务。
- 明确数量账：30人小团 vs 100人大团。
- 明确时间账：五一期间、公交四小时一班、百人团住15晚。
- 明确尊严账：主角被打、被骂黑店、被威胁差评。
- 明确回旋账：他嫌500贵，最后1000也住不上。
