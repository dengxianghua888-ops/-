# Soul Contract

## 读者契约
读者点进来，是为了看“被牺牲的父母”得到清算。契约核心不是亲情修复，而是亲情解绑：母亲终于承认儿子已经死在她心里，然后把丈夫拿命换来的钱、房、尊严和晚年全部收回来。

## 不可背叛的情绪债
| 情绪债 | 必须偿还的方式 |
|---|---|
| 丈夫被放弃抢救 | 反派必须因同样的“救命钱/保命钱”困局崩溃 |
| 狗比亲爹体面 | 后文必须让狗墓地、狗骨灰盒、捐狗形成反讽回旋 |
| 儿子把父亲当买卖 | 必须让儿子自己变成“累赘”，被问“谁来换你” |
| 母亲被血缘勒索 | 必须明确拒绝孙子牌、香火牌、养老牌 |
| 岳家吸血 | 必须让岳家承担连带债务，不能只惩罚儿子 |
| 父亲无墓地 | 结尾必须给父亲体面安葬 |

## 主角灵魂弧
- 起点：跪在抢救室外，仍相信儿子会救父亲。
- 断裂点：看到宠物遗像和三十万墓地，母亲从哀求转为算账。
- 行动线：不哭闹，不求情，用钱、合同、证据一步步清算。
- 终点：不再做“母亲责任”的奴隶，而是丈夫遗愿和自己晚年的执行人。

## 终局味道
结尾必须是冷爽中带一点迟来的温情：反派永无翻身，母亲活得稳，丈夫被好好安葬。最后的情绪落点不是“我赢了”，而是“你没享过的福，我替你好好享”。
