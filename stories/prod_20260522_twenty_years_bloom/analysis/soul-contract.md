# Soul Contract — 《二十年花开荼蘼》

## 读者承诺
读者被承诺：一个被闺蜜和丈夫联手欺骗二十年的女人，重生后将以绝对清醒和决绝，系统性地夺回被偷走的一切——学业、家人、尊严，并让每一个伤害过她的人付出对等代价。

## 情绪债
| 债务 | 欠债人 | 累积方式 | 必须偿还方式 |
|------|--------|----------|------------|
| 高考志愿篡改毁了女主人生 | 钟然 | 上辈子全家因此崩溃 | 志愿必须保住+钟然坐牢 |
| 闺蜜睡了女主男朋友还反过来炫耀 | 宋攸宁 | 当面承认+嘲讽 | 当场打脸+后续法律制裁 |
| 父亲脑溢血死亡 | 钟然/陈越/宋攸宁 | 作弊陷害导致父亲气倒 | 必须保住父亲的命 |
| 母亲心脏病死亡 | 同上 | 连锁反应 | 必须保住母亲的命 |
| 女主被全世界当成作弊者 | 钟然/宋攸宁/陈越 | 联合伪证 | 洗清冤屈+送他们坐牢 |

## 爽点因果链
1. 宋攸宁高考前吃避孕药不让钟然戴套 → 怀孕呕吐暴露 → 女主当场识破
2. 钟然篡改志愿 → 陈越拿了钱有取款记录 → 翻供证据链完整
3. 钟然买通记者（父亲的情妇）→ 女主当众揭穿小三身份 → 记者自毁
4. 宋攸宁用自杀道德绑架 → 最终真的跳楼瘫痪 → 因果回旋

## 道德坐标
读者站女主因为：她是唯一的受害者，从未伤害过任何人，所有反击都建立在"用真相对抗谎言"的逻辑上。反派违反了：信任（闺蜜/恋人最基本的忠诚）、公平（暗中篡改他人命运）、底线（为了自己的利益毁掉无辜者全家）。

## 主角姿态
**冷静决绝型**。重生后零犹豫、零试探、零心软。不跟渣人多说一句废话，行动力极强。上辈子的软弱是因为信任和善良，这辈子的决绝来自彻底看透。

## 神髓禁改项
1. 重生后当场撕破脸，不能有"再观察一下"的犹豫
2. 高考志愿篡改是核心作恶，不能弱化
3. 宋攸宁的绿茶演技+自杀操控双重手段
4. 父母必须被保住——这是最大情绪补偿
5. M3因果回旋：用渣人自己的行为证据反杀
6. M5温度曲线：钟然的完整堕落弧线

## 可替换项
1. 具体考试类型（高考→考研/公考/司考）
2. 具体关系设定（闺蜜→室友/表姐/同事）
3. 外部救援者身份（生父→恩师/伯父/前辈）
4. 具体地点和时代细节
5. 钟然最终结局的具体方式
