# 灵魂契约 (Soul Contract)

**slug**: overload_incense_revenge

## 主角灵魂

苏柠，二十八岁，独立女货车司机。开重卡跑长途三年，靠一脚油门一脚油门攒活钱给老家母亲翻修房子。底色：硬骨头、冷脑、按规矩办事。不撒泼、不私刑、不哭诉，第一反应是报警，第二反应是录音留证，第三反应是把对方按到法律框架里慢慢碾。

## 反派灵魂

李凯，三十多岁，自封"广东物流圈钻石客户"。底色：油滑+恃强凌弱，惯用合同字面+平台权限+黑社会威胁压底层司机。背后真正的庄家是收货方赵东来——长期通过李凯倒卖无证名贵木材。反派的死穴：他赌的是"女司机不敢硬刚"。

## 读者契约

| 期待 | 偿还方式 |
|---|---|
| 看女司机被欺负到底 | 不、第一章就报警，第二章合同字面反咬 |
| 看主角私刑复仇 | 不、全程司法路线，连最后下跪求情都被反录音 |
| 看大反转爽 | 一吨沉香木被定级国家二级保护植物，海关介入 |
| 看反派下场惨 | 五年六个月+五百万罚金+营业执照吊销+妻子卷款跑路 |
| 看主角升级 | 大型国企木材厂主动找她签长约，靠"守规矩"立住 |

## 情绪债清单

1. **被欺骗债**：合同 2 吨过磅 3 吨，被笑"女司机就是女司机"。
2. **公开矮化债**：派出所李凯当警察面把烟气吐主角脸上、骂"法盲""底层货色"。
3. **家人受惊债**：母亲在老家被混混尾随、面包车堵门、红油漆威胁。
4. **行业污名债**：物流大群被发身份证+地址、男司机起哄"早点回家生孩子"。
5. **平台不公债**：账户被封、五万押金冻结、申诉被驳回。

## 严守红线 (forbidden_to_change)

- 不写主角私刑、肉体施暴
- 不写主角"自己抓现行"、不写主角夜闯仓库
- 报警 + 录音 + 上交执法部门 + 司法判决——四段全程合法路径
- 不写未成年涉性涉血场景
- 多出来的一吨木材必须**主动**上交林业执法大队，不能"被搜出来"
- 大反派下场必须由司法机关判决，不能由主角"亲手了结"
