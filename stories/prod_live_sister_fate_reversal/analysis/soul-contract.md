# Soul Contract

## 一句话神髓

一个一直被要求懂事的小女儿，死在家人为救姐姐而锁上的门后；她不复仇、不控诉，只让灵魂旁观、尸检真相、外婆审判和转世胎记证明：被牺牲的人也曾差一点就能幸福。

## 锁定体验

- **主体验**：死后旁观的无力感。
- **主爽点**：迟来发现后的不可逆悔悟。
- **主虐点**：所有人都差一点能救她，却一次次选择了姐姐或自己的判断。
- **主回甘**：她没有回到原家庭，而是在转世后拥有新父母。

## 机制锁定

| 机制 | 必须保留 | 不能漂移成 |
|---|---|---|
| M4 灵魂线视角 | 前20%内明确死亡；后文主角只有旁观权 | 重生复仇、诈死、昏迷醒来 |
| M5 温度反转 | 家人曾爱她或至少亏欠她，后来冷处理，最后崩溃 | 纯恶人被惩罚 |
| M3 因果回旋 | “救姐姐”的规则必须反噬成“害死妹妹”的事实 | 随机事故、外人报复 |

## 人物合约

| 角色 | 功能 | 必须保留的复杂度 |
|---|---|---|
| 温以宁 | 被牺牲者、灵魂旁观者、情绪债主体 | 委屈但不撒泼；善良但不替施害者洗白 |
| 父母 | 预言逻辑执行者 | 不是纯恶，而是把偏心合理化的人 |
| 温以初 | 无辜共谋者、温情反证 | 必须关心妹妹，不能恶毒化 |
| 许时安 | 迟来补偿债 | 爱她但软弱，关键时刻选择顺从大局 |
| 外婆 | 伦理审判者、真正归属 | 必须说出主角不能说出的“不配” |
| 转世小孩 | 回甘证据 | 只能暗示，不能变成原家庭团圆工具 |

## 不可改动的情绪顺序

1. 规则压迫：外部预言让牺牲看似合理。
2. 死亡前置：主角在开局就失去解释机会。
3. 错过递增：家人多次接近真相，却自己走开。
4. 真相落地：尸体发现不是终点，尸检“本可救回”才是爆点。
5. 伦理审判：外婆拆穿父母“只是没保护好”的轻描淡写。
6. 归属转移：骨灰回外婆家，主角从原家庭撤出。
7. 转世补偿：读者知道她获得新生，原家庭不知道或无法占有。

## 禁止结局

- 主角复活并原谅父母。
- 父母哭一场后被叙述判定“他们也不容易”。
- 姐姐承担主要罪责。
- 男主成为主角代理复仇人。
- 转世后被原家庭认回，形成伪团圆。
