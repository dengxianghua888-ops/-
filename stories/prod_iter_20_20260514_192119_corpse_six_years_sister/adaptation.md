# 高保真设定重置 · 豪门家族·六年代孕守墓人版

## 1. 选定方案 A：萧家信托·电子签反咬

### 1.1 一句话神髓
'家族律所合伙人姐姐'用六年时间把我塑造成'萧家唯一信托受益人'+'代姐代孕守墓六年的乖弟弟'，告诉我等姐姐血癌（实为伪装）治好我就解锁二十二亿信托——揭穿日她说'你六年都白干了，姐姐根本没病、妈也没植物人、女儿一出生就被偷送给假表弟、你压根不是受益人，电子签都是磨练你的道具'。我没闹，从墓园保管箱抽出那份盖了家族律所电子签的《受益人确认书》原件，三天后在祠堂十六楼天台按下我自己的反向电子签——把空白《受益人放弃确认书》签成'若放弃则22亿自动转入已故继承人遗产专户'，再跳。

### 1.2 为什么选A而不是B/C
- **B（守尸人·伪血癌姐姐复刻版）**：保真度9.7/10极高，但新鲜度仅5.2/10。番茄读者一眼看出'这就是背尸那篇'，且'背尸'职业被算法判为不适合主流推荐位，违反硬规则'一眼看出原故事不可选'。
- **C（替身演员·替姐姐挡车祸六年）**：保真度7.4/10、逻辑闭合7.6/10，双双低于8.5门槛。M1死环需要'反派亲手开出的具兑付义务的凭证'，娱乐圈片场合同法律效力弱；'容貌替身'设定让读者联想甜宠救赎类，与冷峻反杀基调反向；灭族式偿还（妻自杀+父母出家+假兄弟试药死）在娱乐圈背景下不合理。
- **A（豪门家族·六年代孕守墓人）**：保真8.8 / 新鲜8.6 / 逻辑9.0 / 番茄8.9，全部通过门槛。'电子签确认书+家族信托'天然支持 M1 双向死环，'磨练/学乖/为你好'三句话+'幸福新郎'四字承诺天然支持 M3 因果回旋。

## 2. 神髓如何落地

### 2.1 M1（死环反杀）的载体迁移
- 原稿载体：姐姐反复说'你六年都是为你好+磨练+等你知道真相会感激我'，主角真相揭穿后跳楼把'磨练'反向兑现成姐姐余生街口寻弟疯病
- A版载体：萧家家族律所电子签的《受益人确认书》原件——同一个电子签，签了两次互相矛盾的结论（六年前签'萧承时为唯一受益人'+揭穿日改签'萧承时不是受益人，过去六年所有收益均归萧家信托总账'）
- 死环成立步骤：
  1. B1反派姐姐六年前亲手电子签'萧承时为唯一信托受益人'
  2. B5姐姐当众改口'你不是受益人，电子签都是磨练道具'——同一律所电子签出现互相矛盾结论
  3. B7主角不闹，从墓园保管箱拿出原件（PDF + U盘 + 邮箱备份三处）
  4. B10祠堂十六楼天台主角按下反向电子签：若放弃受益人身份，22亿自动转入'已故继承人遗产专户'——堵死姐姐两条退路：承认主角是受益人=22亿原数归还+伪证医疗费+伪造植物人妈诊断书必须追缴；承认不是=六年所有电子签均为伪证罪+拐骗儿童罪+敲诈勒索
- 物证唯一性保障：电子签可下载、可打印、可上链存证，主角第一时间就把PDF转存到三个独立邮箱+一份U盘+墓园保管箱铁盒，这一动作在B5'冷到骨头缝里的清醒'里用一句话点明。
