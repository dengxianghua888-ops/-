# Soul Contract：她代号深渊

## 核心合约

读者点开这篇文，不是为了看普通破案，而是为了看一个被低估的年轻女性专业人士，在男性连环杀手的凝视、恐吓和“艺术化”包装中，始终保持冷静，把对方从“猎人”拆回“嫌疑人、证据、犯人”。

## 必须兑现的体验

1. **身份爽**：别人以为她普通、柔弱、无害；她真实身份强到让凶手和警方都重新校准。
2. **专业爽**：每一个异常都能被她看见，每一个判断都能落成证据。
3. **反狩猎爽**：凶手以为自己在挑选猎物，实际是被主角设饵引出。
4. **升级爽**：抓到一个凶手不是结束，而是打开更深层的犯罪网络。
5. **冷静爽**：主角越危险越冷静，读者越安心。

## 情绪债类型

| 债务 | 原文累积方式 | 必须偿还方式 |
|---|---|---|
| 身份低估债 | “新来的，好乖啊。” / “普通的转学生。” | 在关键危险场景中亮出“我不只是转学生”。 |
| 安全侵入债 | 翻行李、窗外窥视、夜闯宿舍、死亡画像 | 主角必须反向利用侵入者的自信完成抓捕。 |
| 受害者真相债 | 失踪、墙里尸体、死亡画像、照片墙 | 必须找到尸体/证据，让受害者从“传闻”变成案件事实。 |
| 专业羞辱债 | 凶手把杀人称为艺术，把主角称为同类/艺术品 | 主角必须用法律和证据坐标降维回应。 |
| 黑网悬念债 | 暗网论坛、画师代号、真正画师短信 | 结尾必须保留更大敌人，不可完全封口。 |

## 主角姿态

- **外表**：白衬衫、牛仔裤、帆布鞋、低马尾，低威胁感。
- **内核**：犯罪侧写专家，代号深渊，三年十七案履历。
- **行动方式**：观察、记录、设饵、取证、反制。
- **情绪表达**：不崩溃、不控诉、不恋爱化凶手。
- **标志姿态**：凶手越想把她拉进深渊，她越把“深渊”当工具。

核心证据句：

- “他们享受杀人，我享受抓人。”
- “深渊不是我的归宿。深渊是我的工具。”

## 反派契约

反派必须具备三层特征：

1. **自负**：主动留下画、布偶、倒计时、论坛痕迹。
2. **审美化犯罪**：把杀人称为作品、艺术、定格。
3. **误判主角**：把沈夜当猎物、同类或可招募对象。

反派不能只是普通变态。必须有“自我神话”，这样主角拆穿他时才有爽感。

## 机制锁定

| 机制 | 不可变内容 | 可变载体 |
|---|---|---|
| M2 身份反差爆发 | 表层弱身份 vs 真实专业身份；真实身份必须让对手失去判断优势。 | 转学生可换成实习生、助教、新住户。 |
| M6 多层递进反转 | 至少四层：表层嫌疑人、执行凶手、更高层教唆者/组织、幕后未露面者。 | 校园连环案可换成医院、剧场、直播基地等封闭空间案件。 |
| M7 降维打击 | 主角必须把反派规则切换到专业规则：恐吓 -> 证据；艺术 -> 罪行；猎物 -> 执法诱饵。 | 侧写可换成法医、网安、谈判专家、反诈专家等强专业能力。 |

## 神髓禁改

- 禁止把主角写成被男主保护。
- 禁止让凶手对主角产生浪漫救赎线。
- 禁止主角凭运气脱险。
- 禁止删除“主动设饵”。
- 禁止删除“更高层未落网”的结尾钩。
- 禁止把证据链改成纯心理猜测。
- 禁止让反派被轻易制服却没有自负崩塌。

## 可替换层

| 层级 | 可替换 | 不可替换 |
|---|---|---|
| 场景 | 大学、医院、剧团、封闭训练营 | 必须有内部潜入和女性安全边界危机 |
| 职业 | 侧写师、法医、网安、心理谈判专家 | 必须是可用证据说话的专业能力 |
| 道具 | 油画、照片、雕塑、监控、音频 | 必须有可回收线索功能 |
| 凶手组织 | 暗网论坛、私密群、俱乐部 | 必须让个案升级为网络 |
| 结尾 | 短信、邮件、匿名包裹、监控截图 | 必须证明幕后者仍在看主角 |

## 最终收束语义

这篇文的“深渊”不是堕落象征，而是主角命名危险、凝视危险、反向捕捉危险的工具。改编时必须保留这个语义：主角不是被黑暗吞没的人，她是能在黑暗回头前先找到黑暗的人。
