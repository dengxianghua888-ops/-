## 句法 DNA

### 1. 短句切镜头

原文大量使用单行动作句和判断句：

- “乖？”
- “我叫沈夜。”
- “没有人见过我的脸。”
- “是血。”
- “我的脸。”
- “这是一张网。”

**执行规则**：悬疑段每3-5句就切一次短句，单句最好低于18字。短句承担镜头推近，不承担解释。

### 2. 证据链三段式

常见句型：

```text
我看到/闻到/注意到 X。
正常情况下，X 应该意味着 Y。
但现在，X 只能说明 Z。
```

例：

- “她的瞳孔没有任何变化。”
- “正常的反应应该是惊讶或者紧张。”
- “但苏韵没有。”

**执行规则**：主角的强不能靠旁白宣称，必须靠“异常识别”呈现。

### 3. 否定句推进

原文高频用“不是A，是B”反转认知：

- “那不是摇篮曲。那是一段被倒放的情歌。”
- “这不是威胁，是挑衅。”
- “不是被抓出来的。是被砌进去之前挣扎留下的。”
- “我不是艺术品。我是抓艺术品的人。”

**执行规则**：每个重要线索优先用“不是/而是”完成推理翻面。

### 4. 专业信息必须量化

原文给能力和线索都配数字：

- “二十二岁。”
- “十七起重大刑事案件。”
- “六起是连环杀人案。”
- “死亡时间都在失踪后第七天。”
- “三楼从左往右数第三个窗户。”
- “三天时间考虑。”

**执行规则**：职业强度必须量化，案情节拍也必须量化。

## 对话 DNA

### 对话占比

- 引号字符占比：23.9%
- 对话段落占比：21.9%

### 对话功能

| 类型 | 功能 | 示例 |
|---|---|---|
| 身份探针 | 逼出对方是否知情 | “你认识我。” |
| 专业判断 | 让推理变成行动 | “帮我查一个人。” |
| 反派自恋 | 提供罪行和价值观 | “死亡是最永恒的定格方式。” |
| 主角降温 | 打碎反派神话 | “我是来逮捕你的。” |

### 对话禁区

- 不写长篇情绪控诉。
- 不写恋爱暧昧式“你最懂我”。
- 不让凶手长篇演讲后主角无反制。
- 不用“你为什么这样做”拖慢节奏，主角应直接抓漏洞。
