# Reader Engine：她代号深渊

## 读者入口

目标读者进入故事时，期待的是：

- 强女主被低估后的身份爆发。
- 校园密闭空间里的连环案压迫感。
- 专业破案带来的智性爽点。
- 凶手自负被拆穿。
- 结尾继续有更大案子可追。

## 读者信息差模型

| 阶段 | 读者知道 | 文中多数人物不知道 | 读者因此期待 |
|---|---|---|---|
| 开篇 | 沈夜是代号深渊的侧写专家 | 同学和教授只当她是转学生 | 看身份反差爆发 |
| 宿舍线索 | 歌声、行李、头发都可疑 | 室友还在日常状态 | 看校园安全感被撕开 |
| 苏韵疑云 | 苏韵与画、气味、选课有关 | 刘队和赵小棠未完全警觉 | 看沈夜证明苏韵真实身份 |
| 夜袭宿舍 | 沈夜在等凶手 | 凶手以为自己突袭成功 | 看猎人变猎物 |
| 沈岸落网后 | 案件还有更高层 | 第一案参与者以为主犯被抓 | 看第二层凶手出现 |
| 画师线 | 画师知道沈夜身份 | 刘队未掌握完整威胁 | 看沈夜三天内反查 |
| 结尾 | 程砚秋不是终极画师 | 案件记录写着“已破” | 想追真正画师是谁 |

## 恨意对象设计

| 对象 | 读者为什么恨 | 兑现方式 |
|---|---|---|
| 沈岸 | 杀害女生、操控苏韵、把主角当同类 | 被琥珀胆碱反制，被警方带走，墙尸证据闭环 |
| 苏韵 | 利用受害者信任，为凶手寻找目标 | “她不是受害者。她是共犯。”完成法律定位 |
| 程砚秋 | 把杀人包装成艺术，教唆沈岸，威胁赵小棠/沈夜 | 被录音笔自供锁死，被颜料陷阱和手铐收网 |
| 真正画师 | 在暗处观看、替代程砚秋成为更大威胁 | 结尾短信留下追更仇恨 |

## 爽点释放模型

### 爽点1：读者先知道主角很强

开篇直接告诉读者沈夜身份，后续所有“她好乖”“普通转学生”都变成等打脸的蓄力。

执行关键：

- 不让读者长期误会主角弱。
- 让文中人物误会主角弱。
- 危险越近，读者越期待她掀牌。

### 爽点2：每个恐怖点都能被解释

读者不会只被吓，而会获得“原来如此”的解谜回甘。

| 恐怖点 | 解释回收 |
|---|---|
| 楼道歌声 | 苏韵制造灵异恐慌 |
| 死亡画像 | 凶手记录受害过程 |
| 墙上划痕 | 墙内尸体线索 |
| 第七天 | 作案周期/死亡倒计时 |
| 遗像 | 画师对沈夜的宣战 |
| 画师短信 | 真正幕后者仍在观察 |

### 爽点3：凶手越自恋，败得越具体

原文不是让凶手“突然慌了”，而是给具体崩塌点：

- 沈岸：手术刀刺到一半，身体僵住，脸色惨白。
- 苏韵：证据面前崩溃，说出真相。
- 程砚秋：听见录音笔后笑容僵住，调色刀飞出，被手铐铐住。

### 爽点4：主角回击短而硬

主角的胜利台词不长，但能压住反派世界观：

- “不会。”
- “第三，我抓你。”
- “我是来逮捕你的。”
- “我不是艺术品。我是抓艺术品的人。”

## 追更引擎

| 钩子类型 | 原文载体 | 功能 |
|---|---|---|
| 身份钩 | 代号深渊无人见过真脸 | 让读者等暴露身份 |
| 倒计时钩 | 第七天、三天、第二天 | 让危险有时间压力 |
| 空间钩 | 306宿舍、实验楼、E317画室 | 让读者想进入下一个危险空间 |
| 道具钩 | 布偶、画框、遗像、短信 | 用可视物承载悬念 |
| 层级钩 | 沈岸 -> 画师 -> 真正画师 | 让结尾不是终点 |
| 职业钩 | 侧写、法医学、证据学、暗网追踪 | 保证悬疑推进有专业感 |

## 改编时的读者心理红线

- 不能让主角长时间无助，否则会违背大女主承诺。
- 不能把凶手塑造成值得同情的灵魂伴侣。
- 不能让证据链断裂后靠主角“直觉”补。
- 不能让结尾只剩空泛“还有更大阴谋”，必须给具体物证或信息，如短信、照片、编号、署名。
- 不能让警方完全无能；刘队必须承担取证、支援、审讯、收网功能，主角承担识别和推进功能。
