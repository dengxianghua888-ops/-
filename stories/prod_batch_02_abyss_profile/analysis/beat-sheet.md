# Beat Sheet：她代号深渊

## 结构总览

- **正文长度**：约19021字
- **章节数**：22章
- **核心节奏**：每章一个新线索或新威胁；每3-4章一次大反转。
- **主线递进**：身份反差 -> 校园线索 -> 室友疑云 -> 第一凶手 -> 墙内真相 -> 第二凶手 -> 暗网组织 -> 真正画师未落网。
- **锁定机制**：M2、M6、M7

## 反转层级校验

| Layer | 字数位置 | 层级 | 反转内容 |
|---|---:|---|---|
| Layer 1 | 0-10% | 身份层 | 转学生其实是代号深渊的侧写专家。 |
| Layer 2 | 30-45% | 案件层 | 苏韵不是单纯嫌疑人，而是凶手的“眼睛”和作品。 |
| Layer 3 | 45-60% | 真凶层 | 沈岸现身，墙里还有第一名受害者。 |

## 空 Beat 风险

低。绝大多数章节都交付了至少一种推进：新线索、新嫌疑、新证据、新威胁或新层级。较弱位置是第13章的过渡，但它用“更聪明的人”和“一点二十三分”补足了续航钩。
