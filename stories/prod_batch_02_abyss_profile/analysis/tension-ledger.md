## 微张力循环模板

原文高复用循环如下：

```text
异常物出现 -> 主角不慌 -> 提取细节 -> 给出专业判断 -> 更危险的信息浮出 -> 章尾卡一句硬钩
```

例1：

- 异常物：楼道歌声。
- 主角反应：没尖叫，记时间。
- 专业判断：不是摇篮曲，是倒放情歌。
- 新危险：失踪女生之前也听过。
- 钩子：歌声不是鬼，是人。

例2：

- 异常物：死亡画像。
- 主角反应：检查笔触和细节。
- 专业判断：画者见过尸体或现场。
- 新危险：第七幅空白留给她。
- 钩子：她成了目标。

例3：

- 异常物：遗像和三天期限。
- 主角反应：留下，不撤。
- 专业判断：无证据抓人等于白抓。
- 新危险：窗外眼睛，第二天画框。
- 钩子：倒计时可视化。

## 关键偿还段

### 第一次偿还：沈岸/苏韵

债务来源：

- 宿舍被侵入。
- 布偶写“下一个”。
- 苏韵画里有死者。
- 沈岸把主角当同类。

偿还动作：

- 主角提前等凶手。
- 用琥珀胆碱反制。
- 指挥赵小棠报警。
- 指出实验楼东墙。
- 证据证明苏韵共犯身份。

爽感核心：主角不是被救，而是自己完成反制，并把现场变成收网场。

### 第二次偿还：程砚秋

债务来源：

- 画师画主角遗像。
- 威胁三天后把遗像放枕边。
- 暗示会动普通女生。
- 把主角称为艺术品。

偿还动作：

- 主角追踪深夜画社和程砚秋。
- 进入画室前发定位。
- 引导程砚秋自供。
- 用录音笔固化证据。
- 用颜料陷阱打断攻击。
- 用手铐完成逮捕。

爽感核心：反派自认艺术家，最后被还原成证据链里的犯罪嫌疑人。

## 张力维护原则

- 每次恐怖意象必须后续回收，不能只吓人。
- 每次主角冒险必须有事前判断或后手。
- 每次凶手演讲必须换来证据、身份、动机或自供。
- 每次案件闭环后必须立刻给出更高层级钩子。
- 主角可以身处危险，但不能失去叙事掌控权。
