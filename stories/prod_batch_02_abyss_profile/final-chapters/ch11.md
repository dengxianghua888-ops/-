# 第十一章

第五天夜里，倒计时还剩十三分钟。

我站在病理楼地下冷库外。

手腕上套着纪白留下的冷库腕带。

腕带内侧贴着定位贴，定位贴连着门禁联动。

只要压到指定位置，外廊温控报警会同时启动。

刘队在耳机里说：“警力到位。”

“录音？”

“同步。”

我推开外廊门。

纪白站在冷库外间，白大褂扣到最上面。

他看见我，笑了。

“你还是来了。”

“我想看第六例在哪里。”

“你会看见。”

他伸手，“手机给我。”

我把手机放进托盘。

他没有发现托盘底部的第二枚录音笔。

“你比许曼聪明。”

他说，“可聪明的人更适合被保存。”

“保存？”

我看着他，“你把失踪说得像护理记录。”

他眼神冷了一下，推我进外间。

门在身后合上。

温度骤降，但不危险。

真正低温区在内门之后。

外间是他们用来恐吓和转移的缓冲区。

我后退一步，手腕贴上门禁板。

定位贴亮起。

嘀。

门禁联动启动。

纪白皱眉：“你做了什么？”

我抬手，腕带封口正对监控：“让你的动作有时间线。”

外廊警报响起。

温控报警阈值被人为调低，只要外门关闭超过三十秒就触发。

这个阈值，是我白天让刘队通过物业维修单改回正常值后留下的监控点。

现在，系统记录会显示：纪白关闭外门，林照在外间，温控异常，门禁板被触发。

每一步都有数据。

纪白扑过来抢我的手。

我侧身避开，让他掌心按到门禁板上。

手背烫痕贴近摄像头。

录音笔开始外放。

“第七例，跟我去冷库。”

他的声音在外间回荡。

纪白脸色终于变了。

“你不是护理生。”

“我是。”

我说，“今天课表上写着护理实训。”

我把托盘踢到角落。

底部录音笔翻出，红灯闪烁。

“另一个身份，”我看着他，“你审讯笔录里会知道。”

外门被撞开。

刘队带人冲进来：“纪白，不许动！”

纪白退向内门，手摸到门禁卡。

我把腕带上的薄膜撕下，贴到他袖口：“封蜡粉、指纹、威胁录音、广播登录、许曼口供。

你还缺哪一项？”

他盯着我，像第一次真正看清我的脸。

警员按住他的肩，手铐扣上。

刘队从外间储物柜里取出一个密封袋。

里面是周眠的校园卡、发卡和一张未发送的求助纸条。

第六名女生的关键证据找回来了。

纪白被押过我身边时，低声说：“馆长会喜欢你。”

我没有回答。

手机忽然震动。

论坛后台弹出新邀请。

纪白刚被押走，论坛后台弹出江砚的邀请：第八盏灯，来影像室。
