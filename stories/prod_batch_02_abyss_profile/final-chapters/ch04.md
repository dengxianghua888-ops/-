# 第四章

二十二点四十分，病理楼地下外廊只亮着应急灯。

我推着耗材车，白口罩遮住半张脸。

车底层贴着定位扣，耳机里有刘队的呼吸声。

“林照，确认外廊就撤。”

他说。

“知道。”

冷库门在走廊尽头。

门禁板旁有新擦过的痕迹，旧灰被抹掉一块。

有人不想留下指纹，却忘了擦封蜡粉。

我把耗材单夹在胸前，慢慢靠近。

巡逻灯每三十秒扫过一次。

第六次扫过后，会有一秒暗区。

我等那一秒。

灯暗下去。

手机从耗材单下滑出，镜头对准冷库门侧。

那里新贴了一枚标签。

白底黑字，边缘压着封蜡。

我刚按下快门，门缝里伸出一只戴手套的手。

它抓住我的袖口。

力道不大，像提醒。

“第七例。”

门里的人低声说。

声音被门板挡住，分不清男女。

我没有挣扎。

左手从袖内滑出纤维贴片，反手压到手套边缘。

贴片一碰即粘，带走一小截灰色纤维。

耳机里，刘队声音陡然压低：“撤离。

现在。”

我低声咳了一下，表示收到。

手套却没有松。

门缝又开了一点，冷气扑到手背上。

里面没有灯，只有门禁板的红点映在金属边框上。

我把呼吸调乱，像怕极了：“我只是送耗材……”

“二十三点。”

那人说。

我垂着眼，手机仍在录像。

标签上的字被完整拍下。

第七例。

林照。

今晚二十三点。

“你们找错人了。”

我声音发颤。

门里的人笑了一下。

“没有错。

馆长看过你。”

馆长。

这不是纪白课堂上会随口说出的词。

我手腕一转，把袖口从手套指缝里抽出来。

布料撕开一线，纤维贴片已经藏回掌心。

巡逻灯亮起。

门缝立刻合上。

外廊又恢复空白，好像刚才什么都没发生。

刘队在耳机里问：“受伤没有？”

“没有。”

我把耗材车推离冷库，“拿到纤维。

标签有封蜡，字体和论坛截图待比对。”

“你马上离开。”

“还差一张。”

我回头，对准门禁板拍下红灯旁的划痕。

划痕高一米七六左右。

抓我的人右手习惯用力，手套食指外侧磨损。

不是恐吓。

是接触证据。

电梯门开时，冷库门上的新标签仍停在屏幕里。

冷库外新贴的标签写着：第七例，林照，今晚二十三点。

冷库外的新标签写着第七例林照，时间正好是今晚二十三点。
