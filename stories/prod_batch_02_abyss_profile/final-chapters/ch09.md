# 第九章

第五天凌晨，校医院空诊室亮着一盏白灯。

许曼坐在诊床边，双手被束带固定在身前。

不是审讯室，所以她还在装哭。

“我也是被逼的。”

她说。

我把一只透明证物袋放到桌上。

里面是她试图吞掉的存储卡。

十分钟前，她趁警员换手，想把卡塞进嘴里。

我扣住她手腕，按住下颌，让卡掉在治疗盘上。

她现在还在发抖。

但不是怕我。

是怕卡里的东西被打开。

刘队站在门口，没有说话。

我按下录音笔播放键。

纪白的声音从里面出来。

“她负责记录。

你们女生总喜欢把路线告诉室友。”

许曼脸色白了。

我又把广播登录记录推到她面前。

许曼门禁卡，纪白工号，机房时间差四分二十秒。

“你不是主凶。”

我说，“但你不是无辜者。”

她咬住唇：“我没有碰她们。”

“你给了钥匙，转发课表，记录动线。”

我看着她，“第六名女生周眠，最后一次进旧解剖楼前，给你发过消息。”

许曼猛地抬头。

“她说她害怕。”

我继续，“你回了她四个字，去找纪白。”

她眼泪停住。

我把手机屏幕转向她。

周眠的聊天记录恢复了一半，时间、地点、求助，都在。

“许曼，别把自己演成路人。”

我说，“路人不会有旧冷库备用牌。”

她的手指蜷紧。

“我只是记录。”

她声音哑了，“馆长说，只要记录，不算参与。”

馆长第一次从她嘴里落地。

不是传闻。

不是虚张声势。

我问：“馆长是谁？”

许曼摇头太快：“我没见过。”

“论坛账号？”

她闭嘴。

刘队往前一步。

我抬手拦住他，把一张白兔玩偶照片放到许曼膝上。

“这个腕带编号，是周眠。”

我说，“她不是病例。”

许曼看着照片，肩膀垮下去。

“寒灯档案馆。”

她说，“论坛叫这个。

纪白有执行权限，我只有记录权限。”

“馆长呢？”

她抬头看我，眼里终于有了真正的恐惧。

“馆长不见人。”

她说，“馆长只看归档。”

诊室外走廊传来警员低声汇报。

存储卡读出目录：动线、课表、门禁截图。

许曼忽然抓住床单：“林照，你走不了。”

我低头看她。

她一字一顿。

“纪白只是执行人，馆长要见寒灯。”
