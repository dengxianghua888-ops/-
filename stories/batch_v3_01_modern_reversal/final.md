# 录音笔

## 第一章

林舟的电话打进来的时候，我正在删文件。
三年前的代码备份。
一个一个文件夹。
拖进回收站。
清空。
再拖一个。
清空。
手机震了。
屏幕亮了一下。
林舟。
三年没联系的名字。
我盯着那两个字看了三秒。
没接。
又震了。
还是她。
第三次的时候我接了。
"苏棠。"
她声音哑了。
像感冒了三天没喝水那种哑。
"公司出事了。"
我没说话。

"举报什么。"
"说核心专利的发明人有问题。"

"帮你什么。"
"签一份声明。无异议声明。"
"证明专利归属没有争议。"
我笑了一下。
三年前她把我踢出公司的时候可不是这个语气。
那时候她说的是——
"核心代码是我写的，你只是帮忙调了几个接口。"
当着全公司的面。
当着投资人的面。
当着我前男友陈屹的面。
我没哭。
我只是站在那里。
像个被判了死刑的人听完宣判。
全公司三十多个人看着我。
没有一个人说话。
没有一个人站出来。
他们都知道真相。
但没有人说。
然后我收拾了东西走了。
一个纸箱。
一把机械键盘。
那把键盘是林舟送我的。
创业第一年。
她说："这公司一半是你的。"
一半是我的。
那现在呢？
现在她说："你签了，我给你两百万。"
两百万买我三年？
买我七万三千行代码？
买我爸的住院费？
买我妈的白头发？
我把手机放在桌上。
开了免提。
窗外的天已经黑了。
路灯亮了。
我的出租屋在十二楼。
能看到对面写字楼的灯。
三年前我从那栋楼里走出来。
现在我坐在这里。
一个人。
一台电脑。
一个加密压缩包。
够了。
"林舟。"
"嗯？"
"当年动手脚的，不止你一个人吧。"
电话那头沉默了四秒。
我数的。
一。二。三。四。
"你什么意思？"
"你知道我什么意思。"
"苏棠——"
"明天下午两点。你公司。"
"我去签。"
她松了口气。
我听得出来。
"但我有条件。"
"什么条件？"
"陈屹和赵鸣都得在。"
"为什么？"
"你不想知道为什么。"
我挂了。

"苏棠，别闹大，对谁都没好处。"
对谁都没好处？
对你没好处吧？

把我的commit全部改成了她的名字。
三百七十二个commit。
我一个一个数过。
那些代码是我写的。
每一行。
每一个函数。
每一个深夜debug到凌晨四点的注释。

git filter-branch。

报告上写着：核心算法开发者——林舟。

"前端协助：苏棠。"
协助？
我写了整个推荐引擎的底层架构。
七万三千行代码。
她说我是协助？

"赵鸣，git filter-branch这个命令你还记得吧？"

"你想怎样？"
"明天两点。你也来。"
"不来？"
"那我把邮件原件发给证监会。"
"你不敢。"
"你试试。"
"苏棠，你到底想要什么？"
"明天你就知道了。"
他没再回。
我把手机翻过去扣在桌上。
打开电脑。

未篡改的。

带着时间戳。
带着代码diff。
我看了一眼时间。
明天下午两点。
我会去。
但不是去签字的。
你们准备好了吗？
我准备好了。

A4纸。
三页。

她顿了一下。
"不是没关系。是……当时的分工确实是我主导——"
"林舟。"

"你主导了什么？"
她没说话。
"你告诉我。推荐引擎的核心算法。协同过滤那套。是谁写的？"
沉默。
"数据清洗模块。是谁写的？"
沉默。

"实时推荐的缓存策略。是谁设计的？"
"AB测试框架。是谁搭的？"
"冷启动问题的解决方案。是谁想的？"

"苏棠，我们当时是一起——"
"一起？"
"哪里一起了？"
"你写了哪一行？"
"你说。"
"你说出来。"
"随便说一行。"
"一行就够。"

因为她没写过。
一行都没有。
