# Reader Engine

## 目标读者

- 家庭伦理女性读者。
- 偏好亲情误会、恶人清算、迟来真相的短篇读者。
- 对“父亲背叛家庭”“母亲被冤枉”“孩子被亏待”高度敏感的读者。

## 读者主问题链

1. 女儿为什么只能啃馒头？
2. 4000为什么到账只有500？
3. 是谁动了钱？
4. 周磊是谁？
5. 父亲为什么要这么狠？
6. 女儿会不会知道自己恨错了人？
7. 真相揭开时，母亲还来得及被原谅吗？
8. 父亲会不会真正付出代价？
9. 母亲死后，女儿还能不能好好活？

## 情绪发动机

| 阶段 | 读者情绪 | 触发物 | 期待 |
|---|---|---|---|
| 开篇 | 震惊、疑惑 | 4000 vs 馒头咸菜 | 查钱去哪了 |
| 前段 | 愤怒 | 父亲转走3500 | 立刻追责 |
| 中段 | 厌恶 | 私生子和父亲冷血话术 | 离婚赔偿 |
| 中后段 | 二次愤怒 | 父亲承认故意报复 | 让女儿知道真相 |
| 后段 | 心疼 | 女儿发现恨错人 | 母女赶紧和解 |
| 末段 | 释然加余痛 | 临终陪伴和死亡 | 女儿带着爱继续活 |

## 付费级卡点

1. 银行流水确认父亲转走3500。  
   卡点句功能：嫌疑从“银行问题”变成“家人背刺”。

2. 周磊是父亲儿子。  
   卡点句功能：生活费谜题升级为婚姻背叛。

3. 李红说“为了报复你”。  
   卡点句功能：经济侵占升级为蓄意亲情谋杀。

4. 录音播放给女儿。  
   卡点句功能：读者等待多章的母亲洗冤终于到位。

5. 母亲病情急转直下。  
   卡点句功能：和解完成，但倒计时逼迫完读。

## 爽虐比例

```json
{
  "early_suspense": 0.25,
  "revenge_payoff": 0.25,
  "truth_abuse": 0.25,
  "tear_release": 0.25
}
```

源文不是纯爽文。前半用证据反击给爽感，后半用“来不及”制造完读催泪。

## 读者不能被辜负的点

- 不能让父亲轻飘飘道歉后退场。
- 不能让女儿一句“我错了”就完成全部修复，必须有陪伴行动。
- 不能让母亲完全无责，否则读者会觉得强行洗白。
- 不能拖延证据，关键节点必须有硬物证。
- 不能把结尾写成彻底幸福，余痛才是记忆点。
