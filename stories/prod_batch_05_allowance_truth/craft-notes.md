# Craft Notes

## 定稿处理

本版按 `story/diff.md` 做终稿精修，重点处理四处硬问题：

1. 补强证据合法路径：许念在第2章补发电子签名授权；银行、饭卡记录均限定在本人授权范围内；许砚相关身份与缴费材料改为警方调取、法院调查令或遮敏复印件，原件留在卷宗。
2. 修正第15章断亲钩子：最终句改为“你这辈子，都别说我是你女儿。”
3. 补法律时间桥：第11章开头明确“半个月后”，并交代警方根据流水、缴费单、恢复音频、手机银行登录记录传唤许国成。
4. 降低流程工具感：将部分法律说明转为回执、遮敏材料、签字、卷宗、登录记录等可视化动作推动。

## 结构

- 全文定为12章，单章控制在500-1200字左右。
- 主线递进为：冷馒头视频 -> 五百余额截图 -> 银行流水 -> 许砚学费 -> 父亲抢证 -> 旧车录音 -> 私生子证据 -> 画展知真相 -> 病房和解 -> 看守所断亲 -> 墓前吃热饭。
- 章末均保留钩子，前3章集中建立平台点击点与追更动力。

## 情绪债闭环

- 饥饿债：冷馒头、咸菜、借饭卡、每月五百、墓前热饭形成闭环。
- 母亲疏忽债：林素琴不被写成全然无责，在病房明确承认“不该只相信转账记录”。
- 父亲恶意债：转账记录、许砚学费、录音原话、看守所对峙逐层坐实。
- 时间债：母女相认后仍被病情截断，结尾用“今天不吃馒头”和“两碗饭”回收情绪。

## 投稿适配

- 标题保留“每月四千 vs 冷馒头”的强冲突。
- 导语保留三要素：金额、女儿受苦、丈夫与另一个孩子。
- 付费卡点建议放在第3章末或第4章末：第3章揭出“许砚名师班学费”，第4章揭出“监护人签字处露出许国成的名字”。
## 直接投稿版优化记录

- 补入开篇导语，标题后即抛出核心冲突和反击承诺。
- 正文统一为一句一段，适配移动端直接投稿阅读节奏。
- 强化付费节点为自然章末悬念，不在正文加入内部标记。
- 投稿包新增付费节点地图，便于审稿时确认卡点分布。
