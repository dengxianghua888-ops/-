# Required Revision Diff

## Blocking Fixes

### 1. 补强取证合法路径

现状问题：
- 银行、食堂、画室、户籍、出生证明等关键材料取得过顺。
- “许念的委托说明”突然出现，前文没有来源。

建议改法：
- 在第2章许念发截图后，追加一句她被林素琴追问到崩溃，补发电子授权或身份证照片。
- 第7-8章不要让画室财务直接交出完整隐私材料，改为：
  - 邵明先做证据保全申请；
  - 报案后警方调取；
  - 或法院调查令调取；
  - 林素琴只看到经律师出示的复印件。
- 出生证明、户籍关联材料必须明确来源为“警方调取/法院调查令/当事人授权”，不能凭律师个人拿到。

### 2. 修正第15章末钩

原句：
> 你这辈子，都别说我是我爸。

建议替换为二选一：
> 你这辈子，都别说你是我爸。

或：
> 你这辈子，都别说我是你女儿。

### 3. 补平台简介

建议简介：
> 我每月给集训的女儿转四千营养费，她却在画室楼梯间啃冷馒头。三年后，一段旧视频把我逼回银行柜台，才发现每月到账当天，三千五都会被她父亲转走，供另一个孩子读名师班。可真正让我女儿恨了我十五年的，不只是钱。

### 4. 补法律时间桥

现状：
- 第4天报案，第7天看守所探视，进程偏跳。

建议在第15章前加桥接信息：
> 邵明说，警方根据银行流水、画室缴费单和恢复音频连夜传唤许国成。他起初不认，直到手机银行登录记录和取证音频一起摆出来，才在笔录里签了字。

### 5. 降低模板感

建议压缩：
- “像……”比喻保留最强的几处，其他改成动作。
- 连续“我……”开头段落，改用物件或环境起句。
- 法律台词减少口号化，更多用材料、签字、回执推动。
