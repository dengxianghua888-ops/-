# 高保真设定重置室

## 三套投稿方向

### A. 康复医疗集团线：缴费窗口递协议，发布会揭专利剽窃

开局放在儿童康复医院缴费窗口。主角顾砚舟排队给女儿续哮喘脱敏和术后肺康复疗程，女儿却把离婚协议塞到他手里，说：“爸爸，你别拿我当摇钱树了，一百万够买断你这些年陪诊了吧？”

妻子沈知宁是民营康复医疗集团创始人，五年前以女儿早产肺病、自己要冲刺融资为由，求主角退出医疗器械研发圈，回家照护孩子。主角曾是呼吸康复设备和算法专利核心研发人。妻子后来与康复科主任兼运营总监陆承安同居，把主角说成没工作的陪诊废物，还让女儿认陆承安做“真正能救她的人”。

中段递进：
1. 医院窗口：女儿递协议，按护工工资给父亲估价。
2. 学校义卖/康复营：女儿公开说陆承安才是爸爸，主角宣布不再争抚养权。
3. 集团发布会：沈知宁刚向投资人担保“肺康系统全部自研、临床数据真实”，大屏切出她和陆承安篡改主角专利底稿、挪用家庭资产、同居转账的证据。
4. 离婚庭/专利侵权案：沈知宁用集团债务和医疗纠纷赔偿反咬主角，主角证明债务来自她个人侵权、违规临床和经营挪用，且五年未给家庭一分钱，主角未受益。
5. 结尾：妻女求回，主角只保留探视边界，不复合、不立刻原谅。

优势：亲情背刺、金钱误判、专业价值被盗、公开处刑、庭审债务反杀都能完整承载，医疗康复场景比科技公司更贴近长期照护痛点。

风险：医疗违规不能写成过度猎奇或具体可模仿操作，重点应落在虚假宣传、专利侵权、资金挪用、证据链和家庭清算。

综合评估：可选。

### B. 国际学校教育集团线：家长会递协议，招生直播翻车

开局放在国际学校家长会。主角替女儿交竞赛营费用，女儿当众递离婚协议，说他争抚养权是想让妈妈多赔钱。妻子是教育集团校董，情夫是教研总监。主角当年为女儿阅读障碍和焦虑症放弃教育科技公司核心算法岗位，回家陪读陪诊，还写过自适应学习系统底层模型。妻子和情夫把模型包装成集团新品，准备在招生直播中融资。

优势：学校、孩子、家长会天然适合亲情背刺；教育公平和数据剽窃也能形成规则反杀。

风险：与“孩子公开否认父亲”高度顺滑，但事业线容易从法律财产清算滑成校园打脸，财产量级和债务反杀不如医疗集团硬。

综合评估：备选。

### C. 海岸工程公司线：验收宴递协议，桥梁事故数据反杀

开局放在海边工程验收宴。主角带女儿复查术后钢板，顺路被妻子叫去签字，女儿当着合作方递离婚协议，说他只会靠妈妈养。妻子是海岸工程公司负责人，情夫是总工程师。主角曾是结构安全模型专家，为照顾术后女儿退居家庭，早年模型被妻子公司沿用。情夫后来篡改验收数据，拿主角旧模型申报奖项。

优势：工程验收、事故责任、数据造假能做强证据死环，公开名利场足够硬。

风险：亲子长期照护与工程线联系不如医疗线自然，读者的家庭伦理爽点可能被工程事故稀释。

综合评估：备选。

## 选定方向

选择 A：康复医疗集团线。

选择理由：
- 神髓保真最高：主角不是“隐形富豪”，而是被家庭照护吞掉职业黄金期、专业价值又被妻子和第三者盗用的人。
- 新鲜度足够：从火锅店/科技公司/机器人发布会，重置为医院缴费窗口/康复集团/医疗器械发布会，不会一眼看出原故事。
- 番茄适配强：病童照护、陪诊账单、缴费窗口、公开发布会、离婚庭、专利侵权案，都能持续给出具体证据和金钱清算。
- 逻辑闭合稳：妻子多年不给家庭生活费、反而把资源转给情夫和另一个家庭，天然能反向证明主角未受益，不承担集团债务和违规赔偿。

## 核心设定

主角：顾砚舟，前呼吸康复设备研发专家，曾有三项核心算法和一项雾化康复设备结构专利。女儿早产后患重度哮喘和术后肺功能问题，他应妻子请求退出项目，五年做全职陪诊父亲。

妻子：沈知宁，知宁康复医疗集团创始人。创业初期靠顾砚舟的模型和专利起盘，融资后对外塑造自己“单亲式打拼”的女强人形象，五年内与康复科主任陆承安同居并转移资产。

第三者：陆承安，康复科主任兼集团运营总监。享受沈知宁给的别墅、车、科研署名、临床项目资源，还在女儿面前扮演“能治好她的陆爸爸”。

孩子：顾念安，十二岁，长期被沈知宁和陆承安灌输“爸爸没钱、没工作、拖着妈妈不离婚”。她在缴费窗口递协议，在康复营公开喊陆承安爸爸，并在一次急性哮喘事件中为保护陆承安，诬陷主角忘带急救药。

公开处刑场：知宁康复集团新品发布会暨 B 轮融资路演。沈知宁刚对投资人和媒体承诺“知宁肺康系统完全自研，临床数据真实，集团不存在任何侵权和违规”，主角安排律师提交资产冻结申请，大屏同步播放专利底稿、云端日志、转账记录、同居监控和陆承安聊天录音。

庭审反杀点：沈知宁用集团债务、侵权赔偿、医疗纠纷债务要求主角共同承担。主角提交五年家庭账单、缴费记录、卖房流水、妻子零生活费记录、陆承安受益转账、违规项目资金流，证明债务未用于夫妻共同生活且自己未受益。

## 保留的爽点骨架

1. 300 字内完成亲情背刺和金钱误判：女儿在缴费窗口递协议，一百万买断五年陪诊。
2. 主角长期付出必须具体：夜间雾化记录、急诊缴费单、卖老房、卖母亲金镯、术后康复训练表、专利暂停通知。
3. 反派羞辱必须回旋：护工工资、一百万、没工作、拖后腿、共同债务，后期都要变成判决和证据的一部分。
4. 公开担保必须钉死反派：沈知宁亲口说“全部自研、数据真实、无侵权”，随后被专利日志和录音反锁。
5. 结尾不原谅：女儿可开始补偿，但主角不恢复父女亲密；妻子更不能靠忏悔换复合。

## 敏感表达边界

医疗题材只写虚构机构、虚构产品和虚构流程，不写真实医院名称、真实药品操作细节、可模仿的医疗违规步骤。孩子病症用于证明长期照护压力，不用病痛猎奇。亲子切割要写成监护权、探视权、情感边界，不写煽动遗弃未成年人。法律部分以证据逻辑和判决方向为主，避免冒充具体法律意见。
