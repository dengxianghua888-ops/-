# Reader Engine

## 目标读者

- 喜欢家庭伦理复仇的女性向短篇读者。
- 对“照护劳动不被看见”高度敏感的读者。
- 喜欢证据链、庭审、公开视频、资产冻结等现实规则反杀的读者。
- 期待主角不复合、不圣母、不被孩子眼泪绑架的读者。

## 第一推动力：替长期付出者出气

源文把家庭主夫写成被三重贬低的人：

1. 妻子贬低他没事业。
2. 女儿贬低他穷、懒、图钱。
3. 外人贬低他是保安、收废品、软饭男。

读者的第一情绪不是好奇爱情，而是怒：凭什么？

## 第二推动力：信息差倒计时

前半段持续压着几个问题：

- 女儿花的钱到底是谁出的？
- 主角为什么宁可净身出户也要争抚养权？
- 他以前到底是什么人？
- 妻子为什么这么笃定他离不开？
- 江予辰到底拿走了多少资源？

每次主角想解释，都被妻女打断或否定，所以读者会替他憋着等证据爆开。

## 第三推动力：公开处刑

源文爽点不满足于私下打脸，而是不断扩大观众席：

| 场景 | 观众 | 爽点 |
|---|---|---|
| 火锅店 | 女儿 | 亲情背刺开局 |
| 公司前台 | 员工、保安、情夫 | 软饭污名公开化 |
| 学校 | 老师、同学、妻子、情夫 | 父亲身份被抹除 |
| 发布会 | 媒体、资方、竞品、女儿 | 私德和事业同时塌房 |
| 庭审 | 法官、律师、旁听席 | 财产与债务规则反杀 |
| 家门口 | 女儿、司机 | 亲情火葬场但不原谅 |

改编必须保留至少两个大公开场面，其中一个负责事业塌房，一个负责法律/财产清算。

## 付费卡点模型

适合卡付费或章尾的位置：

1. 女儿递出离婚协议，补充“不许打扰妈妈和辰辰叔叔”。
2. 主角说：“徐一诺，你现在花的钱，都是我的。”
3. 学校同学揭穿：她说江予辰才是爸爸。
4. 主角说：“她，连同你这个人，我都不要了。”
5. 律师发来千万别墅、月子中心、孕产护理证据。
6. 发布会电话响起：公司资产全部被冻结。
7. 徐清婉刚担保技术原创，记者要求投屏视频。
8. 江予辰跑上台说技术员自杀。
9. 徐清婉庭审抛出共同债务威胁。
10. 主角提交“未受益”证据。

## 读者期待管理

必须满足：

- 反派现实代价要够硬：钱、职位、名誉、刑责、亲情全部受损。
- 主角胜利要靠自己过去的能力和证据，不靠突然来的金手指。
- 女儿悔恨要有动作持续性，不是一哭就洗白。
- 主角最后可以留一线人性，但不能收回边界。

不能满足：

- 不能让徐清婉一句“我错了”恢复夫妻关系。
- 不能让江予辰只社死不坐牢或不承担刑责。
- 不能把女儿所有恶意推给母亲洗干净。
- 不能让主角拿到钱后马上炫富式报复，源文的高级感来自平静。
