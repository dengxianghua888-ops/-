# Phase 6 Diff Notes

Gate: pass。以下为 Phase 7 前建议修订，不是退稿失败项。

1. 第10章章末重复  
当前前文已有“一笔。从头划到底”，章末又写“陆砚辞把笔按在联姻条款上，一笔划到底，只剩温瓷的名字。”建议保留章末钩，删前一处或改成“纸面刺啦一声，会议厅静住。”

2. 第6-7章咳血医疗感略突兀  
可以把“咳出血”降成“唇边血丝”，或补一句“他这几天胃出血本来没养好”。不改变高峰，只让身体反应更可信。

3. 第12章伦理债可再压一句边界  
温瓷已经说“现在也觉得”“所以你别碰我”，建议保留并可追加一句：“以后再替我决定，我真的会走。”这样第13章“以后再替我做决定怎么办”更有承接。

4. 第14章旧规矩议题处理方向正确  
“龙凤胎同权”“温瓷共同管理”有效化解重男轻女风险。建议不要再增加宾客反应清单，保持现在的动作兑现。
