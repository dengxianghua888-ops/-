# Diff Review

## Gate-Level Required Changes

1. **补足 production 字数硬门**
   - 当前正文保守估算约 `12100` 字。
   - beat-bible production floor 要求 `15000` 字。
   - 建议新增约 `3000-3500` 字，不要灌水，优先扩写以下高价值段落：
     - 第5章：网暴取证过程可增加平台客服、前台受扰、顾凛声明后反噬。
     - 第8章：律师函前证据链整理可增加执行人员交出凭证动机。
     - 第10章：产权反转可增加许父为何转向、许闻笙提前发录音的动作。
     - 第14章：平台冻结可增加风控规则依据和商务平台同步流程。
     - 第15章：许念母女余波可增加一次公开试镜/物业搬离确认的现场化。

2. **补平台包装**
   - 增加标题与简介版本，供番茄平台转化使用。
   - 标题可沿用 beat-bible：`捧他九百万被嫌老，我转捧短剧男二`。
   - 简介建议必须包含：九百万扶持、家宴羞辱、撤男主、男二逆袭、法务清算。

3. **修正第10章章末钩**
   - 现章末钩回到“许父下楼拿遗嘱”，但本章已揭示遗嘱。
   - 可改为面向第11章的外部钩：
     - `我刚把门禁名单更新完，前台电话打来：许总，陆呈抱着花在楼下。`
   - 或改为家庭余波钩：
     - `许念盯着房产证，第一次不敢再叫我滚。`

## Important Improvements

1. **降低流程感**
   - 第8、12、14章证据和数据密集，可加入少量动作承托：
     - 文件纸边、屏幕刷新、律师停顿、陆呈手指僵住、平台主管递表。
   - 保持冷静爽文，不需要抒情。

2. **强化陆呈后期破防**
   - 当前陆呈后果清楚，但“商业生涯断裂”的现场冲击可更强。
   - 可增加：品牌撤单邮件连跳、经纪人离职、工作室员工退群、粉丝后援会停更。

3. **补顾凛非恋爱挂件证据**
   - 第15章已有复盘材料，可在第12章前增加顾凛主动修正路演话术的一处具体动作。
   - 例如他删掉卖惨句，换成团队署名和镜头拆解。

4. **补平台风控逻辑**
   - 第14章“账号商业合作权限冻结”很好，但建议加一句：
     - `平台商务规则里，虚假合作宣传和合同风险同时命中，会自动进入高危人工审核。`

## No-Change Strengths

- 开篇信息密度强，不建议重写。
- 女主不自证、不复合、不哭诉，主控稳定。
- 顾凛以专业能力承接资源，避免纯年下暧昧。
- 网暴、侵权、产权均使用物证推进，逻辑底盘优于普通爽文。
