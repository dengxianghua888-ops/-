# Reader Engine：读者驱动引擎

## 1. 目标读者

- 番茄女性向短篇读者。
- 喜欢大女主冷静反杀、白眼狼塌房、继妹打脸、年下忠犬补偿的读者。
- 对“我供养你，你却羞辱我”高度敏感的读者。
- 喜欢商业资源、合同、热搜、法务、判决等现实爽点载体的读者。

## 2. 核心情绪按钮

### 按钮 1：供养被羞辱

- 触发句：“前后砸了快七百万。”
- 刺痛句：“人老了花再多钱也没用。”
- 读者情绪：凭什么拿我的钱还嫌我丢人？
- 回收方式：撤单、取消捧场、资源转投沈确。

### 按钮 2：双标

- 触发句：“素来冷漠的他笑容满面。”
- 刺痛动作：给继妹剥虾、送养生茶、加佣人好友。
- 读者情绪：不是性格冷，是只对女主冷。
- 回收方式：女主不再给他热场，直播寒酸。

### 按钮 3：公开否认

- 触发句：“不认识。”
- 读者情绪：三年七百万换一句不认识，必须让他付代价。
- 回收方式：女主用“我跟他又不认识”停止捧场。

### 按钮 4：荡妇羞辱与年龄羞辱

- 触发句：“更年期老女人”“万人骑”“老女人”。
- 读者情绪：网暴越线，必须上法务。
- 回收方式：律师函、证据链、法院判决。

### 按钮 5：资源误判

- 触发句：“我能拿下这个合同，是我的能力。”
- 读者情绪：他真以为资源是自己挣来的？
- 回收方式：品牌方官宣沈确，艾特段旻发侵权警告。

### 按钮 6：鸠占鹊巢

- 触发句：“你就从这个家里滚出去。”
- 读者情绪：住在女主房子里让女主滚？
- 回收方式：父亲揭露房子和股份归属。

### 按钮 7：白眼狼不认错

- 触发句：“我没有错。是她欠我的。”
- 读者情绪：不用等悔悟，让他彻底断职业生涯。
- 回收方式：全网嘲讽、后援会解散、事业断裂。

## 3. 爽点循环模型

```text
羞辱/误判
→ 女主沉默或短句回应
→ 女主执行具体动作
→ 第三方数据/官宣/法律反馈
→ 反派破防并继续误判
→ 更高层级清算
```

### 原文示例

1. 段旻嫌女主老。
2. 女主“没回”，取消千万订单。
3. 沈确直播破亿。
4. 段旻粉丝网暴。
5. 女主法务介入。
6. 段旻误签合同。
7. 品牌官方打脸。
8. 段旻法庭败诉。

## 4. 付费卡点设计

### 卡点 A：段旻直播没女主撑场

- 触发：女主不去捧场。
- 未解决问题：没了女主，段旻还能不能稳住顶流？
- 读者期待：直播数据断崖。

### 卡点 B：沈确八点开播

- 触发：女主把资源给沈确。
- 未解决问题：沈确能不能接住这泼天富贵？
- 读者期待：对家起飞，段旻难堪。

### 卡点 C：段旻粉丝网暴女主

- 触发：段旻暗示女主纠缠。
- 未解决问题：女主会忍吗？
- 读者期待：法务和证据入场。

### 卡点 D：段旻误签合同

- 触发：他以为合同给自己，签名并发海报。
- 未解决问题：品牌方会怎么回应？
- 读者期待：官微公开打脸。

### 卡点 E：继妹让女主滚出家

- 触发：夏姿软逼女主道歉并索要股份。
- 未解决问题：这个家到底谁说了算？
- 读者期待：产权真相揭露。

### 卡点 F：段旻公司求复合

- 触发：段旻以为女主只是想恋爱。
- 未解决问题：女主会不会动摇？
- 读者期待：保安拖走。

### 卡点 G：侵权案开庭

- 触发：段旻指认女主设局。
- 未解决问题：法律认不认他的阴谋论？
- 读者期待：判决压死。

## 5. 留存机制

### 每 800-1200 字小爆点

- 群消息取消订单。
- 直播热搜。
- 粉丝网暴。
- 沈确护主。
- 合同误签。
- 品牌官宣。
- 父亲扇继妹。
- 保安拖段旻。
- 法庭判决。
- 继妹直播失败。

### 每 2500-3500 字大爆点

1. 沈确直播破纪录，段旻取消直播。
2. 品牌方官微宣布沈确并警告段旻侵权。
3. 父亲揭露房子和夏氏股份归属。
4. 法庭判决段旻赔偿与公开道歉。
5. 沈确与女主的新秩序补偿。

## 6. 读者期待管理

### 必须及时满足

- 女主被羞辱后，1-2 场内必须有实质反击。
- 段旻每次嘴硬后，必须出现可量化损失。
- 沈确拿到资源后，必须用成绩证明不是软饭。
- 继妹越界后，必须被更高权力压回去。

### 可以延迟满足

- 女主真实资产归属，可中段揭。
- 段旻最终职业结局，可后段判决后揭。
- 沈确情感补偿，可在事业线成功后逐步加。

### 不能悬空

- 七百万投入必须回收为证据或舆论反转。
- 粉丝网暴必须进入法务线。
- 合同误签必须有官方回应。
- 继妹索要股份必须有产权清算。
- 段旻求复合必须被明确拒绝。

## 7. 情绪释放曲线

| 阶段 | 情绪 | 释放方式 |
|---|---|---|
| 0-15% | 憋屈、愤怒 | 年龄羞辱 + 撤单 |
| 15-35% | 初爽 | 段旻直播寒酸 + 沈确破亿 |
| 35-50% | 二次愤怒 | 网暴升级 + 段旻纵容 |
| 50-65% | 强爽 | 品牌官微打脸 + 律师函 |
| 65-80% | 家庭爽 | 继妹索股份 + 产权揭露 |
| 80-92% | 终极爽 | 保安拖走 + 法庭判决 |
| 92-100% | 松弛补偿 | 沈确事业成功 + 奶茶与未来 |

## 8. 平台适配结论

这篇适合番茄的原因：

- 开篇三段内爆点足够强。
- 女主反击动作非常具体。
- 每个反派损失都可量化。
- 对话冲突密集，适合连载切章。
- 有年下补偿但不喧宾夺主。
- 家庭线提供中后段新冲突，避免单一直播线疲软。

改编时最重要的不是复制直播题材，而是复制“被轻慢的供养者收回资源，并把资源投向更值得的人”这台读者发动机。
