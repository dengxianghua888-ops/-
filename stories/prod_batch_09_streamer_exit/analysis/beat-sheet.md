# Beat Sheet：源文节拍拆解

> 段落编号为按源文叙事顺序归纳的证据锚点，引用原文关键句作为定位。情绪强度 1-10；信息差为读者/女主/反派之间的认知差。

## Beat 1：七百万供养与年龄羞辱

- 位置：开篇至“既然段旻嫌弃我丢人，那我就不继续缠着他了。”
- 原文证据：
  - “我捧了段旻三年……前后砸了快七百万。”
  - “人老了花再多钱也没用。”
  - “榜一是个更年期老女人……你知道是谁吗？”
  - “顺手把……万年老二抬上了首页推荐位。”
- 情绪强度：9.5
- 信息差：
  - 段旻与继妹以为女主只是卑微榜一。
  - 读者立刻知道女主有资源调度权。
- 读者期待：女主立刻撤资，让段旻数据断崖。
- 章尾钩功能：以“我不继续缠着他了”反讽收束，吊起“她会怎么不缠”的期待。
- 机制：M3 / M6
- Hook 功能：完成 H1 极端冲突与即时反击。

## Beat 2：取消千万订单，选中沈确

- 位置：“低头在群里发了条消息：段旻那个千万订单，取消，换人。”至“就沈确吧。”
- 原文证据：
  - “段旻那个千万订单，取消，换人。”
  - “出道十年，前七年跟段旻势均力敌，直到三年前段旻遇见了我。”
  - “是沈确礼貌询问我是否要帮助……自己站在门外守了二十分钟。”
- 情绪强度：8.8
- 信息差：
  - 女主知道沈确曾有实力且有人品。
  - 段旻不知道自己最大资源已被撤走。
- 读者期待：沈确被重新扶起来，段旻第一次摔跤。
- 章尾钩功能：“就沈确吧”是资源换位卡点。
- 机制：M3 / M6 / M5
- 执行要点：反击动作必须具体为群消息、订单、换人。

## Beat 3：段旻公开否认，女主不解释

- 位置：饭局继续至洗手间冲突。
- 原文证据：
  - 夏姿软问：“怎么没见你们说话？”
  - 段旻：“不认识。”
  - “三年砸了七百万，换来一句不认识。”
  - 段旻：“你再这样无底线纠缠我，我会报警。”
- 情绪强度：9.2
- 信息差：
  - 段旻以为女主会继续解释讨好。
  - 女主已开始撤资源，但段旻不知道。
- 读者期待：段旻的“不认识”被女主原句回敬。
- 章尾钩功能：将羞辱债升级为公开否认债。
- 机制：M3 / M5
- 关键镜像：后续女主说“段旻直播，我为什么要捧场？我跟他又不认识。”

## Beat 4：直播未捧场，段旻数据寒酸

- 位置：段旻七点直播至“最寒酸直播”热搜。
- 原文证据：
  - “每次他直播，我都会提前半个小时进去等着，开场先刷九十九个嘉年华热场。”
  - “段旻直播，我为什么要捧场？我跟他又不认识。”
  - “段旻下播后，‘最寒酸直播’话题冲上热搜。”
- 情绪强度：8.7
- 信息差：
  - 粉丝才意识到段旻的数据依赖女主和品牌方。
  - 段旻仍以为自己高高在上。
- 读者期待：沈确直播对比打脸。
- 章尾钩功能：热搜是第一轮公开处刑。
- 机制：M3 / M6
- 爽点：女主用段旻“不认识”原逻辑停止捧场。

## Beat 5：沈确直播破亿，段旻取消直播

- 位置：沈确八点带货至直播结束热搜第一。
- 原文证据：
  - “今晚八点带货直播，粉丝折扣甚至比从前段旻直播间还要低半折！”
  - “段旻的团队发文取消了今晚的直播。”
  - “流水开始跳表，三千万，五千万，八千万，过亿的那一瞬间。”
  - 沈确：“谢谢棉棉姐，谢谢……”
- 情绪强度：9.0
- 信息差：
  - 外界猜测沈确攀上金主，但女主知道这是资源重配。
  - 段旻失去女主后没有独立撑场能力。
- 读者期待：段旻粉丝会如何破防，女主如何应对舆论。
- 章尾钩功能：沈确起势与段旻失声形成强对照。
- 机制：M6 / M5
- 执行要点：数据必须量化，不能只说“很成功”。

## Beat 6：粉丝网暴，段旻纵容，沈确公开维护

- 位置：私信爆炸至法务部拟律师函。
- 原文证据：
  - “不要脸的贱女人……马上手写道歉信录视频道歉。”
  - 段旻：“有些粉丝花点钱就觉得主播该跟她怎么样。说实话，挺吓人的。”
  - “我的照片被人扒出来……p上遗照。”
  - 沈确：“棉棉姐是我最重要的支持者……我不允许任何人侮辱她。”
- 情绪强度：9.4
- 信息差：
  - 段旻认为污名化能逼女主回头。
  - 女主已经准备法务清算。
- 读者期待：女主别只发律师函，要让段旻付出实质代价。
- 章尾钩功能：网暴越线引出“不好聚好散”的升级。
- 机制：M5 / M6
- 关键功能：沈确第一次完成情绪补偿，和段旻冷暴力对照。

## Beat 7：奢侈品合同误签，段旻擅自官宣

- 位置：女主约品牌方签合同至段旻发新品发布会海报。
- 原文证据：
  - “我作为传媒公司的老板约两方来公司线下签合同。”
  - 夏姿软：“你当面跟他道个歉……这件事就过去了。”
  - 段旻“接过来毫不犹豫的签了自己的大名。”
  - “是一张海报，上面写着新品发布会，今晚八点。”
- 情绪强度：9.1
- 信息差：
  - 段旻以为合同是给自己的补偿。
  - 女主知道合同本来属于沈确，段旻签署与宣传会构成侵权。
- 读者期待：品牌方官宣并打脸段旻。
- 章尾钩功能：假海报制造付费级卡点。
- 机制：M2 / M6
- 注意：这里近似“死环载体”，但不是完整 M1，因为没有显式二选一死环陈述。

## Beat 8：品牌官微打脸，律师函压下

- 位置：沈确与段旻同时预告至品牌方两条微博。
- 原文证据：
  - “到底谁发新品？沈确还是段旻？”
  - 品牌方：“欢迎本次新品预售发布人@沈确。”
  - 品牌方艾特段旻：“未经授权使用我方品牌名义进行宣传……已构成侵权。”
- 情绪强度：9.6
- 信息差：
  - 公众疑惑被官方公告一次解开。
  - 段旻仍以为女主能发声明替他兜底。
- 读者期待：段旻电话破防，女主冷静列证据。
- 章尾钩功能：第三方背书打脸，爽点公信力极强。
- 机制：M2 / M6 / M3
- 爽点属性：官方公告比女主自证更有杀伤力。

## Beat 9：电话对峙，证据链浮出

- 位置：段旻来电至女主挂断。
- 原文证据：
  - 段旻：“现在立刻发声明说合同是误会……你这辈子都别想得到我的原谅！”
  - 女主：“我笑你到现在还没搞清楚状况。”
  - “品牌方已经发了律师函，侵权事实清楚。”
  - “我给你花的每一分钱，都有转账记录。”
- 情绪强度：9.3
- 信息差：
  - 段旻还把“原谅”当筹码。
  - 女主握有完整转账、邮件与法务证据。
- 读者期待：团队道歉声明是否翻车，段旻会继续嘴硬吗。
- 章尾钩功能：证据链即将公开，压迫感上升。
- 机制：M3 / M6
- 金句功能：“没搞清楚状况”是权力关系倒转句。

## Beat 10：沈确破纪录并签终生合同

- 位置：段旻团队道歉至沈确递终生劳动合同。
- 原文证据：
  - “最终成交额打破了平台单场直播销售记录。”
  - 沈确：“没有您，就没有我的今天。”
  - “这是一份终生劳动合同。”
  - “我跟段旻那个狼心狗肺的不一样。”
- 情绪强度：8.6
- 信息差：
  - 女主原本只是商业选择，沈确却给出长期忠诚承诺。
  - 读者看到段旻失去的尊重被沈确补回。
- 读者期待：家庭线会不会继续逼女主交出资源。
- 章尾钩功能：事业补偿后切回家庭冲突。
- 机制：M5
- 作用：缓冲复仇强度，提供甜宠补偿。

## Beat 11：继妹索要股份，产权真相揭开

- 位置：女主回家至父亲揭露房产和夏氏归属。
- 原文证据：
  - 夏姿软：“否则你就从这个家里滚出去！”
  - 夏姿软：“你手上夏氏的股份，分一半给我妈。”
  - 父亲：“这套房子，写的是棉棉的名字。”
  - “夏氏集团，是棉棉的母亲一手创办的。她去世后，所有股份都留给了棉棉。”
- 情绪强度：9.7
- 信息差：
  - 继妹以为自己能代表夏家索取股份。
  - 真相是她连住处和姓氏都是被收留。
- 读者期待：继妹母女被赶出核心家庭。
- 章尾钩功能：家庭权力关系彻底倒置。
- 机制：M2 / M6
- 爽点：从直播行业升维到家庭资产清算。

## Beat 12：段旻求复合式纠缠，保安拖走

- 位置：三天后沈确起势至段旻公司纠缠。
- 原文证据：

  - 女主：“保安！”
  - 女主：“我对你没兴趣。”
- 情绪强度：8.9
- 信息差：
  - 段旻仍相信女主爱他入骨。
  - 女主早已把他从情感对象降级为风险人物。
- 读者期待：段旻最后一层自尊如何被法律压碎。
- 章尾钩功能：保安拖走完成情感断联。
- 机制：M5 / M3
- 关键反讽：段旻把女主撤资误读为吃醋，暴露自恋底层逻辑。

## Beat 13：侵权案开庭，段旻法庭失控

- 位置：三个月后开庭至判决结果。
- 原文证据：
  - “是夏棉故意设局害我！”
  - “你毁了我，你毁了我你知不知道！”
  - “五百万赔偿，公开道歉，全网置顶三十天。”
  - “一瞬间，他的肩膀塌了。”
- 情绪强度：9.8
- 信息差：
  - 段旻坚持阴谋论。
  - 法庭只认侵权事实和证据。
- 读者期待：他是否会道歉，公众如何评价。
- 章尾钩功能：司法判决给主线复仇盖章。
- 机制：M6 / M3
- 高潮功能：从流量审判进入法律审判。

## Beat 14：余波清算与新秩序

- 位置：法院后至结尾。
- 原文证据：
  - 段旻：“我不会道歉的。我没有错。是她欠我的。”
  - “段旻的职业生涯彻底断了。”
  - “夏姿软去了一家小公司做文员，月薪六千。”
  - “窗外的阳光正好，桌上的芋泥奶茶还是热的。”
  - 女主回沈确：“好。”
- 情绪强度：8.2
- 信息差：
  - 段旻永远不认错，读者不需要等他悔悟。
  - 女主已经从旧秩序抽身。
- 读者期待：结尾获得松弛感，不是复合，而是未来可期。
- 章尾钩功能：最终钩不再是冲突，而是情绪补偿。
- 机制：M5 / M8轻度
- 收束：不走道德模糊，走直接爽文后的温暖补偿。
