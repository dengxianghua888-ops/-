## 2. 句式节奏

### 主节奏：短句推进 + 对话打脸

原文不是大段抒情，而是用一连串短动作推进：

- “我没回。”
- “群里安静了三秒。”
- “我没再看了。”
- “我直接挂断了电话。”
- “我笑了。”

这类句子承担三个作用：

1. 表现女主冷静。
2. 快速切场。
3. 给下一句反击留顿点。

### 爽点处节奏

爽点常用“动作—结果—公开反馈”三拍：

- 动作：“段旻那个千万订单，取消，换人。”
- 结果：“最寒酸直播”话题冲上热搜。
- 反馈：“段旻的粉丝哀嚎着让我回来。”

改编必须保留这种因果速度，不能用长心理描写稀释。

## 3. 对话 DNA

### 对话占比

- 约 45%-50%。
- 对话多为冲突性短句，而非闲聊。
- 反派对话承担“误判暴露”功能。
- 女主对话承担“降温反击”功能。

### 女主话术

女主语气冷、短、少解释：

- “我跟他又不认识。”
- “你在教我做事？”
- “我闹？”
- “我笑你到现在还没搞清楚状况。”
- “我对你没兴趣。”
- “你的人，自己处理吧。”

女主不主动长篇控诉。她的长句只在列证据时出现，例如转账记录、律师函、侵权事实。

### 段旻话术

段旻的语言核心是自恋和反咬：

- “你再这样无底线纠缠我，我会报警。”
- “我能拿下这个合同，是我的能力。”
- “你这辈子都别想得到我的原谅。”
- “你不就是想跟我谈恋爱吗，可以。”
- “我没有错。是她欠我的。”

他的每句话都要暴露“享受资源却否认资源来源”的逻辑。

### 夏姿软话术

夏姿软的语言核心是挑衅、越界、借势：

- “姐，他说他榜一是个更年期老女人……”
- “你为了让段旻吃醋，竟然做到这个地步。”
- “否则你就从这个家里滚出去！”
- “你手上夏氏的股份，分一半给我妈。”

她的台词必须一步步从炫耀男主播升级到索要资产。

### 沈确话术

沈确的语言核心是感恩、专业、克制：

- “谢谢棉棉姐，谢谢……”
- “棉棉姐不是我的金主，她是我最重要的合作伙伴。”
- “没有您，就没有我的今天。”
- “我会的，我绝不会让您失望。”
- “今晚直播，我紧张。您能来现场吗？”

注意：沈确不是油腻告白，而是职业尊重叠加小心翼翼的情绪价值。

## 4. 叙事视角

- 第一人称女主视角。
- 女主掌握核心资源，但前期不向反派解释。
- 读者与女主共享关键真相，反派处于误判中。
- 叙述保持冷静，靠他人失态制造戏剧性。

典型结构：

1. 反派羞辱。
2. 女主不解释。
3. 女主做一个平台/商业动作。
4. 反派误判升级。
5. 第三方公告或数据打脸。

## 5. 物件与平台动作

原文情绪很少悬空，几乎都落在具体物件或动作上。

| 情绪 | 承载物 |
|---|---|
| 供养债 | 七百万、嘉年华、订单 |
| 资源权力 | 群消息、首页推荐位、品牌方 |
| 舆论压迫 | 热搜、粉丝广场、私信、微博 |
| 法务清算 | 律师函、转账记录、邮件往来、法院判决 |
| 家庭权力 | 房子、股份、合同 |
| 情绪补偿 | 计划表、奶茶、兔子表情包 |

改编时，每个情绪转折必须有类似承载物。

## 6. 金句模式

### 回旋金句

- “我跟他又不认识。”
- “你不能因为我帮了你三年，就觉得我欠你的吧？”
- “那现在，就让他用自己的本事，渡过这个难关吧。”

### 打脸金句

- “我笑你到现在还没搞清楚状况。”
- “这个家，从来都是棉棉说了算。”
- “我对你没兴趣。”

### 补偿金句

- “棉棉姐不是我的金主，她是我最重要的合作伙伴。”
- “没有您，就没有我的今天。”

改编要求：每 1200-1600 字至少出现一句可截图传播的短金句。

## 7. 情绪温度控制

女主温度：

- 开篇：受伤但不哭。
- 中段：冰冷、清算、少解释。
- 后段：松弛、可被沈确细节逗笑。
- 结尾：不是复仇狂喜，而是“旧事过去，未来还长”。

段旻温度：

- 开篇：冷漠高傲。
- 中段：恼怒反咬。
- 后段：自恋求复合。
- 法庭：崩溃但不认错。

沈确温度：

- 前期：被压三年，有礼貌。
- 中段：专业起势，公开维护。
- 后期：忠诚、细节、轻甜。

## 8. 禁止偏移

- 禁止把女主写成内心反复崩溃，原文女主最大魅力是“我不解释，我换人”。
- 禁止让段旻变成聪明反派，他的爽点来自一次次误判。
- 禁止把沈确写成纯恋爱脑，他必须先交成绩。
- 禁止用“空气凝固”“不禁”“命运”等空泛句。
- 禁止把法律和商业动作写虚，必须有官微、合同、律师函、判决等实体。
