## 2. 张力债明细

### 债 1：七百万供养债

- 建债证据：“前后砸了快七百万。”
- 加息证据：
  - “新品上架，去拍。”
  - “他从不加我好友。”
  - “甚至线下见面……全当不认识我。”
- 反派误判：段旻以为这是女主自愿纠缠，不是商业扶持。
- 还债证据：
  - “段旻那个千万订单，取消，换人。”
  - “我给你花的每一分钱，都有转账记录。”
- 爽点性质：资源账清算。
- 改编要求：必须保留一个高额、可追溯、可撤回的投入数字。

### 债 2：年龄羞辱债

- 建债证据：“人老了花再多钱也没用。”
- 加息证据：“榜一是个更年期老女人。”
- 反派误判：段旻以为女主会因为自卑继续砸钱求关注。
- 还债证据：
  - 女主转捧“更年轻的弟弟”沈确。
  - 沈确公开尊重女主：“她是我最重要的合作伙伴。”
- 爽点性质：羞辱反向补偿。
- 改编要求：年龄羞辱不能被弱化成普通冷落，否则标题爽点损失。

### 债 3：不认识债

- 建债证据：
  - 夏姿软：“怎么没见你们说话？”
  - 段旻：“不认识。”
- 加息证据：“你再这样无底线纠缠我，我会报警。”
- 还债证据：“段旻直播，我为什么要捧场？我跟他又不认识。”
- 爽点性质：M3 金句回旋。
- 改编要求：必须设计一句反派前期说过的冷话，后期由女主原结构回敬。

### 债 4：直播数据债

- 建债证据：“每次他直播，我都会提前半个小时进去等着，开场先刷九十九个嘉年华热场。”
- 加息证据：段旻直播时仍不点女主评论。
- 还债证据：
  - “‘最寒酸直播’话题冲上热搜。”
  - “段旻的峰值甚至还没有三线主播高。”
  - 沈确“过亿的那一瞬间，所有人沸腾了。”
- 爽点性质：可量化塌房。
- 改编要求：必须用数据呈现反派失去资源的后果。

### 债 5：粉丝网暴债

- 建债证据：
  - 段旻：“有些粉丝花点钱就觉得主播该跟她怎么样。”
  - 粉丝骂“不要脸的贱女人”“水性杨花”。
- 加息证据：“我的照片被人扒出来。故意丑化，p上遗照。”
- 还债证据：
  - “法务部很快拟好律师函。”
  - “我的法务团队已经整理好所有证据，明天一早就会送到法院。”
- 爽点性质：舆论暴力转法律清算。
- 改编要求：网暴一旦越线，必须进入法务，不可只靠骂回去。

### 债 6：合同误判债

- 建债证据：段旻“接过来毫不犹豫的签了自己的大名。”
- 加息证据：
  - 假海报：“新品发布会，今晚八点。”
  - 段旻微博挂女主：“你就几次三番想毁了我的事业？”
- 还债证据：
  - 品牌方：“欢迎本次新品预售发布人@沈确。”
  - 品牌方艾特段旻：“未经授权……已构成侵权。”
- 爽点性质：第三方官方打脸。
- 改编要求：合同类爽点必须有官方背书，不要只让女主口头解释。

### 债 7：继妹越界债

- 建债证据：
  - “你现在马上去求段旻原谅！”
  - “否则你就从这个家里滚出去！”
  - “你手上夏氏的股份，分一半给我妈。”
- 加息证据：夏姿软以为女主服软，提出三条要求。
- 还债证据：
  - 父亲：“这套房子，写的是棉棉的名字。”
  - “夏氏集团，是棉棉的母亲一手创办的。”
  - 父亲给后妈两个选择：“搬出去”或“离婚”。
- 爽点性质：产权清算。
- 改编要求：继妹必须有一次越界到资产层面的索取，才配被彻底打脸。

### 债 8：段旻求复合自恋债

- 建债证据：
  - “你不就是想跟我谈恋爱吗，可以。”
  - “我答应你，以后你就是我女朋友。”
- 加息证据：他低头要亲女主。
- 还债证据：
  - 女主：“保安！”
  - “我对你没兴趣。”
- 爽点性质：情感权力倒转。
- 改编要求：反派求复合不能写成深情，必须写成自恋和施舍感，方便女主彻底拒绝。

### 债 9：司法清算债

- 建债证据：段旻假海报侵权、粉丝网暴、公开挂女主。
- 加息证据：法庭上仍说“是夏棉故意设局害我”。
- 还债证据：
  - “五百万赔偿，公开道歉，全网置顶三十天。”
  - “段旻的职业生涯彻底断了。”
- 爽点性质：终局盖章。
- 改编要求：后段必须有不可逆后果，不能只停留在热搜嘲讽。

### 债 10：情绪补偿债

- 建债证据：段旻冷脸、不加好友、否认认识。
- 加息证据：段旻纵容粉丝辱骂女主。
- 还债证据：
  - 沈确：“谁要是再骂她一句，就是跟我沈确过不去。”
  - “两万七千字的计划表。”
  - “奶茶到了吗？我让跑腿加急送的，怕凉了。”
  - “今晚直播，我紧张。您能来现场吗？”
- 爽点性质：尊重补偿。
- 改编要求：补偿男的温柔必须建立在事业表现之后，否则会削弱大女主主线。

## 3. 张力升级路径

```text
个人羞辱
→ 直播资源撤回
→ 舆论网暴
→ 品牌合同侵权
→ 家庭资产索取
→ 情感纠缠失败
→ 法院判决
→ 余波降维
```

每一级都比上一级更公开、更有损失、更不可逆。

## 4. 未可删除的还债节点

- “取消千万订单，换沈确。”
- “段旻直播寒酸，沈确直播破亿。”
- “沈确公开维护女主。”
- “品牌官微官宣沈确并警告段旻。”
- “父亲揭露房产和股份归属。”
- “女主叫保安拖走段旻。”
- “法院判决五百万赔偿与置顶道歉。”
- “沈确用事业与细节提供结尾补偿。”

删除任一节点，都会造成对应情绪债无法足额偿还。
