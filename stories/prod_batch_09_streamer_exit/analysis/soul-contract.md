# Soul Contract：灵魂契约

## 1. 读者真正买的是什么

读者买的不是“女主换了一个更年轻的男人”，而是：

> 我真金白银捧你，你却嫌我老、嫌我丢人。那我不吵不闹，把给你的一切收回来，换给一个更值得的人。你失去的不是我的爱，是你赖以体面的全部资源。

这篇的灵魂不是恋爱复仇，而是**供养关系被白眼狼污名化后的资源清算**。

## 2. 女主灵魂底色

### 必须保留

- 有钱，但不是无脑砸钱。
- 有过好感，但不是恋爱脑。
- 被羞辱时受伤，但行动上非常清醒。
- 不靠嘴炮证明价值，而靠订单、品牌、法务、产权推进。
- 她不需要段旻后悔爱她，只需要段旻失去不该占有的资源。

### 原文证据

- “我之前的确对段旻有着说不清的好感。”
- “但远远不到什么活不下去的地步。”
- “我只是把原先给你的资源，收回而已。”
- “你不能因为我帮了你三年，就觉得我欠你的吧？”

### 禁止改写

- 禁止让女主为了刺激段旻而转捧沈确。
- 禁止让女主反复解释自己不是舔狗。
- 禁止让女主在段旻求复合时动摇。
- 禁止让女主最后靠沈确拯救人生。

## 3. 段旻灵魂底色

### 必须保留

段旻不是单纯冷酷，而是**把受益视为理所当然，把给予者污名化为纠缠者**。

他的核心罪名有三层：

1. 享受女主资源，却拒绝给予基本尊重。
2. 在继妹面前泄露并羞辱女主。
3. 资源断供后，仍认为女主欠他，甚至认为“答应恋爱”是施舍。

### 原文证据

- “新品上架，去拍。”
- “不认识。”
- “有些粉丝花点钱就觉得主播该跟她怎么样。说实话，挺吓人的。”
- “我答应你，以后你就是我女朋友。”
- “我没有错。是她欠我的。”

### 禁止改写

- 禁止给他童年创伤式洗白。
- 禁止让他真正意识到女主商业价值后诚恳道歉。
- 禁止让他主动承担粉丝网暴责任。
- 禁止让他结尾体面退场。

## 4. 沈确灵魂底色

### 必须保留

沈确是“资源被正确投放后产生的正反馈”。他证明女主不是只会砸钱，而是会识人、会用人、会扶持真正值得的人。

他要同时满足：

- 专业：计划表、选品、讲品、复盘。
- 感恩：公开承认女主价值。
- 维护：在女主被网暴时站出来。
- 轻甜：奶茶、表情包、请求女主到现场。

### 原文证据

- “两万七千字的计划表，精确到每一分钟该说什么话。”
- “棉棉姐不是我的金主，她是我最重要的合作伙伴。”
- “没有您，就没有我的今天。”
- “奶茶到了吗？我让跑腿加急送的，怕凉了。”

### 禁止改写

- 禁止让沈确一上来就暧昧调情。
- 禁止让他靠脸或年纪赢段旻。
- 禁止让他抢走女主的主线决策权。
- 禁止把他写成只会说“姐姐我爱你”的恋爱挂件。

## 5. 夏姿软灵魂底色

### 必须保留

夏姿软代表“鸠占鹊巢式误判”。她不是因为爱段旻才挑衅女主，而是借段旻证明自己比女主更受欢迎，再进一步索取夏家资产。

她的升级路径：

1. 炫耀段旻对自己温柔。
2. 替段旻逼女主捧场、道歉。
3. 借舆论污名女主。
4. 要求女主交出合同与股份。
5. 被产权真相击穿。

### 原文证据

- “姐，他说他榜一是个更年期老女人……”
- “马上撤回，给段旻公开道歉。”
- “否则你就从这个家里滚出去！”
- “你手上夏氏的股份，分一半给我妈。”

### 禁止改写

- 禁止把她写成单纯抢男人。
- 禁止让她真的拥有夏家核心资产。
- 禁止让她结尾过得比女主更体面。
- 禁止弱化“索要股份”这个越界顶点。

## 6. 爽点灵魂线

### 主线爽点

羞辱 → 撤资 → 对家起势 → 白眼狼塌房 → 法务判决 → 新秩序。

### 家庭爽点

继妹挑衅 → 逼女主道歉 → 索要股份 → 父亲揭产权 → 母女出局。

### 情绪补偿线

段旻冷暴力 → 沈确公开维护。  
段旻不加好友 → 沈确主动复盘。  
段旻嫌她老 → 沈确记得奶茶和现场陪伴。  
段旻说她欠他 → 沈确说“没有您就没有我的今天”。

## 7. 结尾契约

结尾必须让读者感觉：

- 段旻不是被女主“抢男人”毁掉，而是被自己的傲慢、侵权和不识好歹毁掉。
- 夏姿软不是输在不够漂亮，而是输在误判自己有资格索取。
- 女主不是靠爱情赢，而是靠收回资源、重建秩序赢。
- 沈确带来的温暖是奖励，不是救赎。

原文最后一句“而未来，还长着呢”提供的是松弛感。改编可换句子，但必须保留“旧账清完、新路打开”的情绪。
