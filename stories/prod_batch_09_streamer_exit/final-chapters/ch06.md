# 第6章

网暴后第二天，品牌会议室的长桌上摆着两份合同。

左边是旧版联名方案，封面写着陆呈姓名。

右边是新方案，顾凛版海报刚从打印机出来，珠宝贴在他扣住证据袋的手腕上，露得克制又清楚。

品牌总监翻到授权页：“许总，我们只认昼光项目主体。

陆呈个人没有任何联名授权，对吗？”

“对。”

我把试戴样品流转单推过去，“他手里的珠宝盒是样品，用途写明是拍摄物料，不含个人展示权。”

昼光商务在旁边补充：“旧物料今天全部回收。

未回收样品，我会让工作室签二次确认。”

会议屏幕忽然弹出直播切片。

陆呈开播了。

他坐在休息室，脸色比前几天差，手边却放着那只熟悉的珠宝盒。

弹幕问他是不是被品牌抛弃，他笑了一下，把盒子拿到镜头前。

“有些事，下周你们就知道了。”

粉丝立刻刷屏：哥哥还是联名男主！

他打开盒盖，钻石在直播灯下闪了一下。

品牌总监的脸沉下来：“他这是在暗示官宣？”

“录屏。”

我说。

商务已经点开录制软件：“开始了。”

顾凛坐在会议室末尾，一直没插话。

直到总监看向他，他才站起身。

“如果品牌担心舆论，我可以配合补拍一版不露脸手部物料，先让大家关注项目和作品。”

总监看了我一眼：“你的人很稳。”

“他是演员。”

我说，“不是我拿来赌气的工具。”

陆呈直播里还在继续。

“我从来不靠谁。”

他说，“资源是我自己争取的。

真正的合作方知道该选谁。”

我把顾凛版授权合同翻到签署页。

昼光公章落下。

品牌总监签字。

法务在旁边写下备注：陆呈直播涉嫌虚假宣传，待官宣后统一追责。

我把合同递给顾凛：“明天补拍海报。”

他接过去：“许总，我会按品牌要求交片。”

屏幕里，陆呈举着珠宝盒，对着弹幕许诺。

陆呈在直播间举起珠宝盒：下周，我会官宣高奢联名男主。
