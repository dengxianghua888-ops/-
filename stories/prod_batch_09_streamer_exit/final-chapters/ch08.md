# 第8章

官宣反转后当天傍晚，陆呈删了微博。

那条“谢谢等待”消失得很快，但截图已经躺在法务资料夹里，连发布时间、设备型号、评论转发数都截全了。

陆呈工作室发了声明。

“艺人从未主动宣称合作身份，相关解读均为营销号误会。”

品牌法务把声明转给我，只回了四个字：继续递函。

昼光法务办公室里，证据铺了半张桌。

第一份，直播录屏。

陆呈把珠宝盒举到镜头前，亲口说下周官宣高奢联名男主。

第二份，样品签收单。

签收人是陆呈助理，用途栏写明“项目拍摄试戴”，归还日期是本周五。

第三份，授权合同。

昼光与品牌双方签章，联名男主一栏是顾凛。

第四份，营销号付款记录。

这份最关键。

陆呈经纪人以为钱走了外包公司就查不到。

可工作室一个执行怕背锅，把付款截图发给品牌法务，备注里写着“陆呈联名预热通稿，先发十条”。

法务主任把聊天记录打印出来。

纸还热着，边角微微卷起。

“执行为什么愿意交？”

品牌法务说：“他手里有经纪人让他垫款的语音。

现在营销号被追责，他不想一个人扛。”

我点头：“把垫款语音也列入证据目录。”

律师把材料按时间线装订。

“许总，我们发两封。

一封给陆呈工作室，要求停止虚假宣传、公开澄清、赔偿品牌和昼光损失。

另一封给营销号，要求披露委托人。”

品牌法务补了一句：“品牌保留追偿违约损失的权利。”

我点头：“今天送达。”

与此同时，陆呈的商务报价表也传到了我邮箱。

两周前，他单条短视频报价六十万。

官宣反转后，三家品牌撤回询价，经纪人把报价降到二十二万，还没人接。

他没有看到这张表。

他在工作室里发火。

制片发来的现场音频里，他把手机拍在桌上：“删都删了，她还能拿我怎么样？

庆功微博重写，重点写我祝福顾凛，显得我大度。”

经纪人劝他：“律师函可能快到了。”

“吓唬谁？”

陆呈冷笑，“她喜欢我三年，真舍得告？”

门铃响了。

同城送达员站在陆呈工作室门口，让前台签收文件。

封面第一行是：律师函。

律师函送到陆呈工作室时，他正准备发第二条庆功微博。

律师函送达那一刻，他才发现自己蹭过的每一个热度都有价码。
