# 源文爆款基因拆解

## 一句话骨架
女主偶然撞见丈夫二婚，才知道自己和儿子早被他编造成死人；她潜入婚礼，一边补全五年双线婚姻的证据，一边在众目睽睽下“诈尸”，最后把婚礼砸成法庭前奏。

## 类型判断
- 主类型：家庭伦理反杀
- 副类型：婚姻背叛 / 婆家双标 / 法律清算 / 母子新生
- 爽点轴：公开打脸 + 账本清算 + 法律落锤
- 情感轴：不是“他不爱了”，而是“他把最差给我，把最好的给了别人，还顺手抹掉我和孩子”

## Hook 识别
- 命中：`H1 倒叙冲突式`
- 开篇证据：
  - “瑞阳终于苦尽甘来要再婚了。”
  - “前妻是个短命的，结婚没多久就死了。”
  - “明明我活得好好的，怎么就死了？”
- 生效原因：
  - 第一屏就抛出极端事实矛盾：活人听见自己“已死”。
  - 不是慢热铺垫，而是直接把“再婚/死亡/诈骗性身份抹除”三件事同时砸出。
  - 300 字内已经形成核心追问：他为什么敢这么干？新娘知道吗？公婆参与到什么程度？

## 标题公式识别
- 主命中：`T3 生死悖论式`
- 副效果：借用了 `T1 因果反转式` 的后半隐势
- 标题拆法：
  - 前半极端事件：“老公婚礼”
  - 后半悖论真相：“我才知道自己死去多年”
- 有效点：
  - “婚礼”是高公共性舞台。
  - “死去多年”制造最大信息差。
  - 标题已经承诺“身份回魂反杀”。

## 反转机制清单
### 1. M3 因果回旋反讽
- 落点：
  - 周瑞阳先抹掉女主身份，女主在婚礼上当众认领“合法妻子”身份。
  - 渣夫想用钱和“回归家庭”轻飘揭过，女主反手以夫妻共同财产和重婚罪追索到底。
- 关键句：
  - “你把我和儿子都诅咒死了，我难道不应该要个说法吗？”
  - “你花在徐万芳身上的每一分钱，都是我们夫妻共同财产。”
  - “第二，追究你的重婚罪，在场所有人都是证人。”
- 为什么爽：
  - 对方先把她从叙事、婚姻、财产里删掉；她再把对方从婚礼、体面、自由里删掉。

### 2. M5 温度反转曲线
- 落点：
  - 不是抽象背叛，而是大量“对照式偏爱”。
- 关键段：
  - 女主婚礼：便宜影楼、没戒指、老家塑料大棚。
  - 新娘婚礼：贵婚纱照、五星酒店、翡翠镯子、高定婚纱。
  - 女主怀孕闻烟就吐，他不戒；为新娘想要蜜月宝宝，他主动戒烟。
  - 女主怀孕时他不会熬粥；对新娘却“每天逼着我喝汤，还亲自熬”。
- 为什么爽痛并存：
  - 读者不是被“出轨”本身刺激，而是被“原来他有能力也有心思，只是不愿意给你”刺穿。

### 3. M6 多层递进反转
- 层级拆解：
  - Layer 1：街头听闻自己“已死”，丈夫竟要再婚。
  - Layer 2：现场探查，婆家全员共谋，资源配置极度双标。
  - Layer 3：丈夫五年双线婚姻被拆出，女主和儿子被编成“车祸去世”。
  - Layer 4：婚礼现场公开揭穿，新娘从优越感跌入被骗妻身份。
  - Layer 5：假证、财产追回、重婚定罪，情绪反杀升级为制度反杀。
- 强度来源：
  - 每一层不是同一个信息重复，而是从“情感背叛”一路升维到“身份犯罪”。

### 4. M1 死环反杀
- 落点偏后，属于法理死环而非文书死环。
- 关键句：
  - “你婚内出轨，伪造证件，停妻再娶——这桩桩件件，犯的都是重婚罪。”
  - “这么多人都看着呢。”
- 死环结构：
  - 如果婚礼与证件当真，他构成重婚。
  - 如果婚礼或证件是假，他又要承担伪造证件与财产赠与无效后果。
  - 无论选哪边，婚礼现场见证、宾客证词、财产流向都把他锁死。
- 机制价值：
  - 把婚礼闹剧升级成不可逆的司法闭环，避免只停在口头出气。

## 情绪推进总图
1. 诡异感：我活着，为什么别人说我死了？
2. 寒意：丈夫真的在办二婚。
3. 刺痛：婆家并非被骗，而是在踩着我笑。
4. 心碎：他把最好的都给了另一个女人。
5. 暴怒：他甚至把儿子也写死了。
6. 爽点：女主抢麦“老公，结婚这么大的事怎么不告诉我一声？”
7. 加码爽点：新娘也不是胜利者，而是被骗者。
8. 冷爽：财产、假证、重婚、离婚，一项项落地。
9. 补偿：母子新家，叙事权回到女主手里。

## 原文真正卖点
- 不是“小三上位失败”，而是“正妻在丈夫写好的死亡剧本里复活”。
- 不是单纯抓奸，而是当众夺回名分、钱、孩子和法律正当性。
- 不是哭诉受害，而是把每一处差别待遇都变成控诉证据。
- 第三者不是单纯反派，她在后段变成被骗证人，扩大渣夫孤立感。
- 结局没有回头路，彻底切断“为了孩子忍一忍”的常见狗血泄压口。

## 必须保留的爆点组件
- 活人听见自己已死。
- 婚礼现场潜入式观察，边看边补刀式对照。
- 公婆“白送的丧门星 / 八十八万彩礼 / 金条改口费”这组双标证据。
- 渣夫“不是不会爱，是把会爱那部分给了别人”的细节清单。
- 女主上台第一句必须一锤定音式揭身份。
- 新娘从甜蜜优越到认知坍塌的过程。
- “假结婚证”这一层硬反转。
- 结尾必须有法律结果，不可只靠婚礼散场。
- 母子新家必须作为情绪补偿收尾。

## 可替换但不影响机制的表层素材
- 婚礼消费品类：镯子、婚纱照、金条都可换。
- 双标细节载体：戒烟、做饭、汤粥、戒指都可换成同等级“偏爱证据”。
- 法律程序细节可根据设定调整，但必须保留“财产追回 + 重婚定罪/同级法律后果”。
