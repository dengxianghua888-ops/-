# Tension Ledger

## 总体张力模型

源文张力由四条账本同时滚动：

1. 怀孕信息差：读者知道，男主不知道。
2. 身体二次伤害：尸检每推进一步，情绪债加一层。
3. 证据反噬：男主越讲证据，越接近被证据审判。
4. 赎罪是否足额：男主崩溃后，读者继续衡量代价够不够。

## 信息差管理

### 必须提前给读者的信息

- 女主怀孕。
- 男主不知道。
- 林薇薇有问题。
- 男主只相信证据。
- 女主准备纪念日惊喜。

### 必须延迟给角色的信息

- 胎儿存在：延迟到子宫剪开。
- 林薇薇罪证：延迟到电话诈供。
- 男主真实爱意深度：延迟到崩溃和花房赎罪。
- 女主放下恨意：延迟到五年祭日。

## 张力最高的三个“不可提前释放”点

1. 胎儿显形。
   - 不能在尸表阶段被发现。
   - 不能用产检报告提前让男主知道。
   - 必须由男主亲手剪开子宫后看见。

2. 男主崩溃。
   - 不能在尸体刚出现时崩。
   - 前面越冷，后面越疯。
   - 崩溃必须有职业反差：稳手变抖手、法医变疯子。

3. 女主释怀。
   - 不能在男主第一次道歉时释怀。
   - 不能在凶手伏法时释怀。
   - 必须经过长期赎罪后才疲惫放下。

## 改编风险预警

| 风险 | 会损害什么 | 修复方式 |
|---|---|---|
| 开篇铺垫太久 | Hook强度 | 第一段内写死、怀孕、亲密伤害 |
| 男主太早流泪 | 温度反转 | 前40%保持冷静专业 |
| 尸检太轻描淡写 | 身体债不足 | 至少保留白布、刀、器官、子宫四个动作点 |
| 医学细节太猎奇 | 情绪稀释 | 每个专业动作后接亲密回忆或灵魂反应 |
| 凶手惩罚太轻 | 外部正义缺口 | 明确供认、判刑或社会性毁灭 |
| 赎罪太短 | 迟来悔悟廉价 | 拉长时间跨度，给空间物象和生活细节 |
| 结尾太甜 | BE灵魂丢失 | 保留死亡、血、空摇篮、代价余味 |

## 最小保真张力骨架

若改编篇幅压缩，至少保留以下8个张力节点：

1. 女主死且怀孕。
2. 男主决定亲自主刀。
3. 男主用专业术语冷静处理妻子尸体。
4. 女主回忆他曾经温柔。
5. 男主剖到子宫发现胎儿。
6. 男主崩溃并意识到“证据”反噬。
7. 凶手被诈供或证据链击溃。
8. 男主长期赎罪，女主最后复杂放下。
