# Style DNA

## 叙事语体

- 第一人称死后旁观。
- 冷白、克制、刀口式叙述。
- 情绪不靠大段控诉，而靠器械、伤口、白布、灯光、手套、录音、标签等物理物件承载。
- 叙述节奏采用“专业动作 → 亲密回忆 → 当前冷酷 → 灵魂无力”的循环。

## 句式特征

### 1. 短句定锤

常用单句完成不可逆事实。

- “可我还是死了，一尸两命。”
- “他食言了。”
- “现在，证据来了。”
- “太晚了。”
- “尘埃落定。”
- “真相大白。”

执行要点：改编中关键爆点要用短句落地，不要用长解释稀释。

### 2. 反复递进

通过重复词和并列结构堆压迫。

- “没有爱，没有痛，没有一丝一毫的私人情绪。”
- “一根，又一根。”
- “震惊、悔恨、绝望……”
- “每一天，每一个小时，每一分，每一秒。”

执行要点：适合男主崩溃、女主无力、赎罪年限等场景。

### 3. 专业冷词切割亲密情绪

- “死者，安然，女，28岁。”
- “腹部平坦，未见异常隆起。”
- “心脏，重约300克。”
- “子宫，大小形态正常……”

执行要点：职业术语越冷，亲密回忆越痛；专业词不能删。

### 4. 问句用于灵魂控诉

- “江川，你真的，爱过我吗？”
- “你现在还能听到吗？”
- “这个结论，需要你用这么残忍的方式来证明吗？”
- “谁让你，用这种方式，来赎罪了？”

执行要点：问句不要过密，只在情绪转折点使用。

## 段落结构

典型段落链：

1. 当前动作：男主做尸检/整理器械/拿起刀。
2. 女主感受：灵魂颤抖、无声苦笑、冷冷旁观。
3. 回忆插入：曾经温柔或承诺。
4. 现实反打：现在他用相同的手做残忍事。
5. 短句落锤：他食言了 / 太晚了 / 证据来了。

示例：

- 当前：“他拿起镊子，轻轻拨开我额前被血粘住的头发。”
- 回忆：“我记起有一次看他出现场的纪录片……他说：‘我永远不会让你看到这种场面的。’”
- 反打：“他不仅要让我看到，还要亲手为我……开颅。”
- 落锤：“他食言了。”

## 意象系统

| 意象 | 功能 | 原文证据 | 改编等价 |
|---|---|---|---|
| 白布 | 死亡、体面被剥夺 | “白布被猛地掀开。” | 手术单、尸袋、隔离布 |
| 解剖刀 | 男主信仰与伤害合一 | “拿起那把……解剖刀。” | 手术刀、鉴定刀、病理切片刀 |
| 无影灯 | 冷白审判场 | “调试着无影灯的角度。” | 手术灯、审讯灯、检查灯 |
| 子宫 | 信息差炸弹 | “他的镊子，伸向了它。” | 胎盘、产检报告、胎心记录 |
| 组织剪落地 | 理性防线破裂 | “啪嗒。” | 器械落地、笔掉落、录音笔摔落 |
| 向日葵 | 死亡后的温柔赎罪 | “种满了向日葵。” | 白玫瑰、栀子花、婴儿房灯 |
| 空摇篮 | 不可逆失去 | “轻轻地，摇晃着那个空无一人的摇篮。” | 空婴儿床、未拆封童鞋、生日蛋糕 |

## 金句模式

### 主题金句

- “他只相信证据。”
- “现在，证据来了。”
- “你不是不懂人心。你只是，从来不屑于把你的这份‘懂’，用在我的身上。”
- “他亲手为自己，打造的这座，华丽的坟墓。”
- “江川，欢迎回家。”

### 生成规则

- 金句必须从剧情动作中长出来。
- 禁止抽象大词堆砌，如“命运残忍”“宿命轮回”。
- 优先使用回旋句：前文男主说“证据”，后文女主用“证据”审判他。

## 对话风格

- 男主前期：短、冷、职业化。
  - “让他们说。”
  - “我只相信证据。”
  - “不要在这里，干扰我的工作。”
- 男主后期：破碎、重复、低幼化。
  - “放回去……放回去！！”
  - “宝宝……”
  - “安然，我好想你。”
- 女主灵魂：冷看、克制、偶尔尖锐。
  - “江川，现在才说对不起，太晚了。”
  - “这，才是我对他，最恶毒的报复。”

## 禁止风格漂移

- 禁止沙雕吐槽。
- 禁止把尸检写成猎奇医学科普。
- 禁止用过量抒情替代动作。
- 禁止让女主灵魂频繁哭喊撒泼；她可以痛，但主要是冷。
- 禁止男主前期过早露出崩溃，否则胎儿发现爆点失效。
- 禁止结尾变甜宠团圆，必须保留死亡和代价的阴影。
