# Reader Engine

## 目标读者

- 喜欢死后旁观、迟来深情、虐男火葬场的女性向短篇读者。
- 对“一尸两命”“怀孕真相”“丈夫亲手伤害妻儿”有强烈情绪反应的读者。
- 喜欢法医、证据链、凶手伏法、心理战诈供等强情节读者。
- 能接受BE或死后重逢，不要求现实HE的虐恋读者。

## 核心阅读驱动力

### 1. 信息差驱动

读者从开篇就知道女主怀孕，男主不知道。

- 读者问题：他什么时候知道？
- 原文延迟：尸表检验、手掌、胸腹、器官摘取后才到子宫。
- 效果：每一次专业动作都变成倒计时。

### 2. 反噬驱动

男主说“我只相信证据”，读者等他被证据审判。

- 读者问题：证据会以什么方式出现？
- 原文答案：孩子本身就是证据。
- 效果：主题爽点和情绪虐点合一。

### 3. 惩罚驱动

读者不满足于凶手伏法，还要男主偿债。

- 读者问题：他哭够了吗？他付出的代价够吗？
- 原文答案：辞职、毁掉事业空间、花房自囚五年、自杀。
- 效果：把“迟来深情”延长成长期惩罚。

### 4. 释怀驱动

女主从恨到放下，读者跟着判断“惩罚是否足额”。

- 读者问题：她会原谅吗？
- 原文答案：不是轻易原谅，而是五年后疲惫地说“够了”。
- 效果：避免廉价HE，保留BE余味。

## 爆款按钮

### 高刺激按钮

- 一尸两命。
- 法医丈夫亲自主刀。
- 胎儿在子宫中被发现。
- 男主把器官往回塞。
- 凶手电话里自爆。
- 解剖室改花房。
- 五岁生日给不存在的孩子过生日。
- 用解剖台碎片自杀。

### 高共情按钮

- 女主想保护肚子里的孩子。
- 女主想保留最后体面。
- 女主的直觉被男主否定。
- 男主曾经温柔承诺“不会让你看到这种场面”。
- 女主五年后说“惩罚够了”。
- 最后一句“欢迎回家”。

### 高记忆按钮

- “他只相信证据。”
- “腹部平坦，未见异常隆起。”
- “现在，证据来了。”
- “放回去！！”
- “华丽的坟墓。”
- “我来找你们了。”
- “江川，欢迎回家。”

## 读者厌恶雷区

- 男主过早知道怀孕。
- 女主灵魂能干预现实。
- 尸检过程被跳过或只用一句话概括。
- 林薇薇被轻飘带过，没有法律代价。
- 男主哭一场就获得原谅。
- 五年赎罪被缩成几天。
- 结尾变成现实复活团圆。
- 用搞笑或网络梗破坏冷白虐感。

## 改编转化公式

### 首章

必须在300字内完成：

1. 女主死亡。
2. 女主怀孕信息差。
3. 男主职业身份。
4. 男主亲手二次伤害的决定。

### 中段

必须持续交替：

- 专业动作冷酷化。
- 回忆温柔反衬化。
- 女主灵魂无力化。
- 男主理性信条强化。
- 胎儿发现倒计时。

### 高潮

必须做到：

- 胎儿出现具体可视。
- 男主身体反应崩塌。
- 职业能力瞬间失效。
- 语言从专业术语退化成重复哭喊。

### 后段

必须做到：

- 外部凶手伏法。
- 男主失去职业信仰。
- 赎罪空间物象化。
- 时间跨度拉长。
- 女主情绪从恨转为疲惫放下。

## 平台适配判断

- 番茄适配强项：标题直给、冲突极端、强情绪、强钩子、章节末反转明显。
- 潜在风险：尸检医学细节过密可能形成猎奇疲劳。
- 解决方式：医学细节服务情绪，不服务科普；每个术语后接女主回忆或男主崩溃。
