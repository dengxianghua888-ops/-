# Soul Contract

## 核心灵魂

这篇文的灵魂不是“丈夫误会妻子后悔”，而是：

> 一个只相信证据的男人，最终被他亲手剖出的证据审判；一个死去的女人，在无法阻止他伤害自己的过程中，看见他的爱、他的罪和他的迟来崩溃。

## 读者购买的不是剧情，而是四重情绪偿还

### 1. 委屈偿还

女主生前的直觉被男主否定。

- 原文债务：“她不是崇拜你，她是想占有你！”“拿出证据来。”
- 偿还方式：女主用死亡和孩子成为最血淋淋的证据。
- 不可替换点：男主必须曾经不信她，且不信的理由必须与后文反噬一致。

### 2. 身体偿还

女主死后仍被丈夫亲手二次伤害。

- 原文债务：掀白布、尸表检查、剖胸腹、取器官、剪开子宫。
- 偿还方式：男主亲眼看见自己亲手毁掉妻儿，精神崩塌。
- 不可替换点：必须是男主亲自动手，不可改成旁人尸检后转告。

### 3. 孩子偿还

孩子不是单纯虐点，而是全篇最大的证据炸弹。

- 原文债务：“那里有我和江川的宝宝，才三个月大。”
- 爆点偿还：“一个小小的、蜷缩着的、已经成形的生命……出现在了所有人的视野里。”
- 不可替换点：怀孕真相必须在男主最冷静、最专业的动作中被他亲手发现。

### 4. 余生偿还

凶手伏法只是外部正义，男主赎罪才是情绪主菜。

- 原文债务：男主的理性信仰伤害女主。
- 偿还方式：辞职、砸毁解剖室、花房自囚五年、自杀追随。
- 不可替换点：男主必须付出事业、信仰、生活结构和生命级代价。

## 不可动摇的情感契约

| 契约 | 必须兑现 | 违约风险 |
|---|---|---|
| 女主死后旁观 | 女主不能复活干预，只能看、听、痛、冷看 | 复活会毁掉M4无力感 |
| 男主亲手剖验 | 男主必须是二次伤害执行者 | 换成旁人会削弱反噬 |
| 怀孕信息差 | 读者知道，男主不知道 | 若男主早知道，胎儿爆点坍塌 |
| 理性反噬 | 男主的“证据”信条必须回旋打脸 | 若只是普通误会，主题变浅 |
| 迟来悔悟无效 | 道歉不能立刻获得原谅 | 轻易原谅会背叛读者怒火 |
| 足额赎罪 | 男主必须长期受罚 | 只哭一场不够偿债 |
| 结尾复杂 | 可以温柔，但不能轻松 | 甜宠HE会冲淡一尸两命 |

## 主角关系本质

### 女主安然

- 表层身份：被害妻子、孕妇、死者。
- 深层功能：证据本身、审判者、旁观灵魂。
- 情绪轨迹：
  1. 想保护孩子。
  2. 想保留体面。
  3. 对丈夫心寒。
  4. 第一次恨。
  5. 冷看崩溃。
  6. 想看他受罚。
  7. 五年后疲惫放下。
  8. 终局接住他的灵魂。

### 男主江川

- 表层身份：全球顶尖法医、丈夫。
- 深层功能：施害者、证据信仰者、被信仰反噬者。
- 情绪轨迹：
  1. 绝对冷静。
  2. 坚持公正。
  3. 胎儿发现后失控。
  4. 诈供凶手。
  5. 辞职砸毁信仰空间。
  6. 花房守墓五年。
  7. 自杀追随。
- 必须注意：他不是传统恶人，真正的罪是傲慢、冷漠、不信任，以及把职业信仰置于亲密感受之上。

### 林薇薇

- 表层身份：疯狂追求者/实习生。
- 深层功能：外部凶手、男主不信任妻子的引线。
- 情绪功能：承接读者直接愤怒，但不能抢走男主反噬主线。
- 惩罚要求：必须明确供认、伏法、长期失去自由。

## 主题句

- “他只相信证据。”
- “现在，证据来了。”
- “你不是不懂人心。你只是，从来不屑于把你的这份‘懂’，用在我的身上。”
- “你以为，毁掉的是我的尸体吗？不。是你亲手，解剖了我们的爱情，解剖了你自己的心。”

## 改编时的灵魂保真标准

合格改编必须让读者产生以下连续反应：

1. “她已经死了，还怀着孩子。”
2. “他怎么能亲手解剖她？”
3. “快发现孩子，快让他崩溃。”
4. “这就是他要的证据。”
5. “凶手必须付出代价。”
6. “他活该，但看他这样又很痛。”
7. “五年够了吗？”
8. “结尾温柔，但这不是原谅一切。”

如果读者只剩“误会解除后男主追妻火葬场”，则灵魂流失。
