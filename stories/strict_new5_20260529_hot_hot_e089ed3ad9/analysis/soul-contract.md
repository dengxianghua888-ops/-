# Soul Contract

## 读者承诺

读者要看到：一个孩子不再替母亲的迟来深情买单。父亲死了，耳朵坏了，童年毁了，母亲再后悔、再挡刀、再留下财产，也只能偿债，不能换回“妈妈”这个身份。

## 核心神髓

```text
迟来的深情不是爱，是拖欠到无法偿还的债。
```

## 必须兑现的体验

1. **心疼父亲**：父亲必须温柔、穷、硬撑、护子，且死得本不该死。
2. **恨母亲**：母亲不是不知情这么简单，而是每次都选择不查、不信、不管。
3. **恨顾承安**：他必须主动设计、挑衅、夺钱，并亲口承认恶意。
4. **爽在证据**：病历、空卡、遗像、电话自爆、法律文书必须逐层压上来。
5. **终点不原谅**：主角可以收钱、捐钱、活下去，但不能回头。

## 情绪债与偿还

| 债务 | 必须出现 | 偿还方式 |
|---|---|---|
| 父亲替母亲还债捐肝 | 父亲身体垮掉、术后感染 | 母亲查病历后崩塌 |
| 婚礼羞辱 | 父子被赶出、雪夜下跪 | 顾承安体面被撕碎，顾家破产 |
| 儿子耳伤 | 母亲亲手打坏耳朵 | 主角当面拒绝补偿 |
| 五十万空卡 | 救命钱被转走 | 顾承安电话自爆，进入法律清算 |
| 母亲迟来挡刀 | 主角被袭击时她终于挡在前面 | 主角判定“太迟了” |
| 父亲善良 | 蛋糕、摸头、想带儿子离开 | 医疗救助基金延续父亲价值 |

## 不可漂移的关系定位

- 主角对父亲：爱、愧疚、守护、继承。
- 主角对母亲：冷、恨、审判、不回头。
- 母亲对主角：迟来的愧疚，但不配得到原谅。
- 顾承安对父子：夺位、羞辱、害命。
- 读者对主角：允许他狠，允许他不原谅。

## 最小可行改编骨架

```text
重逢场景抛出死亡信息差
→ 外界误赞施害者深情
→ 主角揭开第一层旧债
→ 回忆父亲为施害者付出身体代价
→ 反派夺走救命资源
→ 死亡物证撞脸
→ 空卡/账户/凭证真相引爆
→ 反派亲口自爆
→ 施害者迟来补偿
→ 主角明确拒绝原谅
→ 以受害者名义完成价值补偿
```

## 绝对禁改

- 不能让父亲还活着。
- 不能让母亲“其实一直暗中保护主角”。
- 不能让顾承安的夺钱害命变成误会。
- 不能让主角在母亲临死前叫“妈”并和解。
- 不能删掉“具体金额/具体凭证/具体死亡后果”。
