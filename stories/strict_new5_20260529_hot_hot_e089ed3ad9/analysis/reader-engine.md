# Reader Engine

## 核心读者

- 番茄女性向短篇读者
- 家庭伦理复仇读者
- 偏好“不原谅”“迟来悔恨”“证据反杀”的读者
- 对父子相依、医疗费、偏心继父/小三题材敏感的读者

## 读者追读问题链

| 阶段 | 读者问题 | 源文投喂 |
|---|---|---|
| 开篇 | 妈妈为什么不知道爸爸死了？ | 海底捞重逢，父亲已死钩子 |
| 前段 | 她到底做过什么？ | 假破产、捐肝、婚礼羞辱 |
| 中段 | 父亲是怎么被逼死的？ | 耳伤、露宿、术后感染、五十万手术费 |
| 中后段 | 那张卡为什么没救到人？ | 护士告知卡里没钱 |
| 高潮 | 谁动了五十万？ | 顾承安电话自爆 |
| 后段 | 母亲清算顾承安就能洗白吗？ | 顾承安点破“逼死他的不止我一个” |
| 结尾 | 主角会不会原谅？ | “不是感动。也不是原谅。”；墓园不回头 |

## 爽点按钮

1. **身份反讽**：外人赞沈总深情，主角一句“对，我就是她儿子”打碎人设。
2. **证据暴击**：遗像、病历、空卡、电话免提逐个出现。
3. **金额错配**：几百万腕表 vs 五十万手术费。
4. **迟来无效**：母亲越补偿，读者越等主角拒绝。
5. **法律清算**：顾家破产、诈骗、侵占财产、间接致人死亡、死刑。
6. **价值回正**：遗产不用来修复母子关系，而是救助交不起手术费的父亲和孩子。

## 恨点设计

| 恨点 | 为什么有效 | 必须保留的写法 |
|---|---|---|
| 母亲施舍式关心 | 她以为给点钱就能摆出高位 | 让她说“我给你转点钱”一类上位话 |
| 母亲让父亲认错 | 死者被继续羞辱 | 死亡钩子必须紧跟这句话 |
| 顾承安装病 | 利用同情夺走家庭位置 | 后期必须揭穿“从未绝症” |
| 空卡 | 一张具体卡承载一条命 | 必须让母亲以为钱给了，实际没给到 |
| 母亲不求证 | 这是她无法洗白的根因 | 用“查病历很难吗”式追问钉死 |

## 信息差节制

- 父亲死亡：前10%告诉读者，不告诉母亲。
- 空卡真相：中段让读者知道，后段让母亲知道。
- 顾承安恶意：前中段由主角回忆展示，高潮由本人自爆确认。
- 母亲责任：从头暗示，高潮由主角和顾承安双重定罪。

## 情绪释放要求

结尾必须让读者同时得到两种满足：

1. **报应满足**：顾承安死刑，顾家崩塌，母亲死亡。
2. **尊严满足**：主角不原谅，不回头，把钱变成父亲价值的延续。
