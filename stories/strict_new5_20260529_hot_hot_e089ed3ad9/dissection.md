# 源文爆款基因拆解

## 一句话骨架

母亲抛夫弃子三年后，以为前夫还活着并要求他认错；儿子一点点拿出父亲死亡、五十万空卡、病历和顾承安自爆，把迟来的深情判成无效债务。

## 爆款核心

- **核心卖点**：母亲装深情，却不知道前夫早死了。
- **最大信息差**：读者和主角知道父亲死亡，母亲直到中段才被遗像和病历击穿。
- **最大情绪债**：只差五十万，父亲本能活；那张卡却是空的。
- **最终爽点**：顾承安被破产、起诉、判死刑；母亲挡刀死亡也不换原谅；主角把遗产转成父亲名义医疗基金。
- **神髓判词**：“你不是不知道，你是不在乎。”

## Hook 判断

- **hook_type**：H1 倒叙冲突式。
- **证据**：开篇第1章前12行完成“离婚三年后重逢母亲 → 母亲施舍转钱 → 让父亲认错 → 主角冷抛父亲三年前已死”。
- **强度**：8.7/10。
- **读者被钩住的原因**：母亲为什么不知道父亲死了？父亲怎么死的？主角为什么叫她“沈女士”？

## 标题公式判断

- **原题**：《深情不枉恨流年》
- **公式**：古言对仗式气质 + T3 生死悖论式内核。
- **工程化标题方向**：应把“父亲已死/迟来深情/空卡”外显，例如“爸爸死后三年，妈妈才知道那张卡是空的”。

## 反转机制清单

| 机制 | 源文落点 | 关键证据 | 改编锁定要求 |
|---|---|---|---|
| M3 因果回旋反讽 | 第7-8章病房与电话 | “你不是不知道，你是不在乎！”；顾承安说“逼死他的人，又不止我一个。” | 必须保留施害者规则反身审判：母亲过去用“不知道/被骗”逃责，后期被主角定罪为“不在乎”。 |
| M5 温度反转曲线 | 全文 | 父亲曾等妈妈吹蜡烛；母亲后来冷眼偏袒顾承安；结尾挡刀也太迟 | 必须有“曾经亏欠/似乎爱过”到“归零冷漠”再到“负值悔恨”的完整曲线。 |
| M6 多层递进反转 | 父亲已死 → 遗像 → 空卡 → 自爆 → 死刑/基金 | “我爸死了”；“满墙遗像”；“那张卡是空的”；顾承安电话承认转钱 | 反转层数不能少，且每层必须升维：情感真相、物证真相、财务真相、法律清算、价值补偿。 |

## 关键不可替换因果链

```text
母亲假破产
→ 父亲捐肝卖血替她还债
→ 母亲高调嫁顾承安并羞辱父子
→ 父子被赶走，儿子耳朵被打坏
→ 父亲术后感染恶化，需要五十万手术费
→ 母亲甩卡，顾承安转走钱
→ 父亲错过手术死亡
→ 母亲三年后才知道真相
→ 顾承安自爆，母亲崩塌
→ 主角接受债务补偿但拒绝原谅
```

## 改编禁区

1. 禁止把母亲写成完全无辜被骗。
2. 禁止删掉“空卡”或等价的救命钱失效载体。
3. 禁止让主角主动求和、原谅、回到母亲身边。
4. 禁止把顾承安弱化成口嗨反派，他必须有夺钱害命的实锤。
5. 禁止用大段抒情替代现场交锋、病历、卡、遗像、电话录音等证据。
