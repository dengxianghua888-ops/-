# 源文解构：我是姐姐的对照组

## 核心基因

| 维度 | 值 |
|------|-----|
| 题材 | family_ethics / rebirth_romance |
| 机制 | M5 温度反转 + M6 多层递进 + M3 因果回旋 + M2 身份反差 |
| Hook | H3 死前遗言 + 重生悬念 |
| 情绪曲线 | 阶梯递进型（每次发现真相提升一级） |
| 读者承诺 | 备胎觉醒 → 自我救赎 → 碾压式逆袭 → 真爱补偿 |

## 结构拆解

原文采用 **线性时间线 + 重生双线对比** 结构：
- 开篇即死前遗言（信息炸弹）→ 重生回到姐姐介绍陆霄
- 前30%：识破信号、拒绝入局、选择理科
- 中40%：独立成长、发现更多真相（接吻、产房偷听）
- 后30%：清算+报复+新恋情甜蜜闭环

## 爆款因子

1. **极致反差**：一辈子的"幸福"在临终一句话全部崩塌
2. **代入感强**：重生后每个选择都是读者想替女主做的
3. **渣男递进崩塌**：从体面律师→失业→犯罪→苦力，观感极爽
4. **双线对比**：姐姐两世都不幸 vs 女主觉醒后蒸蒸日上
5. **真爱补偿**：方彦上辈子就在默默关注，甜度高且不突兀
