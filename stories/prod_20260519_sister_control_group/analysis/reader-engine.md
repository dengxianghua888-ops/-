# Reader Engine: 我是姐姐的对照组

## 读者心理操控策略

### 1. 开篇300字：认知炸弹
- 策略: 用丈夫临终遗言制造极致信息差
- 读者状态: 震惊 → 愤怒 → "重来一次她该怎么选？"
- Hook力度: 9/10

### 2. 前20%：选择悬念
- 策略: 展示女主每个与上辈子不同的选择
- 读者状态: 代入感 → 替她做选择的快感 → 等待回报
- 微钩: 每次拒绝陆霄都是一个小爽点

### 3. 中段：真相递进
- 策略: 每隔15-20%揭露一层新真相
- 读者状态: "还有更多？！" → 愤怒叠加 → 等爆发
- 关键: 产房偷听是情绪最高峰

### 4. 后段：清算+补偿
- 策略: 先狠后甜，清算彻底再给甜蜜
- 读者状态: 痛快 → 满足 → 温暖 → 圆满
