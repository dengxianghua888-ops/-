# Adaptation: 职场重生逆袭版

## 选定方案：A（职场版）

### 故事核心
苏念，985计算机专业毕业生，上辈子为丈夫江越放弃大厂offer，去他所在的小城当全职太太。四十年相敬如宾，临终才知江越爱的一直是她的大学闺蜜林薇——当年林薇救过江越一命，他用一辈子"报恩"式地照顾苏念，实际上和林薇暗中往来。

重生回大四秋招季，苏念拒绝跟江越去小城，选择留在一线城市进互联网大厂。与算法竞赛老搭档顾行舟重逢，两人从同事到创业伙伴到恋人。

苏念逐步发现江越和林薇的真相，用掌握的内幕交易证据举报江越，让他从投行精英沦为行业黑名单。最终，顾行舟坦白自己也是重生者——上辈子他一直在隔壁公司默默关注她。

### 新鲜度保证
- 从姐妹关系改为闺蜜关系：避免血缘道德绑架，更贴合都市读者
- 从学业赛道改为职场赛道：大厂、创业、期权等元素更现代
- 从律师改为投行：金融犯罪（内幕交易）举报比法考贿赂更有冲击力
- 时间线压缩：从高中到中年 → 大四到工作五年内，节奏更快
