# Reader Engine

## 核心驱动模型
```yaml
reader_engine:
  primary_fuel:
    - 高位宠爱假象被撕裂
    - 生育权剥夺
    - 名分与舆论羞辱
    - 男主持续站错队
    - 女主冷静脱身
    - 新爱稳定接住
    - 旧爱迟到偿债
    - 社会价值回收
  retention_loop:
    - 每章新增实害
    - 每2-3章新增一层真相
    - 每次以为到底时再升级一档
    - 用海外新生给读者补氧
    - 再用旧人追来制造次峰
    - 用终局事业/家庭双回收封账
```

## 前中后段引擎分工
### 前段（1-4章）
任务：
- 把读者快速绑到女主身上
- 让男主在最短时间内“不可原谅化”

发动件：
- “她是我的命”与“摘她子宫”对撞
- 小三公告
- 家内奴役
- 公开忏悔

读者状态：
- 怒
- 憋
- 想看她走

### 中段（5-9章）
任务：
- 把“虐”升级成“死局”
- 让脱身不只是情绪选择，而是生存选择

发动件：
- 绑架拍照
- 求救电话接到男主调情现场
- 废墟断腿
- 拿她换命
- 手雷自救
- 离婚成功

读者状态：
- 彻底断情
- 需要她活下来
- 开始期待男主火葬场

### 后段（10-18章）
任务：
- 给读者情绪补偿，但不能失速
- 让新人生不是平铺，而是持续长出价值
- 让旧爱追悔足够重、足够晚、足够无效

发动件：
- 剑桥学习线
- 陆之珩认出她、接住她
- 男主查明真相
- 剑桥重逢被无视
- 挡刀死亡
- 女子学校与家庭终局

读者状态：
- 酸
- 爽
- 释然

## 读者情绪按钮
- `委屈按钮`：她明明是妻子，却被打成小三
- `愤怒按钮`：她替他做的一切，被他切割成“你太狠毒”
- `厌男按钮`：男主每次都在她最需要时站错边
- `求生按钮`：她断腿、重伤、无路可退时仍要自己活
- `补偿按钮`：有人告诉她“这不是你的错”
- `回收按钮`：她后来成为别人的安全屋

## 付费点分布
### P1
- 位置：第 1 章偷听真相
- 作用：重击点击后留存

### P2
- 位置：第 4 章当街忏悔
- 作用：中前段高潮，逼付费追后果

### P3
- 位置：第 7 章手雷自救 + 离婚出走
- 作用：女主线第一次硬翻身

### P4
- 位置：第 9 章真相查明
- 作用：读者终于等到男主被反噬

### P5
- 位置：第 14-15 章剑桥重逢与拒绝
- 作用：火葬场高峰

### P6
- 位置：第 17-18 章死亡偿债 + 五年后回收
- 作用：最终情绪闭环

## 爽点来源不是“赢了”，而是“终于不再被定义”
因此改编时要保：
- 她如何被定义成刀、污点、生育风险
- 她如何不再接受这些定义
- 她如何建立新的自我定义：学者、爱人、母亲、校长、庇护者

## 风险预警
- 若中段羞辱密度下降，读者会觉得“也没多惨”，火葬场价值下降。
- 若后段新男主线过长过甜，读者会觉得主线跑偏。
- 若男主反悔来得太早，读者会觉得代价不足。
- 若结尾没有事业回收，只剩感情回收，读者会觉得账没算满。
