# 源文爆款基因拆解

## 一句话核
一个被豪门太子爷从难民营捞出来并打磨成“刀”的女人，在被夺走生育权、名分和尊严后，亲手切断旧命，去海外长出新人生；而那个曾把她当命又当工具的男人，只能在迟到的悔恨里用命还债。

## 题材判定
- 主题材：现代豪门虐爽 / 追妻火葬场
- 副题材：女性脱身新生 / 海外治愈 / 价值回收
- 平台适配：番茄强情绪长短句爽虐文
- 标题外壳：古言意象式
- 正文内核：高压羞辱型 T1 因果反转追妻

## Hook 拆解
判定：`H1 倒叙冲突式`

原因：
- 开篇先立极端身份反差：“有毒的黑玫瑰”“傅家最锋利的刀”“谁都以为她最终的下场是为了傅家而死，可傅云深娶了她。”
- 前 300 字内迅速落入更极端冲突：“婚后三年，她终于怀孕了，却在中环的街头遭遇无差别枪击案。”
- 紧接着在同一章内引爆第一付费级真相：“设计枪击案让嫂子流产，还趁她昏迷让医生摘了她的子宫。”

这不是慢热铺垫，而是“高位宠爱假象”立完立刻砸穿，读者在前章就被迫追问：他为什么要这样对她？她会怎么逃？

## 标题公式识别
原题《花落月都星已沉》使用的是：
- `古言对仗式意象标题`

但正文最强可转化公式其实是：
- `T1 因果反转式`：摘我子宫后，他悔疯了
- `T3 生死悖论式`：我走后，他才知道自己杀了最爱的人

结论：
- 标题是“文艺伪装层”
- 正文发动机是“高伤害 + 高回收”的番茄追妻层

## 反转机制清单
### M5 温度反转曲线
- 温度正峰证据：
  - “没有她，就没有今天的傅氏。她是我的命，谁反对，就是与我为敌。”
  - “阿姿，从今以后……我会用一辈子对你好。”
- 温度归零证据：
  - “设计枪击案让嫂子流产，还趁她昏迷让医生摘了她的子宫。”
  - “你之前的名声本来就不好……再加上这一条，也没什么区别。”
- 温度负值证据：
  - “阿姿，求你了。”
  - “九十九鞭，鞭鞭见血。”
  - “我用这条命还给你。我们……两清了。”

锁定理由：
- 这篇最大爽点不是男主被打脸，而是男主亲手毁掉自己最珍贵的东西，然后在完全失去后才知道痛。

### M6 多层递进反转
- Layer 1 情节反转：
  - 女主醒来偷听到“流产 + 摘子宫 + 私生子”真相。
- Layer 2 社会反转：
  - 公告把她打成小三，全城媒体与路人围殴。
- Layer 3 生死反转：
  - 废墟获救后反被拖去给夏思雨母子换命。
- Layer 4 关系反转：
  - 男主查明全部真相，跪家法追到剑桥，女主已彻底抽离。
- Layer 5 价值反转：
  - 男主用死偿债；女主五年后回港办女子学校，成为“光”的来源。

锁定理由：
- 这文绝不靠一个大反转吃完读者，而是持续阶梯加码。

### M3 因果回旋反讽
- 前置施害逻辑：
  - “她是我的命。”
  - “我也是为她好。”
  - “你之前的名声本来就不好。”
- 回旋句式：
  - “你救过我一次，也杀了我一次。”
  - “我们之间，已经两清了。你救过我，我也替你做了七年的刀。你不欠我，我也不欠你。”
  - 男主命夏思雨“十倍”体验白令姿受过的苦，形成镜像惩罚。
- 收束反讽：
  - 他以“保护”为名夺走她一切，最后只能用死亡完成迟到的偿债。

锁定理由：
- 这篇不是逻辑死环，而是情感和道德上的“你用什么伤我，最后就被什么反噬”。

## 爆点工程图
1. 先给读者一个“最宠她的男人”假象。
2. 第一章内直接撕开“流产 + 摘宫 + 私生子”三连爆点。
3. 之后每章都不是情绪复述，而是新的实害：
- 公告污名
- 围殴
- 家内奴役
- 公开下跪忏悔
- 绑架拍照
- 废墟后换命
- 真相翻盘
- 海外新生
- 旧人追来
- 挡刀身死
- 五年后逆生长
4. 结尾不靠原谅，而靠“她不回头”。

## 角色功能锁定
### 白令姿
- 表层身份：港城豪门主母 / 黑玫瑰
- 深层功能：高压受害者、主动脱身者、价值回收完成者
- 必保特征：
  - 能忍，但不是软
  - 前半程暂忍为离婚与脱身
  - 真正的反击不是撕打，是抽离、断联、重建人生

### 傅云深
- 表层身份：高位掌控型深情男主
- 深层功能：实害施加者、迟到悔恨者、代价承担体
- 必保特征：
  - 爱是真的，控制也是真的
  - 每次关键岔路都选了伤害她的一边
  - 后悔要足够晚、足够疼、足够无效

### 夏思雨
- 功能：合法性替身、生育羞辱执行者、错位白月光假面
- 必保特征：
  - 以“高知/名门/为孩子好”的道德语汇压迫女主
  - 她既是男主错误选择的放大器，也是后期真相翻盘的证据箱

### 陆之珩
- 功能：尊重型新爱、价值见证者、治愈落地器
- 必保特征：
  - 不是横空天降霸总，而是被女主曾救过的人
  - 他爱的不是“脏玫瑰人设”，而是她本人
  - 必须持续、明确、低攻击性地接住她

## 读者为什么会连刷
- 每章都有新伤害，不让情绪平。
- 男主每次都能错得更狠，逼出“别洗白”的追读欲。
- 女主不是原地哭，而是在忍、记、等、走。
- 新男主不是悬浮奖赏，而是“她值得被好好对待”的证据。
- 结局把尊严、事业、亲密关系一次性补齐，完成高额回收。

## 快节奏锁定
该源文虽然篇幅 2.6w+，但仍属于番茄快节奏长短篇，锁定规则如下：
- 仿写不得用解释性长段替代现场羞辱。
- 仿写不得用流程清单替代冲突推进。
- 仿写不得用情绪总结替代“她正在被怎样对待”。
- 每个关键情绪节点必须有具体动作承载：跪、打、拖、扇、扔、哭、追、挡、走。
- 章尾必须落钩，优先用真相再翻、羞辱升级、男主站错队、女主抽离、新人生入口、旧人追来。
