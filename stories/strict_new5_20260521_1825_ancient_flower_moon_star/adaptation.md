# 高保真设定重置室

## 改编目标
本轮只做“设定载体重置”，不改灵魂合同，不削弱核心实害，不把男主洗成误会型深情。

必须保留的发动机：
- 男主以“爱她/保护她”为名，亲手主导不可逆伤害。
- 女主遭遇“流产 + 摘子宫 + 正名剥夺 + 公开污名化 + 社会性围剿”。
- 女主最大的反击不是报复接管，而是冷静脱身、离婚、远走、重建。
- 新男主必须是稳定承接，不是工具型奖励。
- 结尾必须完成“她成为别人的光”的价值回收。

## 三套投稿方向

### A案：自贸港航运财阀 / 危机谈判官 / 灯塔学校
- 女主从撤侨码头被男主捞起，后来成为闻氏航运最锋利的“危机白手套”，擅长替家族摆平港口事故、船员罢工、海关舆情。
- 男主是航运财阀继承人，对外说她是自己的“压舱石”，却为了给名门白月光与所谓“合法继承人”让路，设计港区爆燃事故，借手术摘掉她的子宫。
- 后续羞辱场景可自然落在集团声明、航运论坛直播认罪、码头家属围堵、冷链仓库绑架、油库废墟换命、海外创伤干预进修、归来创办“海灯女孩学校”。

优点：
- 场域够大，既有豪门压迫感，也有工业灾难与港口空间的新鲜感。
- “灯塔/压舱石/风暴/上岸”可形成整套句式回旋，利于 M3。
- 结尾“她成为别人的灯”非常顺。

风险：
- 行业名词不能过密，必须服务情绪，不可写成航运行业文。
- 港口事故与救援流程要写得像真，但不能抢情感主线。

### B案：文保拍卖财团 / 赝品危机修复师 / 少女工坊
- 女主是拍卖财团的“脏活修复师”，专替家族处理赝品、私藏、走私风波，被男主塑造成“替家族挡刀的黑天鹅”。
- 男主为扶持博物馆世家出身的白月光，借慈善晚宴袭击与手术夺走女主生育权，再把她推出去背“赝品丑闻”“私德败坏”。
- 公开羞辱可落在媒体发布会、博物馆台阶认罪、收藏圈封杀；新生线转去欧洲读艺术犯罪与创伤修复，结尾创办少女修复工坊。

优点：
- 审美包装好，容易做出文艺外壳。
- “修复别人文物却修不好自己人生”有反讽感。

风险：
- 拍卖、文保、赝品议题容易偏悬疑，不如 A 案直接、狠。
- “生育合法性压制”落在文博豪门里稍弱，爆点力略逊。

### C案：医疗科技帝国 / 临床舆情清道夫 / 创伤基金会
- 女主是医疗科技集团的临床危机处理人，替男主家族处理试验事故与病患舆情。
- 男主为了保全集团与白月光名医的名声，制造车祸/袭击并签下摘宫手术同意，把女主变成“失控报复的恶女”。
- 后续羞辱可落在医疗听证会、直播道歉、医院楼体坍塌、海外公卫/创伤干预进修，结尾办创伤援助基金。

优点：
- 生育权被夺与医疗暴力逻辑贴合。
- 社会议题天然带舆论压迫。

风险：
- 医疗伦理敏感度太高，稍不稳就会显得刻意猎奇。
- 很容易让读者联想到常见“霸总+医院”套路，新鲜度不足。

## 选定方案
选 A 案。

原因：
- 保真度最高，能完整承接“高位宠爱假象→工业灾难式实害→全城围剿→废墟换命→海外新生→灯塔回收”的阶梯。
- 新鲜度足够，不是一眼看穿原豪门模板。
- 码头、风暴、灯塔这套意象既能撑番茄强钩子，也能给文案和标题更多可用句式。
- “她不是被救上岸，而是被拖进风暴；后来她自己成了别人的灯塔”能稳稳扣住灵魂。

## 选定案的高保真重置包

### 世界壳
- 港城豪门重置为“自贸港航运财阀闻家”。
- 女主不再是“黑玫瑰/刀”，而是闻家专门处理脏活的“危机白手套”。
- 白月光不做单纯情妇，改为“海商法博士 + 航运协会千金 + 合法继承叙事代言人”。

### 核心关系
- 女主岑砚灯：撤侨码头孤女，被男主带回、训练、重用，也被驯化成替他出面的那把刀。
- 男主闻砚舟：说她是“压舱石”，实则把她当成可被牺牲的稳定器。
- 对照女宋知澜：代表名门、学历、血脉、体面秩序，用“为了孩子”“为了家族合法性”压她。
- 新男主贺停山：当年曾被她在海外冲突里救过，后来成为灾后心理干预医生，以持续、低攻击性的尊重接住她。

### 冲突链条
1. 开局先立“她是闻总最信任的人”，再立婚后三年终于怀孕。
2. 第一爆点直接给：港区定向爆燃，孩子没了，子宫也没了，且是男主签字主导。
3. 女主偷听到真相后不闹，暗中换离婚证。
4. 集团与航协联合声明，把她打成插足者与事故元凶。
5. 她被逼去照顾宋知澜母子，被迫念直播道歉稿，在航运论坛外当众认罪。
6. 冷链仓库绑架、偷拍视频、求救失败，完成情感彻底断电。
7. 油库坍塌后她刚被挖出，又被男主拖去换宋知澜母子上救援艇，锁死男主罪行。
8. 她用船载应急震爆弹自救离港。
9. 男主查明继承人与事故双重真相后崩塌，追到海外。
10. 女主在海外完成专业与人格新生，拒绝回头。
11. 男主最终以挡刀/挡爆偿债。
12. 五年后她创办“海灯女孩学校”，收容受创女孩，完成终极价值回收。

## 替换映射摘要
- 豪门婚姻压迫 → 航运财阀内部秩序压迫
- 黑玫瑰/刀 → 危机白手套/压舱石
- 枪击流产 → 港区爆燃事故流产
- 私生子合法性压制 → 家族继承人与航运血脉合法性压制
- 当街下跪忏悔 → 国际航运论坛外直播认罪
- 废墟换命 → 油库坍塌后被逼换救援名额
- 剑桥犯罪心理 → 海外顶尖创伤干预/灾难心理项目
- 女子学校 → 海灯女孩学校

## 机制保真提醒
- M5 温度反转：前半段必须真给宠、真给信任、真给“她是我的命”的替代句式，否则后半段不疼。
- M6 多层递进：每次升级都必须是新实害，不能用哭戏复读。
- M3 因果回旋：闻砚舟前期所有“为了你好/让你上岸/你是我的压舱石”都要在后期反噬。

## 敏感议题边界
- 生育权剥夺必须作为暴力与控制书写，不能被包装成“为她好”而不被批判。
- 公开羞辱重在社会压迫和人格碾压，不做色情化或猎奇化描写。
- 绑架与偷拍只保留威胁和羞辱功能，不细写身体细节。
- 新男主提供尊重，不以“拯救者高高在上”覆盖女主主体性。
